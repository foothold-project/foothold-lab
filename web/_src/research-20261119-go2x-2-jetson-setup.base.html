CycloneDDS 를 넣은 까닭: Go2 는 ROS 2 통신을 CycloneDDS 로 하는데, Jetson 기본 통신 (FastDDS) 으로는 L2 점구름이 안 보였다. ROS 2 명령 앞에 export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp 를 붙인다.

하지 말 것: apt 로 고치기

apt --fix-broken install · apt upgrade 금지. 이 Jetson 은 L4T 커널 · 부트로더 · 도구 다섯이 고정 (hold) 돼 있고, 버전이 섞여 있다 (커널 · 부트로더 36.4.0 · 나머지 36.4.7). 그래서 apt 는 어떤 설치도 거부한다. fix-broken 은 이 묶음을 맞추려고 커널 · 부트로더를 건드릴 수 있다 (로봇 컴퓨터가 안 뜰 위험).

새 패키지는 받아서 직접 넣는다: apt-get download <패키지> → sudo dpkg -i <파일>.deb. 빠진 의존 패키지도 같은 방법. 설정은 sudo dpkg --configure <이름들> 처럼 이름을 적는다 (-a 안 씀). CycloneDDS 때 처음에는 libacl1-dev 가 빠져 네 개가 「설정 안 됨」 으로 남았고, 둘을 더 받아 넣어 끝났다. Tailscale 도 설치 스크립트의 마지막 apt 단계는 같은 까닭으로 실패해 같은 방법으로 넣었다.
