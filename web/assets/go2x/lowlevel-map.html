11/23 에 더한 것: 12 절 실행기 해설 (이름 · 설치 자리 · 코드 짜임) · 13 절 Jetson 성능 설정 · 14 절 결정 기록. 아래 1~11 절은 11/22 기준입니다. 11/22 에 Jetson 에서 우리 START 정책이 Go2 관절 12 개를 직접 움직였고, 실기 확인 12 항목을 모두 통과했습니다. 1~7 절은 실제로 돌아간 것, 8~11 절은 앱에서 실제 Go2 를 움직이고 학원 복도 지도를 만드는 계획입니다. 모든 그림과 표는 아래 세 가지로 상태를 적었습니다.

실기 확인 11/22 로봇에서 돌려 봄 코드 있음 가짜 SDK 시험만 · 실기 미확인 수행 전 새로 만들 것 · 아직 안 돌림
1 · 구조

누가 무엇을 맡나

Go2 몸통의 순정 펌웨어(모드 이름 mcf)가 평소 걷기와 리모컨을 맡습니다. 「위 + start」를 누르면 실행기가 순정을 잠시 내려놓습니다. 그다음 정책이 1 초에 50 번 관절 목표를 계산해 모터 드라이버에 보냅니다. 리모컨 신호는 순정이 꺼져도 LowState 에 실려 계속 들어옵니다.

정책 한 걸음 (1 초에 50 번)

  • 관측 45: 몸 각속도 3, 중력 방향 3, 명령 3, 관절 각 12, 관절 속도 12, 직전 행동 12
  • 입력 9 개: 관측 45, 이력 10 칸 (최신이 앞), 깊이 두 장 (5 스텝마다 · 한 장 늦게), GRU 상태 두 개 되먹임, 깊이 주기, 첫 스텝 표시, 정답 지도 사용 여부, 정답 지도 32×16
  • 출력: 관절 목표 = 기본 자세 + 0.25 × 행동 (±17 자름) → 안전 상한 ±1.6 rad. PD kp 25 · kd 0.5
  • 관절 순서: 정책은 [hip · thigh · calf] × [FL · FR · RL · RR], SDK 는 [FR · FL · RR · RL] × [hip · thigh · calf]. start.py 가 바꿔 끼움
  • 지금 모드: 끔 (off · 고유수용감각만). 깊이는 0 으로 넣음. 복원 (D435i 깊이) 모드는 뒤로
  • 명령: 왼 막대 앞뒤 = vx (−1.3~1.5 m/s), 왼 막대 좌우 = vy (±0.5), 오른 막대 좌우 = wz (±1.2 rad/s). 중립 떨림 0.05 무시. 시뮬과 같은 가감속 상한
2 · 상태

실행기 상태와 리모컨

실행기는 다섯 상태 중 하나에 있습니다. 화살표 글자는 전환을 일으키는 조합이나 사건입니다. 순정 상태에서 실행기는 모터에 아무것도 보내지 않습니다.

조작쓸 수 있는 상태하는 일상태
위 + start순정 · 감쇠 · 엎드림START 정책으로 넘겨받기 (서 있든 엎드려 있든 그대로)실기 확인
← + startSTART · 감쇠천천히 엎드림 → 감쇠 → mcf → RecoveryStand → 3 초 뒤 free walk실기 확인
→ + startSTART · 감쇠같은 순서 → classic실기 확인
L2 + ASTART2 초 동안 천천히 엎드림 → 감쇠실기 확인
L2 + BSTART (순정에서는 순정이 처리)즉시 감쇠. 선 채면 털썩 주저앉음실기 확인
아래 + start어디서나AME-2 자리. 지금은 한 번 알림만 (student ONNX 대기)실기 확인
넘어짐START60° 넘게 0.5 초 → 감쇠 → mcf → RecoveryStand코드 있음
3 · 안전

안전 장치

  • --live 와 승인 표식이 둘 다 있어야 보냅니다. 없으면 dry-run 으로 읽고 계산만 하고, 송신은 0 입니다.
  • 승인 표식은 사람이 만들고 0600 권한, 30 분 안에 만료됩니다. 몸통 일련번호가 0 이라 MAC 으로 대신 확인합니다.
  • LowState 가 50 ms 넘게 끊기면 감쇠합니다.
  • 순정 복귀는 CheckMode 로 붙었는지 확인하고 5 번까지 다시 시도합니다. 끝내 안 붙으면 감쇠하고 알립니다 (성공이라 적지 않음).
  • 관절 목표는 기본 자세에서 ±1.6 rad 안으로 자릅니다. 넘겨받을 때 관절 속도 상한도 있습니다 (위로 1.5 · 0.5 · 2.4, 아래로 3.75 · 1.25 · 3.0).
  • 로봇 명령은 팀장 동의 뒤에만 보냅니다. 원격 프로세스는 PID 로만 끕니다.

8 · 앱 연결

앱 화면에서 실제 Go2 를 움직이는 길

앱 저장소에는 노트북 연결 프로그램 (foothold_agent.setup), 서버 경유 조종 (순정 SportClient 로 걷기), 실기 지도 만들기 (mapping · uslam) 가 이미 있습니다. 모두 가짜 SDK 로만 시험했습니다. 새로 만들 것은 실행기가 앱 명령을 받는 부분, Jetson 과 로컬 서버를 잇는 터널, 시뮬에 실기 자리를 같이 띄우는 부분입니다.

연결 프로그램은 서버 주소가 HTTPS 이거나 127.0.0.1 의 HTTP 일 때만 받아들입니다 (setup/pairing.py). ai-lx01 에서 SSH 역방향 터널을 열어 Jetson 의 자기 자리 8810 을 로컬 서버로 이으면 코드 변경 없이 붙습니다. 공개 HTTPS 주소는 필요 없습니다.
9 · 키보드 조종
수행 전

키보드 한 번에 실기와 시뮬이 함께 움직임

웹 조종 화면에서 키를 누르면 같은 속도 명령이 앱 시뮬 로봇과 실제 Go2 에 함께 갑니다. 실기에서 돌아온 위치는 시뮬 공간에 실기 자리로 그립니다. 아래 순서는 계획이며 아직 한 번도 돌리지 않았습니다.

규칙 (계획)내용
키 배치앱 시뮬 조종 키와 같게. 모드 바꾸기는 Shift+1 (START) · Shift+2 (AME-2, 지금은 알림만). 팀장 11/22 13:05 · 13:12. 순정 classic · free walk 웹 키는 아직 정하지 않음. 화면 안은 app-design-lx 가 정함
리모컨 우선막대를 건드리거나 버튼을 누르면 그동안 앱 명령은 무시
끊김앱 명령이 0.3 초 끊기면 속도 0 (정지 감속은 7 절 결정을 따름)
STOP앱 STOP = L2 + A (천천히 엎드림). 비상 = L2 + B 와 같은 감쇠
모터 맡는 쪽순정 상태는 연결 프로그램의 Go2Sink, START 상태는 실행기. 둘이 같이 쥐지 않게 모드를 보고 나눔
시뮬과 실기 위치실기 위치는 몸통 odometry. 루프 닫기가 없어 오래 걸으면 시뮬과 어긋남 → 시작 자리를 맞추는 단추가 필요
10 · 단계

진행 순서 전부 수행 전

A

Jetson 을 로컬 서버에 연결 · 실기 Go2 등록

  • Jetson 에 연결 프로그램을 aarch64 용으로 설치. 설치 파일 3 개는 받아 둠 (websockets · qrcode · opencv), numpy 는 있는 1.26.4
  • ai-lx01 에서 SSH 역방향 터널 → Jetson 에서 http://127.0.0.1:8810 로 연결
  • 6 자리 코드로 담당 운영자 계정에 「실기 Go2」 등록 · 배터리 · 자세가 웹에 뜨는지 확인
  • 서버 조종 스위치를 켜려면 로컬 서버 재시작 필요 (팀장 확인 뒤)
B

실행기가 앱 명령을 받기

  • 바꿀 자리: lowlevel.py policy_step 의 goal = command_from_remote(...) 한 줄과 tick 의 모드 조합 처리
  • 연결 프로그램이 받은 속도 · 모드 · STOP 을 Jetson 안 loopback 으로 실행기에 넘김
  • 가짜 SDK 시험부터. 실기는 팀장 「보내」 뒤
C

앱 조종 화면에서 실제 Go2 움직이기

  • 먼저 순정 걷기 (이미 있는 서버 조종 경로) → 다음 START 모드
  • 같은 명령을 앱 시뮬에도 (9 절)
D

학원 복도 지도 만들고 시뮬과 실기를 함께

  • 로컬 서버에 실제 장소 「학원」 · 사람 층 「복도」 만들기 (지도 만들기는 실제 장소 · 사람 층에서만 열림)
  • 웹 「지도 만들기」 → 복도를 천천히 걷기 → 「지도 저장」 → PCD 등록 (5 cm 칸 누적 · 루프 닫기 없음)
  • 저장한 지도를 복원 지도 유형으로 시뮬 공간에 올리고, 시뮬 로봇과 실기 자리를 같이 띄움
  • 먼저 확인할 것: 이 Go2 X 몸통에서 라이다 점군 주제 rt/utlidar/cloud 가 오는지

Kp · Kd 가 하는 일

실행기는 관절마다 목표 각도를 주고, 모터는 「목표와 어긋난 만큼」 과 「움직이는 빠르기만큼」 힘을 냅니다. 모터 힘 = Kp × (목표 각 − 지금 각) + Kd × (목표 속도 − 지금 속도).

영어 이름하는 일쉬운 비유
Kpproportional gain (비례 이득) · 위치 이득 · 관절 강성 (stiffness)목표 각도에서 벗어난 만큼 되돌리는 힘의 세기 (N·m / rad)관절에 단 용수철. 무거운 짐을 들고 쪼그려 앉을 때 허벅지에 힘을 꽉 준 사람 (60) 과 힘을 반쯤 뺀 사람 (25) 의 차이. 힘을 뺀 쪽은 무게가 한쪽 다리로 쏠리면 그 무릎이 먼저 접혀 버립니다.
Kdderivative gain (미분 이득) · 속도 이득 · 감쇠 (damping)관절이 빨리 움직일수록 반대로 잡아 주는 힘 (N·m·s / rad)문이 쾅 닫히지 않게 잡아 주는 도어클로저, 또는 자동차 쇼크업소버. 0.5 는 거의 없는 수준이라 한번 꺾이기 시작하면 그대로 빨려 들어가고, 5 는 꺾이는 순간 「천천히」 를 걸어 버틸 시간을 줍니다.

Kp 25 → 60 은 같은 어긋남에 2.4 배 힘으로 버티고, Kd 0.5 → 5 는 꺾이는 속도를 10 배 세게 잡습니다. 둘을 함께 올려야 「버티되 출렁이지 않게」 됩니다 (Kp 만 올리면 용수철처럼 튕길 수 있음). 걸을 때는 정책이 학습한 25 · 0.5 를 그대로 씁니다. 학습 때와 다른 값을 쓰면 정책이 아는 다리가 아니게 되기 때문입니다.
