## 2. 방향 옵션 (고르는 게 아니라 조립 재료)

### A. 원안 유지 + 실기는 스트레치
시뮬 RL 완결(커리큘럼·평가·RoboGauge 비교) + 디지털트윈·실사 렌더 스토리. 실기는 unitree_rl_lab 공식 배포 스택으로 **시도까지만 약속** (성공하면 대박, 실패해도 "왜 어려운가"가 기록 자산).
- 강점: 지금까지 4주 자산 전부 유효. 오흥재(RL·트윈) 축 그대로.
- 약점: 실기 장면이 안 나올 위험. 멘토 우려와 정면 충돌.

### B. 층위 결합 (보행=우리 RL 연구, 실기 데모=항법)
연구·학습 기여는 **시뮬 RL 보행**으로, 실기 데모는 **순정 보행 + SLAM·Nav2 험지 자율주행**으로 이원화. BITE 스택을 데모 층에 흡수하되, 그들과의 차별 = ①시뮬 트윈에서 항법 코스를 먼저 재현·검증 ②RL 정책과 순정의 험지 성능 비교 리포트.
- 강점: 실기 장면이 거의 보장됨(검증된 길). 팀원 다수(ROS 수업 중, SLAM 흥미)의 역할이 자연스럽게 생김. 조선대 자원(XT16·경험자)과 정합.
- 약점: 보행 RL이 "시뮬 안 이야기"로 좁아짐. BITE 재탕으로 보일 위험(차별점을 시뮬 연계로 세워야 함).

### C. 시뮬 완결형 (디지털 트윈 중심)
실기는 순정 시연 최소화. 최종 산출물 = **미경험 험지의 디지털 트윈**(3DGS/실측 스캔) + 그 안에서의 RL 적응 학습 + 실사급 렌더 서사(팀장 VFX 축 극대화).
- 강점: 외부 변수(장비·반출·하드웨어)에서 자유. 일정 리스크 최소. 영상 산출물이 발표에 강함.
- 약점: "실물 없이 끝났다"는 인상. 실기 접점을 원하는 팀원 동기 저하 가능.

> 조립 예시: **B의 실기 데모 + A의 시뮬 RL 비교 + C의 트윈 서사** = "같은 험지를 ①실물(순정+항법)로 건너고 ②트윈에서 RL로 학습해 비교한다". 필요한 것은 F1·F2 답과 팀원 역할 정합.
