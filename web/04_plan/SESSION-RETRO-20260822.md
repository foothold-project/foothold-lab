## 원인 진단 (정직하게)

- **세션 길이**: 이 세션은 극도로 길어 과거 대화가 요약 압축되며 세부(RoboGauge 수치 등)가 흐려진다. 모델 결함이라기보다 **컨텍스트 운영의 문제**이며, 볼트 그라운딩(원장·파일 재독)으로 보완해야 한다.
- **속도 우선 관성**: 배치를 빨리 닫으려다 안건 전수 확인을 건너뜀.

## 개선 (즉시 적용)

1. 멀티파트 전수 응답 + 응답 구조를 사용자 번호에 맞춤 (영속 규칙)
2. 안건 원장 상태를 매 배치 보고에 표기 (기존) + **응답 전 원장 대조** (강화)
3. 채팅 답변에도 구체 수치·단계 포함, 게시물엔 도식 필수 (영속 규칙)
4. 소유권·비용 주체 확인 후 제안 (영속 규칙)
5. 세션 위생: 개인 방향성·홈페이지 같은 대형 주제는 별도 세션 분리 검토 (팀장 결정 대기 — 모델 전환 질문과 함께 답변)
