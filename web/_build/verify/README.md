# 검증 도구

## 왜 여기 있나

독립 검수가 지적했다. 계산 스타일 수집기·비교기·자기시험·기준선이 **세션 스크래치패드에만**
있었다. 그러면 다른 장비에서 재검증할 수 없고, 세션이 끝나면 사라진다 (철칙 2).
그래서 재사용할 도구를 추적 경로로 옮겼다.

**스크린샷 전부를 git 에 넣지는 않는다.** 큰 이미지는 이슈 첨부로 남기고,
여기에는 «무엇을 어떤 조건으로 쟀는가» 와 수치만 둔다.

## 매 빌드 자동 관문 (여기 도구가 아니다)

빌드가 스스로 돈다. 사람이 부르지 않는다.

| 관문 | 모듈 | 무엇을 보나 |
|---|---|---|
| `[0.6]` | `handpages.py` | 손 관리 소스에 **생성기 소유 마커가 없는가** · 슬롯은 합법 |
| `[1.33]` | `timecheck.py` | 시간 입력이 `buildtime` 한 곳인가 |
| `[3.462]` | `markercheck.py` | 배포본의 소유 마커 짝·중복·고아·제거 범위 · **안 채워진 슬롯** |
| `[3.4625]` | `contentcheck.py` | 손 관리 페이지의 **본문·코드·링크·제목이 살아남았는가** |
| `[3.463]` | `varcycle.py` | CSS 변수 직접·간접 순환 |

`contentcheck` 는 두 기준을 함께 쓴다. 손으로 쓴 것은 **이관 직전 고정본** 지문과 견주고,
생성·주입된 값은 **정본 입력**과 따로 견준다. 낡은 출력을 내용 정답으로 삼지 않는다.
계산 스타일 관문이 «화면이 같은가» 를 보는 자리라면, 이쪽은 «글자가 그대로인가» 를 본다.
코드 한 줄이 바뀌어도 상자 크기는 같아서 계산 스타일로는 절대 잡히지 않는다.
반대 방향도 실측했다. 손으로 쓴 강조 span 7개가 사라진 것은 내용 지문이 못 잡고
계산 스타일 관문이 잡았다 (2026-09-03). **두 관문은 서로를 대신하지 못한다.**

고정본 지문은 `_build/content_fixtures/` 에 있고, `contentcheck.REQUIRED` 에 적힌 페이지는
지문이 없으면 **빌드가 선다.** 없는 것을 «검사할 것 없음» 으로 넘기면 관문이 조용히 사라진다.

**소유자 표의 정본은 `markercheck.OWNERS` 하나다.**
`handpages` 는 거기서 파생만 한다. 두 곳이 각자 문자열 목록을 들었더니
여덟 마커를 통째로 놓쳤다 (2026-09-02 독립 검수).

## 일회성 이관 도구 (사람이 부른다)

빌드에 들어가지 않는다. 손 관리 페이지를 새로 이관할 때만 쓴다.

```bash
# 1) 생성물이 섞인 페이지에서 «순수 소스» 를 뽑는다
python _build/verify/split_source.py <볼트경로> index.html

# 2) 이미 있는 소스에서 생성기 소유 블록만 걷어낸다 (슬롯이 필요한 것은 슬롯을 남긴다)
python _build/verify/purify_source.py <볼트>/_build <볼트>/_src/index.base.html
```

`purify_source.py` 의 범위는 `markercheck.OWNERS` 가 정한다. 여기서 목록을 새로 만들지 않는다.

## 계산 스타일 비교 (사람이 부른다)

무시각변경 이관을 판정하는 **필수 관문**이다. 픽셀 diff 는 OS 별 폰트 렌더링 차이가 있어
단독 필수로 쓰지 않는다 (팀장 결정 2026-09-02).

```bash
# 1) 스냅샷을 받을 수집기를 띄운다 (127.0.0.1:8824 · 파일로 저장)
#    토큰을 정해 두면 브라우저에 그 값을 넣는다. 안 정하면 실행할 때 화면에 찍힌다.
SNAP_TOKEN=verify24 python _build/verify/collect.py &

# 2) 전·후 산출물을 각각 정적 서버로 띄운다 (cd 대신 --directory 를 쓴다.
#    cd 가 안 먹은 채로 뜬 서버가 «빈 폴더» 를 내보내 404 를 냈다. 실측 2026-09-02)
python -m http.server 8835 --bind 127.0.0.1 --directory <이관 전 out> &
python -m http.server 8834 --bind 127.0.0.1 --directory <이관 후 out> &

# 3) 이 폴더 자체도 띄운다. 그러면 채취기를 «붙여 넣지 않고» 파일 그대로 불러 쓴다.
#    붙여 넣기는 옮겨 적다 틀린다. script 태그는 교차 출처라도 실행된다.
python -m http.server 8826 --bind 127.0.0.1 --directory _build/verify &

# 4) 각 포트의 아무 페이지에서 (출처가 달라 8834 와 8835 는 따로 돌아야 한다)
#    window.__SNAP_TOKEN = 'verify24'
#    script src=http://127.0.0.1:8826/snap.js
#    await window.__H.selftest()                          <- 먼저 도구를 시험한다
#    await window.__H.run('index-after-1280','/index.html',1280,900,'light')

# 5) 비교한다. 이름은 snap/ 기준이고 확장자는 붙이지 않는다
python _build/verify/style_diff.py index-before-1280 index-after-1280 index.html
```

`style_diff.py` 는 `page_overrides.json` 의 `허용` 을 **실제로 읽는다.**
전에는 아무도 안 읽어서, 목록을 채워도 관문이 달라지지 않았다 (독립 검수 지적).

판정 조건 · 스키마와 «의미» 가 성한가 · `meta.count` 가 실제 요소 수와 맞는가 ·
같은 뷰포트인가 · **같은 테마인가** · 빈 style/media 껍데기 0 ·
비교가 유의미한 크기인가 (요소 30개 이상) · **허용 밖 차이 0**

의미 검사가 무엇을 막나. 모양은 맞는데 뜻이 없는 스냅샷이 있다.
필수 CSS 값이 `null`·빈 문자열·공백뿐이면 **못 잰 것**이고, 양쪽이 똑같이 못 쟀으면
차이 0 으로 조용히 통과한다. `_box` 의 `true`/`NaN`/`Infinity` 도 같다.
`NaN` 은 자기 자신과도 다르므로 판정을 아예 뒤집는다. 창이 `0x0` 이면 아무것도 못 쟀다.
테마가 다르면 색이 통째로 달라져 그 차이를 이관 탓으로 읽게 된다.

## 도구를 먼저 시험한다 (원칙 1)

세 도구 모두 «답을 아는 입력» 을 스스로 가지고 있다. 쓰기 전에 돌린다.

```bash
python _build/verify/style_diff.py --selftest   # 빈 el+위조 count · 스키마 5종 · 표본 크기
python _build/verify/collect.py --selftest      # 격리 임시폴더에서 경로 탈출 13종 거부
await window.__H.selftest()                     # 전수 수집 · 네 번째 형제의 변경과 소실
```

2026-09-02 독립 검수가 이 셋에서 각각 결함을 재현했다. 그래서 자기시험이 생겼다.
`style_diff` 는 요소가 하나도 없는데 «40개 쟀다» 고 우기는 스냅샷 두 개를 통과시켰고,
`snap.js` 는 같은 묶음의 앞 3개만 모아 네 번째부터는 아예 못 봤으며,
`collect.py` 는 Windows 절대경로를 주면 출력 폴더 밖에 파일을 썼다.

2차 검수는 두 곳을 더 짚었다. `style_diff` 의 스키마가 **모양만** 봐서 뜻이 없는 값을
통과시켰고, `collect.py` 가 `Origin` 을 `startswith` 로 봐서 `localhost.evil.example`
같은 **혼동 출처**를 믿었다. 접두사는 문자열이 어디서 끝나는지 모른다. 지금은
`urlsplit` 으로 파싱해 host 를 정확히 견주고 되돌이 주소인지 본다. 토큰 검증은 그대로다.

## 기준선과 증거 (비민감)

`baseline.json` 이 조건·수치·증거 색인을 들고 있다.

스냅샷 원본은 `snap/` 에 **커밋해 둔다.** 값은 CSS 속성 27종과 상자 좌표뿐이고
열쇠는 DOM 경로라, 비밀이나 보호 본문이 담길 자리가 아예 없다 (열쇠 456개 중 한글 0개).
`baseline.json` 의 `증거` 절에 입력 커밋·조건·SHA-256·재실행 명령이 모여 있다.

**이 증거가 덮는 범위를 오해하지 말 것.** 「이전」 기준선 `2226dcd` 는 `index` 이관 커밋
**그 자체**이고, `brief` 는 그보다 5커밋 앞선 `6d904f4` 에서 이미 이관됐다. 그러므로 이
전수 검증이 증명하는 것은 `2226dcd -> 0979157` 구간, 곧 **소유 블록 제거와 슬롯 계약
신설**이 화면을 바꾸지 않았다는 것뿐이다. 두 페이지의 **최초 이관** 전후 동일성은 여기서
소급 증명되지 않으며, 그 판정은 아직 표본 채취기 시절 수치(`index` 145/141 ·
`brief` 150/149)에 기대고 있다. `baseline.json` 의 `★적용_범위` 를 볼 것.

스크린샷 원본은 여기 넣지 않는다. 큰 이미지는 이슈 첨부로 남긴다.
