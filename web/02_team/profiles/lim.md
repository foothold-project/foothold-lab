## 맡은 것

FOOTHOLD의 `A/정책학습` 담당. 보행 정책 학습과 보상 설계, 실험 설계와 반복이
이 자리에서 나온다. Go2 가 험지에서 «어떻게 걸을지»를 결정하는 층이다.

정책은 한 번 잘 나오는 것이 아니라 실험을 몇 번 돌려 좁혀 가는 것이다.
그 반복을 맡는다.

## 배경

전남대학교 인공지능학부 인공지능전공 4학년(휴학). Python·PyTorch·TensorFlow·
Ultralytics YOLO 로 모델을 직접 학습시켜 왔고, OpenCV·NumPy·Pandas·Matplotlib
로 데이터를 다룬다. 학습 환경은 CUDA·Google Colab·Roboflow·Label Studio 를
사용한다.

**Vital Flow** (AI 기반 응급의료행위 자동 로깅) 에서 데이터셋 구축·라벨링·증강,
YOLO 학습, 행위 판별 휴리스틱 설계와 구현을 담당했다. 의료기기 9종·라벨
15,085개를 증강해 22,606장 규모로 만들고, 그 결과를 웹 타임라인과 자동
기록지까지 이어붙였다.

| 무엇 | 왜 이 프로젝트에 쓸모 있나 |

| 파인튜닝 R&D | 기존 정책을 험지에 맞게 다시 맞추는 것이 이 프로젝트의 본 과제다 |

| 판별 규칙 설계 | 모델 출력만으로 부족할 때 규칙으로 메우는 방법을 안다 |

## 협업 방식

직접 돌려본 결과를 근거로 가져와 논의를 빠르게 좁힌다.

## 방향

관심 분야는 Computer Vision · Physical AI · Vision-Language-Action 이며,
시각·언어·행동을 잇는 멀티모달 엔지니어를 지향한다. 모델 구현과 실험·성능
개선을 선호 역할로 두고 있고, 대학원 진학을 고려하며 세부 연구 분야를
탐색 중이다.
