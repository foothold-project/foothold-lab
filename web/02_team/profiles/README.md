# 팀원 소개 (표지 «팀» 섹션에 펼쳐집니다)

이 폴더의 마크다운이 표지 하단 팀 카드에 붙습니다. 이름을 누르면 펼쳐집니다.

## 파일 이름

본인 inbox 폴더 이름과 같게 합니다.

| 이름 | 파일 |
| --- | --- |
| 오흥재 | `lead.md` |
| 임석헌 | `lim.md` |
| 맹라현 | `meang.md` |
| 이민우 | `lee.md` |
| 오현민 | `oh.md` |

## 어떻게 올리나

본인 inbox 폴더(`inbox/{이름}/`)에 올리면 팀장이 확인 후 여기로 옮깁니다.
올리는 즉시 디스코드와 팀장 텔레그램으로 알림이 갑니다.

## 무엇을 쓰나

정해진 틀은 없습니다. 다만 아래가 있으면 멘토·외부에 설명하기 좋습니다.

- **배경** : 무엇을 해왔는가
- **이 프로젝트에서 맡은 것** : 구체적으로
- **강점** : 그것이 왜 이 프로젝트에 쓸모 있는가

## 주의

- 표지는 공개 페이지입니다. **전화번호·주소·주민번호 같은 개인정보는 쓰지 마세요.**
- 첫 줄의 `# 제목` 은 자동으로 지워집니다. 카드에 이름이 이미 있기 때문입니다.
- 표·목록·굵게·링크가 쓸 수 있습니다.
