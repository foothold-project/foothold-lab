# inbox: 팀원 제출함

**여기 올리면 팀장이 검토해 `docs/` 정본으로 반영하고, 반영된 것은 주간 다이제스트에 실린다.**
이 폴더는 웹에 게시되지 않는다. 게시되는 것은 `docs/` 뿐이다.

## 사용법 (규칙은 이것뿐)

1. **자기 폴더에만 쓴다** (meang / oh / lim / lee). 남의 폴더를 건드리지 않으면 git 충돌이 원천적으로 없다.
2. 파일 맨 위에 두 줄:
   ```
   작성 2026-08-13
   요지: 한 문장으로, 이 문서가 말하는 것
   ```
   이 두 줄이 있어야 팀장 큐레이션과 다이제스트 자동 초안에 물린다.
3. 형식은 자유 (md 권장, 이미지·짧은 영상 가능). **10MB 넘는 파일은 git 에 넣지 말 것**: 팀 채널로 공유(추후 NAS).

## 흐름

`inbox/<나>/` 에 제출 → 팀장이 검토·보완 → `docs/` 정본 반영 → 다음 빌드에 웹 게시 → 주간 다이제스트에 요약
