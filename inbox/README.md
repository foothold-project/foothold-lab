# inbox: 팀원 제출함

여기는 **던지는 곳**입니다. 형식을 맞추지 않아도 되고, 다듬지 않아도 됩니다.
읽고 정리하는 것은 팀장이 합니다.
반영된 것은 `docs/` 정본이 되고, 주간 다이제스트에 실립니다.
**이 폴더는 웹에 게시되지 않습니다.** 공개 사이트로 나가는 것은 `docs/` 뿐입니다.

## 올리는 법 (처음 한 번만 읽으면 됩니다)

```
git checkout -b inbox-내이름     # 브랜치 만들기 (이름은 아무거나)
git add inbox/내폴더/파일.md
git commit -m "메모 추가"
git push -u origin inbox-내이름
```
push 하면 GitHub 가 «Compare & pull request» 버튼을 보여줍니다. 누르면 끝.
PR 에 **`inbox/` 아래 파일만** 있으면 팀장이 확인하고 머지합니다. **내용은 손대지 않습니다**. 형식 관문이지 검열이 아닙니다.
**`docs/` 나 규칙 문서를 같이 고쳤다면 검토 후 머지합니다.** 그쪽은 이미 정리된 정본이라,
모르고 덮어쓰면 남의 작업이 사라집니다. 실제로 2026-08-25 에 회의록 정본이 그렇게 덮였습니다.
(main 에 직접 push 하면 거절 안내가 옵니다. lab 의 main 은 팀장만 만집니다)

## 규칙 (이것뿐입니다)

1. **자기 폴더에만 씁니다.** 남의 폴더를 건드리지 않으면 git 충돌이 원천적으로 없습니다.
2. **파일 맨 위에 메타 5줄을 답니다.**
   ```
   > 분류: 회의록 | 리서치 | 실험 | 계획 | 결정 | 운영 | 현장 | 가이드
   > 작성: 오흥재 · 2026-08-27 02:07
   > 근거: 전사 N세그먼트 | 공식 문서 | 실측 | 본인 노트 | 미확인
   > 요지: 한 줄로, 이 문서가 말하는 것
   > 상태: 초안 | 검토중 | 확정 | 대기
   ```
   **inbox 안에서는 안 갖춰도 머지됩니다.** 다만 `docs/` 로 올라가는 순간
   빌드가 막습니다. 처음부터 달아 두면 승격할 때 손댈 것이 없습니다.
   「작성」에 **시각까지** 쓰면 같은 날 여러 번 고쳐도 순서가 보입니다.
   「요지」는 **주간 다이제스트 자동 초안**이 읽습니다.
3. 파일 이름은 `YYYYMMDD-주제.md` 를 권합니다. 예: `20260813-지형타일-측정메모.md`
4. 형식은 자유입니다(md 권장, 이미지·짧은 영상 가능).
   **100MB 넘는 파일은 git 에 넣지 마세요 (GitHub 이 거부합니다).** 팀 채널로 공유하거나 팀장에게 알려주시면 처리합니다.

## 무엇을 올리나

측정 로그, 실패 기록, 캡처, 참고 링크 모음, 회의 중 메모, 설치하다 막힌 지점.
**정리되지 않은 것일수록 여기가 맞습니다.** 정리된 것만 올리려다 안 올리는 것이 가장 나쁩니다.

## 그 다음에 무슨 일이 일어나나

팀장이 읽고 쓸 만한 것을 `docs/research/` 로 옮겨 정본으로 만듭니다.
정본이 되면 **자동으로 공개 사이트에 실립니다.**
옮길 때 갖추는 것은 이렇습니다.

| 항목 | 내용 |
|---|---|
| 제목 | 맨 위 `# 제목` 한 줄 |
| 메타 5줄 | `분류` · `작성` · `근거` · `요지` · `상태` (아래 예시) |
| 증거 표기 | `확인됨` · `추측` · `미측정` |
| 원 출처 링크 | 참고한 곳 |
| 민감정보 없음 | 연락처 · 주소 · 토큰 |

```
> 분류: 리서치
> 작성: 홍길동 · 2026-08-27 09:41
> 근거: 공식 문서
> 요지: 한 줄로 이 문서가 말하는 것
> 상태: 초안
```

**분류는 여덟 중 하나입니다.** 회의록 · 리서치 · 실험 · 계획 · 결정 · 운영 · 현장 · 가이드.
**내용과 분류가 맞아야 합니다.** 본인 학습 계획을 「회의록」으로 올리면 회의 기록이 아닌 것이
회의 목록에 섞입니다. 그건 「계획」입니다.

**이 다섯을 미리 달아두면 그대로 승격됩니다.** 안 달아도 제출은 됩니다.
자동 검토가 «무엇이 빠졌는지»를 알려주고, 팀장이 채워서 옮깁니다.

## 주의

그건 #foothold-resource 나 금고로 갑니다.
