# inbox: 팀원 제출함

여기는 **던지는 곳**입니다. 형식을 맞추지 않아도 되고, 다듬지 않아도 됩니다.
읽고 정리하는 것은 팀장이 합니다.
반영된 것은 `docs/` 정본이 되고, 주간 다이제스트에 실립니다.
**이 폴더는 웹에 게시되지 않습니다.** 공개 사이트로 나가는 것은 `docs/` 뿐입니다.

## 규칙 (이것뿐입니다)

1. **자기 폴더에만 씁니다.** 남의 폴더를 건드리지 않으면 git 충돌이 원천적으로 없습니다.
2. **파일 맨 위에 두 줄을 답니다.**
   ```
   작성 2026-08-13
   요지: 한 문장으로, 이 문서가 말하는 것
   ```
   이 두 줄이 있어야 팀장 큐레이션과 **주간 다이제스트 자동 초안**에 물립니다.
3. 파일 이름은 `YYYYMMDD-주제.md` 를 권합니다. 예: `20260813-지형타일-측정메모.md`
4. 형식은 자유입니다(md 권장, 이미지·짧은 영상 가능).
   **10MB 넘는 파일은 git 에 넣지 마세요.** 팀 채널로 공유하거나 팀장에게 알려주시면 처리합니다.

## 무엇을 올리나

측정 로그, 실패 기록, 캡처, 참고 링크 모음, 회의 중 메모, 설치하다 막힌 지점.
**정리되지 않은 것일수록 여기가 맞습니다.** 정리된 것만 올리려다 안 올리는 것이 가장 나쁩니다.

## 그 다음에 무슨 일이 일어나나

팀장이 읽고 쓸 만한 것을 `docs/research/` 로 옮겨 정본으로 만듭니다.
정본이 되면 **자동으로 공개 사이트에 실립니다.**
옮길 때 네 가지를 갖춥니다: 제목(h1) · 증거 표기(`확인됨`/`추측`/`미측정`) · 원 출처 링크 · 민감정보 없음.
