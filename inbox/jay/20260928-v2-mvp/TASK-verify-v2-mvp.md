## 6. 실측 · 학습 기록에서 나온 것 셋

**6-1. 커리큘럼 붕괴는 우리 환경 탓이 아닙니다.**

`Curriculum/terrain_levels`

| step | NVIDIA 설정 처음부터 | `v2g2` (resume) | `fs1` | `fs2` |
|---|---|---|---|---|
| 0 | 3.528 | 1.981 | 1.981 | 1.981 |
| 175 | **0.524** | 4.63 | **0.002** | 0.003 |
| 500 | 3.140 | 5.948 | 3.585 | 1.826 |
| 1499 | 5.632 | 6.016 | 4.841 | 4.097 |

레벨 5.9 이상으로 돈 반복 수는 `v2g2` 2735 / 3001 · `fs1` **0** / 4501 · `fs2` 62 / 4501 · NVIDIA 설정 처음부터 **0** / 1500 입니다.

승급은 원점에서 직선거리 > `size/2` = 4.0 m (`curriculums.py:49`), 강등은 거리 < `|명령| x 20.0 x 0.5` (`:51`) 입니다.

**6-2. `lr` 1e-3 은 NVIDIA 의 처음부터 기본값입니다.**

`go2/agents/rsl_rl_ppo_cfg.py:32` 에 `learning_rate=1.0e-3` · `go2/gap_training/gap_ppo_cfg.py:18` 에서 우리가 `1.0e-4` 로 낮췄습니다 (그 파일 주석이 resume 용이라고 적고 있습니다). adaptive 스케줄의 lr 최고점은 NVIDIA 설정 처음부터 0.00759@6 · `fs1` 0.00657@8 · `v2g2` 0.00051@5 입니다.

**6-3. GPU 효과는 0 입니다.**

`v2b-r`(cuda:0) 대 `v2b-p11`(cuda:1) 은 `device` 한 칸만 다른 짝입니다. 체크포인트 **121 개 전수**에서 정책 가중치와 optimizer 상태 텐서까지 전부 동일 (최대 차 0.000e+00). 처음부터 · lr 1e-3 경로에서도 `probe-det-g0`(cuda:0) 과 `fs2`(cuda:1) 의 `model_0` · `model_25` 가 완전 동일합니다.

**함정** · 파일 sha256 은 121 개가 전부 다릅니다. `torch.save` 가 텐서의 device 를 함께 적기 때문입니다. `CRITERIA.md:507` 이 이 칸을 「미측정」으로 둔 것도 이 함정일 수 있습니다.
