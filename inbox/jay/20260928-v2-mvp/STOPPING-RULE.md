# 언제 정책 탐색을 멈추는가 · 판정 규칙

> 분류: 기준
> 작성: 오흥재 · 2026-09-28
> 근거: 실측 (`sim/eval/results/20260923-v2rs` · `20260921-v2ab` 의 48 칸 성적 · 시드 셋)
> 요지: **한 칸 바꿔 얻은 것이 시드만 바꿔 생기는 흔들림보다 작으면 멈춘다.** 축 1 은 이미 그 선을 넘었다
> 상태: 확정
> 판: v1.0

---

## 0. 왜 이 문서가 있나

「언제까지 설정을 더 흔들어 볼 것인가」에 답이 없었다. 그래서 실험이 **효과를
재는 것**에서 **잡음을 재는 것**으로 넘어가는 자리를 못 보고 지나쳤다.

이 문서는 그 자리를 **수로** 정한다. 다음 실험을 설계하는 사람(과 에이전트)이
이것을 보고 멈출지 계속할지 정한다.

---

## 1. 규칙 두 줄

```
규칙 1   한 칸 바꿔 얻은 것 <= 시드만 바꿔 생기는 흔들림
         -> 정책 탐색을 멈춘다. 더 흔들면 잡음을 재는 것이다

규칙 2   시드 흔들림이 판정 폭만큼 크다
         -> 튜닝 말고 «자» 를 고친다. 표본을 늘리거나 값과 구간을 같이 적는다
```

**둘은 다른 상황이다.** 규칙 1 은 「정책이 천장에 닿았다」이고 규칙 2 는
「자가 무뎌서 천장이 어디인지 못 본다」이다.

---

## 2. 바닥선을 어떻게 얻나

**같은 레시피를 시드만 바꿔 최소 셋 돌리고, 그 지표의 폭을 잰다.** 그 폭이
그 뒤 모든 비교의 바닥선이다. 그보다 작은 차이는 차이가 아니다.

시드를 안 돌렸으면 바닥선이 없고, 바닥선이 없으면 **어떤 개선도 개선이라고
말할 수 없다.** 시드 셋은 비용이 아니라 전제다.

## 3. 실측 · 2026-09-28 기준

### 3-1. 축 1 (48 칸 평균 · 난이도 0.5 · iter3000)

같은 레시피 · 시드만 다른 셋.

| 판 | 시드 | 48 칸 평균 |
|---|---|---|
| `v2g2-feetair01` | 42 | 94.19 |
| `v2g3-feetair01-s43` | 43 | 92.94 |
| `v2g4-feetair01-s44` | 44 | 93.52 |

```
시드 폭   94.19 - 92.94 = 1.25 %p      <- 축 1 의 바닥선
```

`v2b` 에서 **한 칸씩만** 바꾼 자식들.

| 판 | 바꾼 한 칸 | 48 칸 평균 |
|---|---|---|
| `v2b` | (부모) | 93.44 |
| `v2b-r` | 없음 (기준 재현) | 92.79 |
| `v2n-noise02` | height scan 잡음 ±0.10 -> ±0.02 | 93.44 |
| `v2s-stones10` | stepping_stones 10 % 추가 | 91.79 |
| `v2g-feetair1` | `feet_air_time` 1.0 | 93.08 |
| **`v2g2-feetair01`** | **`feet_air_time` 0.1** | **94.19** |
| `v2sg-stones10feet01` | 위 둘의 결합 | 91.69 |

```
자식 여섯의 폭        91.69 ~ 94.19 = 2.50 %p
최고 자식이 기준보다   94.19 - 92.79 = +1.40 %p
시드 폭                              1.25 %p
```

**+1.40 과 1.25 가 거의 같다. 규칙 1 에 걸린다. 축 1 은 멈출 자리다.**

### 3-2. 어디서 멈췄어야 했나

| 구간 | 얻은 것 | 시드 폭 | 판정 |
|---|---|---|---|
| `v2a` -> `v2b` | 축 1 하락 `2·1·2·0` -> `0·0·0·0` | 1.25 %p | **잡음보다 큼. 계속할 이유가 있었다** |
| `v2b` -> `v2g2` | 48 칸 93.44 -> 94.19 (+0.75) | 1.25 %p | **잡음 안. 멈출 자리였다** |

**`v2b` 에서 멈췄어야 했고 자식 다섯 판과 시드 두 판이 초과였다.**

그리고 규칙을 그대로 적용하면 이렇게 된다.

> **`v2g2` 가 `v2b` 보다 낫다고 말할 수 없다.** 48 칸 평균이 94.19 대 93.44 로
> `v2g2` 가 높지만 시드 폭 1.25 %p 안에 들어간다.

**그러면 왜 `v2g2` 를 배포 후보로 골랐나.** 성적이 나아서가 아니라
**가장 두껍게 잰 판**이기 때문이다. 기준선은 잘하는 판이 아니라 잘 잰 판이어야
한다. 아래 5 절에 나란히 적는다.

### 3-3. 축 2 (아홉 칸 · iter3000)

| 판 | 시드 | 아홉 칸 |
|---|---|---|
| `v2g2-feetair01` | 42 | 8 / 9 |
| `v2g3-feetair01-s43` | 43 | 4 / 9 |
| `v2g4-feetair01-s44` | 44 | 7 / 9 |

```
시드 폭   8 - 4 = 4 칸 / 9          <- 눈금의 «절반» 에 가깝다
```

**축 2 는 규칙 2 에 해당한다.** 1~2 칸 차이는 아무 뜻이 없다.

**왜 무딘가.** 아홉 칸이 전부 문턱을 넘었나 못 넘었나 둘 중 하나인데,
정책들이 하필 문턱 위아래에 몰려 있다.

```
v2g2 의 wz +1.00    0.3994      문턱 0.40
                    0.0006 차이로 한 칸이 통째로 미달이 된다
```

**표본을 늘려도 참값이 문턱 위에 앉아 있으면 안 갈린다.** 64 env 에서
1024 env 로 올려 실제로 확인했다. 미달 칸이 `회전 낙상` 에서 `wz +1.00` 으로
**옮겼을 뿐 개수는 8/9 그대로**였다.

**그래서 축 2 에서 할 일은 정책을 흔드는 것이 아니라 자를 고치는 것이다.**

| 무엇 | 기준이 바뀌나 | 다시 재야 하나 | 비용 |
|---|---|---|---|
| 값과 구간(Wilson)을 같이 **적는다** | 아니오 | **아니오** | **0** |
| 표본을 64 -> 1024 로 | 아니오 | 예 | 칸당 약 2.5 분 |
| 문턱 값 자체를 바꾼다 | **예** | 아니오 | 절차 필요 · **결과를 본 뒤에는 하지 않는다** |

첫째 줄은 공짜다. `fell_count` 와 `envs` 가 이미 저장돼 있어 Wilson 은 산수다.

## 4. 규칙이 막으려는 것

**결과를 보고 최댓값을 고르는 것이다.** 그런데 「나중 체크포인트가 더 좋은 것」
까지 막으려는 것은 아니다. 둘을 갈라야 한다.

```
단조로 오르면    학습이 된 것이다. 마지막을 고르는 것이 옳다
들쭉날쭉하면     최댓값은 운일 수 있다. 그때만 위험하다
```

실제 궤적으로 보면 이렇다.

| 판 | 궤적 | 읽기 |
|---|---|---|
| `v2a` 축 1 하락 | 2 · 1 · 2 · **0** | 대체로 내려간다. 마지막을 고르는 것이 타당하다 |
| `v2g2` 축 2 | 6 · **2** · 5 · 8 | iter2000 이 2 로 주저앉는다. **학습 곡선이 아니다** |
| `v2b-r` 축 2 | 4 · 5 · **9** · 6 | 한 점만 솟았다 내려온다. **봉우리다** |

**그리고 운인지 실력인지 가르는 진짜 시험은 시드다.** `v2g2` 의 8/9 는
시드 43 에서 4/9, 시드 44 에서 7/9 였다. **재현되지 않았다.**
`v2b-r` 은 다른 시드로 잰 적이 없다.

## 5. 그래서 두 후보를 나란히 놓는다

**배포는 `v2g2` iter3000 이다. 강력한 참고 비교군은 `v2b-r` iter2500 이다.**

| | `v2b-r` @2500 | `v2g2` @3000 | 시드 폭 |
|---|---|---|---|
| 48 칸 평균 (d0.5) | 93.12 | **94.19** | 1.25 %p |
| 미경험 10종 | 89.10 | **90.70** | |
| 기존 6종 | 99.83 | **100.00** | |
| 축 1 진짜 하락 (그 점) | 0 | 0 | |
| 축 1 진짜 상승 (그 점) | 5 | **8** | |
| **축 1 네 점 하락** | **2 · 0 · 0 · 0** | **0 · 0 · 0 · 0** | |
| 축 2 (1024 env) | **9 / 9** | 8 / 9 | 4 칸 |
| `stepping_stones` 1.0 m/s | 0 % | **24 %** | |
| 난이도 스윕 | 있음 | 있음 | |
| 시드 재현 | **없음** | 있음 (43 · 44) | |

**읽는 법.**

- 48 칸 차이 1.07 %p 는 **시드 폭 1.25 %p 안**이다. 성적으로는 구별되지 않는다
- 축 2 한 칸 차이도 **시드 폭 4 칸 안**이다. 구별되지 않는다
- **자료로 갈리는 것은 하나다.** 축 1 네 점에서 `v2b-r` 은 iter1500 에 하락 2 가
  있고 `v2g2` 는 넷 다 0 이다. **체크포인트를 골라야 하는 부담이 `v2g2` 쪽이 작다**
- `v2b-r` 의 9/9 는 네 점 중 한 점이고 `회전 낙상` 이 0.344 -> 0.109 -> **0.031**
  -> 0.3125 로 한 점만 내려앉는다. **봉우리다**

**결론** · 두 판은 성적으로 구별되지 않는다. `v2g2` 를 고른 근거는
「더 잘한다」가 아니라 **「더 두껍게 쟀고 체크포인트 선택 부담이 작다」** 이다.
보고서에 그렇게 적는다.

## 6. 신경망을 바꾸면 이 일이 버려지나

**버려지는 것은 가중치 하나다.** 관측 차원과 뜻이 바뀌면 resume 이 안 되므로
체크포인트는 못 쓴다. 그 외는 남는다.

| 남는 것 | 왜 |
|---|---|
| **평가 하네스** | 정책을 지형에 올리고 행동만 잰다. 관측이 무엇이든 상관없다 |
| **기준선 숫자** | 새 구조가 넘어야 할 선. 이것이 없으면 「더 낫다」를 반증할 수 없다 |
| **환경의 함정** | 커리큘럼 붕괴 · `ang_vel_z` 와 heading 의 한 쌍 · 노출 구조. 신경망이 아니라 «환경» 이야기다 |
| **명령과 보상 설정** | 새 구조도 명령을 받고 보상으로 배운다. 출발 설정이 된다 |
| **이 문서** | 멈출 선을 재는 방법 자체 |

**진짜로 버려지는 것은 「정책 수준에서 마지막 몇 %p 를 더 짜내는 시간」이다.**
그래서 신경망 교체가 예정돼 있으면 **규칙 1 에 닿는 순간 멈추는 것**이 맞다.

한 가지 확인이 필요하다. 새 구조가 depth 를 쓴다면 **관측을 만드는 환경 설정**을
하나 더 만들어야 한다. 판정 코드와 지형은 그대로다.

## 7. 이 문서를 어떻게 쓰나

새 실험을 걸기 전에 이 셋을 적는다.

```
1  무엇을 한 칸 바꾸나
2  그 지표의 시드 폭은 얼마인가 (없으면 먼저 시드 셋을 돌린다)
3  기대하는 효과가 그 폭보다 큰가
```

**3 번이 「아니오」면 걸지 않는다.**
