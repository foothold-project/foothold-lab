### 1.7 Path-Guided Curriculum Learning (PGCL) `논문 확인 (IV-C2 · 식 7 ~ 10 · Fig. 4 · IV-D)`

1. privileged 지도에서 **Generalized Voronoi Diagram 위 A\*** 로 전역 경로를 만든다 [41].
2. 수준 k 에서 부목표 집합 G_k = {g_s^(k,1), …, g_s^(k,N_k) := g}, 경로를 따라 **d 미터 간격**으로 표본. 시작 k = 1, d = 1 m.
3. 에이전트가 G_k 의 부목표를 **차례로 모두** 도달하면 k ← k + 1, d ← d + 1 m. 매 순간 정책의 목표 관측은 「아직 안 닿은 다음 부목표」.
4. d 가 경로 길이를 넘으면 최종 수준 K (최종 목표만). K 에서 「꾸준히 성공」 하면 새 start · goal 을 무작위로 뽑는다. 「꾸준히」 의 횟수 · 문턱은 `논문 미기재`.
5. 부목표 도달 판정 식 (10): T_k,i = min{t : ‖p_B^W - p_gs^W‖₂ < 0.1 m}.
6. 목적 식 (8) · (9): 모든 수준 k 와 부목표 i 의 기대 할인 수익의 합을 최대화.
7. 지도 · 부목표는 **teacher 학습 전용**. student 는 부분 관측 (최종 목표만).
8. IR (상태 방문 수, Table II r2) 과 PGCL 은 보완 관계. 둘 다 빼면 Room SR 98.4 → 53.0. `논문 확인 (V-C · Table IV)`
- 전역 경로가 **낮은 통로 아래를 지나는 경로를 허용하는지** (즉 GVD 를 어떤 높이 단면에서 만드는지) 는 `논문 미기재`. 이것이 「자세를 낮춰 통과하라」 는 부목표 유도의 핵심이므로 구현 전에 정해야 한다 (5 절 갈림길 G3).

| HiPAN 항법 + E1 기반 속도 3 칸 (M3 포함) | vx · vy · wz. **h · roll 없음** | G1 「HiPAN w/o Pos. Adjustment」 | Room SPL 88.8 → 74.1 (낮은 장애물 우회) · Complex-1 SR 94.4 → 74.2 · Complex-2 94.7 → 73.1 |
| HiPAN 항법 + 저수준이 **스스로** 자세를 바꾸는 속도 3 칸 (RPL 식 depth · MoE-Loco 식 proprio) | vx · vy · wz | G4 | Complex-1 SR 90.2 (RPL) · 85.3 (MoE-Loco), 충돌 1.38 → 3.73 · 5.67. 저자: 「속도 명령이 저수준이 덜 덮은 상태로 몰아 분포 이동」 (V-C) |

- **결론:** 속도 전용 저수준과 짝지은 HiPAN 은 논문이 스스로 성능 손실과 충돌 증가를 보고한 구성이다. 팀장의 충실 요구에 따라 이 명세의 기본은 **저수준에 h · roll 추종을 넣는 것** (3 절 L 단계) 이다. 속도 전용 결합은 「G1 w/o Pos. Adjustment 를 재현하는 대조군」 으로만 남긴다.
- 논문이 START 저수준으로 실험한 적은 없다. 위 손실 숫자는 Go1 · 논문 환경 · 논문 저수준의 값이고 **우리 수치는 전부 `미확인`** 이다.
- 또 하나의 사실: HiPAN 의 가중치는 공개되지 않았다. 「HiPAN 의 항법기를 재사용할 수 있나」 는 실제로는 물을 수 없고, **모든 층을 우리가 처음부터 학습** 한다. 재학습 물음은 3 절처럼 「우리 저수준이 바뀔 때마다」 로 바뀐다.

## 3. 저수준이 바뀌면 무엇을 다시 학습하나 · 단계 계획

### 3.1 왜 다시 학습하나 (논문 근거)

- 고수준 MDP 의 전이 P̄ 에 **저수준 student 가 내장** 돼 있다 (IV-C1). 저수준이 바뀌면 (체크포인트 · 명령 공간 · estimator · 제어 주기 어느 것이든) P̄ 가 바뀌고, 그 위에서 최적화된 고수준 teacher 는 다른 MDP 의 정책이 된다.
- 고수준 student 는 저수준 motion estimator 의 x̂_m 을 입력으로 받는다 (IV-C3). estimator 가 바뀌면 student 입력 분포가 바뀐다.
- 저자가 G4 에서 본 것이 바로 「고수준이 가정한 저수준과 실제 저수준의 불일치 → 분포 이동 · 충돌」 이다 (V-C).

| 저수준의 변화 | 다시 해야 하는 것 |
|---|---|
| 가중치만 (같은 명령 공간 · 같은 estimator 구조 · 같은 주기) | 고수준 teacher 재학습 또는 fine-tune (`논문 미기재`, 어느 쪽이 충분한지는 재야 함) + student 재증류 |
| 명령 공간 (칸 · 범위) | 고수준 teacher 처음부터 + student |
| estimator 구조 · 이력 길이 | 고수준 student 재증류 (teacher 는 x_m privileged 라 영향 없음) · 단 저수준 student 가 바뀌면 P̄ 도 바뀌어 teacher 도 |
| 제어 주기 | 전부 |

## 4. 실제 Go2 배포 구조 (말로)

### 4.1 무엇이 어디서 도는가

실기는 Go2 EDU 순정 + D435i (memory 10/12 팀장 확정). **탑재 컴퓨터 종류는 `미확인`** (`DESIGN-topdown-20261013` C5 「ROBOT-SPEC 미확인」 · 운영진 회신 대기). 논문은 Go1 + Intel NUC 였다. 두 배치안을 둔다.

- 배치 A (논문 꼴): 탑재 컴퓨터 하나에 아래 전부. 항법 student 는 GPU (있으면) 또는 CPU 추론.
- 배치 B: 저수준 · 상태 브리지 · 안전 브리지는 탑재 컴퓨터, depth 전처리 · 항법 student 는 외부 노트북 (유선). 지연이 10 Hz 틱 (100 ms) 안에 들어와야 하며 `미확인`.

| 노드 | 하는 일 | 입력 → 출력 | 주기 |
|---|---|---|---|
| D435i 드라이버 | depth 스트림 | 1280 × 720 @ 30 fps 또는 424 × 240 (둘 다 16:9. 180 × 320 은 1280 × 720 의 정확히 1/4) | 30 Hz |
| depth 전처리 | hole-filling (librealsense) → 4 m clip → [0, 1] → 180 × 320 리샘플 → stamp | depth → `DepthNorm` | 10 Hz (프레임 선택) |
| 상태 브리지 | SDK LowState (q · q̇ · IMU rpy · gyro · 발 힘) → o_p 57 (발 위치는 FK · 접촉은 발 힘 문턱 `우리 제안`) | LowState → `Proprio57` | 50 Hz (SDK 는 500 Hz) |
| 저수준 student | o_p 이력 50 · 10 + 유지된 c → Δq 12 → q0 + Δq 와 Kp · Kd 를 LowCmd 로 | `Proprio57` + `cmd_applied` → LowCmd · `MotionEstimate` | 50 Hz |
| 목표 제공자 | 세계 틀 목표 g 와 로봇 자세로 p_g^B = R_WB^T (g - p_B) | odometry + g → `GoalBody` | 10 Hz |
| 항법 student | depth · ō_p = [o_p, c_{t-1}] · x̂_m · p_g^B → ĉ (GRU 상태 유지) | → `PostureCommand` | 10 Hz |
| 명령 · 안전 브리지 | 범위 clip · 유효 기간 · STOP 우선순위 · 되돌림 | `PostureCommand` + STOP → `cmd_applied` | 50 Hz |
| 기록 | 요청 · 적용 · 정책 직전 세 기록 (CONTRACT 2 칸) · 93 열 시계열 틀에 h · roll 열 추가 | | 50 Hz |

- odometry: 논문은 원천을 적지 않았다 (N11). 선택지는 Go2 순정 SportModeState 위치 추정 (드리프트 `미확인`) 또는 11/30 SLAM 트랙. 막다른 길 복귀가 30 ~ 60 m 에 걸치므로 (Fig. 6) 드리프트가 목표 방향을 틀면 복귀가 깨진다 → 갈림길 G5.
- 카메라 모드: 1280 × 720 은 Min-Z 280 mm, 424 × 240 은 105 mm (ROADMAP 의 데이터시트 기록). 낮은 통로 바로 앞에서 근거리가 중요하므로 **두 모드로 S3 등가 시험을 둘 다** 한다 `우리 제안`.
- roll 은 Go2 IMU 가 직접 주지만 논문 구조는 저수준 estimator 의 roll̂ 을 항법에 넣는다. 충실 구성은 estimator, 실용 대안은 IMU 직결. 갈림길 G4.

### 4.2 지연 예산 (`우리 제안` · 전부 `미확인`)

depth 노출 → 전처리 → 항법 추론 → 브리지 → 저수준 적용까지 한 고수준 틱 (100 ms) 안. 각 구간을 stamp 차로 재고, 시뮬 P̄ 에 같은 지연 (고수준 1 틱 = 저수준 5 틱 + 측정 지연) 을 넣는다. 논문은 「실행 지연을 P̄ 에 반영」 한다고만 적었다 (IV-C1).

### 4.3 안전

- STOP 뒤 명시적 재개 전까지 늦게 온 `PostureCommand` 를 버린다 (CONTRACT 3 칸).
- 통신 단절 0.3 s → [0, 0, 0, h_nominal, 0]. 관절 토크 0 과 속도 0 을 구분.
- h · roll 은 브리지에서 **단계 L 에서 잰 Go2 가능 구간** 으로 clip. 학습 범위와 다르면 항법 쪽도 그 범위로 학습해야 한다 (N9).
- 유리 · 반사면 (논문 VI) 은 실내 시험장에서 미리 가리거나 keepout 으로.
