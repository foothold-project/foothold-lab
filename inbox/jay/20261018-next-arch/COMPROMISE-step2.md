## 0. 원칙 다섯 (팀장 승인 문구 · 정본)

| 번호 | 원칙 (승인 문구 그대로) | 뜻 풀이 (고1) |
|---|---|---|
| **①** | 방법(신경망 구조 · 손실 · 학습 단계 teacher→student · 보상 형태 · curriculum 규칙)은 그대로 | 논문이 「이렇게 배운다」 고 한 틀은 하나도 빼거나 줄이지 않는다 |
| **②** | 로봇 · 장면 크기는 논문 규칙대로 Go2 에 맞추고 계산 근거 기록 | 로봇이 작아졌으니 장애물 높이 · 지도 크기 같은 「자」 는 논문의 규칙으로 다시 재서 적고, 왜 그 숫자인지 남긴다 |
| **③** | 예산은 날짜로 고정(예 teacher ~11/12 · student ~11/25), 「논문 반복 수의 n %」 로 기록 | 얼마나 오래 배울지는 달력으로 정하고, 논문 대비 몇 % 배웠는지 숫자로 남긴다 |
| **④** | 공개 안 된 부분(지도 생성기)은 논문대로 만들되 일정 밖이면 「정답 지도 student」 대체판으로 표기 | 저자가 안 준 부품은 논문대로 만들되, 시간이 모자라면 대신 쓴 부품이 무엇인지 이름표를 붙인다 |
| **⑤** | 결과는 「논문 재현」 이 아니라 「AME-2 방법의 Go2 구현 (예산 n %, 대체 사항 목록)」 | 보고서 제목부터 「재현」 이라 쓰지 않는다 |

**① 의 하위 규칙 (lead 지시): 논문 대 공식 코드(저자의 Isaac Lab G1 재이식 · README 「mostly vibecoded」 · 「half-archived」) 가 어긋나면 논문을 따른다.** 코드에만 있는 기능(muon · bf16 · multi-head critic · Gaze · 목표 원뿔 커리큘럼 · CoM DR · value loss renorm · entropy 감쇠) 은 끄거나 「코드 추가」 로 표기한다. 코드가 논문의 정성 서술을 구체화한 값(구멍 채움 · 스텀블 1.1 f_z + 1 N · 미끄러짐 0.3 m/s · 접촉 1 N · u 변환식 · LSIO 폭 · MoE 16 · 에피소드 16 s) 은 논문 미기재를 메우는 출처로 쓴다 (20a · 19b §1 동의).

적용 순서: 한 항목을 보면 ① 인지(방법) → ② 인지(크기) → ③ 인지(시간) → ④ 인지(미공개) 를 차례로 묻고, 어디에도 안 들어가면 「우리 선택 · 출처」 로 ⑤ 의 대체 사항 목록에 올린다.
