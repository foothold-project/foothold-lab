## 직접 확인한 자료

`확인됨` [Unitree 공식 Go2 페이지](https://www.unitree.com/go2/)에서 이미지와 영상 주소를 확보했다. 영상 파일을 내려받아 시점을 이동한 뒤 브라우저에서 프레임을 캡처했다. AI로 후면을 추정하거나 보충하지 않았다. 원본 영상 전체의 모든 프레임을 검사한 것은 아니다.

## 다음 생성에서 고정할 것

1. 전면 세로 패널과 머리 아래 검은 LiDAR 하우징의 배치.
2. 낮고 긴 회색 몸체, 원형 관절 하우징과 가느다란 굽은 링크의 비율.
3. 다리 끝의 작은 검은 고무. 큰 신발이나 발굽처럼 부풀리지 않는다.
4. 후면 중앙 구조와 좌우 관절. 보이지 않는 내부 연결부는 발명하지 않는다.
5. 같은 개체의 표면색·패널 이음새·나사 위치·마모를 컷 사이에 유지한다.
6. 미세한 표면 거칠기와 젖은 부분의 국소 반사를 구분한다. 과한 HDR, 크롬, 플라스틱 광택을 피한다.

기존 생성 컷에서 특히 하부 LiDAR 누락·변형, 두꺼운 다리, 커진 발고무를 우선 교정한다. 그림의 연출 승인을 실제 기체 형상 검증 완료로 취급하지 않는다.

## 확인의 한계와 추가 모듈

`미확인` 공식 홍보 자료 속 각 개체의 세부 모델·촬영 당시 하드웨어 세대가 팀 보유 개체와 완전히 같은지는 확인하지 않았다. 페이지에 함께 있는 자료라도 사양과 외형 세부가 다를 수 있다. 영상의 동적 자세와 원근을 정투상 치수로 사용하지 않는다.

[팀 장비 기록](GO2-HARDWARE-REFERENCE.md)의 Orin NX 16GB, D435i, HESAI-360은 사용자 보유 확인이다. 실제 동시 장착 위치와 배선은 미확인이다. 공통 기본 기체 시트에 임의로 합성하지 않고 모듈 설명을 분리한다. 후면 프레임의 주변 센서 그래픽은 생성 참조에서 제외한다.

## Nano Banana Pro 생성 시도와 수정

사용자 요청에 따라 Higgsfield MCP에 `nano_banana_pro`, 4K, 공식 참조 4장을 넣고 다면 시트를 요청했다. 첫 결과는 **사용 제외**다. 몸통 위에 없는 머리를 추가하고 전면 센서를 중복했으며 다리 링크와 후면 구조를 바꿨다. 공식 형상과 맞지 않아 캐릭터 정본으로 사용하지 않는다.

수정은 공식 측면 보행 프레임 한 장을 넣고 자세·기체를 유지한 채 배경만 정리하는 요청으로 범위를 좁혔다. 이 후보도 공식 원본과 나란히 비교한 뒤 사용 여부를 결정한다. 정면·후면을 생성 모델에 한 번에 재구성하도록 맡기지 않는다.

요청과 작업 ID는 [생성 기록](assets/go2-reference/nanobanana-generation.json)에 남겼다. 요청 모델은 `nano_banana_pro`이지만 첫 완료 응답의 모델명은 `nano_banana_2`였다. 내부 별칭인지 대체 실행인지는 `미확인`이다. 모델명을 임의로 동일시하지 않는다.

두 번째 단일 측면 결과는 첫 시트보다 실제 Go2의 전체 윤곽에 가깝지만, 원본 픽셀 보존이나 완성된 다면 시트는 아니다. **미승인 후보**로만 보존한다. 사용자 비용 문제 제기 이후 추가 유료 생성을 중단했다. 두 건 전후 잔액은 5,000.5에서 4,992.5로 8크레딧 감소했다. 두 번째 요청은 [수정 요청 기록](assets/go2-reference/nanobanana-correction.json)에 남긴다.

가격 추가 조회: 같은 MCP의 `nano_banana_pro` 사전 견적은 2K 2크레딧, 4K 4크레딧이다. 두 실행에는 4K를 지정했다. 이후 사용자가 웹도 2K 2크레딧, 4K 4크레딧이라고 확인했다. 현재 비교한 조건의 가격은 같다. MCP 견적은 추가 비용 없이 estimate 도구로 확인했다.

사용자가 GPT Image 2.5 Sunburst로 제대로 된 캐릭터 시트를 한 번만 재요청하도록 승인했다. 이 요청은 배경 정리가 아니라 정면·측면·후면·사선 전신을 동일한 외형으로 구성하는 다면 시트다. [입력 자료와 복사용 프롬프트](GO2-SUNBURST-PROMPT.md)를 함께 기록한다. 이 지시는 Sunburst 한 건에 한하며 반복 생성을 승인한 것이 아니다.

## 추가 디테일 시트

사용자가 4방향 시트의 일관성을 긍정적으로 평가한 뒤 디테일 시트 한 장 추가를 승인했다. [추가 디테일](assets/go2-reference/go2-detail-sunburst-v1.png)은 발·하단 다리, 무릎, 상부 관절, 전면 센서의 근접 참조다. 공식 원본 3장으로 Sunburst 2K high 한 번만 생성했고 HTML에 4방향 시트 다음으로 배치했다. LiDAR 아래 끝은 생성 컷에서 잘려 있으므로 공식 근접 원본을 병용한다. 세부 치수 검증을 대신하지 않는다.
