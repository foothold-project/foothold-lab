## 2. 차단 문제와 최종 해제 판정

### B1. 12쪽 첫 클릭에서 여러 환경 영상과 ‘1개 환경’ 표기가 충돌: 최종본에서 해제

초반·중간 판정본에서는 미통과였다. 마지막 상태만 보면 놓치는 수치 의미의 오류였으며, 다음은 수정 전 재현 내용이다.

- 재현: 12쪽 초기 상태 → 다음 1회. 또는 12쪽 마지막 상태 → 이전 1회.
- 실제 상태: `data-current-step="1"`, `.env-counter`는 `1`, 영상은 재생 중이다. 여러 지형 칸과 로봇 무리가 동시에 보인다. `학습 설정 4,096개 · 화면은 600개 환경으로 렌더한 학습 시연` 문구는 `data-step="2"`여서 opacity 0이다.
- 이는 순간 전환만의 문제가 아니다. 발표자가 다음을 누르기 전까지 ‘1개 환경’ 표기가 계속 남는다. 역방향에서도 영상이 처음부터 재생되며 같은 문제가 재현됐다.
- `design/technical_scene.py`의 `army-caption`·`army-render-note`, `design/intro_story.js`의 `playArmy()`가 실제 동작과 일치한다. 영상 확대 배율 2.2는 한 로봇 또는 한 환경만을 선택한 카메라가 아니다.
- 최종 단계의 4,096과 600 구분은 정확하다. 그러나 영상이 시작되는 첫 단계에는 그 구분이 없어 U205의 ‘영상 600환경과 학습 4096 구분’을 전 구간에서 충족하지 못한다.

**해제 기준:** 영상이 보이는 순간부터 600개 렌더와 학습 설정의 의미를 함께 표시하고, ‘1개 환경’은 단일 로봇 설명 장면에서만 사용한다. 숫자 연출을 유지한다면 화면 속 개체 수와 학습 규모가 구별돼야 한다.

**최종 재검증:** 01:44:43 재빌드에서 `.army-render-note`가 `data-step="1"`로 바뀌고 단계 1의 숫자 제목은 숨겨졌다. 다음으로 진입한 경우와 마지막 단계에서 이전으로 돌아온 경우 모두 제목 `display:none`, 600개 설명 opacity 1, 영상 재생을 직접 확인했다. 단계 2에서는 4,096에 도달하고 설명도 계속 표시된다. 단계 1에서 PDF를 출력해도 4,096과 600이 함께 나와 인쇄 상태가 깨지지 않는다. **B1 통과·해제.**
