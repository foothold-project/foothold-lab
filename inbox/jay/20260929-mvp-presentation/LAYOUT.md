## 지금 확인할 것

첫 장부터 넘겨보며 이야기의 순서, 제목의 의미, 자료가 충분히 크게 보일 자리인지 확인한다. 이것은 내용과 자료를 모두 채운 완성 발표가 아니다. 사진·영상 자리에 어떤 증거가 들어갈지 적어 두었으며 임의의 로봇 영상이나 생성 이미지를 실험 결과로 넣지 않았다.

NVIDIA에서 현재 모델까지의 발전을 하나의 프로젝트 성과로 설명한다. v1은 중간 결과다. 전체 성과와 특정 설정 하나의 인과 효과를 구분한다는 원칙이 각 버전을 별개의 완성품이나 별개 연구 성과로 분리하라는 뜻은 아니다.

검토 메모에는 화면의 핵심, 필요한 자료·조건, 다음 장면으로 이어지는 말을 넣었다. 세부 실험 기록을 발표 화면 전체에 늘어놓지 않았다.

## 조작

| 키 | 기능 |
|---|---|
| 오른쪽·아래 화살표, Space, PageDown, Enter | 다음 화면 |
| 왼쪽·위 화살표, PageUp, Backspace | 이전 화면 |
| Home / End | 처음 / 마지막 |
| 숫자 입력 후 Enter | 해당 번호로 이동 |
| G | 전체보기와 원하는 화면 선택 |
| N | 검토 메모 |
| F | 전체화면 |
| B | 검은 화면으로 가리기 |
| Escape | 메모·전체보기·가림 닫기 |

화면 오른쪽 가장자리를 누르면 다음, 왼쪽 가장자리를 누르면 이전으로 이동한다. 하단 구간을 누르면 해당 구간으로 이동한다. 자동 넘김은 없다. 동작 줄이기 설정에서는 진입 애니메이션을 끈다.

## 확인한 범위

`확인됨`: Chrome headless에서 34개 화면을 렌더하고 모아보기 이미지를 검토했다. 제목·본문·도식의 영역 넘침 검사에서 문제를 발견하지 않았다. 실행 중 JavaScript 오류는 없었다. 기본 이동, 전체보기 선택, 메모, 가림, 번호 이동, 전체화면과 동작 줄이기 설정을 확인했다. 1280×720, 1920×1080, 1024×768, 390×844에서 화면이 뷰포트 안에 맞게 배치되는 것도 확인했다. 작은 휴대전화 화면에서의 발표 가독성까지 보장하는 것은 아니다.

실제 영상·사진의 가독성과 재생은 아직 검증하지 않았다. 자료를 채운 뒤 해당 화면만 다시 확인한다. 발표 시간은 미확정이다. 문서의 장수만으로 발표 시간을 보장하지 않는다. 별도 Astra 검증을 자동 실행하지 않았다.
