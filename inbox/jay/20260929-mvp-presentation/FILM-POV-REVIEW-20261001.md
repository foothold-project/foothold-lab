이슈 #490. 작성 보조 Codex. 표본 프레임 검사는 전체 프레임의 오류 부재나 음향 청취 검증을 뜻하지 않는다.

## O1과 O2

확정 의도: 완전 블랙에서 먼 빨간 점이 두 번 깜빡인다. 카메라 쪽에서 앞으로 비추는 이동광이 기둥, 부서진 바닥, 틈과 물을 훑는다. 빛이 닿는 부분만 드러나며 천장이나 공간 전체 조명이 켜지지 않는다. 시선과 광축이 가까운 바닥으로 내려가 O2로 이어진다. 손전등 물체나 손은 등장하지 않는다.

`확인됨` O1 v2 0.05초에는 벽 윤곽이 이미 보인다. 1.5~4.8초 광선은 왼쪽 기둥 뒤에서 사선으로 들어오는 모양이다. 카메라 방향에서 비추는 광원과 다르다. O1 v2 자체는 끝까지 원경이다. 요청 준수 판정은 불합격이다.

`확인됨` O1b 연결 후보는 약 2초부터 시선을 아래로 옮기고 3.5초 이후 O2의 자갈 바닥 구도로 이어진다. 연결 동작은 확보했으나 앞부분 측면 광원이 그대로여서 O1 오류까지 해결한 것은 아니다. 두 컷을 최종 완성으로 표시하지 않는다.

## O5

v2 job `7e85eabf-688d-43d7-8684-391b9e4a2cb3` 제외. 사람 신발형 사지가 좌측에 나타나 센서 POV에 어긋난다. 편집 코드에서 해당 파일 사용을 차단한다.

v3 job `2fb8f0fd-d1eb-441c-a2ff-1f3bcc3f933a`. 승인된 몸체 없는 HUD 이미지로 Seedance 2.5 5초·480p·음향 포함 생성. 견적 15크레딧. 프롬프트 첫 문단에서 몸체·다리·발·사람·장비 프레임 진입을 금지하고, 캐릭터 재질을 나열하던 공통 문구를 빼 화면에 실제 존재하는 지형만 설명했다.

`확인됨` 0.05~4.8초 10개 표본 프레임에서 사람·로봇 신체가 보이지 않는다. HUD 수치와 지형 스캔 변화는 있으나 지시한 VX 감속 순서를 정확히 지켰다고 볼 수 없다. 몸체 생성 오류 수정 후보이며 최종 UI 승인본은 아니다.

## E5pre

Kling job `041a40ba-ffb6-4a9b-a7da-418372393e4b` 제외. 약 1초부터 다리가 등장하고 후반은 로봇을 뒤에서 보는 장면이 된다. 사용자도 걸음과 발소리 불일치를 지적했다. 기존 프롬프트의 no visible robot body 문장만으로 결과가 지켜지지 않았으며, 검수 없이 연결 후보로 전달하면 안 된다.

수정은 원래 승인한 빈 지형 이미지와 앞 컷 E4에서 추출한 음원을 별도 참조로 사용한다. E4 영상 외형을 참조에 섞지 않는다. 첫 시점부터 끝까지 보행 카메라 POV만 유지하고 턱 직전에서 정지한다. 지형 스캔은 표면에 부착한다. 실제 음원 참조는 `567dae6b-c111-4e54-a0c6-80a241851d0f`이며 E4 원음 5초 추출본이다. 별도 녹음이나 실제 로봇 실측 음원으로 주장하지 않는다.

수정 job `169314ee-3d67-473d-afef-f44476099e72`, Seedance 2.5 5초·480p·음향 포함, 견적 15크레딧. 생성 결과의 발소리가 참조와 정확히 일치한다고 보장하지 않는다. 연결 편집에서도 공통 발소리와 접지 간격을 맞춰야 한다.

`확인됨` 수정본 생성 후 0.05~4.8초 10개 표본 프레임에서 외부 로봇·사지 없이 카메라가 턱에 접근한다. 약 2~3초의 스캔은 짧은 선 형태로 나타난다. 조밀한 표면 점군이나 앞뒤 발소리 일치까지 검증 완료한 것은 아니다. 같은 스토리보드 E5pre 아래에 수정본 재생 버튼을 연결했다.

## 전체 진행 상태

O2·O3·O3b·O4·O6, E3·E4·E5·E5b·E6 영상 초안 파일이 있다. 일부는 생성 후 HTML 재생 버튼 반영이 누락돼 있었으며 이번에 연결했다. O7·E2와 두 컷 연결 편집은 기존 결과다. O1 광원 오류, O5 수치, E5pre 스캔·박자 연결은 남았다. E7 생성은 실패했고 대체 편집은 아직 렌더하지 않았다. 전체 연결본, Opening, Ending, 통합 사운드와 1080p는 미완료다. 이 상태를 스토리보드 상단에도 명시했다.
