## 장비 구성과 확인 범위

| 구분 | 구성 | 근거와 상태 |
|---|---|---|
| 기본 기체 | Go2 EDU | 기존 팀 장비 기록 |
| 기본 LiDAR | 4D LiDAR L2 | 제공 이미지에 L2 표기를 직접 확인. 사용자가 실제 기체와 같은 이미지라고 답함. 실물 개체 직접 검사는 아님 |
| 기본 카메라 | 전면 카메라 | 제공 이미지에 Front camera 표기를 직접 확인. 추가 D435i와 구분 |
| 추가 컴퓨팅 모듈 | Orin NX 16GB | 사용자 보유 확인. 영상은 Orin Nano 8GB와 NX 16GB 선택 사양을 함께 소개 |
| 추가 깊이 카메라 | Depth Camera D435i | 사용자 보유 확인 및 영상 표기 확인 |
| 추가 LiDAR | HESAI-360 | 사용자 보유 확인 및 영상의 3D Navigation Radar HESAI-360 표기 확인. 제조사 세부 제품 식별자는 미확인 |

추가 보유는 현재 장착, 통신 연동, 정책 입력 연결 또는 실기 평가 완료와 같은 뜻이 아니다. 이 상태들은 미확인이다. 이미지의 발 센서 표기만으로 현재 actor가 발바닥 접촉 센서 값을 직접 입력받는다고 설명하지 않는다.

## 영상 직접 확인

[사용자 제공 모듈 영상](go2_module.mp4)은 1280×720, 약 7.01초다. PyAV로 영상 전반의 주요 시점 프레임을 추출하여 확인했다. 모든 프레임을 검사한 것은 아니다.

| 대략적 시점 | 보이는 내용 | 발표에서의 활용 |
|---|---|---|
| 0.5~1초 | 상부 컴퓨팅 모듈과 Orin 선택 사양 | 팀 보유 NX 16GB만 강조. 영상의 최대 연산량을 팀 설정 실측값으로 사용하지 않음 |
| 1.5~2초 | Depth Camera D435i | 기본 전면 카메라와 별도 모듈임을 표시 |
| 2.5~3초 | MID-360 | 영상의 다른 선택 사양. 팀 보유로 기록하지 않음 |
| 약 4초 | HESAI-360 | 사용자 확인 구성에 해당하는 장면 |
| 4.5~5.5초 | 소형 로봇 팔 | 팀 보유로 기록하지 않음 |
| 약 6.5초 | 충전 장치 | 팀 보유로 기록하지 않음 |

제공 제품 이미지는 이번 답변의 첨부 자료이며 원본은 로컬 임시 경로에 있다. 영상 자체는 위 상대 경로로 보존되어 있다. 영상의 재사용 허용 범위는 별도 확인되지 않았다.

## 장면 반영

동일한 Go2의 위치와 시점을 유지하고 클릭에 맞춰 기본 센서, 추가 컴퓨팅 모듈, 추가 센서를 순차 강조한다. 부품을 한꺼번에 펼쳐 복잡하게 만들지 않는다. 사용자 영상의 모듈 교체 방식은 이 연출의 참고 자료로 삼는다.

그다음 같은 자세의 시뮬레이션 기체로 전환해 187개 height scan, 나머지 48개 입력, actor, 12개 관절 위치 목표를 설명한다. 현재 시뮬레이션의 height scan은 ray casting으로 얻는다. 실제 D435i 또는 HESAI-360 데이터를 현재 정책에 연결했다고 표현하지 않는다. critic과 학습 갱신은 실행 경로와 구분한다.
