## 현재 기준

`확인됨` [공식 캐릭터 시트](output/FOOTHOLD-Go2-character-sheet.html)에 정면·측면·후면과 원본 출처를 모았다. 기존 스토리보드는 연출 확인용이다. 영상 생성, 실제 데이터 연동, 통합 음향 제작은 아직 완료하지 않았다.

|---|---|---|

| 4 | 나머지 컷 생성과 임시 편집 | O7·E1 발걸음은 같은 소스에서 분리하는 방식을 우선. 컷마다 생성된 소리를 보존하며 전체 연결 확인. 실패한 컷만 수정 |

## 영상 제출 시 빠뜨리지 않을 조건

- O1은 블랙에서 시작해 움직이는 빛으로 위험한 공간을 부분적으로 드러낸다. 손전등 물체는 등장시키지 않는다. 원경에서 바로 바닥 접사로 뛰지 않고 시선이 내려가는 동작 또는 짧은 중간 컷으로 연결한다.
- E2는 고정된 빛과 어두운 뒤 공간을 유지한다. Go2가 뒤에서 앞으로 걸어 나오며 드러난다. 탐색광으로 기체를 찾아내는 장면으로 바꾸지 않는다.
- E5pre는 카메라 뒤에서 위를 지나 앞으로 걷는다. 발을 렌즈 양옆에 억지로 맞추지 않는다. 턱을 오른 뒤 한두 걸음 이동하고 앉기 직전에 잘라 E5b 정면의 앉는 동작으로 연결한다.
- E5b는 조금 높은 정면 원경. 앞다리는 지지하고 뒷다리가 접히며 앉는다. 현재 시안은 비교 이미지에서 우선 개선한다.
- 빨간 경광등은 느린 점멸, 물방울은 국소 파문, 연무는 낮고 드물게. 돌가루는 발 접촉에 반응하는 소량의 부스러기로 표현한다.
- 각 초안은 `generate_audio=true`를 명시하고 결과에 소리가 실제 포함됐는지 확인한다. 컷별 독립 배경음악은 요청하지 않고 현장음·동작음을 우선한다.
- HUD 수치는 실측 로그가 연결되기 전까지 콘셉트 데이터로 관리한다. scan과 CV 연출은 실제 MVP의 구현·성능 증거가 아니다.
- 사운드는 이미지와 같은 비중으로 제작한다. 요청한 영화들의 무게감과 긴장 전개를 참고하되 기존 곡을 복제하지 않는 독자적인 무가사 음향으로 구성한다.

모델 명칭·해상도·길이·가격은 실행 시 Higgsfield 제공 옵션을 다시 확인한다. 이미지 비교와 저해상도 초안을 통과한 뒤 고해상도 제작에 들어간다. 지금 단계에서 전체 컷을 한 번에 고해상도로 생성하지 않는다.
