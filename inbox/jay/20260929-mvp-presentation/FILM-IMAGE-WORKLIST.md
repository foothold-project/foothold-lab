## 제출 전 대조 항목

각 컷마다 다음 항목을 실제 request.json과 첨부 목록에서 확인한다. 문안 작성만으로 통과 처리하지 않는다.

- 장면 참조는 해당 컷의 보존 원화인가. 캐릭터 시트는 외형 참조로만 지정했는가.
- 카메라 높이·시점·거리, 로봇 위치·크기, 좁은 경로와 불규칙한 틈을 바꾸지 않았는가.
- 앞 컷의 진행 방향, 다음 컷의 목표 위치·발 접촉·동작 연결을 설명했는가.
- 원화의 형상 보존과 원화의 HDR 재현을 구분했는가. 조명 고정과 재질 변경 지시가 충돌하지 않는가.
- 콘크리트는 거칠고 다공성, 녹은 둔한 반사, 외장은 부드러운 도장 반사, 발고무는 무광인가.
- 마른 면·축축한 면·물웅덩이가 불균일한가. 물을 없애거나 화면 전체 명도만 낮추지 않는가.
- 과한 국부 대비·선명도·윤곽 강조·하얀 점 반사·채도 과장을 제한했는가.
- 영상에서는 현장음 포함, 물방울·옅은 연무·접촉 부스러기·느린 목표등 점멸을 맥락에 맞게 요청했는가.

## 확인된 수정과 한계

`확인됨` 직접 이미지 열람: v3는 v2보다 콘크리트 전면의 하얀 반사와 로봇의 광택이 줄었다. E3는 바닥과 배관의 강한 반사가 일부 남는다. E4는 대비가 줄었으나 틈의 형상과 다리 지지 자세를 원화와 계속 비교해야 한다. 정확한 3D 공간 일치나 보행 역학은 검증하지 않았다.

`확인됨` 브라우저에서 E3·E4의 현재 이미지가 각각 ending-e3-sunburst-v3.png, ending-e4-sunburst-v3.png임을 확인했다. 바로 아래 원화 버튼을 누르면 ending-storyboard-v2.png의 해당 패널로 바뀌고, 현재 시안 버튼으로 돌아온다. JavaScript 오류 0건.

반영 지연: v3 생성 후 HTML에는 잠시 v2가 남아 있었다. 사용자의 질문 뒤 실제 표시 버전을 확인하고 수정했다. 이후 생성 완료만으로 화면 반영 완료라고 보고하지 않는다.

## 사용자 최신 결정

구도·지형은 전체 이야기와 컷 연결을 더 좋게 만든다면 개선해도 된다. 원화는 비교 기준이며 절대적인 복제 목표가 아니다. 동작은 이미 정해둔 핵심을 유지한다. 생성 결과의 완성도로 판단한다.

## E5b 공간 재구성 · 우선 수정

E3의 좁은 중앙 경로와 양옆 수면이 E5b의 넓은 반복 단차 배경으로 바뀌어 공간이 연결되지 않는다. 서 있는 후보도 같은 문제다. 현재 두 후보는 외형뿐 아니라 배경도 수정 대상이다. 기존 E5b 원화를 공간 정본으로 유지하지 않는다. E3의 전체 경로와 E5의 도착 턱을 하나의 배치로 묶고, 목표에서 출발 방향을 돌아보는 시점으로 구성한다. 그 배경 위에서 두 자세를 만든다. 검토 기록: USER-REQUIREMENTS-LOG.md U167.
