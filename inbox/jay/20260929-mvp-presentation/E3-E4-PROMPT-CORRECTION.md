> 요지: 배경 재설계를 중단하고 기존 승인 원화의 구도·지형·물을 보존한다.

## 실제 오류

원래 v2 문안에도 reachable short 15-25cm gaps와 modest steps가 있었다. 따라서 25cm라는 개념 자체를 이번에 처음 추가했다고 한 앞선 설명은 정확하지 않다. 실제 변경 오류는 승인 원화를 직접 참조하지 않고 새 E2를 공간 기준으로 삼은 것, 넓고 충분한 지지면·거의 같은 높이의 대응 발판을 구체적으로 강제한 것, 그 결과인 새 E3를 다시 E4 공간 기준으로 사용한 것이다. 원화가 갖고 있던 수면·좁고 불규칙한 길·거칠게 깨진 틈을 보존하지 못했다.

기존 프롬프트는 덮어쓰지 않는다. 기존 원화의 형태와 구도가 시각적 정본이며, 전체 장면을 다시 설명해 만드는 방식 대신 변경할 부분만 지정한다.

| 유지 | 변경 허용 |
|---|---|
| 기존 E3·E4 카메라·원근·로봇 위치와 크기 | Go2 외형을 승인 캐릭터·공식 자료에 맞춤 |
| 수면, 국소 반사, 어둠과 빛의 위치 | 과한 HDR·플라스틱 광택만 절제 |
| 발판 윤곽·높이·불규칙한 너비·틈의 거친 단면 | 회색 도장·관절·작은 발고무 재질 정렬 |
| 원래 접지 위치와 통과 자세 | 접지와 형상이 충돌하면 지형을 임의로 바꾸지 않고 검토 대상으로 남김 |

수정 문안: [E3](assets/ending-e3-v2-edit-proposal.prompt.txt), [E4](assets/ending-e4-v2-edit-proposal.prompt.txt). 두 문안 모두 기존 ending-storyboard-v2의 해당 패널을 직접 장면 참조로 지정한다. v1 실패 시안을 배경 정본으로 재사용하지 않는다. 실제 모델 제출 JSON과 참조 첨부는 아직 만들지 않았고, 추가 크레딧을 사용하지 않았다.


## 후속 실행

v2·v3 실제 제출과 결과는 [작업 목록](FILM-IMAGE-WORKLIST.md)에 기록했다. v2는 HDR 지적으로 미채택. 현재 HTML에는 재질 수정 v3를 반영했으며 사용자 승인 전이다. 위의 미실행 기록은 요청 준비 당시의 상태다.
