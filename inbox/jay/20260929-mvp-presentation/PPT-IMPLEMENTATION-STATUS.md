## U202 이전 수정 이력

`확인됨` 과거 섹션 분류를 그대로 화면으로 만들면서 최신 장면 설계를 지키지 못했다. 연구 질문과 Track 설명이 목차와 Go2 소개 사이를 끊었다. 제목과 항목을 넣는 것으로 이야기와 연출을 구현했다고 볼 수 없다.

- 목차 직후 Go2 소개, 센서, 시뮬 관측, actor, 관절 목표와 보행, critic과 학습, 4096 환경, 실패 진단 순서로 연결했다.
- 관절 목표가 보행으로 돌아오는 실제 평가 영상을 추가했다. 관절별 출력 값과 동기화된 시각화는 아니다.
- 다섯 레시피는 gap·rails·stepping_stones·pit·floating_ring 실제 지형 사진으로 제시한다. 이 사진을 최초 실패 실험 영상이라고 주장하지 않는다.
- v1 문제 설명 중 v2 해결 장면을 먼저 보여주던 연구 질문 페이지를 제거했다.
- Track 설명은 보행 결과와 한계 뒤, 현장으로 이어갈 다음 과제 앞에 배치했다.
- 발표자 메모는 앞 장의 결과에서 다음 질문으로 연결하도록 수정했다. 멘트만으로 아래의 시각 연출 미구현을 대신했다고 보지 않는다.

본문의 근거와 배치는 design/evidence_layouts.py에서 화면별로 구성한다. 원자료 재집계 결과는 PPT-EVIDENCE-AUDIT.json에 남긴다. 최초10종 집계·생존/전진/추종의 차이·gap 선택과 미검출 처리·학습 비중·명령 변경·보상 비교·지형별 최종 결과를 본문에서 확인하도록 바꿨다. 소방 공식 공고 발췌와 실제 Twin 실행도 연결했다. 이 조치를 영화적 연속 장면과3D 시각화의 구현 완료 또는 공식 발표 최종 승인으로 간주하지 않는다.
