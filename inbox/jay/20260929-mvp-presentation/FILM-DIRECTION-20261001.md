> 요지: 암전의 빨간 점으로 시작하고, 보행 POV에서 턱을 스캔한 뒤 외부 시점의 오르기로 연결한다.

이 문서는 이전의 충돌하는 연출 설명보다 우선한다. `확인됨`은 대화의 승인과 정지 이미지 열람 범위이며, 영상 동작·센서 실측의 확인을 뜻하지 않는다.

## O1 · 완전한 블랙에서 공간을 발견한다

완전한 블랙에 아주 먼 빨간 경광등 점만 작게 두 번 깜빡인다. 이후 화면 밖에서 움직이는 빛이 바닥과 기둥을 훑고, 빛이 닿는 부분에만 끊긴 발판·틈·수면이 드러난다. 천장 조명이 켜지거나 방 전체 노출이 올라가는 방식으로 대신하지 않는다. 실제 손전등 물체를 화면에 넣지 않는다.

빛과 시선이 가까운 발밑으로 내려오는 움직임을 O2의 바닥 관찰로 이어 원경에서 근경으로 갑자기 뛰지 않게 한다. 두 번 점멸의 정확한 간격과 컷 길이는 영상 편집에서 조절하며 불필요하게 오프닝을 늘리지 않는다. O1 v2는 이동광 중간 상태의 조명 참고이며 첫 프레임이 아니다.

사용자가 승인한 `terrain-question-bright-v1.png`는 별도의 밝은 원경이다. 오프닝 다음 발표에서 “이런 험지에서는 어떤 로봇으로 주행하는 것이 좋을까요?”라는 질문에 사용한다. 영상 첫 화면에 밝은 이미지를 그대로 넣지 않는다.

## E5pre · 보행 POV로 확정

사용자가 기존 바닥 고정 카메라 위를 지나가는 안 대신 보행 POV를 선택했다. 기존 이미지와 문안은 대안 기록으로만 보존한다.

1. E4에서 틈을 건넌 직후, Go2의 전방 시점으로 전환한다. 기존 E5pre 원화의 카메라보다 조금 뒤에서 접근을 시작한다.
2. 몸에 달린 카메라처럼 작은 상하·좌우 보행 움직임과 함께 목표 설비 쪽으로 전진한다. 사람의 머리 높이나 바닥에 놓인 외부 카메라로 바뀌지 않는다.
3. 마지막 낮은 턱이 가까워지면 LiDAR를 연상시키는 점군·스캔이 가까운 바닥에서 턱의 앞면과 윗면으로 이어져 높이 차를 드러낸다. 가까운 면부터 먼 면으로 읽히고 지형 표면에 붙어야 한다. 빈 틈을 면으로 메우거나 벽을 관통하지 않는다.
4. 턱 바로 앞까지 접근해 높이와 디딜 윗면이 읽히는 순간 컷한다. 이 컷에서 턱을 오르지 않는다. 거대한 임무 패널이나 전송 UI로 지형을 가리지 않는다.
5. 다음 E5는 외부 후면 시점이다. 같은 턱·목표·진행축을 유지하며 앞발을 올리고 뒷발로 밀어 오른다. 직전 POV의 접근 속도와 착지 리듬을 잇고 위치가 순간 이동하지 않게 한다.

스캔은 영상의 관측 콘셉트다. 실제 Go2 LiDAR 로그, 정확한 광선 개수 또는 actor의 187차원 height scan을 그대로 재현했다는 표기를 하지 않는다. O6의 height scan과 동일 센서 출력이라고 단정하지 않는다.

E5pre는 연출 확정이며 새 POV 시작 이미지 후보는 생성되었다. 스캔 끝 프레임과 영상은 아직 제작 전이다. 기존 바닥 카메라 이미지를 새 POV 결과라고 표시하지 않는다.

## E5b · 원래 구도에서 뒤 중앙 영역만 수정

위치 이동 v2·v3·v4는 최종 채택하지 않는다. 원래 서 있는 그림의 로봇 위치·크기·포즈·카메라·전경 발판을 보존하고, 사용자가 보라색으로 표시한 뒤 중앙 영역만 불규칙한 좁은 접근로로 수정했다. 서 있는 `ending-e5b-standing-region-v1.png`는 사용자 승인이다.

앉는 끝 프레임은 승인한 서 있는 이미지를 정본으로 사용한다. 배경과 로봇 위치를 유지하고 앞다리는 지지한 채 뒷다리를 접어 앉는 포즈만 바꾼다. `ending-e5b-seated-region-v1.png`도 사용자 승인됐다. 서 있음·앉음 한 쌍의 정지 이미지 승인이며 E5b 영상 v1이 생성되었으며 영상 승인은 별도다.

## HUD · 이미지 6장 승인

| 상태 | 이미지 | 전달 내용 |
|---|---|---|
| O4 | hud-mission-sunburst-v2.png | 블랙 위 임무 수신, 접근·촬영·전송 |
| O5 | hud-observe-sunburst-v2.png | 원경 지형과 자세·명령·반응 |
| O6 | hud-scan-sunburst-v2.png | 근거리 표면 scan만 |
| E6 | hud-record-sunburst-v2.png | 목표 설비·경광등 CV 박스와 촬영 |
| E7 전송 | hud-transfer-sunburst-v2.png | 전송 진행과 수신 대기 |
| E7 완료 | hud-complete-sunburst-v2.png | 붉은 100%·MISSION COMPLETE·수신 확인 |

사용자는 v1의 배치·내용 승인 뒤 과한 대비와 HDR 재질을 다시 지적했고 6장 전체 수정을 요청했다. 대비·재질 수정 v2 생성 후 “HUD 모두 승인 반영해”라고 승인했다. 영상 입력은 v2를 사용한다. 숫자는 연출용 예시다. 일정한 명령은 유지할 수 있고, 몸 상태·추정 속도와 수평계는 보행에 반응해야 한다. 영상은 통합 이미지와 각 요소의 동작 관계를 Higgsfield에 전달해 생성한다. 정지 HUD를 움직이는 영상 위에 붙인 것으로 완료 처리하지 않는다.

정지 이미지에서 확인한 후속 점검 항목: O6 메시 밀도, 빈 공간 부근 일부 점의 부착, E6에서 E7로 이어지는 설비 위치, 완료 시 배경까지 붉게 바뀌는 전환. 승인된 이미지를 임의로 재생성하지 않고 영상 연결에서 확인한다.

각 생성 영상의 기본 음향을 함께 받는다. 최종 공간음·발소리·효과음·가사 없는 무게감 있는 음악은 전체 영상의 흐름을 기준으로 별도 구성·믹싱한다. 오프닝과 엔딩의 발걸음 전환 리듬을 보존한다.

## 영상 제작 착수

사용자의 영상 진행 지시에 따라 E5b 서 있음·앉음과 O5 관측을 각각 Seedance 2.5, 5초, 480p, 음향 포함으로 제출한다. 컷별 사전 견적은 15크레딧이다. 두 영상의 동작 확인과 사용자 최종 승인은 별개다. E5pre POV 시작 이미지는 생성 중이며 다음 턱 앞 스캔 프레임과 함께 확인 후 영상화한다.


## 제작 결과 반영

O5 영상 `d2cebc3a-a8f5-443a-ad36-4ffec586ca73`, E5b 영상 `6715a7eb-c9d0-458c-bfdb-5b0fdf387a33` 생성 완료. 각각 5초·480p·음향 포함으로 요청했고 견적은 15크레딧이다. 영상 승인 전으로 스토리보드 각 컷 아래에 연결했다. E5pre 시작 이미지 후보 `6af8dc4d-6188-488d-b067-39adddcaadb4`도 다운로드했으며 별도 승인 전이다.

영상 샘플 확인: 시작·중간·끝 프레임을 추출해 보았다. E5b는 서 있음에서 앉음으로 변한다. O5는 2.5초와 4.8초에서 VX CMD 0.30·STATE 0.28이 동일해 요청한 감속 수치 변화가 반영되지 않았다. O5 영상은 수정 대상이며 승인된 HUD 이미지와 구분한다. 두 파일 모두 브라우저에서 약 5초, 854×480 및 오디오 디코딩을 확인했다. 음질 청취 평가는 하지 않았다.


## 최종 영상 전달 위치 · 사용자 확정

영상 제작 완료 후 `output/FOOTHOLD-film-storyboard.html`의 맨 위 본문에 전체 연결본, Opening 분리본, Ending 분리본을 모두 넣는다. 새 HTML로 분산하지 않는다. 전체 연결본을 가장 먼저 크게 두고 Opening·Ending은 바로 아래에서 각각 재생한다. 세 파일 모두 재생·음향·탐색·전체화면을 지원하고 실제 출력 길이를 표시한다. 개별 컷의 기존 재생·원화 비교 버튼은 유지한다.

전체 연결본은 발표 본문 대기 시간을 넣지 않은 연속 마스터다. 동일한 편집 타임라인에서 Opening과 Ending을 분리하며, 발걸음에서 블랙으로 이어지는 분할점의 동작·돌가루·소리 여운을 보존한다. 무심코 같은 동작을 반복하거나 프레임·소리를 누락하지 않도록 연결본과 분리본을 대조한다. 최종 사운드 미완료 시 임시 음향임을 표시한다. Q&A는 별도 슬라이드로 유지한다.

현재 페이지 상단에 세 결과의 위치와 제작 중 상태를 마련했다. 실제 전체 연결본·분리본은 아직 완성되지 않았으므로 재생 파일을 연결하지 않았다.
