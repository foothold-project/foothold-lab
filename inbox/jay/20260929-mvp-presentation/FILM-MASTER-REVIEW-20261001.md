## 산출물

`확인됨` 기존 [스토리보드](output/FOOTHOLD-film-storyboard.html) 상단에 전체 69.5초, Opening 31.125초, Ending 38.375초를 넣었다. 모두 854×480, 24fps이며 오디오 트랙이 있다. 전체본의 암전 프레임에서 분리했다. 개별 컷 아래 버튼도 같은 통합본의 해당 시간으로 연결한다.

제작 순서는 화면 전체 렌더, 전체 타임라인 음향 구성, 통합본 출력, 두 구간 분리다. [편집 계획](assets/film-master-v1.plan.json), [편집 소스](assets/film-master-v1.jsx), [사운드 소스](design/build-film-sound-v1.py), [출력 주소](assets/film-master-v1.outputs.json)를 보존했다. 편집 프로젝트 압축본은 출력 주소의 zip 링크에 있으며 대용량이므로 git에 넣지 않았다.

## 바뀐 구간과 제작 방식

- O1: v3 생성 영상이 기둥에서 바닥으로 내려본다. 주변까지 밝아지는 문제를 이동광 범위 마스크로 제한했다. 시작 블랙과 작은 적색 두 번 점멸을 직접 구성했다. 7.95초와 O2 시작 8.05초를 표본 비교했다. 카메라 이동은 생성 영상이며 조명 보정은 편집이다.
- O5: 사람 발이 나온 v2는 제외했다. 몸체 없는 v3를 사용하고 명령·추정 속도 여섯 칸을 감속 순서에 맞게 교체했다. 이는 시나리오 예시이며 실제 로그와 동기화한 수치가 아니다.
- E5pre: O6 스캔 영상을 참조한 v3를 사용했다. 접지 시점에 맞춰 상하 충격·롤과 E4 생성 발소리를 추가했다. 실제 Go2 계측 진동으로 주장하지 않는다.
- E7: 두 번의 생성 요청이 ip_detected로 실패했다. 차단의 세부 원인은 미확인이다. 승인된 두 이미지에 전송률·전송 막대·적색 완료·화면 신호 끊김·블랙을 직접 편집했다. 숫자 겹침이 있던 첫 독립 렌더 대신 수정한 통합본을 재생한다.

## 사운드

개별 생성 영상의 효과음을 보존하고, 하나의 공간음·비가사 합성 저음 배경·임무 신호·완료 효과를 전체 타임라인에 구성했다. E5pre의 접지음은 E4 생성 음원의 발소리 후보를 재사용했다. 실물 로봇 녹음이 아니다. 특정 영화의 음원을 복제하거나 사용하지 않았다.

`확인됨` 출력 파일 측정은 통합 음량 -17.51 LUFS, true peak -0.78 dBTP, 음량 범위 3.3 LU다. 측정은 청취 평가를 대신하지 않는다. 현재 1차 믹스이며 사용자의 실제 재생 환경에서 음색·긴장감·걸음 박자를 평가한 최종 믹스는 아니다.

## 확인과 남은 단계

브라우저 페이지 오류 0건, 상단 세 영상 메타데이터 로드, 모든 컷 버튼 및 E7 64.5초 구간 진입을 확인했다. [검사 기록](assets/film-master-v1.qa.json)과 [경계 프레임](output/film-master-boundaries-v1.jpg)을 남겼다. 표본 검사로 생성 영상의 모든 프레임과 물리적 보행을 보증하지 않는다.

다음은 사용자의 480p 영상·음향 검토와 수정 범위 확정, 이어서 승인된 방식의 1080p 출력 및 최종 믹스다. PPT는 사용자의 대기 지시를 유지한다.
