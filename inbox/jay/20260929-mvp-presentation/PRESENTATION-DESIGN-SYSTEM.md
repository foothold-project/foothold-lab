## 1. 브랜드를 참고한 MVP 발표용 변형

`확인됨`: 로컬 foothold-brand HEAD `582bad0`의 `BRAND_BIBLE.md`, `VOICE_AND_MESSAGE.md`, `tokens/foothold.tokens.json`, 로고 정본을 읽었다. 사용자는 브랜드 정본을 확인하되 모든 원칙을 그대로 도입할 필요는 없고 MVP에 맞게 변형해도 된다고 명시했다. FOOTHOLD의 인상을 유지하면서 이번 발표에 맞는 시각적 변형을 허용한다. 해당 저장소는 변경하지 않는다. [브랜드 정본](https://github.com/foothold-project/foothold-brand)의 색과 로고를 출발점으로 삼고, 아래 크기·배치·표현은 발표용 기준안으로 정의한다. 기존 웹 문서의 폭을 발표 화면에 그대로 옮기지 않는다.

- 브랜드 토큰 원문 사본: [brand-tokens.snapshot.json](design/brand-tokens.snapshot.json). 발표의 별도 색 정본이 아니다.
- 발표 공통 스타일: [presentation.css](design/presentation.css). 표지와 다음 화면에서 함께 사용한다.
- 브랜드 로고: `assets/foothold-lockup-compact-dark.svg`. 심볼과 글자의 정본 비율을 유지한다.
- 기존 lab의 compact 로고와 브랜드 정본은 바이트가 달라, 이번 표지는 브랜드 정본을 그대로 복사해 사용한다. 별도 글꼴로 로고를 다시 만들지 않는다.

## 반드시 유지할 요소와 변형 범위

사용자 최종 지시: “다만, 로고 형태 및 아이콘, 슬라이드 각도, 폰트 느낌 등은 지켜. 그리고 우리 브랜드 슬로건, 등도 변하면 안됨.” 이전의 변형 허용은 아래 고정 요소를 변경할 권한이 아니다.

| 고정 요소 | 적용 |
|---|---|
| 로고·아이콘 | 브랜드 정본 SVG의 형상·비율·조합 유지. 원본 파일을 사용하고 재생성하거나 늘이지 않음 |
| 기울기·각도 | 워드마크의 기존 전방 기울기는 SVG 그대로 유지. concept 문서의 3도는 워드마크에 대한 설명이며 모든 슬라이드나 텍스트를 3도로 기울이라는 뜻으로 확대하지 않음. 기존 브랜드의 사선 표현을 사용할 때 해당 원본 기준을 유지 |
| 폰트 느낌 | Pretendard 중심의 기술적 산세리프, 로고는 아웃라인 원본. 다른 장식 글꼴로 교체하지 않음 |
| 영어 슬로건 | Find the next foothold. |
| 한국어 슬로건 | 불확실한 지형에서도, 다음 걸음을 이어갑니다. |
| 목표 비전 | 시뮬레이터에서 천 번 넘어지고, 현장에서는 넘어지지 않는다. 사용 시 TARGET VISION 표시 유지 |

변형 가능한 것은 정보 배치·크기 위계·장면 구성·사진과 영상의 사용·전환 연출이다. 프로젝트 제목과 공식 슬로건은 서로 다른 역할이다. 모든 슬라이드에 슬로건을 반복할 필요는 없지만 사용할 때 문구를 바꾸지 않는다.

## 2. 전체 화면의 문법

| 장면 | 바탕·구성 | 일정하게 유지할 것 |
|---|---|---|
| 표지·오프닝·엔딩 | 어두운 이미지, 큰 제목, 적은 문구 | 동일 Go2와 공간의 연속성, 공식 로고, 흰 제목과 청록 강조 |
| 주제 구간 시작 | 어두운 브랜드 바탕 또는 관련 이미지, 큰 질문 하나 | 구간 제목 위계, 넉넉한 여백, 다음 본문의 질문 |
| 기술 설명 | 종이색 바탕, 로봇·관측·신경망이 중심 | 제목·라벨·연결선·강조 순서, 동일 자산의 위치 |
| 실험 과정 | 같은 장면의 이전·변경·결과를 단계적으로 공개 | 같은 카메라·척도·모델 색, 변경 이유를 읽는 순서 |
| 결과 비교 | 종이색 바탕, 차트나 영상 크게 | 비교 순서, 범례, 단위, 조건, 출처 위치 |
| 남은 과제 | 종이색 또는 구간 전환용 어두운 바탕 | 성과와 미검증 과제의 구분, 다음 행동 |

이 표의 배치는 고정 템플릿이 아니라 시작 기준이다. 현재 표지 이미지의 영화적인 분위기는 유지하며, 기술 설명에도 동일한 조명·로봇 자산·색의 관계를 이어갈 수 있다. 밝고 어두운 화면은 내용 역할로 정한다. 운영체제 테마에 따라 발표 중 바뀌지 않는다. 한 화면의 핵심은 하나이며 반복되는 동일 크기 카드가 기본 레이아웃이 되지 않는다.

## 3. 글자 위계

1600×900 기준 픽셀이다. 화면 전체를 비례 축소한다. 서체는 Pretendard, Malgun Gothic, Segoe UI 순서이며 로고는 SVG 원본이다.

| 역할 | 크기·굵기·행간 | 규칙 |
|---|---|---|
| 표지 제목 | 70 / 750 / 1.14 | 두 줄 안에서 프로젝트 핵심 |
| 주제 구간 제목 | 40 / 700 / 1.16 | 짧은 질문 또는 핵심 문장 |
| 각 슬라이드 제목 | 26 / 700 / 1.20 | 문장 한 개, 최대 두 줄 |
| 서브주제 | 22 / 650 / 1.30 | 그림 또는 비교 단위의 이름 |
| 본문 | 20 / 450 / 1.50 | 짧은 설명. 길어지면 화면을 나눔 |
| 본문 강조 | 본문 크기 / 700 | 핵심 구절 하나. 청록과 굵기를 함께 사용 가능 |
| 도식·차트 라벨 | 18 / 550 / 1.35 | 항목과 단위를 직접 읽을 수 있게 |
| 캡션·조건 | 16 / 450 / 1.40 | 영상 판정·실험 조건·기간 |
| 출처·보조 표기 | 16 / 450 / 1.40 | 필수 조건을 작은 출처 칸에 숨기지 않음 |
| 핵심 수치 | 56 / 700 / 1.05 | 단위는 22. 숫자 한 개만 크게 쓰고 근거 연결 |

9월 30일 사용자 피드백으로 구간 80→48, 제목 56→32, 서브주제 32→26, 본문 28→22, 라벨 24→20, 캡션 20→18, 출처 18→16으로 줄였다. 이것은 1차 축소 기록이다. 이어 사용자가 약 80% 추가 축소와 표지 제목 크기를 지적해 표지 88→70, 구간 48→40, 제목 32→26, 서브주제 26→22, 본문 22→20, 라벨 20→18, 캡션 18→16으로 조정했다. 출처는 가독성을 위해 16을 유지한다. 작아진 글자를 근거로 한 화면에 내용을 더 많이 쌓지 않는다. 실제 발표 화면에서 가독성을 확인하며 조정한다.

제목의 위치와 크기로 층위를 전달한다. 임의 영어 대문자 장식이나 새 슬로건을 붙이지 않는다. actor·critic·optimizer는 원어로, 시드는 ‘시드’로 쓴다.

## 4. 색의 역할과 가독성

| 역할 | 밝은 화면 | 어두운 화면 |
|---|---|---|
| 바탕 | #f6f5f1 | #12161d |
| 주 텍스트 | #161c26 | #e9e7e1 |
| 보조 텍스트·출처 | #4a5566 | #adb5c1 |
| 브랜드·채택·현재 강조 | #0e7a6e | #3ec7b4 |
| 주의·미확인 | #a86a08 | #dc9a30 |
| 실패·금지 | #a3342a | #e56d5e |

브랜드의 caption 전용 옅은 회색은 발표 작은 글씨에 바로 쓰지 않고 더 진한 secondary 값을 사용한다. 본문·라벨·출처는 4.82:1을 목표로 확인한다. 사진 위 글자는 암부 또는 배경막 위에 둔다. 이미지를 바꾸면 그 위치에서 다시 확인한다.

실측: 종이색 바탕에서 기본 청록은 4.78:1, 앰버는 4.07:1이다. 작은 글자는 브랜드의 진한 텍스트용 값 #0b6459와 #8a5600으로 구분해 사용한다. 원 브랜드 색은 로고·면·선에 유지한다.

모델 비교는 NVIDIA·v1·v2 순서와 이름을 유지한다. NVIDIA는 보조 잉크색, v1은 주 잉크색의 빈 도형/점선, v2는 청록색 실선/채운 도형으로 구분한다. 모델의 색과 낙상·실패의 상태 색을 섞지 않는다. 색만으로 구분하지 않고 직접 라벨과 선 모양을 함께 쓴다.

## 5. 화면 배치

- 16:9, 1600×900. 브랜드를 참고해 32px 그리드를 기본으로 사용하고 세부 간격은 8px 단위다.
- 사방 안전 여백 64px. 주요 본문은 왼쪽 x=64에 정렬한다. 제목과 본문에 따로 좁은 폭을 걸지 않는다.
- 본문 화면 상단은 구간 안내 영역이다. 우측 x=1088부터 폭 448px, y=48부터 높이 96px를 픽셀 Go2 경로의 예약 영역으로 둔다. 제목·그래프와 겹치지 않는다.
- 제목은 일반적으로 y=160, 본문은 y=288부터 배치한다. 화면에 필요한 경우 같은 그리드 안에서 조정하며 장면 연속성이 우선이다.
- 출처는 하단 y=808부터 28px 행간으로 최대 두 줄. 그림의 판정·조건은 그림 바로 옆에 둔다.
- 표지와 전체 화면 영상은 별도 장면이다. 작은 진행 표시를 생략하는 방안은 제작 제안이며 사용자와 실제 화면으로 확인한다.

## 6. 이미지·도식·표·영상

- 실제 결과, 개념 설명, 생성 이미지는 같은 증거로 취급하지 않는다. 생성 여부와 원출처는 자산 기록에 남긴다. 사용자의 U26 지시에 따라 표지 화면에는 생성 이미지 문구를 표시하지 않는다.
- 표지는 현재 사용자가 좋다고 한 이미지의 절제된 빛·어두운 공간·은색 Go2를 기준으로 한다. 기술 설명용 실제 로봇 형상과 센서 위치는 검증 가능한 자산을 쓴다.
- 같은 로봇의 관절·센서·관측을 설명할 때는 기체 크기와 카메라를 유지한다. 다른 화면이라는 이유로 매번 새 장면으로 바꾸지 않는다.
- 도식은 실선 2~3px. actor 실행 경로와 critic·optimizer 학습 경로를 라벨과 선 모양으로 구분한다. 동그라미와 연결선을 과하게 늘리지 않는다.
- 비교 영상은 카메라·재생속도·구간을 맞추고 모델명을 고정 위치에 둔다. 실패율을 낙상률로 바꾸어 적지 않는다.
- 차트는 단위·분모·조건을 표시한다. 조건이 다른 결과를 같은 수치 비교로 연결하지 않는다. 표는 헤더와 핵심 경계만 사용하며 칸마다 진한 테두리를 두르지 않는다.
- 라이선스와 원출처 기록은 자산 문서에 유지한다. 발표 표기는 읽을 수 있는 짧은 출처와 링크로 한다.

## 7. 움직임과 조작

| 동작 | 기준안 | 목적 |
|---|---|---|
| 일반 나타남 | 240ms, ease-out | 클릭한 정보만 공개 |
| 같은 물체의 위치 변화 | 480ms, ease-in-out | 이전 상태와 다음 상태 연결 |
| 구간 전환 | 700ms | 큰 이야기 전환 |
| 표지 진입 | 최대 1400ms | 인사 전에 이미지와 제목 정착 |
| 설명 중 영상 | 발표자가 재생·정지 | 말의 호흡에 맞춤 |

자동으로 다음 슬라이드로 넘기지 않는다. 뒤로 가면 이전 상태로 복원한다. F 전체화면, N 화면 안 메모, P 별도 발표자 메모 창, B 암전, 방향키·Space 발표 진행을 유지한다. 동작 줄이기에서는 핵심 정보의 최종 상태를 표시한다.

발표자 메모는 화면 안에서 좌우 배치를 바꿀 수 있다. P 또는 ‘별도 창으로’ 버튼으로 연 창은 사용자가 듀얼 모니터의 원하는 위치로 옮긴다. 별도 창의 글자 크기는 독립 조정한다. 브라우저가 팝업을 막으면 화면 안에서 안내한다. 현재 표지 메모의 내용 변경은 별도 창에도 반영되며, 전체 슬라이드 확장 시 같은 연결을 유지한다.

픽셀 Go2는 일반 UI 이동 규칙만 적용하지 않는다. 실제 다리·몸통·접지가 움직이는 걷기, 틈 넘기, 경사 오르기 상태가 필요하다. 사용자 뜻은 페이지마다 위치만 바꾸는 아이콘이 아니다. Nano Banana 등 원화 제작과 sprite-gen 등 동작 제작의 조합은 후보이며 도구 미확정이다. 반복 동작과 전체 발표 위치의 연결은 실제 샘플을 보고 결정한다.

## 8. 제작 적용과 변경

한 장씩 제작할 때 앞뒤 장면과 함께 본다. 제목 위계·색 의미·안전 여백·도식 선·출처·동작을 체크한다. 시스템 밖 예외가 필요하면 이유를 남기고 공통 스타일을 먼저 수정한다. 브랜드 원본은 이 발표 작업에서 바꾸지 않는다.

현재 적용: 표지 1장. 미적용: 기존 34장 초안. 시각 기준 HTML은 규칙을 보기 위한 견본이며 실제 실험 결과나 완성 발표가 아니다.
