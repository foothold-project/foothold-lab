## 지금 제작에 적용하는 기준 · 2026-09-30

사용자 원문: “우리 이미지는 imagegen으로 만들어서 일부 과한 HDR이나 플라스틱 같은 광택으로 실사감을 대신하고 있는 부분도 있는데 현실의 작은 불균일함이 살아있는 사진이었으면 좋겠어.”

이 요구는 이미지부터 적용한다. 영상 후처리로 미루지 않는다. 기존 장면은 구도·공간 참조이며 재질 정본이 아니다. 거친 콘크리트, 도장, 금속, 고무의 반사를 구분하고 마른 면·젖은 면·고인 물을 불균일하게 배치한다. 과한 HDR·국부 대비·윤곽 선명도·전면적인 젖은 광택을 줄인다. 빛이 닿지 않는 부분은 어둡게 남긴다. 불균일함은 표면과 빛의 자연스러운 차이를 뜻하며, 무작위 노이즈·기울어진 카메라·과장된 흠집을 뜻하지 않는다.

| 구간·요소 | 현재 확정한 요구 | 제작에서 확인할 것 |
|---|---|---|
| O1 | 블랙에서 시작. 정면 원경에서 움직이는 빛으로 위험한 공간을 발견 | 손전등은 설명을 위한 비유. 손전등 소품·사람·손을 넣지 않음. 시선과 빛이 바닥으로 내려오며 근경 연결 |
| 선호 원화 | 바닥 질감·틈 가장자리·깊은 틈·원경 scan·발 디딤 컷 보존 | 기존 좋은 그림을 임의로 폐기하지 않음. 같은 앵글 반복은 컷 길이·시점으로 조정 |
| O4·O5·O6 | 블랙에서 미션 수신 후 시야 복귀. 영어·기하학적 HUD. 원경 HUD와 근경 height scan 분리 | 의미 없는 수치 배제. 로그 미연결 값은 실측으로 표시하지 않음. scan은 지형에 붙고 빈 틈을 가짜 면으로 메우지 않음 |
| O7·E1 | 발을 내딛고 연속 보행. 한 영상에서 오프닝·엔딩 분리 | 가능하면 같은 보행 원본 사용. 같은 착지와 착지음의 중복 방지 |
| E2a·E2 | 거의 암흑인 뒤쪽에서 Go2가 걸어 나와 고정광 안에서 드러남 | 정면·조금 높은 카메라, 중앙 중경의 작은 기체와 큰 공간. 탐색광·전역 노출 증가로 대체하지 않음 |
| E5pre·E5·E5b | 카메라 뒤에서 위로 지나감. 턱을 오르고 한두 걸음. 앉기 직전에 정면 원경으로 컷 | 렌즈 양옆 발 배치 강제 금지. 앞다리는 지지하고 뒷다리만 접어 앉음. 목표는 정면 카메라 쪽에 위치 |
| E6·E7 | CV 인식, 촬영, 전송 진행, 적색 100%·MISSION COMPLETE, 신호 종료 후 블랙 | 완료는 경보가 아닌 해소. 이후 별도 슬라이드 가운데 Q&A, 발표용 브랜드 폰트 |
| Go2 | 공식 자료와 승인한 캐릭터·디테일 시트를 공통 참조 | 몸체 비율·센서 형상·관절·다리 굵기·발고무 통일. 회색 외장과 회색 관절, 검은 센서·고무 구분 |
| 환경 | 드문 물방울, 얇은 안개, 깜빡이는 목표등, 접촉에 따른 작은 부스러기 | 발 접촉과 지형을 가리지 않음. 의미 없는 레이저·과도한 붕괴 추가 금지 |
| 사운드 | 480p 초안부터 컷별 원음 포함. 최종은 전체 영상에 맞춰 새로 구성·믹싱 | 무가사·무보컬. 공간음·발소리·UI·파편·음악의 연결과 무게감. 컷마다 독립 음악을 붙이지 않음 |

E2 이미지·기준 문서·HTML 반영을 완료했고, 사용자가 제작을 승인한 **E2a 시작 이미지 한 장을 생성했다. v1은 사용자 피드백으로 미채택이다. 10월 1일 공간 조명을 다시 요청한 v2를 생성했으며 사용자 확인 전이다. v2는 분위기 수정 후보이고, 뒤쪽 출발 위치는 아직 미해결이다.** E2는 빛 속에 도착한 상태의 이미지이며 2026-09-30 사용자가 승인했다. 승인 원문: “지금 E2 작업한 결과물 좋아. 컨펌 ok”. E2a 결과 확인 뒤 영상 A/B 비교를 진행하는 순서다. 다른 컷의 외형 통일과 최종 음향은 후속 범위를 정해 진행한다. 정지 이미지나 HTML 전환을 실제 보행·연결 검증 완료로 기록하지 않는다.



이슈: [#490](https://github.com/foothold-project/foothold-lab/issues/490). 이 문서와 HIGGSFIELD-SHOT-PROMPTS.md v0.3가 최신 제작 기준이다. 과거의 정지 상태 E2, 렌즈 양옆 발 배치 강제, 무음 영상 초안 권고는 폐기한다. HTML은 구도 확인용이며 프레임 단위 편집 정본이 아니다.

### E2 첫 적용 결과 · 사용자 승인 완료

[새 E2 원본](assets/ending-e2-sunburst-v1.png) · [HTML 비교](output/FOOTHOLD-film-storyboard.html#e2-review) · [실제 요청과 참조](assets/ending-e2-sunburst-v1.request.json). Sunburst 2K high 한 장, 사전 견적 2.75크레딧. Job `e50cdb44-11b5-4ef8-b2cb-894930dab0c9`.

`확인됨` 이미지 직접 열람: 중앙 중경의 정면 Go2와 큰 공간 구도 유지, 회색 외장과 검은 하부 센서 표현, 이전보다 절제된 전면 광택. `미확인` 나사·발고무의 미세 형상 일치와 실제 관절 동작. 이미지의 기체가 작으므로 부품 단위 일치까지 판정하지 않는다. 기존 E2a 조명 참고는 보존했고, 새 시작 후보는 아래 제작 결과에 기록했다. 추가 재생성 없이 이 한 장을 제시했고 사용자가 승인했다. 움직임과 미세 부품 일치까지 승인·검증됐다는 뜻은 아니다.

## 1. 영화 전체의 리듬

오프닝은 공간을 이해하려는 조심스러운 시선에서 시작한다. 바닥의 위험을 발견하고 임무를 받은 뒤, 첫걸음으로 발표를 연다. 엔딩은 그 첫걸음을 이어서 보행 주체를 공개하고, 통과·접근·정지·관측·전송의 순서로 해소한다. 모든 컷에 사건·카메라 이동·효과를 동시에 넣지 않는다. 한 컷에서 읽어야 할 움직임은 하나를 중심으로 둔다.

| 연결 | 카메라와 Go2 동작 | 컷 연결 기준 |
|---|---|---|
| O1 → O2 | 어두운 공간을 작은 좌우 시선 움직임과 이동광으로 탐색. 후반에는 빛과 카메라가 아래쪽 중거리 바닥으로 내려옴 | 곧바로 원경에서 매크로로 뛰지 않음. 같은 빛의 이동 방향과 밝은 패치를 이어받아 근접 컷으로 전환 |
| O1b 후보 | 원경의 기둥과 가까운 바닥이 함께 보이는 몸체 높이의 중거리 POV | O1의 끝 동작만으로 연결되지 않을 때 짧은 삽입 컷으로 사용. 처음부터 필수 컷으로 늘리지 않음 |
| O2 → O3 → O3b | 표면 질감, 가장자리, 틈 깊이를 차례로 발견 | 같은 사선 구도 세 컷을 길게 반복하지 않음. 조명 이동 방향과 화면상 틈 방향을 유지 |
| O3b → O4 | 목표의 존재를 기억한 상태에서 시각 정보 차단 | 블랙에 신호음이 먼저 들어오고 MISSION이 읽힘. 디지털 효과는 이 상태 전환에 집중 |
| O4 → O5 → O6 | 임무에서 넓은 관측 시야로 복귀한 뒤 가까운 디딤을 살핌 | HUD는 원경 가장자리, 가까운 바닥에서는 scan만. 센서 전환 이후에도 지형 위치 유지 |
| O7 ↔ E1 | 발이 접촉하고 다음 걸음으로 이어짐 | 같은 보행 원본에서 나눠 쓰는 것을 우선. 접촉 발·방향·속도·몸체 높이·빛·음향을 맞춤 |
| E2a → E2 | 처음에는 훨씬 어두운 깊은 공간. 고정된 빛은 살아 있고 Go2가 뒤쪽에서 앞으로 걸어 나와 중앙 중경 빛의 영역에 들어섬 | 카메라가 빛을 흔들며 찾거나 전체 노출만 올라가는 효과 금지. 로봇 이동으로 윤곽과 얼굴이 읽히게 함 |
| E2 → E3 | 앞에서 주체 공개 후 뒤에서 통과 경로를 따라감 | 컷으로 카메라를 바꾸고 화면 중앙 진행축 유지. 180도 회전 카메라를 생성에 강제하지 않음 |
| E3 → E4 | 발이 틈에 접근할 때 측면으로 전환 | 실제 지지면에 발이 닿는 동작을 연결. 카메라는 새 틈이나 다른 지형을 만들어내지 않음 |
| E4 → E5pre | 목표 접근의 바닥 카메라 | Go2가 뒤에서 카메라 위로 건너가듯 통과. 렌즈 양옆에 발을 특정 위치로 배치하도록 강제하지 않음 |
| E5pre → E5 | 카메라 위 통과 후 같은 목표 앞 턱으로 접근·등반 | 몸통의 짧은 가림이나 발 들림을 컷 지점으로 사용. 가림을 디지털 glitch로 대신하지 않음 |
| E5 → E5b | 턱을 오른 뒤 한두 걸음, 감속. 앉기 직전에 정면 컷으로 전환하고 앉는 동작을 보여줌 | 후면에서 이미 앉은 뒤 정면으로 바꾸지 않음. 같은 정면 구도의 서 있는 시작 프레임이 필요 |
| E5b → E6 | 앞다리로 지지하고 뒷다리를 접어 앉아 목표를 바라봄 | 응시 뒤 목표 POV. 목표는 E5b 카메라 뒤에 있으며 로봇 뒤에 또 등장하면 안 됨 |
| E6 → E7 | 촬영, 전송, 수신 확인, 적색 100%·MISSION COMPLETE | 완료 화면의 호흡을 확보하고 마지막에만 짧은 신호 종료. 경보식 반복 점멸은 사용하지 않음 |

HTML의 타이머·크로스페이드 지연을 실제 영상에 복사하지 않는다. 생성 모델에는 각 컷 내부 동작을 명확히 요청하고, 컷 연결은 완성 클립의 실제 동작 프레임을 보고 편집한다. 모델이 알아서 모든 컷의 박자를 일치시킬 것이라고 가정하지 않는다.

## 2. E5b에 대한 판단

현재 정면 원화는 앉은 자세와 중앙축을 설명하는 데는 쓸 수 있지만 최종 기체·재질 정본으로 삼기에는 약하다. 상체 기울기와 다리 두께, 균일한 금속 반사가 장난감 같은 인상을 준다. 뒤에서 오르던 능동적인 움직임에 비해 완성된 정지 자세만 보여 활력이 떨어지기도 한다.

다음 비교에서는 같은 정면의 서 있는 시작과 앉은 끝을 한 쌍으로 확보한다. 두 앞발이 지지한 상태에서 무게를 옮기고, 뒷다리를 접어 엉덩이를 낮춘 뒤 작은 잔동작만 남긴다. 사람처럼 허리를 세우거나 관절을 잠그지 않는다. 정면 원경은 유지하되 관절이 읽힐 정도 크기를 확보하고 불필요한 정지 시간을 늘리지 않는다. 실제 허용 관절 범위는 미확인이므로 생성 이미지를 로봇 동역학 검증처럼 설명하지 않는다.

## 3. 같은 Go2를 유지하는 기준

각 컷의 기존 이미지는 구도 참조다. 모두를 기체 정본으로 동시에 쓰면 서로 다른 다리·발 형상을 평균낼 수 있다. 공식 정면·측면·후면 자료와 승인한 Sunburst 캐릭터·디테일 시트를 공통 참조로 사용한다. [캐릭터 시트](output/FOOTHOLD-Go2-character-sheet.html)에서 원자료와 생성 시안을 구분한다. 실제 장비 사진의 사용 가능한 경로는 제작 시 재확인한다.

- 몸통 길이·높이, 다리 링크 두께, 관절 하우징 직경, 발 고무 길이·끝 모양을 컷마다 비교한다.
- 공식 참조의 회색 외장·회색 관절 하우징·검은 센서 면·발고무 구성을 유지한다. 새 장비나 사람 손 같은 요소를 추가하지 않는다.
- 물기·먼지·상처의 위치와 강도도 연속성을 가진다. 컷마다 새 제품처럼 초기화하지 않는다.
- 렌즈 왜곡으로 가까운 발이 커 보이는 현상과 실제 부품 형상 변경을 구별한다.
- 지원되는 경우 동일 이미지 참조를 매 요청에 넣는다. 같은 시드만으로 외형 일관성이 보장되지는 않는다.

## 4. 사진의 불균일함과 분위기

HDR의 국부 대비와 과도한 선명도, 모든 표면에 똑같이 번지는 젖은 광택을 줄인다. 플라스틱 같은 광택을 먼지 필터 하나로 덮지 않는다. 콘크리트는 마른 곳·젖은 곳·물이 고인 곳이 다르고, 금속은 도장 마모·거친 산화·작은 긁힘에 따라 반사가 달라야 한다. 빛이 닿지 않는 부분은 검게 남겨도 된다. 과한 색수차·필름 그레인을 실사감의 대용으로 쓰지 않는다.

| 요소 | 연출 기준 |
|---|---|
| 물방울 | 특정 천장·배관에서 드문드문 떨어지고 바닥에 닿을 때 작은 파문. 모든 컷에 비처럼 내리지 않음 |
| 안개·연무 | 낮은 틈과 배관 주변에서 천천히 흐름. 발 접촉과 목표를 가리지 않으며 컷마다 이동 방향을 유지 |
| 붉은 경광등 | 부드럽게 밝아졌다 약해지는 일정한 주기 제안. 주변 젖은 바닥의 붉은 반사도 같이 변화. 기준 주기 약 2초는 연출 제안 |

## 5. 사운드 제작과 오프닝·엔딩 분리

사용자 최신 지시: **Seedance 2.5의 480p 초안부터 컷별 생성 소리를 포함한다. `generate_audio=true`.** 이전 무음 초안 권고는 취소한다. 각 컷의 발소리·물·모터·공간 잔향을 임시 편집 재료로 보존한다. 이를 최종 음향으로 그대로 이어 붙이지 않는다.

컷별 요청에서는 동작에 맞는 현장 소리를 생성하되 대사·가사·보컬을 넣지 않는다. 컷마다 별도 음악이 생기면 전체가 단절되므로 개별 생성에는 음악 없이 현장 소리를 우선 요청한다. 사용자가 원하는 무게감은 전체 편집의 독립된 음악·공간음 설계에서 만든다. 영화 제목은 분위기 참고이며 기존 선율·음원·특정 감독의 음악을 복제하지 않는다.

전체 음악은 깊고 절제된 저음, 느린 화성 변화, 긴 공간 잔향, 금속의 공명, 간헐적인 펄스와 침묵으로 설계한다. 시작부터 계속 최대 음량으로 밀지 않는다. 작은 물방울·발 접촉과 넓은 공간의 대비가 규모를 만든다. 무보컬·무가사이며 꼭 곡 형태일 필요는 없다.

별도 구성: 음악과 저음층, 공간음, 보행·접촉·모터, 파편·물, UI·신호. 최종 편집에서 클립의 원래 소리를 선별하고 필요 구간을 새로 만들거나 교체한다. 생성 원본에 분리된 음향 트랙이 있다고 가정하지 않는다. 음악이 섞이거나 소리가 깨끗하게 분리되지 않으면 해당 구간을 다시 만든다.

- O1에서 컷을 바꿔도 같은 공간음이 이어지고, 다음 바닥 컷의 물방울 소리가 먼저 들릴 수 있다.
- 발 접촉은 화면의 접지 프레임에 맞춘다. 파편 소리는 아래 공간으로 멀어지고 잔향이 뒤따른다.
- E5pre에서는 기체가 카메라 위로 지나며 가까운 구동음과 발소리가 커졌다가 목표 쪽으로 멀어진다. 과장된 항공기 같은 효과음은 피한다.
- 완료의 적색 전환은 경보음이 아니라 안정적인 수신 확인음과 음악적 해소로 읽히게 한다.
- 발표장 스피커와 모노 재생에서도 발 접촉·임무 신호가 들리는지 확인한다. 저음이 나머지를 덮지 않게 한다.

O7과 E1은 가능하면 **같은 원본 보행 클립**에서 편집 손잡이를 확보한다. 마스터에서는 한 걸음이 이어지고, 발표용 오프닝에서는 발걸음 후 공간음 잔향을 정리해 발화 공간을 만든다. 엔딩은 같은 음색·공간감과 다음 동작으로 돌아온다. 연결 검토 없이 같은 접촉음이나 발 디딤을 두 번 반복하지 않는다. 각 발걸음 전후 여유 프레임을 보관하고 컷 지점은 영상 완성 후 정한다.

## 7. MCP에서 여러 컷과 캐릭터 참조를 다루는 방법

`확인됨` 2026-09-30 MCP 모델 스키마에서 Seedance 2.5의 `omni_reference`, 시작·끝 이미지와 이미지·영상·음향 참조, 4~30초 길이, 480p draft 및 완료된 draft를 1080p로 마무리하는 항목을 확인했다. 여러 컷을 하나의 프롬프트로 요청할 수 있으나, 현재 Seedance 2.5 모델 스키마에는 컷마다 길이·전환·참조를 지정하는 독립적인 storyboard 입력 필드가 없다. MCP 전체의 제한은 아니다. Cinema Studio Video 2에는 multi_shots와 auto/custom 설정이 있고, Cinema Studio Video 2·3.0은 Elements 지원 목록에 있다. 수동 multi_prompt의 상세 형식은 실행 전에 추가 확인한다. 일괄 생성 도구는 독립 요청을 병렬 제출하는 기능이며 컷 사이의 동일성을 보장하는 기능이 아니다.

Elements는 공통 캐릭터·공간·소품 참조를 저장하는 기능이다. 다만 현재 MCP Elements의 지원 목록에는 Seedance 2.0과 GPT Image 2 등이 있고, **Seedance 2.5와 GPT Image 2.5 Sunburst는 명시돼 있지 않다.** 지원하지 않는 모델에서 이름 호출만 사용하면 참조가 적용되지 않을 수 있으므로 이번 제작은 승인한 공식 사진과 캐릭터·디테일 시트를 매 요청에 직접 첨부한다. [공식 Seedance 안내](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-seedance)의 일반 설명과 현재 MCP 지원 범위를 구분한다.

한 프로젝트 폴더에서 결과와 프롬프트를 관리하고, 동일한 외형 참조를 공유한다. E2a~E2처럼 같은 카메라에서 이어지는 동작은 한 영상으로 요청하는 것을 우선한다. O7~E1도 같은 보행 원본을 나눠 쓰는 방식이 우선이다. 모든 컷을 한 번에 생성해 컷별 승인·수정 가능성을 잃지 않는다. 공통 이미지 참조와 시드만으로 부품 형상이 완벽하게 고정된다고 주장하지 않는다.

## 8. CLI·MCP 비교와 다음 승인 범위

[공식 계정 연결 안내](https://higgsfield.ai/creator-hub/help-center/integrations/what-is-higgsfield-api)는 두 방식 모두 기존 계정의 크레딧을 사용한다고 설명한다. 별도 개발자 API 결제와 구분한다. CLI만의 생성 할인이나 Codex 조합의 최저 총비용을 입증하는 비교 자료는 미확인이다. 이번에는 CLI를 설치하거나 유료 생성하지 않았다.

## 9. 전체 이미지 통일과 후속 브랜드 영상

사용자는 승인 E2를 보고 전체 컷의 이미지를 먼저 일관되게 정비하는 방향을 제안했다. 이미지 기반 영상의 외형·재질·공간 기준은 원화에서 먼저 맞춘다. 다만 이미지의 품질만으로 보행·관절·접촉·시간적 연속성·음향이 해결되지는 않는다. 현재는 E2a 한 장을 먼저 진행하고, 이후 컷별 보존·수정 대상을 묶어 제시한다.

현재 MCP 이미지·영상 batch 도구는 요청당 1~6개의 독립 작업을 받는다. 단일 이미지 생성의 일반 count 스키마는 1~4지만 실제 모델 제약을 별도로 따른다. jobs_wait의 8개와 결과 갤러리의 24개는 조회·표시 한도이며 생성·계정 동시 실행 한도가 아니다. 계정별 실행 한도는 미확인이다. CLI로 여러 묶음을 순차 제출할 수 있어도 서비스 제한을 우회하는 것은 아니다.

제작 원칙: 같은 Go2 공식·캐릭터·디테일 참조를 공유하고, 컷마다 배경·카메라 참조의 역할을 구분한다. 로봇이 없는 오프닝 컷에는 Go2를 억지로 넣지 않는다. 승인받은 바닥·깊은 틈·발 디딤 구도는 보존한다. 같은 순간의 시작·끝 이미지와 앞 컷에 의존하는 다음 컷은 순차 제작한다. 서로 독립적인 컷만 묶는다. 결과는 컷 ID·원본·프롬프트·참조·비용·승인 상태를 함께 저장하며 묶음 일부 실패 때문에 성공한 컷까지 재제출하지 않는다.

[브랜드 영상 후속 이슈 #505](https://github.com/foothold-project/foothold-lab/issues/505): PPT 완성 후 기존 스토리보드 A·생성 클립·Isaac Sim 프리비즈와 lead/brand-launch-video 기록을 확인한다. 이번 작업에서 해당 자료를 열거나 lead에 연락하지 않았다. 브랜드 영상은 현재 오프닝·엔딩과 별개 작업이며 로고·슬로건·캐릭터·공간·조명 기준을 확인한 후 기존 자산 재사용부터 검토한다.

`확인됨` 직접 이미지 열람: 승인 E2와 유사한 카메라·기둥 배치를 유지하고 기체가 더 뒤쪽에서 작게 보인다. `미확인` 발밑에서 도착 위치까지 연속된 지지면. 몸체가 아직 명확히 읽혀 거의 암흑인 출발 의도를 충분히 충족했는지도 사용자 확인이 필요하다. 추가 재생성이나 영상 생성은 하지 않았다.

사용자가 [Cinema Studio 웹](https://higgsfield.ai/ko/generate)에서 모델 선택, Cinema Studio 4.0 기본 추천, movement 선택을 보았다고 전달했다. 사용자 관찰 기록이며 에이전트의 로그인 UI 재확인은 아니다. 3.0 견적을 4.0에 대입하지 않는다. 카메라 movement와 Go2 동작을 별개로 지정한다. E2는 고정 카메라, E3는 뒤에서 추적, E5pre는 낮은 고정 카메라 위로 통과가 기준이다. 브랜드 엔딩 movement 검토는 [후속 이슈 #505](https://github.com/foothold-project/foothold-lab/issues/505)에 연결한다.

### E2a 미채택 기록 · 2026-09-30

사용자 원문: “이건 지금 go2 만 명도 낮췄는데? 뭐라고 프롬프트 썼길래 저따구냐? 레퍼런스 이미지를 제대로 안줘서 그래? 분위기?”

실제 요청은 승인 E2·공식 정면·캐릭터 시트·디테일 시트 4장을 포함했다. 그러나 `Keep the same environmental exposure`와 어둠을 기체 위치만으로 표현하라는 문구로 배경 밝기를 고정했다. 이 지시가 거의 암흑인 공간 안에서 빛만 살아 있는 분위기 요구와 충돌했다. 외형 참조 누락이 아니라 조명 설계와 요청의 오류다. 생성기가 내부적으로 무엇을 우선했는지는 미확인이다.

결과는 보존하되 후속 영상 시작 프레임으로 채택하지 않는다. 다음 요청은 카메라·지형·기체 외형을 고정하고, 공간의 주변광과 반사광을 낮추며 국소광만 남기는 방향으로 수정한다. 영상에서는 전체 노출을 올려 공개하는 효과 대신 Go2가 고정광으로 걸어 들어오게 한다. 새 이미지 생성은 아직 하지 않았다.

### E2a v2 분위기 수정 결과 · 2026-10-01

[수정 이미지](assets/ending-e2a-sunburst-v2.png), [실제 요청](assets/ending-e2a-sunburst-v2.request.json). 배경 노출 고정 지시를 제거하고 공간 전체의 주변광 감소와 제한된 고정광을 우선했다. `확인됨` 직접 열람: 주변 벽·기둥·바닥의 밝기가 낮아지고 국소광이 남았다. **미해결: Go2가 여전히 빛 안쪽에 있어 뒤쪽 어둠에서 출발하는 위치가 아니다.** 사용자 승인과 영상 연결 검증은 하지 않았다. 추가 비용 2.75크레딧, E2a 두 차례 합계 5.5크레딧. 사용자 제작 지시로 수정 한 장을 생성했으며 영상은 제출하지 않았다.
