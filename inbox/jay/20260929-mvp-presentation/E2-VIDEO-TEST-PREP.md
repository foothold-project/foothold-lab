# E2 공개 장면 영상 시험 준비

> 요지: 어두운 방과 고정광을 유지하고 미세한 달리인으로 Go2가 고정광으로 걸어 들어오는 5초 장면을 비교한다.
> 상태: 요청·견적 준비 완료. 영상 생성 미제출
> 판: v1.1

## 승인과 입력

사용자는 E2a v3에 대해 “너무 뒤로 간거 같다는 느낌이 없지않아 있지만 … 승인한다”고 말했다. 이어 다음 작업을 실수 없이 준비하라고 지시했다. E2a 이미지 추가 수정은 하지 않는다.

- 시작 프레임: [승인 E2a v3](assets/ending-e2a-sunburst-v3.png), job `acda2e91-a241-4e2e-908c-31e0adfa48b2`.
- 외형·도착 구도 참조: [승인 E2](assets/ending-e2-sunburst-v1.png), job `e50cdb44-11b5-4ef8-b2cb-894930dab0c9`.

`확인됨` 두 모델 모두 시작·끝 이미지 역할을 지원한다. 그러나 E2는 배경 전체가 더 밝다. 끝 프레임으로 강제하면 전역 노출 증가가 생길 수 있으므로 이번 요청에서는 E2를 일반 이미지 참조로 전달한다. E2의 배경 밝기는 복사하지 않고, E2a의 고정광과 주변 어둠을 유지하도록 명시했다. 이는 충돌을 줄이기 위한 선택이며 결과 보장은 아니다.

## 공통 연출

5초, 480p, 16:9, 음향 포함, 모델별 1편. 조금 높은 정면 원경에서 처음 약 0.5초는 구도를 유지하고, 이후 아주 짧고 느린 달리인으로 접근한다. 고정 건축물의 화면상 크기 변화는 수% 정도의 절제된 움직임을 의도하며 실제 수치는 영상에서 확인한다. Go2는 독립적으로 일정한 보행으로 빛 쪽에 접근한다. 카메라 줌이나 전역 밝기 변화로 공개를 대체하지 않는다. 정확히 끝 위치에 맞추려고 달리거나 갑자기 가속하지 않는다. 필요하다면 자연스러운 접근 구간을 편집에 사용한다.

어둠과 옅은 안개, 간헐적인 물방울을 유지한다. 발 접촉음·미약한 모터음·물방울·공간 잔향을 받는다. 음성·가사·완성 음악은 요청하지 않는다. 전체 영화의 음악과 음향 믹싱은 기존 지시대로 후반에 별도 제작한다.

## 요청과 견적

| 항목 | Seedance 2.5 | Cinema Studio 3.0 |
|---|---|---|
| 요청 | [실제 제출용 JSON](assets/E2-video-test-seedance25.request.json) | [실제 제출용 JSON](assets/E2-video-test-cinema30.request.json) |
| 모드 | omni_reference, standard bitrate, draft false | genre auto |
| 공통 설정 | 5초 · 480p · 음향 포함 | 5초 · 480p · 음향 포함 |
| 견적 credits_exact | 15 | 17.5 |

합계 **32.5크레딧**. 2026-10-01 이 입력으로 비용 조회 완료, 영상 생성은 제출하지 않았다. Cinema 도구의 정수 표시 17 대신 정확값 17.5를 기록한다. Cinema Studio 4.0 견적이 아니다. 두 모델의 내부 구조가 같은지도 확인되지 않았다.

Seedance의 별도 draft 모드는 7일 이내 1080p finalize 기능이 있지만, 이번 비교는 기존 합의의 일반 480p 조건이다. draft 비용과 결과 보존 범위를 확인하지 않고 자동 전환하지 않는다.

## 결과에서 볼 것

1. Go2가 발을 디디며 앞으로 이동하는가. 몸체만 확대되거나 발이 미끄러지지 않는가.
2. 일정한 속도인가. 5초 도착을 위해 가속·점프·순간이동하지 않는가.
3. 다리·발고무·센서 형상이 유지되는가. 틈 위 허공을 걷거나 지형이 변형되지 않는가.
4. 달리인이 작고 매끄러운가. 줌으로 대체하거나 급격히 밀고 들어오지 않는가. 광원은 고정되고 배경 전체가 밝아지지 않는가.
5. 발소리가 접촉에 맞는가. 원음 트랙이 있으며 실제 소리 내용이 요청과 맞는가.

원화만으로 실제 거리와 속도(m/s)를 재지 않았다. 따라서 5초가 충분하다고 확정하지 않는다. 짧은 시험으로 판단하고, 문제가 있으면 수정 원인을 특정한 뒤 길이·입력 조건 중 필요한 항목만 바꾼다. 자동 반복 생성은 하지 않는다. 오프닝과 엔딩을 가르는 발소리 전환은 이 E2 공개 컷이 아니라 O7·E1 편집 구간에서 별도로 보존한다.
