# 승인 영상 업스케일과 1080p 재생성 비교

> 분류: 리서치
> 작성: Codex · 2026-10-01 01:16
> 근거: Higgsfield MCP 견적, 공식 업스케일 도움말, 사용자 충전 단가
> 요지: 1080p 재생성은 60크레딧. 업스케일 실계정 견적은 미확인이다.
> 상태: 업스케일 견적 대기

| 방식 | 5초 비용 | 기존 영상 유지 |
|---|---:|---|
| Seedance 2.5 480p·음향 포함 | 15크레딧 | 현재 제작 방식 |
| Seedance 2.5 1080p·음향 포함 새 생성 | 60크레딧 | 같은 문안이어도 같은 동작·조명이 보장되지 않음 |
| 기존 480p 영상 업스케일 | 미확인 | 기존 프레임을 입력으로 향상. 세부 외형 변형 가능성은 검토 필요 |

`확인됨` 1080p는 O7과 같은 요청에서 해상도만 바꿔 조회했다. [견적 응답](assets/seedance25-1080p-cost.json). 생성은 실행하지 않았다. 4,000크레딧 $190이라는 사용자 제공 충전값으로 환산하면 크레딧당 $0.0475, 15크레딧 $0.7125, 60크레딧 $2.85다. 세금은 포함하지 않았다.

업스케일 추가 비용을 U라고 할 때, 이미 만든 영상을 사용할 경우 U가 60보다 작으면 새 1080p 생성보다 추가 지출이 적다. 처음부터 제작비를 비교하면 15+U가 60보다 작아야 하므로 U가 45 미만이어야 한다. 재시도 비용은 제외했다.

공식 도움말은 모델·목표 품질·고급 설정에 따라 실행 버튼 견적이 달라진다고 설명한다. 또한 ByteDance는 기존 내용 향상 용도, Topaz Video는 새로운 세부 묘사를 만들 수 있는 방식으로 구분한다. 현재처럼 Go2 외형과 보행이 승인된 영상에는 기존 구도와 동작 보존을 우선하는 업스케일을 먼저 비교하는 것이 타당하다. 다만 480p에서 사라진 발·관절 세부를 정확하게 되찾는다는 보장은 없다. [Higgsfield 공식 도움말](https://higgsfield.ai/creator-hub/help-center/troubleshooting/my-video-upscale-is-stuck-or-failed-what-should-i-do).

실계정 웹 견적을 확인하려던 브라우저 새 창 실행은 자동 승인 검토에서 `blocked by policy`로 거부됐다. 구체적인 이유는 제공되지 않았다. 공개 페이지와 현재 MCP 도구에서 해당 파일의 정확한 업스케일 견적을 얻지 못했다. 금액을 추정해서 확정하지 않는다.

권고: 컷·동작 승인 후 업스케일 견적을 받고 한 컷으로 품질 비교. 동작 자체에 문제가 있는 컷은 업스케일로 해결하지 않는다. 이번에는 업스케일과 1080p 생성을 실행하지 않았다. 기존 E2는 별도 draft 모드로 생성한 영상이 아니므로 draft→finalize 가격을 적용할 수 있다고 단정하지 않는다.
