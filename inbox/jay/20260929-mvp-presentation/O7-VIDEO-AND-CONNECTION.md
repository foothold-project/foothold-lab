## 연결 편집

8.75초·24fps. O7 0~5초와 E2 원본 0~3.75초를 사용했다. E2의 후반 틈 접근을 사용하지 않았다.

| 타임라인 | 화면 |
|---|---|
| 0~4.625초 | 고정 카메라의 발 컷 |
| 4.625~4.958초 | 왼쪽에서 오른쪽으로 검은 화면이 덮임 |
| 4.958~5.250초 | 완전 블랙 |
| 5.250~5.625초 | 검은 덮개가 사라지며 E2 등장 |
| 5.625~8.750초 | E2 접근 |

`확인됨` 출력 영상 5.042초와 5.167초 프레임의 RGB 최댓값이 0이다. 검은 전환 방향도 직접 열람했다. [전환 프레임](assets/foot-to-e2-v1.transitions.jpg), [측정 결과](assets/foot-to-e2-v1.qa.json).

## 확인 범위와 남은 점

고정 구도, 왼쪽에서 오른쪽으로 지나가는 다리, 후반 빈 화면을 확인했다. 다리·발의 재질은 승인 이미지와 유사하며 별도 HDR·선명화 필터를 추가하지 않았다. 가까운 발이 중간에 다시 디디는 구간이 있다. 몸이 잘린 구도이므로 앞발 두 개 다음 뒷발 두 개라는 순서와 해부학적 동일성을 확정하지 않았다. 작은 파편의 낙하도 명료한 연출로 확인하지 못했다. 이 항목들은 충족 완료로 표시하지 않는다.

기존 E2의 배경 밝아짐은 원본에 남아 있다. 최종 채택은 사용자 판단을 받는다. 음향은 각 생성 원본의 트랙을 사용한 임시 연결이다. 무음이 아닌 신호와 피크 0.395를 측정했으나 직접 청취, 접촉음 동기화, 잔향 연속성은 미확인이다. 영화 전체 음악·공간음·효과음의 최종 믹싱은 별도 단계다.

이 연결본은 오프닝과 엔딩의 시각적 연결 확인용이다. 발표에서는 발 컷 뒤 블랙에서 오프닝을 끝내고, 발표 후 엔딩이 블랙에서 다시 시작한다.

## 사용자 영상 승인과 노출 보완

2026-10-01 사용자가 “일단 발 영상은 좋다.”라고 확인했다. 전체 스토리보드에는 연결본 링크만 있어 발견하기 어려웠다. 연결본·발 원본 플레이어와 승인 이미지를 상단에 직접 넣고, 미리보기 발 버튼도 실제 영상 재생으로 바꿨다. 원본에는 블랙이 없고 연결본에만 편집으로 추가했다는 점을 표시했다. 추가 유료 생성은 없다.

## 전환 수정 v2

사용자가 직선 블랙 경계를 지적하고 파편의 여운을 남기도록 수정안을 요청했다. [같은 스토리보드](output/FOOTHOLD-film-storyboard.html)에서 v2와 v1을 재생할 수 있다.

4.0~4.65초 왼쪽이 먼저 부드럽게 어두워진다. 4.5~5.0초 나머지 빛이 사라지고 5.0~5.25초 완전 블랙. E2는 5.25초부터 시작하며 블랙 덮개는 0.125초에 사라진다. 두 원본의 재생 속도는 바꾸지 않았다. 전체 9초. 작은 파편을 새로 만들거나 원본에 없는 디테일을 복원하지 않았다.

기존 발 소리에 180ms 지연·0.16 감쇠의 짧은 잔향을 추가하고 블랙까지 감쇠시켰다. E2 음향은 0.16초 페이드인, 종료부 0.2초 페이드아웃. 최종 영화 사운드 믹스는 아니다. 영상 전환 프레임을 직접 열람했고 5.083초·5.25초 RGB 최댓값 0을 측정했다. 오디오 피크 0.349. 직접 청취 평가는 미확인이다. 유료 생성 호출 없이 기존 원본 편집만 수행했다.
