# E5pre의 공간음·보행 연결 수정

> 분류: 실험
> 작성: 오흥재 · 2026-10-01 08:10
> 근거: 사용자 연결본 피드백 · build-film-sound-v1.py · 원본 및 전체본 오디오 측정
> 요지: E5pre 원음만 15.8dB 더 억제한 편집 오류를 분리하고 한 번의 영상 재생성으로 보행 연결을 다시 확인
> 상태: v4 1건 제출. 전체 음악 제작은 미완료

## 원인

`확인됨` 기존 믹스는 다른 컷 원음에 0.62, E5pre에만 0.10 배율을 적용했다. 배율 차이는 20 log10(0.10/0.62) = 약 -15.85dB다. 원음에서 효과음과 공간음을 분리하지 않았기 때문에 E5pre의 공간음까지 같이 낮아졌다. 이후 E4의 짧은 접지음 후보를 반복 추가해 원래 공간과 효과음의 비율도 달라졌다. 전체에 얹은 E6 반복 음원 0.055 배율은 이를 청감상 해결했다고 검증한 것이 아니었다.

Web Audio로 각 원본의 첫 5초를 디코딩해 왼쪽 채널을 측정했다. 평균 RMS와 50ms 구간 RMS 하위 10%는 다음과 같다. 하위 10%는 조용한 구간의 신호 크기일 뿐 공간음만 분리한 측정값은 아니다.

| 원본 | 전체 RMS dBFS | 조용한 구간 하위 10% dBFS |
|---|---:|---:|
| E4 v1 | -31.21 | -37.59 |
| E5pre v3 | -31.90 | -37.82 |
| E5 v1 | -35.59 | -39.09 |

원본 E5pre에 오디오가 없거나 원본 신호가 유독 작은 것은 아니다. 공간음의 내용·잔향이 같은지는 이 측정으로 확정할 수 없다. 전체본 구간 RMS는 E4 -15.87, E5pre -16.78, E5 -16.84dBFS로 비슷하지만 저음 배경과 별도 효과가 포함된 값이다. 전체 음량을 맞추는 것과 공간감이 이어지는 것은 다르다.

## 수정 범위

사용자는 E5pre를 한 번만 다시 생성하라고 했다. v4는 Seedance 2.5, 5초, 480p, 음향 포함 1건, 견적 15크레딧이다. 작업 ID는 000e10a8-969b-4936-9611-db98371a471e다. 앞 E4·뒤 E5 영상을 동작과 공간 연결 참조로, O6를 스캔 표현 참조로, E4 추출 음원을 소리 참조로 제공했다. 외부 카메라 구도와 로봇 형상은 결과 화면에 복제하지 않도록 명시했다.

v4는 원음의 지속적인 공간음과 접지음을 보존한 상태로 먼저 E4·E5 사이에서 비교한다. 이전 연결본에 임의로 더한 진동·반복 접지음은 이 비교에 넣지 않는다. 결과를 확인하기 전 자동 재생성하지 않는다. 기존 전체본은 비교용으로 보존한다.

## 전체 음악의 상태 정정

기존 전체본은 생성 컷 효과음, 반복 공간음, 코드로 합성한 저음 배경과 신호음을 넣은 임시 믹스다. 요청한 영화적 음악의 전개와 마무리를 갖춘 별도 음악 제작을 끝낸 상태가 아니다. 현재 Higgsfield MCP generate_audio는 음성 전용이며 음악·효과음 생성을 지원하지 않는다. 모델 검색의 sonilo_music는 game pipeline only로 표시되어 일반 음악 생성 경로로 임의 사용하지 않는다. 사용 가능한 음악 서비스 확인 후 전체 영상 음악을 제작하고, 전체 믹스에서 발표용 두 구간을 분리한다.
