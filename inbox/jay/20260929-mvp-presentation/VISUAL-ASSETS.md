## 실험 시연에 필요한 정보

좋은 연구 시연에서 참고할 것은 보기 좋은 동작뿐 아니라 명령과 반응, 지형과 발 디딤을 한눈에 읽을 수 있게 하는 구성이다. 논문 저장소의 GIF·영상은 해당 연구가 고른 시연이며, 그것만으로 모든 조건에서의 성능을 판정하지 않는다. 신규 저장소 조사 결과는 [연구 참고 자료](RESEARCH-REPO-REFERENCES.md)에 기록한다.

## 자료를 요청할 때 함께 전달할 조건

기존 결과에 적절한 컷이 없는 경우 lead·RL 담당에게 전달할 요청 초안이다. 이번 레이아웃 제작에서는 다른 세션에 메시지를 보내거나 새 GPU 실험을 시작하지 않았다.

- 대상 모델·체크포인트, 지형·난이도, 명령의 시간표, 평가 시드와 시작 조건.
- 보여줄 행동 하나와 시점. 예: 정지 명령 전후의 실제 속도, 회전 중 몸의 안정성, 발이 디딤돌을 벗어나는 순간.
- 비교 컷은 동일한 카메라·재생 속도·구간으로 준비. 비동기 시연을 동기화된 실험처럼 합치지 않음.
- 명령 `vx`, `vy`, `yaw rate`와 필요한 실제 반응만 표시. 발표에 불필요한 디버그 HUD는 최소화.
- 전체 평가 결과와 해당 컷의 에피소드 식별자를 함께 기록. 성공 컷만으로 전체 성능을 대표하지 않음.

횡이동·후퇴·회전이 잘 되는 다른 논문의 영상은 다음 연구의 참고 자료로 활용한다. 입력 센서, 명령 범위, 학습 과제와 제어 방식이 우리와 같은지 확인하기 전에는 직접 성능 비교에 사용하지 않는다.

## 표현 도구

도표와 연구 구조는 편집 가능한 HTML·SVG를 우선한다. HyperFrames·Archify·Manim 등은 필요한 움직임과 출력 형식이 정해진 뒤 선택한다. GPT 이미지 생성·Nano Banana 계열은 현장 개념 이미지나 설명용 일러스트 후보이며, 이번에는 계정의 실제 모델 목록을 확인하거나 생성하지 않았다.
