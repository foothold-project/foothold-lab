| | |
|---|---|

| 체크포인트 | `model_2500.pt` |

### `v2b` 와 무엇이 다른가 · **`sim device` 하나입니다**

`v2b` 는 `sim cuda:1 · PPO cuda:0` 으로 **장치가 갈린** 배치였습니다. `--device` 가 시뮬만 옮기기 때문입니다(`train.py:127` 대 `138`).

**`v2b-r` 은 둘 다 `cuda:0` 이라 기준선 `foothold-v1`·`v2a` 와 «같은 배치»입니다.** 그래서 비교가 성립합니다.

### 학습 설정 · `v2a` 에서 **한 칸만** 다름

```
rel_standing_envs   0.02 -> 0.10      «이 한 칸» 이 v2a 와의 차이

명령
  전진 속도   0.4 ~ 1.5 m/s
  옆방향      0.0 ~ 0.0      «닫힘»
  회전        -1.0 ~ 1.0
  목표 방향    ±π · 비율 1.0
  재표집      10 초

학습 지형 (8x8 m · 10 행 20 열 · 커리큘럼 켬)
  계단 0.15 · 역계단 0.15 · 상자 0.15 · 거친바닥 0.15
  경사 0.10 · 역경사 0.10 · omni_gap 0.10 · 난간 0.10

보상
  속도추종 1.5 · 회전추종 0.75 · 수직속도 -2.0 · 롤피치 -0.05
  토크 -0.0002 · 가속 -2.5e-07 · 행동변화율 -0.01 · 발체공 0.01
  자세 0.0(꺼짐) · 관절한계 0.0(꺼짐)
```

**왜 `rel_standing_envs` 를 올렸나** · 그전에는 정지를 사려고 `lin_vel_x` 하한을 열었는데 축 1 을 여섯 칸 잃었습니다 (`gap 0.5` 98→35 · `rails 1.5` 60→6). **「하한을 여는 것」은 축 1 을 팔아서 정지를 사는 거래**였습니다. `rel_standing_envs` 로 직접 사면 축 1 을 안 팔아도 될 것이라는 가설이었고 **맞았습니다.**

## 2 · 축 2 · 아홉 칸 전부

| 칸 | 값 | 표본 env | 문턱 |
|---|---:|---:|---|
| turn 낙상 | 2/64 = 0.0313 | 64/64 | ≤ 0.10 |
| stop 낙상 | 1/64 = 0.0156 | 64/64 | ≤ 0.03 |
| hold 낙상 | 0/64 = 0 | 64/64 | ≤ 0.03 |
| hold 잔류속도 | 0.002713 m/s | 64/64 | ≤ 0.005 |
| hold 관절떨림 | 0.002452 rad/step | 64/64 | ≤ 0.01 |
| 회전 −1.00 | 0.5573 | 64/64 | ≥ 0.40 |
| 회전 −0.50 | 0.6307 | 64/64 | ≥ 0.40 |
| 회전 +0.50 | 0.5530 | **63/64** | ≥ 0.40 |
| 회전 +1.00 | 0.6595 | **62/64** | ≥ 0.40 |

**아홉 칸 전부 통과입니다.** 3 차 검증이 `per_env.json` 과 parquet 192 개에서 다시 계산했고 최대 절대차가 `6.94e-18` 이었습니다.

### `9/9` 가 뜻하지 «않는» 것

```
아홉 episode 가 성공했다       X
로봇 64 대가 전부 성공했다      X
맞음 · 아홉 개의 «서로 다른 집계 문턱» 을 넘었다
```

회전 뒤 두 칸은 **넘어진 개체를 빼고 평균**한 값입니다. 낙상률 분모에는 64 가 다 남습니다.

**낙상률의 Wilson 95 % 상한은 문턱을 넘습니다** (turn `0.86 ~ 10.70 %` 대 문턱 `10 %`). **점추정 기준 통과이지 모집단 보장이 아닙니다.**

### 「첫 9/9」의 범위

**NVIDIA 원본은 이미 9/9 입니다.** 정확히는 **「우리 재학습 22 개 시점 중 첫 9/9」** 입니다. 종전 최고는 `F` 의 회전 +1.00 `0.4195`(51/64)였고 이번은 `0.6595`(62/64)입니다.

## 4 · 관측 · **판정에 «안» 들어가는 것**

### 4-1 · 난이도 스윕 · **거의 평평합니다**

48 칸 평균입니다.

| 난이도 | 0.5 m/s | 1.0 m/s | 1.5 m/s |
|---|---:|---:|---:|
| 0.1 | 95.1 % | 98.6 % | 93.0 % |
| 0.3 | 93.2 % | 93.8 % | 88.1 % |
| **0.5** | 93.6 % | 93.6 % | 92.2 % |
| 0.7 | 93.0 % | 93.8 % | 88.4 % |
| 0.9 | 90.2 % | 93.2 % | **77.9 %** |

**0.1 에서 0.9 까지 평균이 93 % 언저리입니다.** 무너지는 건 **난이도 0.9 · 1.5 m/s** 한 칸입니다.

**뜻밖의 것** · 난이도 **0.1 에서 `floating_ring 1.5` 가 1 %** 입니다. 0.5 에서는 98 % 입니다. **난이도 매개변수가 그 지형에서 단조롭지 않습니다.** 따로 봐야 합니다.

### 4-2 · 후진 · **안 넘어집니다. 다만 뒤로 못 갑니다**

명령 `-1.0 m/s` · 6 초 · `unseen10` · 난이도 0.5

| 지형 | 생존율 | 전진(m) |
|---|---:|---:|
| `gap` · `rails` · `floating_ring` · `repeated_boxes` | 100 % | −0.21 ~ −0.35 |
| `pit` · `repeated_cylinders` | 99 % | −0.35 |
| `discrete_obstacles` · `star` | 96 % | −0.32 ~ −0.37 |
| `wave` | 92 % | −0.42 |
| `stepping_stones` | **62 %** | −0.48 |

**6 초에 0.35 m 밖에 안 물러납니다.** 명령대로면 6 m 를 가야 합니다.

```
읽을 수 있는 것   후진 명령을 받아도 «넘어지지 않는다» (안전 확인)
읽을 수 «없는» 것  「후진 능력」 · 학습 범위가 0.4 ~ 1.5 라 배운 적이 없다
```
