## 이 표에서 읽히는 것 넷

### 1 · 배포본 `foothold-v1` 의 약점이 보인다

```
rails 1.5 m/s    21 %     다섯 번 중 한 번
rails 1.0 m/s    48 %
gap   1.5 m/s    68 %
rails 0.5 m/s    70 %
```

**우리 재학습은 이 넷을 크게 올렸습니다** (`rails 1.0` 은 48 -> 100).

### 2 · NVIDIA 원본은 1.5 m/s 에서 거의 전멸한다

**1.5 m/s 에서 0 % 인 지형이 «열 개»** 입니다. 그래서 「NVIDIA 대비 상승 28~31」이 나옵니다. 축 2 는 9/9 인데 축 1 고속을 못 버팁니다.

### 3 · `stepping_stones` 는 누구도 못 넘는다

```
NVIDIA 0 · v1 0 · v2a 0~4 · v2b-r 0
```

`v2a 2500` 의 **4 %** 가 계보 전체 최고입니다. **절대 최저 칸이 계속 0 인 까닭이 이것뿐입니다.**

### 4 · 정지 비율의 «진짜» 효과

`v2a` 와 `v2b-r` 은 정지 비율만 다릅니다 (0.02 대 0.10).

```
            축1 하락   rails1.5   gap0.5   pyr_stairs_inv1.5
v2a 2500    2         79         71       72
v2b-r 2500  0         91         98       99
```

**`v2a` 가 떨어뜨렸던 칸을 `v2b-r` 이 올렸습니다.** 다만 `1500` 에서는 `v2b-r` 도 하락 2 입니다.

## 주의

```
이 표는 «난이도 0.5» 하나다. 스윕이 아니다
칸마다 100 에피소드이고 seed 는 42 하나다
100 % 는 「항상 된다」가 아니라 「이 100 판에서 다 됐다」는 뜻이다
  Wilson 95 % 하한은 96.3 % 다
```
