## 물을 것

### 1. 뿌리 원인이 무엇입니까

위 순서까지는 제가 확정했습니다. **그 앞이 알고 싶습니다.**

```
critic 이 왜 1577 에서 갑자기 발산했는가
그 이전 판들에 전조가 있었는가 (제가 못 본 지표가 있는지)
시드 43 이 무엇을 다르게 만들었는가
  같은 지형 · 같은 명령 분포인데 표집이 달라진 것뿐인가
  아니면 어떤 «특정 상황» 이 시드 43 에서만 생기는가
```

### 2. **지금 있는 자료만으로 어디까지 갑니까**

이것을 분명히 해 주십시오. `tfevents` 는 100 에피소드 평균만 들고 있습니다. env 별 값도, minibatch 별 KL·gradient 도, 옵티마이저 상태도 없습니다.

```
자료만으로 «된다» 면      -> 그것으로 답을 내십시오
자료만으로 «안 된다» 면    -> 무엇을 더 재야 하는지 «구체적으로» 적으십시오
                          어떤 계측을 어디에 넣고 몇 판을 돌려야 하는지
```

### 3. 재현이 «완벽하다» 는 것을 활용할 수 있습니까

학습이 비트 단위로 결정론적입니다. 그러면 **계측을 넣고 시드 43 을 다시 돌리면 같은 자리에서 같은 일이 일어납니다.**

```
1578 직전에서 멈추게 하고 상태를 통째로 덤프하는 것이 가능합니까
model_1550 에서 이어받아 계측을 켠 채 30 판만 돌리는 것이 가능합니까
  (rsl_rl 의 resume 이 옵티마이저 상태까지 복원하는지 확인해 주십시오)
그렇게 하면 «전체 3 시간» 이 아니라 «몇 분» 이면 됩니까
```

**이것이 되면 원인 추적 비용이 완전히 달라집니다.** 확인해 주십시오.

### 4. 막을 관문

원인과 별개로 **다음에 이런 일이 생기면 세 시간을 버리지 않게** 하고 싶습니다.

```

그리고 이 관문이 «정상 학습을 잘못 멈추지 않는다» 는 것을 어떻게 시험합니까
```
