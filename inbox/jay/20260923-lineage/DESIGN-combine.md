## 3. 가설은 **하나**다 · 상호작용

> **두 개입의 효과가 더해지는가, 서로 깎는가.**

이것이 「한 실험에 한 가설」을 지키는 이유는, 묻는 것이 **두 개입의 합**이
아니라 **합과 각각의 차이** 이기 때문이다. 그 차이는 네 칸이 다 있어야만
계산된다. 세 칸으로는 답이 없고 네 칸이면 답이 하나다.

`AUDIT8-plan.md` v1.1 이 준 식을 그대로 쓴다.

```
상호작용 = [성과(결합) − 성과(stones)] − [성과(발체공0.1) − 성과(부모)]

  > 0   더해진다 (상승 효과)
  = 0   독립이다 (각자 몫만큼)
  < 0   서로 깎는다
```

### 예측을 «먼저» 적는다

| 지표 | 예측 | 왜 |
|---|---|---|
| `stepping_stones` 진행 (1.0 m/s) | **상호작용 > 0** | 안전과 통과는 다른 능력이고 서로 막지 않는다 |
| `stepping_stones` 생존 | 상호작용 ≈ 0 | stones 노출이 생존을 올리고 발 체공은 생존과 무관했다 |
| 48 칸 평균 | **상호작용 < 0** | 둘 다 `boxes`·`random_rough` 노출을 줄이거나 자세를 바꾼다 |
| 축 2 `turn/fell_ratio` | 상호작용 < 0 | stones 혼합과 발 체공이 둘 다 회전 안정성을 건드린다 |

**이 예측을 결과 «전에» 적는다.** 맞으면 기전을, 틀리면 무엇을 잘못 봤는지
가린다.

## 7. 이 설계에서 «주장할 수 없는» 것

```
「stones 를 넣은 효과만」            줄인 두 지형의 노출 감소가 섞여 있다

「상호작용 부호가 일반적이다」          이 평가 척도·이 예산에서의 값이다
```

## 8. 아직 못 잰 것 · **이 설계의 약점**

`v2s` 와 결합 판이 학습 중 **실제로 틈에 노출됐는지 확인하지 못했다.**

`hf_terrains.py:373~385` 가 간격 `0.08 + 0.12d` 를 격자 0.1 로 나누고 정수로
자르므로 **난이도 0.1 에서는 간격이 0 셀** 이다. 곧 틈이 없다. 초기 지형
레벨이 최대 2 라서 **초반에 틈 없는 구간에만 머물렀을 수 있다.**

`AUDIT9-approve.md` 9 절이 「stones 전용 레벨과 실제 틈 노출을 반드시 본다 ·
전 지형 평균 레벨로 대신하지 않는다」고 못박았고 **아직 안 했다.**
학습 로그에 지형 레벨이 찍히지 않아 사후에 못 읽는다. **재는 방법을 따로
만들어야 한다.**

이것이 안 풀리면 「stones 노출이 생존을 올렸다」의 기전을 단정할 수 없다.
성적 변화는 남고 까닭이 미확정이다.

## 9. astra 에 묻는 것

1. **「상호작용이 0 이상인가」가 「한 실험에 한 가설」을 지키는 물음인가.**
   두 칸을 동시에 바꾸는 판인데, 부모와 단독 둘이 이미 있으므로 요인 배치가
   닫힌다는 논리가 성립하는가. 성립하지 않으면 무엇이 더 필요한가.

2. **상호작용을 어느 지표로 재는가.** 48 칸 평균 · `stepping_stones` 진행 ·
   생존 · 축 2 칸 수를 각각 따로 계산해야 하는가, 아니면 하나를 주 지표로
   미리 정해야 하는가. 여러 지표에서 부호가 갈리면 어떻게 읽는가.

3. **부모 칸을 `v2b-r` 로 두는 것이 맞는가.** 그 판의 축 1 하락이
   [2,0,0,0] 으로 `iter1500` 에 둘이 있다. 다른 세 칸과 비교할 때 이것이
   상호작용 계산을 왜곡하는가. `v2b-p11` 로 바꾸면 달라지는가 (121/121 동일).

4. **8 절의 「실제 틈 노출 미측정」이 이 실험을 미루어야 할 사유인가.**
   아니면 성적은 재고 기전은 미확정으로 남기고 가도 되는가.
   미루지 않는다면 노출을 «지금 돌고 있는 판에서» 잴 방법이 있는가.

5. **팀장이 `v2g2-feetair01` iter3000 을 다음 부모로 확정했다.** 그런데 그
   판은 축 2 관문을 못 넘었고 `iter2000` 이 2/9 다. **학습 곡선이 불안정한
   모델을 부모로 삼는 것이 위험한가.** 위험하면 무엇을 먼저 확인해야 하는가.

6. **다음 실험의 순서.** 결합 · 독립 시드 확인 · `iter2000` 붕괴 원인 ·
   `turn/fell_ratio` 한 마리 차이 · 표준편차 log 전환 · stones 노출 측정 중
   무엇을 먼저 해야 최적 모델에 빨리 닿는가. 근거를 들어 순서를 정해 달라.

7. **이 설계 전체가 「가설 하나 -> 근거 -> 단계적 개선」이라는 요구를
   만족하는가.** 만족하지 않는 부분이 있으면 무엇을 어떻게 바꿔야 하는가.
