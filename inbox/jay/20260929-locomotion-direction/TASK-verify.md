# 험지·기본 명령 연구 방향 문서 독립 검증 의뢰

기존 이슈 #482의 검증 작업이다. 같은 폴더 `DIRECTION.md`를 검증하고 `VERIFY-astra.md`에 결과를 쓴다. 이 문서는 검증 의뢰이며 세션 해석에 대한 동의를 구하지 않는다. 틀린 곳을 찾아라. 확인됨이라고 적은 값도 다시 재라.

이슈와 작업 브랜치는 작성 세션이 이미 만들었다. 동시 작업 중인 공유 체크아웃에서는 git pull·checkout·add·commit·push, 학습 실행, docs 수정 없이 읽기와 지정된 검증 결과 파일 작성만 한다. 별도 검증자를 재귀적으로 부르지 않는다.

검증할 것:

- 학습 YAML의 명령, 초기 지형 레벨, push, 관측 구성. 공식 NVIDIA 학습 이력과 로컬 기본 설정을 구분했는가.
- 다섯 프로브의 n, fell 건수, tracked_vx 평균을 per_env.json에서 직접 재계산. turn_rev가 후퇴라는 오독이 없는가.
- actor의 목표 관측, 경유점 방식, curriculum, resume와 optimizer 구분의 기술적 오류.
- AME-2, MARG, START 원문과 문서 설명의 일치. 새로 확인 못한 부분은 미확인.
- 한국어 표현, 사실과 제안의 구분, 근거 이상의 과장, 미래 실험의 실행 승인으로 읽힐 여지.
- 근거 경로와 로컬 원자료의 접근 한계. 불필요한 추가 실험 없이 문서 오류를 확인한다.

발행을 막을 오류와 선택적인 보강을 구분한다. 최종 판정은 공유 가능한 제안 문서인지에 대한 판정이며 제안 실험의 효과를 승인하는 것이 아니다. 한국어, em dash 금지, 시드 사용, actor·critic·optimizer는 원어로 쓴다.
