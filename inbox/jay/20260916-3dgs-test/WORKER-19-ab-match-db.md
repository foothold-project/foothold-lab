## 0. 왜 이 구분이 중요한가

|---|---|---|

## 1. 무엇을 조회하는가

merge2 의 데이터베이스를 찾으십시오(`_out/shot2pipe/merge2/` 아래 `.db`). **어느 파일을 썼는지 경로와 크기를 보고서에 적으십시오.** 없으면 있는 것을 찾아 적고, 그래도 없으면 「데이터베이스 없음」으로 적고 멈추십시오.

`images` 테이블에서 `image_id` 와 `name` 을 읽어 이름 접두사로 클립(A · B · D)을 가릅니다. COLMAP 의 `pair_id` 규칙(`pair_id = image_id1 * 2147483647 + image_id2`, `image_id1 < image_id2`)을 **소스나 문서로 확인하고 그 근거를 적으십시오.** 추측으로 쓰지 마십시오.

다음을 냅니다.

| 재는 것 | 어디서 |
|---|---|
| 클립 쌍(AA · AB · AD · BB · BD · DD)별 **`matches` 행(원시 매칭) 쌍 수**와 매칭 수 합 · 중앙값 · 최대 | `matches` 테이블 |
| 클립 쌍별 **`two_view_geometries` 행(기하 검증 통과) 쌍 수**와 인라이어 수 합 · 중앙값 · 최대 | `two_view_geometries` 테이블 |
| A-B 쌍 중 **인라이어 상위 20 개**의 이미지 이름 · 인라이어 수 · `config` 값 | |
| 비교용으로 A-D 쌍과 A-A 인접 쌍의 같은 수치 | **이것이 기준선입니다.** A-D 는 희소 모델에서 2,970 점을 공유했으니 「붙은 경우」가 어떤 수치인지 보여 줍니다 |

`two_view_geometries` 의 `config` 값이 무엇을 뜻하는지(예: 미정의 · 퇴화 · 평면 등) COLMAP 소스나 문서에서 확인해 적으십시오. **확인 못 하면 값만 적고 `미확인` 으로 두십시오.**
