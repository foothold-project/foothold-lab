# 2. 자로 잰 높이

## 무엇을 · 왜

- 무엇: 바닥→몸 중심, 바닥→D435i 깊이 광학 중심의 높이를 줄자로 잰다. 선 자세 · 앉은 자세 둘 다. 사진으로 기준점을 남긴다.
- 왜: 1 번 값 (녹화 깊이로 바닥 평면을 맞춰 얻은 카메라 높이 · 각) 은 깊이 카메라 공장 보정과 매트 두께에 기대고 있다. 손으로 잰 값과 2 cm 안에서 맞으면 1 번 값을 시뮬 카메라 장착을 고치는 근거로 쓸 수 있다.

## 비교표 (1 번 계산값 · 시뮬 장착 · 자로 잰 값)

몸 높이는 SDK `body_height` (monitor.csv 중앙값). 카메라 높이 계산 「A · B 예상」 은 `몸 높이 + z·cos θ − x·sin θ` (θ = 몸 앞숙임 = 녹화 카메라 각 − 몸 기준 장착각 35.0°). 몸 기준 장착각 35.0° 는 11/18 D435i IMU 와 Go2 IMU 상대각 실측값이다.

| 항목 | 녹화 계산 (1 번) | 시뮬 장착 A 예상 | 실측 장착 B 예상 | 자로 잰 값 (2 번) | 차이 (자 − 녹화) |
|---|---|---|---|---|---|
| 장착 위치 (몸 중심 기준 x, y, z) | 해당 없음 | (0.25, 0, 0.12) m · 학습 정본 | (0.35, 0, 0.07) m · 11/18 근사 | x: ___ · z: ___ m | |
| 장착 아래 각 (몸 기준) | 해당 없음 | 35° | 35.0° (IMU 상대각 실측) | 해당 없음 | |
| **선 자세** 몸 높이 | 0.3218 m (SDK) | 정책이 정함 | 같음 | ___ m | |
| 선 자세 몸 앞숙임 θ | +3.59° (38.59 − 35.0 · 계산) | 0° 가정 시 | +3.59° | 해당 없음 | |
| 선 자세 카메라 높이 | **0.3716 m** (매트 위) | 0.4418 (θ=0) · 0.4259 (θ=3.59°) m | 0.3918 (θ=0) · **0.3697** (θ=3.59°) m | ___ m | |

| 매트 두께 (발이 눌린 채) | 미측정 | | | ___ mm | |

읽는 법 (계산 · 미확인):
- 선 자세 녹화 높이 0.3716 m 는 B 예상 0.3697 m 와 2 mm 차이, A 예상과는 5 cm 넘게 차이 난다. 지금 실기 카메라는 학습 장착 A 가 아니라 B 쪽이다.
- 앉은 자세 B 예상 0.1494 m 대 녹화 0.1431 m 는 6 mm 차이. SDK 몸 높이가 어느 점을 재는지 미확인이라 이 정도 차는 설명이 남아 있다.
- 바닥 기준 카메라 아래 각 38.59° 는 학습 35° 보다 3.6° 더 숙였다. 몸이 앞으로 숙였는지, 매트가 기울었는지는 미확인 (자 측정 때 매트 없이 맨바닥에서 한 번 더 재면 가른다).

잴 점 (사진에 화살표로 표시):
- 바닥→몸 중심: Go2 몸통 옆면의 앞뒤 가운데 · 위아래 가운데 (몸통 상자 중심). 정확한 기준점이 IMU 인지 `base_link` 인지는 미확인이라, 몸통 위 · 아래 모서리 높이 둘을 같이 잰다.
- 바닥→D435i 광학 중심: 깊이 원점은 「왼쪽 이미저」 (카메라 뒤에서 보아 왼쪽). 앞에서 보면 색 렌즈 바로 옆 렌즈다 (녹화의 깊이→색 외부 매개변수가 x 쪽 +14.8 mm 라 서로 붙어 있다). 그 렌즈 중심 높이를 잰다.
- 몸 중심→렌즈 앞뒤 거리 (x) 와 위아래 거리 (z): B (0.35, 0.07) 를 1 cm 단위로 다시 정한다.

| 항목 | 합격 |
