## 2. 규칙 v2 (정확히)

용어: 저장본 간격 50 회 · **창 = 연속 5 저장본**(N−200 … N, 첫 점과 마지막 점 사이 **200 회**). 인접 창은 4/5(80 %) 겹치므로 창 평균의 변화는 (새 점 − 빠진 점)/5 로 순간 하락이 다섯 배 작게 보인다(analyst 5.2). 그래서 운영 중단선(4) 과 마지막 저장본 조건(2 · 5) 은 창 평균 밖에 둔다. 단계 시작 뒤 +50 … +250 의 첫 다섯 저장본이 첫 창이므로 **첫 판정은 단계 시작 250 회 뒤**(부모 시작점 m1500 은 창에 넣지 않는다). 창 경계 = 50 회마다 미끄러지며(가장 최근 5 개, 인접 창은 4/5 겹침) 평가가 다 있는 저장본. 결측은 8.

1. **기준선(부모)**: 단계 시작 저장본과 그 앞 여섯(50 간격, 합 7) 의 경우별 Q · C · kept 평균 μ 와 모표준편차 σ. EX-35 는 m1200~m1500(§3.3 표). **이것은 「채택 부모 m1500 의 능력 유지」 에서 「최근 정책 집합의 평균 수준 유지」 로 계약을 바꾸는 것이다**(analyst 2.3): right_then_left 하한 0.584 → 0.242, fwd_then_left 0.563 → 0.212 로 m1500 대비 69 % · 72 % 하락까지 허용된다. 이름과 하한을 공개하고 팀장이 고른다(§6 7). 다음 단계의 기준선을 「직전 단계 졸업 창 5 + 앞 둘」 로 매번 다시 잡으면 누적 망각을 감출 수 있으므로, 대안은 **단계 시작 기준선을 사슬 전체에 고정**(C0 졸업 띠를 계속 씀) 이다(§6 7). 64 env 전진(A2) · 생존도 같은 7 저장본 평균(§3.4). 창의 다섯 저장본은 **같은 처치**(같은 설정 해시 · 새 과제 노출 시작 뒤) 여야 하며 옛 단계 저장본을 새 단계 창에 섞지 않는다(analyst 5.3).
2. **유지(MAINTAIN)**: 창 평균이 **모든 경우** 에서 Q ≥ μ − 1.0σ, C ≤ μ + 1.0σ, kept ≥ 14, **그리고 마지막 저장본 단독으로 여섯 경우 kept ≥ 14**(기존 넘어짐 허용 기준 그대로 · 평균 규칙만으로는 kept [16,16,16,16,6] 평균 14 가 통과하고 실제 m2000 의 켬 13 · 13 · 가림 12 · 13 이 가려진다, analyst 막음 2). A2 창 평균 ≥ 부모 7 평균 × 0.90(현행 ×0.9 를 한 점 → 평균으로만 바꿈), 생존 창 평균 ≥ 60/64. 하나라도 미달 = 그 창 MAINTAIN_FAIL.
3. **새 과제(NEW_TASK)**: 창 평균이 성공선(walk_turn 두 부호 Q ≥ 0.25 · C ≤ 0.6 · kept ≥ 14 · 반대 0 · 적분 ≥ 3.2 m) 통과 **그리고** 직전 창 평균 대비 Q 하락 ≤ 0.083 · 적분 하락 ≤ 0.2 m(추세: 「그래프가 이어지는가」, 첫 창은 직전 없음 → 추세 조건 생략, 둘째 창부터).
4. **멈춤(STOP)**: 3 절 운영 중단선은 **저장본 하나** 에도 그대로(Q < 0.12 어느 경우 · 64 env 회전 생존 < 48 · 켬 fwd1.0 < 기준 × 0.90 · NaN · 기동 실패). 창 평균으로 가리지 않는다.
5. **넘김(EXPAND)**: 한 창에서 2 · 3 이 모두 맞고 HOLD_NO_DATA 없음 · A12 재현 일치 · A11 영상 판독 「없음」 이면 **그 창 경계에서 바로 다음 단계**. 최소 체류는 따로 없다(창 하나 = 250 회가 실효 최소). 넘김 저장본 = 창의 마지막 저장본. 창 평균 통과는 마지막 저장본의 성과를 보장하지 않으므로(넘기는 것은 정책 평균이 아니라 마지막 정책 하나, verifier 7 절) **마지막 저장본 단독**으로도 운영 중단선(4) 과 새 과제 성공선(기존 값 · 저장본 하나 판정) 을 통과해야 한다. 새 문턱이 아니라 기존 저장본 판정의 재사용이다(팀장 확인 §6 5).
6. **되돌림(REVERT)**: MAINTAIN_FAIL 창이 **연속 둘**(연속 창 경계 둘, 간격 **50 회** · 저장본 4/5 겹침) → 직전 단계 값으로. 하나면 HOLD(같은 조건 계속). 두 번 되돌리면 멈춤 · 보고.
7. **계속(CONTINUE)**: 유지 통과 · 새 과제 미달 → 같은 조건 계속. 평평(새 과제 창 평균이 2 창 연속 개선 < 0.083) 또는 상한(같은 조건 1,500 회) 에서 멈춤 · 보고(현행 §4b.2 유지).
8. **결측**: 창 다섯 저장본 중 하나라도 평가 없음 → HOLD_NO_DATA(연장 불가 · 넘김 불가 · 보고). 평가 사슬은 **50 회 저장본마다** 턴 16 세 모드 + map64 를 돈다(지금 사슬 그대로).
