## 1. 왜 고치나 (실측)

### 1.1 현행 규칙을 부모 자기 저장본에 걸면 전부 깨진다 `[실측 · ckpt_fluct.py]`

| 부모 저장본 | 현행 규칙(m1500 − 0.20 / + 0.25 / kept < 14) 깃발 |
|---|---|
| m900 ~ m1050 | 경우 넷~다섯 Q · C 모두 미달 |
| m1100 · m1150 | right_then_left Q 0.271 · 0.433 < 0.584, fwd_then_left Q < 0.563 … |
| m1200 · m1250 · m1300 · m1350 · m1450 | right_then_left Q 0.216~0.453 < 0.584 · fwd_then_left Q 0.180~0.374 < 0.563 · C 초과 |
| **m1400** | right_then_left Q 0.537 < 0.584 · fwd_then_left Q 0.456 < 0.563 |
| 합 | **12 / 12 MAINTAIN_FAIL**. 부모가 부모를 못 지킨다 |

까닭: m1500 은 right_then_left 0.784 · fwd_then_left 0.763 로 7 저장본 평균 0.425 · 0.385 보다 **+2σ** 인 점이다. 한 점을 기준으로 쓰면 그 점이 높은 쪽 흔들림일 때 뒤 저장본 전부가 「하락」 이 된다. EX-35 m1950(0.496 · 0.476) · m2000(0.559 · 0.571) 의 drop_Q 가 정확히 이 경우다. 두 값은 부모 7 저장본 **평균보다 높다**.

### 1.2 저장본 간 흔들림의 크기 `[실측]`

| 측정 | Q | 비고 |
|---|---|---|
| 같은 저장본 재측정 폭(JUDGE-SPEC 6.6, 여섯 쌍 최대) | 0.083 | 옛 pooled 24 쌍 최대 0.115 |
| 부모 m1200~m1500 저장본 간 SD(경우 평균 뺀 잔차, 42 칸) | **0.175** | 절대 최대 0.378 |
| 경우별 SD | 0.092(indep_left) ~ 0.217(indep_right) | 좌 · 우 · 전환 모두 재측정 폭의 1~2.6 배 |
| 연속 3 저장본 평균의 SD(σ/√3) | 0.101 | ≈ pooled 폭 0.115 |
| **연속 5 저장본 평균의 SD(σ/√5)** | **0.078** | ≈ 재측정 폭 0.083 → 한 창 평균 = 재측정 한 번만큼 |

팀장의 「정본도 1500 까지 들쑥날쑥」 이 숫자로 이것이다. 저장본 하나의 Q 는 정책 변화와 흔들림을 못 가른다. 다섯 개 평균이면 흔들림이 재측정 잡음 수준으로 내려온다.

## 2. 규칙 v2 (정확히)

용어: 저장본 간격 50 회 · **창 = 연속 5 저장본**(N−200 … N, 250 회) · 창 경계 = 50 회마다 미끄러지며(가장 최근 5 개) 평가가 다 있는 저장본.

1. **기준선(부모)**: 단계 시작 저장본과 그 앞 여섯(50 간격, 합 7) 의 경우별 Q · C · kept 평균 μ 와 모표준편차 σ. EX-35 는 m1200~m1500(§3.3 표). 다음 단계의 기준선은 **직전 단계 졸업 창 5 저장본 + 그 앞 둘**(합 7) 로 같은 식. 64 env 전진(A2) · 생존도 같은 7 저장본 평균(§3.4).
2. **유지(MAINTAIN)**: 창 평균이 **모든 경우** 에서 Q ≥ μ − 1.0σ, C ≤ μ + 1.0σ, kept ≥ 14. A2 창 평균 ≥ 부모 7 평균 × 0.90(현행 ×0.9 를 한 점 → 평균으로만 바꿈), 생존 창 평균 ≥ 60/64. 하나라도 미달 = 그 창 MAINTAIN_FAIL.
3. **새 과제(NEW_TASK)**: 창 평균이 성공선(walk_turn 두 부호 Q ≥ 0.25 · C ≤ 0.6 · kept ≥ 14 · 반대 0 · 적분 ≥ 3.2 m) 통과 **그리고** 직전 창 평균 대비 Q 하락 ≤ 0.083 · 적분 하락 ≤ 0.2 m(추세: 「그래프가 이어지는가」, 첫 창은 직전 없음 → 추세 조건 생략, 둘째 창부터).
4. **멈춤(STOP)**: 3 절 운영 중단선은 **저장본 하나** 에도 그대로(Q < 0.12 어느 경우 · 64 env 회전 생존 < 48 · 켬 fwd1.0 < 기준 × 0.90 · NaN · 기동 실패). 창 평균으로 가리지 않는다.
5. **넘김(EXPAND)**: 한 창에서 2 · 3 이 모두 맞고 HOLD_NO_DATA 없음 · A12 재현 일치 · A11 영상 판독 「없음」 이면 **그 창 경계에서 바로 다음 단계**. 최소 체류는 따로 없다(창 하나 = 250 회가 실효 최소). 넘김 저장본 = 창의 마지막 저장본.
6. **되돌림(REVERT)**: MAINTAIN_FAIL 창이 **연속 둘**(창 경계 둘, 100 회 사이) → 직전 단계 값으로. 하나면 HOLD(같은 조건 계속). 두 번 되돌리면 멈춤 · 보고.
7. **계속(CONTINUE)**: 유지 통과 · 새 과제 미달 → 같은 조건 계속. 평평(새 과제 창 평균이 2 창 연속 개선 < 0.083) 또는 상한(같은 조건 1,500 회) 에서 멈춤 · 보고(현행 §4b.2 유지).
8. **결측**: 창 다섯 저장본 중 하나라도 평가 없음 → HOLD_NO_DATA(연장 불가 · 넘김 불가 · 보고). 평가 사슬은 **50 회 저장본마다** 턴 16 세 모드 + map64 를 돈다(지금 사슬 그대로).

## 6. lead · 팀장이 정할 것
