이슈 #484의 작업이다. 새 이슈·브랜치·검증자 호출과 시뮬레이션·학습 실행은 하지 않는다. 현재 저장소의 다른 작업은 건드리지 않는다. 결과는 이 폴더의 `VERIFY-MVP-3.md`에 작성한다. 작성자는 Codex astra다. 한국어, 시드, actor·critic·optimizer 원어, em dash 금지를 지킨다.

사용자가 제작 이력(HUD 유무·화면 크기 등), fs1·fs2 참고 항목, 부록 원보고서 개정 이력을 공식 제출본에서 제외하도록 요청했다. 웹 기록을 삭제한 것이 아니다. 이 제외는 승인된 편집이다. 원문과 똑같이 되돌리라는 검증이 아니다. 실험 조건과 실패, 해석의 한계, 그림·영상은 유지해야 한다.

최종 동기화에서 공개본이 v3.6에서 v3.9로 바뀌었다. 저속 추종 해석 정정, 확장 축 영상 18편, 미경험 지형 영상 9편, 지형별 표 등이 추가됐다. `source/report.html`이 새 기준이며 앞 보존본은 `source/report-92f8729d1c60.html`이다. 아래 수량과 수정 주장도 직접 다시 세어 틀린 곳을 찾는다.

- ZIP: HTML·두 PDF·49개 원영상·사용 안내·manifest. 네트워크를 차단해 상대경로 영상이 재생되는지, PDF가 출력 파일과 같은 바이트인지 확인한다. HTML 단독은 공개영상URL, ZIP 안HTML은 상대경로다.

`#web-content`와`#print-root`는 같은 콘텐츠의 화면·인쇄 DOM이다. 단순 합산하지 않는다. 새 탭의 기본 인쇄, 버튼 인쇄, 인쇄 후 복귀, 모바일 가로 넘침, PDF 목차 목적지, 모든 페이지의 잘림·글자·여백을 검사한다. 새 표와 영상이 늘어난 구간을 특히 본다.

한국어 표현·근거·오해·과장을 검증한다. 모든 연구 주장의 전면 재실험을 요구하는 것은 아니며, 재지 못한 부분은 미확인으로 남긴다. 제출 차단 오류와 선택적 보강을 구분한다. 이전 검증 보고서는 옛 해시에만 유효하므로 이번 파일들의 SHA-256을 새로 남긴다. 오류가 있으면 보고서로 알리고 산출물은 직접 고치지 않는다.
