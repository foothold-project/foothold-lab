## 원문 보존을 직접 센 결과

`inventory.json`, `coverage.json`, `pagination-audit.json`의 수를 증거로 대신하지 않았다. 보존 HTML의 section과 자식 노드를 직접 순회해 제출 HTML·인쇄용 DOM과 대응시켰다.

| 항목 | 직접 센 결과 | 판정 |
|---|---|---|
| 본문 절 | 원문·제출 HTML 각 16개 | 일치 |
| 본문 블록 | 원문 최상위 자식 중 script·style·위치 표시 span을 제외한 306개 | 웹·인쇄용 DOM 대응 누락 0개 |
| 표 | 원문·제출 HTML 각 45개 | 일치 |
| 표 셀 | 각각 1,047개 | 8개 셀의 문구 치환만 있고 숫자 변경 없음 |
| 인쇄용 표 분할 | 45개 표가 51개 조각 | 반복 표 머리를 제외하고 원문 블록별 행·셀을 합치면 순서와 값 일치 |
| 본문 원 그림 | 8개 | HTML의 원 이미지 바이트가 보존 자료와 일치 |
| 인쇄용 그림 | 원 그림 8개에 대응하는 12개 조각 | 그림 4·6·7의 분할을 포함해 정보 보존을 렌더와 SVG 텍스트로 대조 |
| 직접 삽입 영상 | 웹 본문 각 22편 | 파일 대응·순서 일치. 인쇄용 복제 DOM을 별도 영상으로 중복 세지 않음 |
| PDF 영상 장면 | 대표 22개 + V22 추가 2개 | 24개 모두 PDF에서 추출한 JPEG 바이트가 `stills/` 원본과 일치 |
| PDF 텍스트 | 웹 본문의 문단·목록·셀·제목·캡션·코드·장면 설명 등 비어 있지 않은 1,400개 항목 | 공백·줄바꿈 정규화 후 PDF 텍스트 미검출 0개 |

표의 문구 변경은 31번째 표 1개 셀과 개정 이력 표 7개 셀이다. 개인 직함·“터진 판” 등의 표현을 바꿨으며 숫자는 같다. 영상 조작부의 `0.25x·0.5x·1x·2x`는 본문 수치와 분리했다. 이 배속은 새 조작부에도 있다.

제목 16개를 포함해 원문 대응 블록 29개의 텍스트가 달랐다. 제목과 조작부를 제외한 숫자열 차이는 V15 시각 정정 블록 한 곳이다. 주요 개인 이름·내부 직함 치환은 기술적 수치나 비교 조건을 바꾸지 않았다. 추가된 원자료 접근 안내도 확인했다. 실험 조건·실패·한계 문구가 통째로 사라진 사례는 발견하지 못했다.

SVG 인쇄본은 원본과 바이트가 같은 그림으로 취급하지 않았다. 확대·재배치한 별도 그림이다. 원 SVG의 숫자·조건·설명 텍스트와 인쇄본을 대조했고, 분할 SVG 안에 숨겨진 중복 텍스트가 존재하므로 추출 텍스트만으로 보존을 판정하지 않고 실제 페이지에서 보이는 부분도 확인했다. 원본 PNG 2개와 SVG 6개를 PDF 비트맵 수만으로 세는 방식은 사용하지 않았다.

## 대표 성능 수치 재계산과 검증 한계


새 실험을 실행하지 않았다. 바로 접근할 수 있는 기존 CSV와 환경별 JSON을 다시 집계했다. 이는 원보고서의 모든 과학적 주장을 재검증했다는 뜻이 아니다.

`sim/eval/results/20260928-v2-sweep/sweep_long.csv`에서 난이도 0.5, 미경험 8종, 속도 0.5·1.0·1.5 m/s인 24개 셀을 모델별로 골라 산술평균했다. 해당 CSV의 SHA-256은 `51d4faee0dab222760ed477b66d117d5b2ea4d2becef21067c0d3e283266e706`다. 지형은 `discrete_obstacles`, `floating_ring`, `pit`, `repeated_boxes`, `repeated_cylinders`, `stepping_stones`, `star`, `wave`다.

위 CSV에는 이미 집계된 성공률이 들어 있다. 이번에 24개 셀을 다시 평균한 것은 확인했지만 그 모든 에피소드의 성공 판정을 시계열에서 새로 계산하지는 않았다.

`sim/eval/results/20260929-axis2-fall/`의 `nvidia`, `v1`, `v2` 아래 `stop·hold·turn/per_env.json`도 직접 셌다. 각 파일은 64개 기록이다.

| 낙상 건수 / 64 | NVIDIA | v1 | v2 |
|---|---:|---:|---:|
| stop | 0 | 13 | 0 |
| hold | 0 | 5 | 0 |
| turn | 4 | 64 | 7 |

따라서 제출본의 0.2031, 0.0781, 0.0625, 1.0000, 0.1094는 반올림과 맞는다. `20260921-v2ab-axis2/v2a-iter1500/turn/per_env.json`과 `v2b-iter1500/turn/per_env.json`의 낙상도 각각 59/64, 4/64로 다시 확인했다.

영상 재촬영 자료와 예전 성적표의 세부 지표가 항상 같은 실행에서 나온 것은 아니다. 예를 들어 9월 29일 재촬영의 v1 hold 관절 떨림 평균을 9월 18일 성적표의 값 0.125841과 그대로 같은 것으로 취급하면 안 된다. 후자는 `20260918-command-baseline/foothold-v1/hold/per_env.json`에서 다시 평균하면 0.12584133744589054다. 영상 사례와 성적표 집계를 구별한 원문의 설명은 유지해야 한다.

모든 모델의 계보, 정책 수준 탐색의 성능 상한, 시드 간 차이의 통계적 유의성, 모든 지형 레이아웃에 대한 일반화, 배포 파일 동일성과 실기 안전성은 이 제출본 변환 검증으로 승인하지 않는다. 직접 검증하지 않은 연구 주장은 `미확인`이다. 원문의 기존 한계 설명을 보존한 것과 그 결론을 새로 입증한 것은 구분한다.

V20·V21의 선택 프레임 3.6초에서 HUD 전진 거리는 각각 약 4.03m·3.91m다. 원래 캡션의 4.56m·4.46m는 영상 종료 무렵의 값이다. V20·V21의 scene-note에는 “캡션의 전진 거리는 영상 전체의 최종값이며, 대표 장면 시각의 HUD 값과 다를 수 있다.”가 이미 있다. 이 설명은 HTML과 PDF 30쪽에 모두 있으므로 추가 보강 요구를 철회한다.

## PDF 레이아웃과 HTML 동작

최종 PDF는 A4 34쪽이다. 01/34부터 34/34까지 번호를 확인했고, 전체 페이지를 직접 렌더해 읽었다. 인쇄용 본문 높이 초과는 0곳이다. 본문은 대체로 10pt, 표는 대체로 8pt이며 초기 SVG의 극단적인 축소는 해소됐다. 작은 코드·영상 메타데이터·HUD까지 큰 본문 글씨처럼 읽힌다는 뜻은 아니다.

HTML은 Chromium에서 1440px와 390px 너비로 확인했다. 페이지 전체 가로 넘침, 웹 본문의 깨진 이미지, JavaScript 실행 오류는 없었다. 최종 HTML에 이미 들어 있는 인쇄용 페이지가 웹 본문에 중복 노출되지 않는 것도 확인했다. 기본 인쇄와 자체 준비 경로는 모두 34쪽이고, 각각 새로 생성한 PDF 텍스트가 제출 PDF와 정규화 후 같았다.

영상 조작 코드는 초기 검증판과 최종판을 직접 비교해 같음을 확인했다. 실제 재생 검사는 영상 묶음 9개, 22편에서 재생 시간이 증가하고 미디어 오류가 없는지 확인했다. 함께 재생·일시정지, 배속 변경, 처음으로 돌아가기도 검사했다. 전체 영상에 배속 0.5가 적용되고 리셋 후 모두 정지·시각 0이었다. 초기 3편 묶음의 배속 2와 일시정지도 확인했다.

## 링크와 외부 전달

fragment를 제외한 외부 고유 URL 26개를 실제 요청해 모두 HTTP 200 응답을 확인했다. 영상 22편, 보고서·평가 프로토콜·계보 문서·PR 연결을 포함한다. `/issues/461`은 해당 PR로 연결된다. 확인 시점의 접근 결과다.

PDF 외부 URI 28개는 HTTPS다. 영상 링크 22개의 파일명과 `#t=` 시각은 HTML·장면 목록과 일치한다. 내부 목차 16개도 최종 목적지까지 확인했다. 특정 PDF 뷰어가 링크를 연 뒤 영상 시작 시각을 처리하는 방식은 모든 뷰어에서 검증하지 않았으므로 `미확인`이다.

HTML의 파일 상대 링크 `FOOTHOLD-MVP.pdf`는 같은 `output/` 폴더에 존재한다. HTML·PDF를 같은 폴더로 전달해야 이 연결이 유지된다. 이미지는 포함돼 있지만 영상 재생에는 인터넷이 필요하다. `data-local="media/..."`는 실제 오프라인 대체 경로로 사용되지 않는다.

최종 PDF 32쪽 근거 절에는 `sim/`, `_out/`, `params/`가 저장소 또는 로컬 원자료 경로이며 제출 파일에 원자료 전체가 포함되지 않는다는 안내가 추가됐다. 이 보고서에서도 그런 원자료는 링크가 아니라 코드 경로로 적었다. 외부 독자가 원자료 전체를 직접 내려받아 재현할 수 있는지는 `미확인`이다.

## 선택적 보강

다음은 현재 제출본을 차단할 정도의 누락·수치 오류로 판단하지 않았다.

- PDF 6~7쪽의 그림 4는 분할됐지만 캡션의 “두 묶음을 나란히”, 그림 설명의 “왼쪽 판”이 남았다. “앞쪽의 미경험 8종” 등 실제 배치에 맞는 참조로 바꾸고 두 번째 패널에도 세로축 눈금을 반복하면 독립적으로 읽기 쉽다.
- PDF 21쪽·33쪽의 본문 사용 높이는 약 75%, 29쪽은 77%, 마지막 34쪽은 70%다. 그림·표를 보존한 여백이며 빈 페이지나 잘림은 아니다. 더 줄일지는 가독성과 함께 결정할 수 있다.
- “함께 재생”은 정밀한 동기화가 아니다. 초기 로딩 후 stop 세 영상에서 약 0.568·0.518·0.115초가 동시에 관측됐다. 엄밀한 같은 시각 비교가 목적이면 로딩 완료 후 공통 시각 맞춤과 재생 중 동기화가 필요하다.
- “터진”, “구운”, “판”, “하네스”, “검토자 물음” 등 내부 문체가 일부 남았다. 외부 독자용으로 용어를 정리할 여지가 있으나 수치나 연구 한계를 약화시키는 전면 재작성은 필요하지 않다.
