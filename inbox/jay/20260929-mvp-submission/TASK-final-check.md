# 제출 차단 문구 수정 후 변경 부분 재검증

> 근거: VERIFY-MVP-3.md의 B1~B3 및 선택적 보강
> 요지: 이미 통과한 통계·영상은 반복하지 않고 수정된 문구와 새 출력의 대응을 확인한다.
> 상태: 검증 의뢰 · 판정 `미확인`

이슈 #484. 결과는 `VERIFY-MVP-4.md`에 작성한다. 작성자 Codex astra, 한국어, 시드, actor·critic·optimizer 원어, em dash 금지. 새 학습·시뮬레이션·다른 검증자·이슈·브랜치는 만들지 않는다. 이전 보고서는 옛 해시의 기록으로 보존한다.

**3차 보고서의 7절에 따라 변경 부분을 재검증한다.** 변경되지 않은 원자료의 핵심 수치 재집계, 영상 49편 전수 재시청·다운로드는 반복하지 않는다. 요약 PDF도 3차에서 통과한 파일 그대로다. 수정 완료 주장만 믿지는 말고 아래 문구와 관련 표, 최종 파일에서 직접 확인한다.

- B1: s10-b011·b051·b052·b054와 s12-b015의 외란 설명을 통일했다. --keep_pushes는 기존 외란 이벤트 유지 옵션이며 SCENARIOS에는 push_robot이 없다. 외란 비교 전에 이벤트 조건과 회복 지표를 정의하고 발생을 검증해야 한다. 구현 완료·하네스 없음의 모순이 다른 곳에도 남았는지 확인한다.
- B2: s12-b015에서 HUD 제작 설명과 fs1·fs2 식별자를 없애고 resume 비교의 목적만 남겼다. 완료된 영상 제작 계획 행도 제외했다. s15-b002에서는 HUD 유무 집계 행과 학습 진행 영상의 폐기·이전 버전 설명을 없애되 현재 원영상·생성 경로는 유지했다. s14의 기존 승인 제외도 유지한다.
- B3: s10-b048에서 레시피 영향 배제 단정을 삭제했다. 세 모델에서 공통 경향이 관찰됐다는 사실과 원인 분리가 미확인이라는 한계를 구분했다.
- 선택적 보강: s10-b013은 유효 표본 평균으로, b029는 env 51 사례 영상과 집계의 구분으로 수정했다. b019의 저속 오차 원인도 가설로 제한했다. b052의 시점 불명확한 manifest99개는 평면을 지정하는 코드 근거로 대체했다.
- 조판: 표 제목이 페이지 끝에 홀로 남지 않도록 제목과 표의 첫 두 행을 함께 배치한다. 관련 페이지와 새 전체 렌더의 넘침, 목차15개, 영상49개 및 대표장면51개의 대응을 확인한다.
- 재현: summary_pdf.py는 원자료 사본 source/evidence/를 우선 읽도록 했다. 원래 원자료와 같은 바이트 12개를 보존했으며 summary-evidence.json의 원자료 해시와 맞춰 확인한다. 원자료 폴더가 없는 분리 작업 공간에서도 실행해 동일한 집계값을 확인했다. 요약 출력의 내용은 바꾸지 않았다.

HTML·본문 PDF·ZIP을 다시 만들었으므로 새 SHA-256과 ZIP 내부 두 PDF 일치, HTML 상대 영상 경로 치환을 확인한다. 영상 파일 자체는 모두 3차 통과 파일과 동일하다. 숫자·그림·영상이 삭제되거나 뜻이 달라진 곳이 없는지 수정 범위 중심으로 확인한다. 차단 오류가 해결됐으면 최종 제출 가능 여부를 명시한다.
