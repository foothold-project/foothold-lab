[TASK-reverify.md](TASK-reverify.md)와 사용자의 추가 지시를 수행했다. 같은 해시에서 이미 직접 수행한 원문·수치·영상 장면·전체 PDF 검증은 [VERIFY-MVP.md](VERIFY-MVP.md)의 독립 검증을 재사용했다. 이번에는 새 범위인 ZIP 전달, [CONTENT-MAP.md](CONTENT-MAP.md), 검증 보고서 자신의 사실 정확성을 확인했다. 원문과 제출 파일은 수정하지 않았다. git 조작, 새 이슈, 학습·시뮬레이션, 다른 검증자 호출도 하지 않았다.

## 판정과 대상 해시

**이 ZIP은 제출 가능하다. 새로 확인한 제출 차단 사항은 없다.** ZIP을 모두 풀고 HTML·PDF·media 폴더의 배치를 유지하면 HTML 영상 22편이 인터넷 없이 재생된다. PDF의 공개 영상 링크와 외부 원자료 링크에는 인터넷이 필요하며, 동봉 안내문도 이를 구분한다. 이 판정은 제출본 변환·전달 범위에 한정하며 원보고서의 모든 과학적 주장을 새로 승인하지 않는다.

해시는 manifest를 옮겨 적지 않고 실제 파일 바이트에서 직접 계산했다.

## ZIP의 실제 오프라인 전달

작성 세션의 `delivery-check.json`, `offline-check.json`, `package-manifest.json`을 통과 근거로 대신하지 않았다. 원 ZIP을 독립 임시 폴더에 해제하고 파일과 브라우저 동작을 검사했다.

| 검사 | 직접 확인한 결과 | 판정 |
|---|---|---|
| ZIP 크기·구조 | 45,982,745바이트. HTML·PDF·안내문·manifest 각 1개와 MP4 22개, 총 26개 파일 | 확인됨 |
| ZIP 무결성 | 중복 이름 0개, CRC 오류 0개, 압축 해제 대상 밖으로 나가는 경로 0개 | 확인됨 |
| 영상 바이트 | ZIP의 22개 MP4와 `source/media/` 대응 파일을 직접 비교, 불일치 0개 | 확인됨 |
| PDF 바이트 | ZIP PDF와 고정 제출 PDF가 완전히 같음 | 확인됨 |
| 오프라인 HTML 변경 범위 | 고정 HTML의 공개 영상 URL 22종을 `media/파일명.mp4`로 치환하면 ZIP HTML과 전체 문자열 일치 | 확인됨 |
| 로컬 경로 | src·href의 로컬 참조 67개, 고유 문자열 45개. fragment를 제외한 대상 파일 누락 0개 | 확인됨 |
| manifest 대조 | 먼저 직접 읽고 해시를 계산한 25개 실물 파일이 ZIP 내부 manifest의 크기·해시와 모두 일치 | 확인됨 |
| 외부 화면 의존성 | 외부 script·stylesheet 없음. 이미지와 스타일이 포함돼 있으며 웹 본문 이미지 로딩 실패 0개 | 확인됨 |

ZIP 안 HTML의 해시가 일반 제출 HTML과 다른 이유는 영상 URL의 로컬 경로 치환이다. 본문·스타일·스크립트·대표 그림·조판된 인쇄 DOM을 별도 내용으로 바꾼 것이 아니다. 일반 `output/FOOTHOLD-MVP.html`의 온라인 재생과 ZIP 안 HTML의 오프라인 재생을 구분해야 한다.

실제 재생은 Windows의 Chrome을 Playwright로 실행한 새 브라우저 컨텍스트에서 검사했다. 컨텍스트를 오프라인으로 설정하고 HTTP·HTTPS 요청도 차단한 뒤, ZIP에서 직접 해제한 HTML을 `file://`로 열었다. 기존 작성 세션의 해제 폴더나 웹 서버를 사용하지 않았다.

- 화면 영상 22편, 비교 묶음 9개를 실제 조작했다. 22편 모두 `currentSrc`가 해제 폴더의 로컬 MP4였다.
- 모두 재생 시간이 0.15초 이상 증가했고, 디코딩된 프레임 수 13~14개, `readyState=4`, 1280×720 크기를 확인했다. 미디어 오류는 0개였다. 이는 각 영상의 재생 진입 검사이며 22편을 처음부터 끝까지 다시 시청했다는 뜻은 아니다. 파일 전체 동일성은 위의 바이트 대조로 확인했다.
- 9개 묶음 모두 재생·일시정지, 배속 0.5, 초기화 후 정지·시각 0을 확인했다.
- HTTP·HTTPS 요청 0개, JavaScript 오류 0개였다. 인쇄 DOM에는 video 태그가 0개이며 화면 영상 22편과 중복 재생되지 않는다.
- 인쇄 전·후 이벤트 뒤 화면 본문은 표시되고 인쇄 DOM은 숨겨지는 복귀 상태도 확인했다. 실제 OS 인쇄 대화상자에서 취소 버튼을 누르는 동작을 새로 검사한 것은 아니다.

동봉 `읽어주세요.txt`의 압축 전체 해제, media 폴더 유지, PDF 동일 폴더 배치 지시는 실제 구조와 맞는다. 다른 운영체제·모든 브라우저의 동작은 `미확인`이다. 확인한 환경에서 외부 서버 없이 전달·재생할 수 있다는 판정은 성립한다.

## CONTENT-MAP.md의 페이지 대응

작성 세션의 집계 코드를 실행하지 않고 보존 원문에서 절별 표·그림·영상 수를 세고, 고정 HTML의 인쇄 페이지별 source-id와 영상 ID로 페이지를 독립 추출했다. 같은 source-id의 분할 그림·표는 논리적으로 묶었다. 고정 PDF와 인쇄 DOM의 대응은 기존 독립 검증을 재사용하고, 영상별 ID·대표 시각 문구는 실제 PDF의 해당 페이지에서도 다시 대조했다.

| 대응표 | 검사량 | 결과 |
|---|---:|---|
| 본문 절 | 16행의 페이지 목록과 절별 표·그림·영상 수 | 모두 일치 |
| 원 그림 | 8행의 파일명과 페이지 목록 | 모두 일치 |
| 영상 | 22행의 ID·파일명·대표 시각·페이지 | 모두 일치. PDF 해당 페이지에서 장면 메타데이터 미검출 0개 |

분할 그림의 페이지는 그림 4가 6·7쪽, 그림 6이 15·16쪽, 그림 7이 21·22쪽이다. V01~03은 11쪽, V04~05는 12쪽, V06~07은 14쪽, V08~16은 26쪽, V17~19는 28쪽, V20~21은 30쪽, V22는 31쪽이다. 자료 대응표의 값을 직접 추출한 결과와 대조해 오류를 발견하지 못했다. `확인됨`

검증 도중 대응표의 상태 표기에 코드 서식만 추가됐다. 이 한 곳을 되돌린 바이트 해시가 최초 검사본과 같음을 확인했으며, 페이지 대응 내용은 바뀌지 않았다. 위 표에는 서식 변경 후 해시를 기록했다.

## 기존 검증 보고서의 오기 정정

지적받은 두 조치는 고정 산출물에 이미 들어 있었다. 수정판을 제출하라고 요구할 사안이 아니라 검증 보고서의 잘못된 서술을 고칠 사안이다.

| 위치 | 기존 보고서의 잘못된 서술 | 직접 확인한 사실과 정정 |
|---|---|---|
| B5, HTML `s7-b124`·PDF 16쪽 | “검토자가”로 고쳤고 “나는”이 남았다고 기록 | 실제로는 “반복적인 학습 중단을 검토하면서”로 시작하는 새 문단이다. 해당 문단에 두 표현 모두 없고, 웹 본문 전체에서도 “나는”·“검토자가” 잔존을 찾지 못했다. 기존 B5 표와 선택적 문체 권고에서 이 주장을 정정함 |
| V20·V21, HTML scene-note·PDF 30쪽 | 최종 거리 설명을 추가하면 좋겠다고 권고 | “캡션의 전진 거리는 영상 전체의 최종값이며, 대표 장면 시각의 HUD 값과 다를 수 있다.”가 이미 있음. 해당 문단과 선택적 보강 요구를 정정·철회함 |
| V01~V03, HTML scene-note·PDF 11쪽 | 최종 거리와 선택 시각의 값을 구분할 필요가 있다고 기록 | 위와 같은 설명이 세 영상에도 모두 있음. 영상 검증 표의 연관 오기도 함께 정정함 |

B5의 실제 새 문단은 다음과 같다.

> 반복적인 학습 중단을 검토하면서 원인 탐색이 「어느 설정이 중단을 유발하는가」에 한정돼 있었음을 확인했다. 변한 설정만 비교하는 방법으로는 모든 실험에서 변하지 않은 변수의 영향을 찾기 어렵다.

보존 원문은 특정 인물과 1인칭을 사용한 뒤 “변하지 않는 변수는 그 방법으로 안 보인다”는 한계를 설명한다. 새 문단도 바뀐 설정만 비교하면 공통 변수의 영향을 찾기 어렵다는 한계를 유지한다. 화자를 없앴다는 이유로 이 한계가 소실되거나 연구 주장이 강해진 것으로 볼 근거는 없다.

기존 보고서의 거리 실측값 자체는 취소하지 않았다. V20·V21의 대표 장면 HUD와 영상 최종값은 다르며, 제출본이 이미 그 차이를 설명한다는 사실을 잘못 놓친 것이었다. 검증 보고서만 정정했고 원문·HTML·PDF·ZIP은 수정하지 않았다.

## 남는 사항과 재검증 조건

이전 보고서의 그림 4 방향 참조 문구, 일부 여백, 영상 간 정밀 동기화, 일부 내부 용어에 관한 선택적 보강은 유지한다. B5의 1인칭 잔존과 거리 설명 누락 권고는 유지하지 않는다. 원보고서 전체 연구 주장, 실기 안전성, 제출 파일에 포함되지 않은 원자료 전체의 외부 재현 가능성은 기존대로 `미확인`이다.

해시가 같은 현재 ZIP에는 추가 제출 차단 사항이 없다. ZIP만 다시 묶더라도 새 ZIP 해시를 남겨 구성과 파일 동일성을 확인해야 한다. HTML·PDF의 내용이나 조판이 바뀌면 해당 변경 범위에 맞춰 기존 검증을 갱신해야 한다.
