# MVP 제출본 수정 후 재검증 의뢰

> 분류: 운영
> 작성: Codex · 2026-09-29 12:19
> 근거: 공개 원보고서와 제출본 검증 의뢰
> 요지: 원문 보존과 전달 기능의 오류를 독립적으로 찾아 수정 여부를 재검증한다.
> 상태: 검증 의뢰 · 판정 `미확인`

원문: https://foothold-project.vercel.app/research-20260928-v2-mvp-report

이슈 #484의 독립 재검증이다. 첫 판정은 `VERIFY-MVP.md`에 그대로 보존하고, 이번 결과는 `VERIFY-MVP-2.md`에 작성한다. 새 이슈나 브랜치를 만들지 않는다. 학습·시뮬레이션·다른 검증자 호출은 하지 않는다. 한국어, 시드, actor·critic·optimizer 원어 유지, em dash 금지. 작성자는 Codex astra다.

`TASK-verify.md`의 범위와 B1~B5를 다시 검증한다. 아래 수정 주장은 검증의 결론이 아니다. 실제 파일과 원자료에서 다시 확인한다.

- B1: 출력용 제목 ID와 목차를 연결했다. PDF 링크 16개가 해당 절의 실제 페이지와 위치로 이동하는지 검사한다.
- B2: 조판된 인쇄 DOM을 HTML에 함께 저장한다. `#web-content`가 화면 원본, `#print-root`가 인쇄본이다. 화면 영상은 22개이며 인쇄 DOM에는 video 태그가 없다. 새 탭에서 기본 인쇄, 자체 버튼, 인쇄 취소 후 복귀를 검사한다. 두 DOM의 표를 단순 합산해 원문이 90개 표라고 세지 않는다.
- B3: 화면용 원 SVG 6개는 그대로 보존했다. PDF에서는 `print_figures.py`가 원본 문구와 값을 읽어 다시 배치한다. SVG 6개와 PNG 2개의 모든 정보가 유지됐는지 직접 확인한다. 난이도 곡선은 좌우 패널을 위아래로 나누고, 학습 중단 그림과 다음 단계 도식도 내용 경계에서 나뉜다. 반복 헤더와 같은 source-id를 가진 그림 조각은 논리적으로 한 그림이다. SVG 그림의 축, 범례와 수치, 요약 문구가 잘리지 않았는지 전체 렌더와 PDF 텍스트에서 확인한다. 원문에는 없던 데이터나 잘못된 색 대응을 만들지 않았는지도 확인한다.
- B4: V15 캡션을 대표 장면 3.5초, 낙상 판정 3.70초, 전체 길이 6.48초로 정정했다. 보존 원문은 수정하지 않고 변경 기록을 남겼다.
- B5: s7-b124는 특정 화자를 없애고, 변한 설정만 비교해서는 공통 변수의 영향을 찾기 어렵다는 한계를 유지한 문단으로 바꿨다.
- 선택적 보강: V01~03·V20~21 캡션의 전진 거리는 영상 전체의 최종값이라는 설명을 덧붙였다. 근거 절에 로컬 재현 경로는 제출 파일에 모두 포함되는 자료가 아니라는 안내를 덧붙였다.

이번에도 원문 306블록·45표·8그림·22영상과 표의 수치, PDF의 모든 본문·대표 장면 24개 보존을 직접 대조한다. 기존 원문 과학적 주장 전체에 대한 승인과 제출본 변환 검증을 구분한다. 읽기 어려운 도표나 잘림, 무의미하게 빈 공간이 남으면 지적한다.

`output/FOOTHOLD-MVP-submission.zip`에는 오프라인 HTML, 같은 PDF, 원 영상 22편이 들어 있다. 구조, 영상 바이트, 상대 경로, 실제 오프라인 재생도 확인한다. 작성 세션의 `delivery-check.json`, `package-manifest.json`은 독립 확인을 대신하지 않는다.

대상 파일 SHA-256과 최종 제출 가능 여부를 명확히 남긴다. 제출 차단 항목과 선택적 보강을 구분하고, 이전 지적이 해결됐다는 주장도 그대로 믿지 않는다.
