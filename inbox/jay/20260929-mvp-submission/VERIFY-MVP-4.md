**최종 제출 가능.** [3차 검증](VERIFY-MVP-3.md)의 차단 오류 B1~B3이 모두 해결됐다. 변경 부분에서 새 차단 오류를 찾지 못했다. 판정은 아래 고정 파일에 적용한다.

[이번 의뢰서](TASK-final-check.md)와 3차 보고서 7절에 따라 변경 문장·표·조판·파일 대응에 한정해 재검증했다. 변경되지 않은 핵심 수치의 재집계, 영상 전수 다운로드·재시청, 요약 PDF 재생성은 반복하지 않았다. 원문·제출 파일·기존 검증 보고서는 수정하지 않았다. 학습·시뮬레이션·다른 검증자 호출·이슈·브랜치·git 변경도 하지 않았다.

## 1. 판정 해시

파일에서 SHA-256을 직접 계산하고 검사 종료 시점에 다시 대조했다. 검사 중 변경은 없었다.

| 대상 | 바이트 | SHA-256 |
|---|---:|---|
| `output/FOOTHOLD-MVP.html` | 31761933 | `ee361febb29bd5f51bb9f44a597e15799be40e512a8e0ef241a3c158e54d116f` |
| `output/FOOTHOLD-MVP.pdf` | 9476013 | `f227277eff1a2dbe5ab3d1c4406675d9a98b2dff873fb10a616cf967408bdf94` |
| `output/FOOTHOLD-MVP-summary.pdf` | 418631 | `f392bf32ec11a6e8063854cc7a70905e77176189ad077caea836cd4800d8ff48` |
| `output/FOOTHOLD-MVP-submission.zip` | 108648739 | `652473e55b052d3a8546cbf6bd9110525406c57922ec84ccc87eb81849c0b555` |

`source/report.html`은 3차와 같은 `bc58eb7522fb777710233d05077fb1ffee761b9d2c7de44c13820540ae5cf828`이다. 요약 PDF도 3차 통과 파일과 바이트가 같다. 이번 정정은 보존 원문을 덮어쓰지 않고 제출본에 반영됐다.

3차에서 승인한 `s14`의 제외와 원문 판 이력 제외도 유지됐다. 제출 본문에서 `fs1`, `fs2`, “HUD 유무”, “이 판에서 붙였다”, “버린 4,096”의 잔존은 찾지 못했다. 원문 기록까지 삭제하거나 승인된 제외를 되돌린 변경은 없다.

### B3. 레시피 영향 배제 단정 제거: 통과

## 4. 새 PDF와 HTML의 조판·자료 대응

`확인됨`. 본문은 여전히 A4 40쪽이다. 모든 페이지를 같은 조건으로 렌더해 3차 PDF와 픽셀을 비교했다. 바뀐 페이지는 **23·24·25·26·28·32·39·40쪽**, 나머지 32쪽은 렌더 결과가 같았다. 변경된 8쪽을 시각적으로 확인했으며 잘림·겹침·표 제목 고립을 발견하지 못했다.

## 5. ZIP과 요약 원자료 사본

### 새 ZIP의 전달 대응

`확인됨`. ZIP의 실제 항목은 54개다. HTML 1개·PDF 2개·영상 49개·사용 안내·manifest가 들어 있다. manifest에 기록된 53개 파일의 크기와 SHA-256을 직접 계산해 모두 일치했다.

두 PDF는 ZIP 밖의 최종 PDF와 각각 바이트가 같다. 영상 49개는 3차 ZIP의 같은 파일과 SHA-256이 모두 같다. ZIP 안 HTML의 영상 상대경로 49개도 3차와 같고 실제 ZIP 항목을 가리킨다.

새 단독 HTML의 공개 영상 URL을 ZIP용 상대경로로 치환하면 ZIP 안 HTML과 정확히 같다. ZIP 안 HTML의 SHA-256은 `150cf9365c33cb9d490f9d64d2b239517ceff7da09dd21bc25f84292e0687433`이다.

따라서 3차의 오프라인 영상 재생 판정을 재사용한다. 이번에는 영상 전수 재생·다운로드를 반복하지 않았다. HTML 스크립트의 차이도 표 제목 조판 처리뿐이며 영상 제어 코드는 바뀌지 않았다. PDF의 영상 링크는 종전처럼 인터넷 연결이 필요한 공개 주소다.

### 원자료 사본의 새 읽기 경로

`확인됨`. `summary-evidence.json`에 기록된 원자료 12개를 직접 대조했다. CSV 1개, 정지·회전 환경별 JSON 9개, 저속 환경별 JSON 2개다. 각 파일에서 다음 세 값이 모두 일치했다.

1. 원래 로컬 `sim/eval/results/` 파일의 SHA-256
2. `source/evidence/` 아래 같은 상대경로 사본의 SHA-256
3. `summary-evidence.json`의 기록값

`summary_pdf.py`의 `source_bytes()`는 `source/evidence/` 사본을 먼저 읽고, 사본이 없을 때 원래 경로를 읽는다. 이 함수만 분리해 원래 원자료 경로가 존재하지 않는 임시 공간에서 실행했고 12개 모두 보존 사본과 같은 바이트를 반환했다. 원자료 사본 우선 읽기라는 변경 동작은 직접 확인했다.

요약 집계와 PDF 생성 전체를 다시 실행하지는 않았다. 변경되지 않은 집계를 반복하지 말라는 이번 의뢰에 따른 것이다. 집계 내용은 3차 결과를 재사용하며, 최종 요약 PDF의 해시가 3차 및 `summary-evidence.json`의 `summary_sha256`과 같은 것을 확인했다.

참고로 새 `summary_pdf.py`의 SHA-256은 `20621496afd5f8253ebdaf1596e97f6b84ede8336aacf519f7db8d00f7778c2f`, `summary-evidence.json`은 `b01e2ae4e225767c58f8183deccd1ff4a15451f6503e8c895a427c0a09d5e685`이다. 원자료 경로는 로컬 재현 자료를 뜻하며 외부 공개 다운로드를 보장하는 링크가 아니다.

## 6. 최종 판정과 범위

**차단 오류 0건. 위 해시의 HTML·본문 PDF·요약 PDF·ZIP은 제출 가능하다.** 수정 문장은 관찰·가설·미측정을 구분하며, 3차에서 지적한 모순과 과장이 해소됐다. 이번 변경에서 추가로 요구할 선택적 보강은 없다.

3차에서 남긴 실물 출력 가독성, Windows 인쇄 대화상자의 실제 취소 조작, 새 실험에 의한 원인 분리는 여전히 `미확인`이다. 이번 제출 판정을 이러한 시험의 통과나 연구 가설의 확정으로 읽어서는 안 된다. 변경되지 않은 범위에는 3차 검증의 근거와 한계를 함께 재사용한다.
