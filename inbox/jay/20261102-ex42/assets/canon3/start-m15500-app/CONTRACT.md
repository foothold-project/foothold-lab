## 2. 같은 출력 확인 (CPU · `parity.json`)

| 확인 | 결과 |
|---|---|
| ONNX checker | 두 그래프 통과 (map_on 323 · map_off 388 node · 보정 때문에 m13000 보다 34 node 많다) |
| 합성 입력 12 경우 | PyTorch 대 onnxruntime CPU 최대 차이 1.05e-5 (기준 3e-5) |
| 실제 Kit 입력 9 경우 × 20 스텝 (평지 · rough L0 · 계단 L2 × 복원 · 끔 · 정답), ORT 의 GRU 출력을 되먹임 | 최대 차이 7.48e-6 (기준 1e-4) |
| 보정이 그래프 안에 들었나 | 같은 입력에서 보정을 뺀 PyTorch (b = 0) 와의 행동 차이가 아홉 경우 모두 0.013~0.017 (같은 출력 확인 기준의 100 배 넘음). ONNX 는 보정을 넣은 PyTorch 와 7.48e-6 안에서 같으므로 보정은 ONNX 안에 있다 |
| 보정식이 학습 코드와 같은가 | 묶음의 감싸개와 학습 함수 `correct_est_vx` 를 vx −0.2~0.6 격자 1,601 점에서 대조: 최대 차이 0 |

PyTorch 쪽 답은 평균 지각 + 보정 b 0.010 + 자세 명령 0 의 길로 냈다 (평가와 같은 길).

**실제 입력의 뜻.** m6000 묶음 때 Kit 이 기록한 입력을 그대로 넣고 GRU 상태만 이 저장본 것으로 이었다. 로봇을 몬 것은 m6000 이므로 이 저장본이 스스로 걸은 궤적은 아니다. 입력 정렬과 ONNX 가 PyTorch 와 같은 답을 내는지를 보는 시험이고, 걸음 성적을 보는 시험이 아니다. GPU · Kit 을 쓰지 않았다.
