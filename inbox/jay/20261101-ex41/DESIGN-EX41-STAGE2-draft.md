(다) critic 만 거울 증강(lead 안 · planner 동의). **트리거**: 팀장 안 「구간 2 첫 1,000 회 안에 W78 v2 오른쪽 이동 비율이 왼쪽의 80 % 미만이면」 에 동의한다. 아래 둘은 planner 의 **제안**이고 팀장 승인 문구가 아니다(lead 가 묻는 중 · 승인 전에는 팀장 안 그대로 적용): ① **양방향**: min(좌, 우)/max(좌, 우) < 0.8 (어느 쪽이 약해도). 근거: 약한 쪽이 저장본마다 바뀐다(§3.1 · §3.2 · §3.1b, m4500 오른쪽 23 % 대 74 % → m4750 W78 L2 는 왼쪽 0.15 대 오른쪽 0.23). 한쪽만 보면 왼쪽이 약한 저장본을 놓친다. ② **두 점수표 연속**(250 회 간격, 같은 쪽일 필요 없음): 한 저장본의 흔들림으로 알고리즘을 바꾸지 않기 위해. 적용 자리: 고정 L2 · L5 가운데 하나라도. 이 규칙을 지난 자료에 걸어 보면 m4500(0.31 또는 0.44) · m4750(0.65) 가 연속 둘이라 **m4750 에서 발동**했을 것이다(계산 · 영상 1 env 와 W78 dz 를 이동 비율 대용으로 쓴 것이라 참고값). **방법**: rsl_rl `use_data_augmentation`(actor · critic · 행동을 한 함수로 같이 증강, 코드 `ppo.py:314~346`) 은 쓰지 않고, **값 손실에만 거울 표본을 더한다**: critic 관측 o_c 의 거울 M_c(o_c) 를 같은 returns 목표로 한 번 더 평가해 value_loss = ½[(V(o_c) − R)² + (V(M_c o_c) − R)²] (1 : 1, 클립 변형도 같이). actor · 지각 · 버퍼는 손대지 않는다. 구현은 PPO 하위 클래스(runner 가 `start_runner.py:256` 에서 PPO(**alg_cfg) 를 만드는 자리에 끼움) · 거울 M_c(위 표) · 시험 M_c(M_c(x)) = x 와 좌우 뒤집은 지형에서 V 차이 확인. 켜는 시점: 트리거가 걸린 다음 **단계 경계**(S2a 끝 n500 또는 S2b 끝 n1000; 학습 알고리즘 변경이므로 250 회 경계에서는 안 켬 · 가정). 전제: V(Mo) = V(o) 는 동역학 · 보상 · 정책이 대칭일 때 정확하고, 비대칭 정책 아래서는 근사다(그래서 critic 만 · 가중 1 : 1 로 시작, 가정). 「AME-2 식」 의 근거는 lead 가 AME-2(2601.08485) 193 행에서 읽은 「critic 에 좌우 대칭 증강」(읽기 FACTS §4 · planner 미재측). 원문의 비율 · 손실 꼴은 §9 Q8.

### 5.12 S2c 상한 자동 연장 규칙 (팀장 추가 요구 (2))

팀장 요지: 상한 초과는 멈춤 · 보고가 맞다. 다만 흐름이 좋으면 성과 단계로 넘어가길 원하므로, 멈추기 전 자동 규칙 하나. 자동으로 L4 로 낮추지는 않는다.

제안(가정값, 팀장 확인 §9 Q13):

- S2c 는 n1001 부터 성과 승급 · 강등을 켠다. 50 회 저장본마다 env 평균 지형 레벨 L̄(n) 을 기록한다(Isaac Lab 커리큘럼 로그 `Curriculum/terrain_levels` 꼴, 우리 `terrain_levels_mixed.py` 에 기록이 있는지 §10 미확인).
- n1500 에서 Δ = 평균(L̄, n1251~n1500) − 평균(L̄, n1001~n1250) 을 계산한다.
- **Δ ≥ +0.5 레벨** 이고 W15 D57 유지 · 서 있기 64/64 ±3 이면 **+500 한 번 자동 연장**(n2000 까지), 원장에 「자동 연장 · Δ 값」. 근거(계산): L0~2(평균 1) 에서 L5 상한 분포(중앙값 4) 까지 +3 레벨이 필요하고, 500 회를 두 창으로 나눴을 때 직선으로 오르면 Δ = +1.5. 그 1/3 인 +0.5 를 「오르는 중」 의 바닥으로 둔다.
- Δ < +0.5(평평) 또는 D57 하락이면 멈춤 · 보고(연장 없음).
- 연장 뒤 n2000 에서도 §4 관문 미달이면 멈춤 · 보고(두 번째 연장 없음 · L4 자동 하향 없음).
- 관문 통과는 250 회 경계 어디서든 바로 T0′ 로 넘어간다(연장 중이라도).
