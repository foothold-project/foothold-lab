## 1. 만들 것

1. **무인 사슬 실행기 `s2_chain_runner.py`.** 사람 · 모델 세션 없이 도는 **순수 프로그램**(LLM 호출 없음). 승인된 `s2_chain_manifest.json` 과 승인 json 을 읽어 단계를 순서대로 띄운다. 요구:
   - 세션과 분리: Windows 에서 부모(터미널 · Claude · Codex)가 죽어도 계속 돈다(기존 1043 학습이 부모 없이 돈 사례가 있음). 시작 방법(분리된 프로세스로 띄우는 법)과 시작 · 종료 시 확인 방법을 문서화. **알림 경로를 버리지 않는다**: 프로세스 수 · 산출물 mtime · `chain_status.json`(최근 갱신 시각 · 현재 단계 · 마지막 합격 / 보류 · 다음 예정) 로 외부에서 확인 가능하게. 상태 파일은 일정 간격으로 갱신(죽으면 갱신이 끊김).
   - 단계 진행: 3 단계의 `s2_stage_gate.py` 가 합격이라고 할 때만 다음 단계 인수를 만들어 띄운다. 보류 · 실패 · 불명이면 **그 자리에서 멈추고** 상태 파일에 사유를 남긴다(다음 단계 안 띄움). 자동 재시도 없음(승인에 retry 가 있을 때만 그 안에서).
   - **시간 상자(time-box) 확장:** 합격한 짧은 A/B 뒤, 마감(인자 필수 `deadline_epoch`, 토 10/17 정오 기준 제안)까지 **고정 증분(update 수 인자)으로 학습을 이어가는 단계를 사전 등록된 규칙으로** 반복한다. 증분마다 체크포인트 + 합격 판정, 마감 전 마지막 증분은 마감 안에 끝날 것으로 예상되는 크기만(예상 시간은 직전 증분 실측으로 계산). 마감 직전 체크포인트 경계에서 멈춘다. 마감 뒤 새 단계 안 띄움.
   - **GPU 두 장 채우기:** 한 GPU 에 한 번에 Isaac 하나, 두 GPU 는 동시에 가능(슬롯 · 변환 lock 이 직렬화). 기본 배치 제안: GPU 0 = arm B, GPU 1 = arm A 를 같은 단계 번호로 병행. 한 arm 이 보류되면 같은 후보의 다른 arm 도 함께 재검토한다는 사전 등록(README 8.2 4행)대로 **둘 다 멈추고** 사람에게 넘긴다.
   - 안전: STOP 파일 · 마감 · 승인 단회 claim · 승인 digest 결박 · 장치 UUID / 여유 확인은 3 단계 사슬과 같은 규칙. 시험 중 프로세스 종료는 시험이 직접 띄운 자식에만(PID 재사용 시험은 psutil 표 대체).
   - CPU 시험: 가짜 단계 실행 파일들로 (a) 정상 사슬이 끝까지 (b) 한 단계 보류 시 멈춤 (c) 부모를 죽여도 분리된 실행기가 계속(시험이 직접 띄운 가짜 부모만 사용) (d) 상태 파일 갱신 끊김 감지 (e) 마감 경계에서 멈춤 (f) 두 arm 한쪽 보류 시 둘 다 멈춤 (g) STOP 파일. 코드 변이는 정상 소스의 같은 시험 통과 뒤 지정 라벨 실패만 CAUGHT.
2. **교체 가능한 지도 encoder.** 2 단계의 `S2MapActorCritic` 이 지도 encoder 를 이름으로 고르게(`map_encoder=mlp|attn`, 기본값 없음, 모르는 이름 거절) 하는 최소 변경 사본(원본은 고치지 않음). `mlp` 는 현재(374 → 128 → 64) 그대로. `attn` 은 **AME-2 식 attention 지도 encoder 의 작은 후보**: 점별 국소 특징(높이 · mask · 상대 위치) + 전역 특징 → multi-head attention → 64 차원, 출력 차원은 `mlp` 와 같게 해 actor 첫 층 입력(0 초기화 열)을 바꾸지 않는다. `PAPERS-architecture.md` 의 AME-2 · MARG 구조 사실에 근거하고, **논문과 다른 곳 · 빠진 숫자는 추측하지 말고 목록**으로. 공정성: arm 사이에 다른 것은 encoder 구조뿐(같은 부모 · 같은 지형 · 같은 예산 · 같은 PPO). A(지도 상수) · B-mlp · B-attn 세 arm 의 매개변수 수 · 연산량을 보고. 시험: 0 초기화 동치(초기 action 이 부모와 같음) · 지도 정보 차단(A) · 출력 형상 · 학습 가능 매개변수 목록 · 고정 encoder 규칙(`EncoderControl`)과의 호환 · 변이.
3. **A/B 비교기 `s2_compare_ab.py`.** 학습 중 지형 조우 기록(`assigned` · `approach` · `pass` · `avoid` · `fall` · `stall`)과 단계 결과를 읽어, arm 별 gap · 징검다리의 **통과율(접근 대비) 곡선**과 A 대비 차이를 체크포인트마다 계산한다. 신뢰구간은 Wilson(수 계산), 표본 부족이면 「판정 불가」. 사전 등록 기준(제안: 목표 칸마다 95 % 구간 하한 > 0 이고 평균 차 ≥ 10 %p)은 **인자로 받고** 결과를 본 뒤 바꾸지 않는 규칙을 코드로 강제(기준을 파일로 먼저 동결해 해시를 기록하고, 비교 보고에 그 해시를 적음). 이것은 방향을 빨리 보는 용도이며 독립 평가가 아님을 보고서 머리에 명시. 합성 로그(알려진 답)로 시험.
