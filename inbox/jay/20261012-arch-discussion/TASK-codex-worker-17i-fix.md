(b)(c)(e) 와 (d) 모두 APPROVED 가 아니어야 하고, **함수가 아니라 전체 CLI (`validate_dump.py --approve ...`) 까지** 끝까지 돌려 종료 코드와 출력으로 확인한다 (사본 폴더 안). 기존 `VA-*-A9c` 시험은 한 값만 바꿔 이 분기를 지나지 않으니 새 시험을 더한다.

**C2 (17i 4 절) 묶음 파서와 묶음 자체 해시.** (i) `read_bundle()` (497 ~ 504) 가 basename 으로 항목을 덮어쓰고 64 자 길이만 본다. 중복 이름 · 해시가 64 자 16 진수가 아닌 줄 · 이름이 빈 줄을 거절하게 고치고 시험한다. **C3 (17i 4 절 마지막) 형식 계약 시험을 둘로.** `compare_native.py` 의 `_dim()` (68 ~ 77) 과 layout 검사 (names 와 dims 를 zip) 에 대해, 작은 **합성** 형식 시험을 더한다: 정상 정수 · 허용 숫자 문자열은 같은 값으로 읽고, 길이가 다른 목록 · 빈 값 · 숫자가 아닌 문자열 · 음수 · bool · 잘못된 형은 **명확한 invalid** 로 닫아야 한다 (names 와 dims 길이가 다르면 zip 이 조용히 자르지 않도록). 그리고 실제 기록 사본을 읽는 기존 통합 시험 (T23 · VA-real) 은 이름을 분리해 「합성 형식」 과 「실제 기록 통합」 임을 이름에서 알 수 있게 하고, 실제 기록 사본이 없을 때 **조용히 skip 하지 않고** 실패하거나 명시적으로 「환경에 실제 기록 없음 (SKIPPED_NO_REAL)」 로 출력해 요약에 별도로 센다.

**C4 (17i 5 절 · 17f §3) 기동 전 대조와 기동 전 장치 · 여유 확인 (실제 실행 경로 `run_dump.py`).**
- (i) **상대 로그와 구형 registry 의 읽기 전용 대조를 기동 전 단계로 넣는다.** `_eval/slot/isaac_usd_registry.json` (구형) 을 읽어 (쓰지 않는다) 가리키는 로그 경로와 그 부모 폴더를 얻고, 지금 CE12 가 넘기는 `--scan_dirs` 범위와 비교한다. 범위 밖이지만 실제로 존재하는 로그는 읽기 전용 검색 대상에 자동으로 더하고 그 목록을 `run.json` 의 `preflight` 에 기록한다. **구형 registry 를 읽을 수 없으면 「충돌 없음」 으로 치지 않고 기동을 보류** (종료 코드는 기존 보호 코드와 겹치지 않는 번호를 `rg` 로 확인해서 고르고 보고서에 적는다). 존재하지 않는 로그 (사라진 과거 로그) 는 목록에 따로 적되 그것만으로 막지 않는다 (17f §3: 무조건 복원 요구 아님).
- (ii) **기동 전 장치와 여유를 읽는다.** guard 의 실행 중 요약과 별개로, slot 을 띄우기 전에 `nvidia-smi` (읽기 전용 조회) 로 대상 GPU 의 인덱스 · UUID · 총량 · 여유 MiB 를 읽어 `run.json` 의 `preflight` 에 시각과 함께 기록한다. 조회 실패 · 대상 GPU 를 못 찾음 · 여유가 요구 값 (기본 guard 의 `--min_free_mib` 와 같은 값) 미만이면 **자식 호출 전에 보류**. 조회 실패를 통과로 취급하지 않는다. `--dry_run` 에서도 이 조회와 대조를 하고 결과를 출력한다 (조회는 GPU 를 쓰지 않는다).
- (iii) 시험: 구형 registry 가 읽히지 않는 경우 → 자식 0 회 · 여유 조회 `None` → 자식 0 회 · 여유 부족 → 자식 0 회 · 모두 정상 → 자식 1 회와 `preflight` 기록 (가짜 nvidia-smi 와 임시 사본 registry 로). 실제 `_eval/slot/` 는 쓰지 말고 읽기만.

**C5 (17i 5 절) 경로 의존.** `validate_dump.py` 와 `compare_native.py` 가 작업 디렉터리에 따라 상대 NPZ · compare 보고서 경로 때문에 A6 과 재확인이 실패한다 (저장소 루트에서 돌리면 실패, `_eval` 에서 돌리면 성공). 보고서 파일 위치 기준 또는 `_eval` 루트 기준의 **절대 경로 해석**으로 고쳐 어느 디렉터리에서 돌려도 같은 결과가 나오게 하고, 두 작업 디렉터리에서 같은 입력으로 같은 결과인지 시험한다.
