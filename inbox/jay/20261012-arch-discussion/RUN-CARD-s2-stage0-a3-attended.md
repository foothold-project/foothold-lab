# 이 일이 무엇이고 왜 하는가 (쉬운 설명)

우리는 로봇에게 「지형 지도」를 주면 틈과 징검다리를 더 잘 건너는지 비교하려고 합니다. 그 비교를 하려면 시뮬레이션 안에서 **지도 값이 실제 땅 높이와 맞는지**를 먼저 알아야 합니다. 지도가 틀렸으면 비교 자체가 가짜가 됩니다.

그래서 첫 GPU 일은 학습이 아니라 **지도를 읽어 보기만 하는 15 분짜리 점검**입니다. 로봇 8 마리를 알려진 모양의 바닥(계단 하나, 징검다리 둘, 틈 하나)에 세워 놓고 256 걸음 동안 지도 값을 기록합니다. 뇌(신경망)는 한 번도 고쳐지지 않습니다.

결과는 셋 중 하나입니다.
- **시작 실패:** 프로그램이 못 뜨거나 GPU 이름이 안 맞아 0 행. 왜 멈췄는지 기록이 남습니다.
- **부분 수집:** 도중에 멈춤. 어디까지 모였는지 남습니다.
- **256 행 수집:** 끝까지 모였지만 아직 「통과」가 아니라 **「검증 보류」** 입니다. 지도 값이 진짜 땅에서 나왔다는 증거 몇 개가 더 필요합니다 (두 번째 점검).
