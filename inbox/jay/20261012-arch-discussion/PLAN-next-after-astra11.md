# ASTRA 11 반영: 다음 실험 계획

## 바로잡힌 사실 (lead · 조사 쪽 잘못)

- CTS-MoE (2606.19633) Table 3 의 대조는 **gap 98.3 % 대 blind CTS-MoE 40.0 %** (40.3 % 는 CTS-Single). gap 과제는 waypoint 보상이라 정지 · 극저속 추종의 근거가 아니다.
- DAWN 97.2 % 는 시뮬이다. 실외 70 cm gap 은 6/10.
- REAL 0.28 은 gap **성공률 28 %** 이고 Overall 0.78 의 집계 근거는 미확인.
- Footmap 은 「몸체 좌표 속도 보상이면 돌을 돌아가는 사례가 있다」 이지 「속도 명령이면 늘 피한다」 가 아니다.
- WTR 을 START 앞판으로 보고 층 크기를 옮기면 안 된다 (제거 실험 숫자가 다르다). START 는 0.3 m/s 미만 명령을 0 으로 바꾸므로 우리 0.1 ~ 0.2 m/s 목표와 맞지 않는다.
- v2 징검다리 「24 %」 는 1.0 m/s 의 지형 시드 다섯 (24 · 1 · 3 · 19 · 0 %) 중 최댓값이라 대표 성적이 아니다. v2 는 회전 · 정지 (standing 0.1) 도 학습했다.
- lead 의 「gap 은 무조건 봐야 한다」 는 과장. 일정한 작은 틈은 보폭으로 넘을 수 있다. 미리 구별해야 하는 발판 배치에서 외부 정보가 필요하다는 것이 정확한 말이다.
