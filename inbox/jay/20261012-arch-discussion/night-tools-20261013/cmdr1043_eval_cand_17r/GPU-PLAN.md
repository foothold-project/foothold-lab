# GPU에서만 확인할 항목

1. 새 driver·post·비교기와 전체 과학 계약의 바이트 해시, 새 승인 연결, 입력 불변성, 1043 두 군의 완료와 bundle `SAME`을 기동 직전에 다시 대조한다. `UNDECIDED`가 하나라도 있거나 1042 승인·hold·로그를 읽으면 중단한다.
2. 물리 GPU index와 UUID, `CUDA_DEVICE_ORDER=PCI_BUS_ID`, 자식의 논리 CUDA 0 UUID, 기동 전 여유 4096 MiB 이상, 다른 GPU·Isaac 작업을 대조한다. 조회 실패·장치 불일치·미참여 Isaac이 있으면 자식 0회로 중단한다.
3. 공통 Isaac 실행 lease를 자식 트리 종료까지 보유하는지, slot v3의 변환 잠금은 별도이며 획득 순서가 일정한지 확인한다. 모든 GPU 0/1 실행 경로가 lease에 참가한다는 근거가 없으면 기동하지 않는다. slot v3만으로 직렬 실행이 된다고 해석하지 않는다.
4. 부모 평지 알려진 답: q 원본·새 평가기 같은 입력의 `cells.json`과 `traj.npz`를 바이트 대조하고, 작은 PhysX 버퍼와 기본 버퍼를 대조한다. 부모·off·on 대표 run에서 reset의 XY ±0.5 m, Z +0~0.2 m, 고정 yaw, 기본 관절, 속도 0, 명령·관측 지문·episode ID·짝을 확인한다. 다른 지형의 버퍼 동등성은 별도 확인한다.
5. 대표 run에서 사용량 최고값·여유 최저값·소요 시간을 기록한다. STOP, 마감, 코드·입력 변경, UUID 불일치, 여유 부족, 로그·stamp·짝 불일치가 생기면 수집을 중단하고 무효·미수집 목록을 남긴다.

GPU 0의 과거 평지 시작 시험은 50.9초, 최소 여유 12,917 MiB, 최대 사용 3,385 MiB였다. 이 한 시험은 1043의 45회 또는 555회 처리량·peak·안정성을 증명하지 않는다. 현재 후보의 driver와 post 코드는 이식됐지만 manifest 실행 필드가 미정이라 실제 기동은 차단된다. 이 계획 자체는 기동 승인이 아니다.
