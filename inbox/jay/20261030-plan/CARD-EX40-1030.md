# EX-40 연속 단계 카드

## 1. 출발과 변경

부모 저장본 없이 m0에서 시작하여 같은 학습 프로세스가 m8000까지 진행한다. 마지막 update 번호는 8000이며 `max_iterations=8001`이다. 전체 환경은 단계 진입 직후 강제 reset하지 않는다. 각 환경의 다음 자연 reset 때 명령과 지도 단계를 채택한다. 명령 시드0, 환경·PPO 시드42, env3072, rollout24는 S-B10 기준 YAML SHA와 대조한다. 지형 자동 승급과 DR은 아래 명시된 변경이 있으므로 기준 YAML과 모든 값이 같다고 쓰지 않는다.

지형은 D71이 채택한 analyst 0111f9d5 §3(연속7종 L0~2 유지)을 따른다. 자동 승급이 꺼진 실행에서 `world_frame=true`의 효과를 확인했다고 쓰지 않는다. 실제 `curriculum.terrain_levels=null`과 배치 L0~2를 확인한다. 순수 평지 학습 열이나 듬성 학습 열을 추가하지 않는다.

S-B10 대비 의도된 차이 2: 현재 지형 설정은 자동 승급 끔(L0~2 고정)이다. `terrain_curriculum: fixed_l02`가 기본값이며 `max_init_terrain_level=2`, `curriculum.terrain_levels=null`을 적용한다. D72~D76은 이 지형 정책을 바꾸지 않았다. 옛 카드의 결정 대기 표기는 D71 채택 범위와 맞춰 정정한다. 실제 배치와 승급 억제는 Kit 미확인이다.

## 2. 정지 두 벌점

정지 슬롯의 첫 0.5초 동안 0에서 1로 선형 증가시킨다. 다른 슬롯에는 적용하지 않는다. 발 순서는 FL, FR, RL, RR이다.

| 간격 | `w_gap Σ max(h−0.005,0)/0.05` | `w_gap=−0.2`; h는 발 collision sphere의 최저점과 전용 지면 ray의 차이. RayCaster의 `yaw` 정렬로 광선은 발의 roll·pitch와 무관하게 수직 아래를 향한다. 발 prim에서 local x −0.002 m 오프셋을 쓴다. |

## 3. Heading과 승급

이번 선택은 D69의 arm B다. A는 구현상 비교 옵션일 뿐 본 카드 실행 대상이 아니다. arm B는 B0부터 전진 슬롯 절반의 재추출 때 현재 yaw를 목표로 잡고 gain 0.5, 보정 |wz| 상한 0.5를 적용한다. B2부터 제자리 회전 슬롯의 30 %는 무작위 목표 방향으로 돌며 목표 회전 |wz| 상한 1.5를 적용한다. B0의 제자리 회전 절댓값 범위는 `[0.5,1.2]`이다. A와 B의 명령 생성 난수 호출 수와 순서는 같다. 물리적으로 reset 시각이 갈라진 뒤 같은 개별 명령열을 보장하지 않는다.

`promotion: fixed, shadow_gate: true`가 현재 값이다. D72에 따라 단계 진입은 고정 회차이며 성과 판정은 그림자 기록만 남기고 자동 승급시키지 않는다. YAML의 `gate` 구현은 선택 가능하지만 이 카드의 현재 실행 설정은 아니다. 총 m8000 상한은 점수 때문에 늘어나지 않는다.

## 이전 v4/v5 광선 이력

아래는 당시 결과이며 현재 B12 판정으로 재사용하지 않는다.

### v4 광선 위치와 실측 관문

광선의 시작점은 발 기준 local x = −0.002 m를 yaw로만 돌린다. 벌점에 쓰는 충돌구 중심은 같은 offset을 발의 full quaternion으로 돌린다. 두 XY 위치의 거리 차는 회전이 어떻든 최대 `2 × 0.002 = 0.004 m`이고, pitch 60° 단독이면 `0.002 × (1 − cos 60°) = 0.001 m`이다. 따라서 계단 모서리 약 1~2 mm 안에서는 광선이 다른 면을 맞힐 수 있다. 이 위치 차를 없앴다고 주장하지 않으며, 실제 mesh hit와 발생률은 Kit에서 미확인이다.

10/30 v4 Kit B smoke는 학습 rc 0·15 update와 광선 hit 유효 100%를 보였으나 확인기는 HOLD였다. 발별 분위수 함수가 각 발 열이 아니라 네 발 전체를 모았고, S-B10 기준 지형 7종의 23열에는 이름이 `flat`인 열이 없어 평지 표본은 구조적으로 0이다. 따라서 v4 영수증의 네 발 동일 분위수는 발별 증거로 사용할 수 없다. 원자료는 `C:/Users/AI-WS01/s2_lab/ex40/v4_kit_smoke_20261030_lead1/`이다.

v5 Kit 짧은 확인은 각 갱신의 진짜 발별 간격 p5/p50/p95, 유효 hit 수, 광선 hit z와 지형 원점 z 표본, 비유한 힘과 간격 발생 수를 남긴다. 평지 열 검사는 요구하지 않는다. 대신 15갱신 전체 정지 발 유효 hit 비율 ≥0.99와 **네 발 각각의 유효 갱신 p50 간격 0~10 mm**를 검사한다. 발별 유효 수 합·비유한 수·hit 표본 필드·분위수 유한성을 대조하고, smoke에서는 힘과 간격의 비유한 발생 수가 0이어야 한다. 기존 3·6·9·12 단계 전환과 최종 저장 확인도 유지한다. 새 영수증 마커가 없으면 합격시키지 않는다. 이 관문은 CPU 코드로 준비했으며 v5 실제 Kit 통과는 미확인이다.
