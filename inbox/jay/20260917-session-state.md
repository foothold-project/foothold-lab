## 0. 왜 이 문서가 있나

팀장이 Orca 업데이트와 Windows 재부팅을 하러 간다. **재부팅 자체는 안전하다**(1 절). 다만 재부팅 후 Orca 터미널 **핸들이 전부 바뀌므로**, 세션을 이름으로 다시 찾아 연결해야 한다. 이 문서가 그 지도다.

**이 문서는 재부팅 뒤에 버린다.** 진행 상황의 정본은 각 세션의 문서와 git 이다.

### 1-1. 지켜야 할 것 둘

1. **`terminal close --worktree ... --all` 을 쓰지 않는다.** Orca 문서: 이 명령이 터미널 탭 · 레이아웃과 **에이전트 재개 기록(agent-resume records)** 을 영구히 지운다. 그냥 재부팅은 지우지 않는다. 나중에 재개할 것이면 close 가 아니라 **Sleep** 을 쓴다.
2. **재부팅 후 터미널 핸들이 바뀐다.** Orca 문서: 핸들은 런타임 범위이고, **Orca 재시작 뒤에는 다시 목록을 뽑아 새 핸들로만 이어야 한다.** 옛 핸들과 새 핸들에 동시에 보내면 안 된다.
