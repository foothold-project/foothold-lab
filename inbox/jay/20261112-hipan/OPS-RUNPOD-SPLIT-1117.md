## 3. 데이터가 오가는 길

```
로컬 ──(S3 올리기)──▶ 저장소 rzklpc35sl (EU-RO-1) ◀──(붙임 /network-volume)── Pod
로컬 ◀──(S3 받기)─── jay/<일>/<시각>/ : progress.log · 결과 · DONE
```

- 저장소는 하나 (rzklpc35sl · EU-RO-1). Pod 는 이 저장소가 있는 데이터센터에만 뜬다.
- ssh 는 쓰지 않는다 (R3 에서 sshd 가 안 떴고, 이미지 안에서 apt 가 권한으로 막혔다: R3b 진행 로그 읽기). Pod 의 시작 명령 하나가 일을 다 하고 진행 로그를 저장소에 쓴다.
- 로컬 → Pod: 하위 정책 저장본 (EX-42 끝 저장본) · 방 메시 · 우리 코드 묶음. 올릴 때 sha256 목록을 같이 올리고 Pod 안에서 대조한다. 다르면 일을 시작하지 않는다.
- Pod → 로컬: 저장본 (정해진 회차마다 저장소에 바로 씀) · 학습 로그 · 평가 json · 영상. 로컬에 받은 뒤 sha256 을 대조한다.
- 로컬 자리: HiPAN 은 `/home/jay/data/foothold/hipan/<일>/<시각>/` · 영상은 `/home/jay/data/foothold/s2_lab/ex42_record/...` (지금 쓰는 자리 그대로).
- 키: 로컬에서 읽기만 한다. Pod 의 환경 변수 · 시작 명령 · 로그에 넣지 않는다.

## 4. Pod 표준 (모든 스크립트가 지킬 것)

| 항목 | 표준 | 까닭 |
|---|---|---|
| 이름 | `jay-<일>-<시각>` | 팀원 Pod 와 섞이지 않게 |
| 지우기 | 스크립트가 자기가 만든 id 만 지운다. 이름으로 찾아 지우지 않는다 | 팀원 Pod 금지 |
| 진행 로그 | `progress.log` 에 줄마다 시각 · 단계 · 종료 코드 · 30 초마다 살아 있음 줄 | ssh 가 없어 이것이 유일한 눈 |
| 끝 표식 | 저장소에 `DONE` | 로컬이 이것을 보고 받고 지운다 |
| 상한 | 스크립트마다 시간 상한과 달러 상한을 상수로. 넘으면 받을 것 받고 지운다 | 잊힌 Pod 가 계속 돈을 쓴다 |
| 로그 없음 | 12~15 분 안에 진행 로그가 안 생기면 지운다 | 시작 명령이 안 돈 Pod |
| 판정 | 종료 코드가 아니라 산출물로 (Isaac 은 예외 뒤에도 0 을 낸다) | 반복된 실수 |
| 두 단계 | `--print` (돈 0) 로 요청과 시작 명령을 먼저 보이고, lead 가 `--start --lead-approved` | 유료 실행은 승인 뒤 |
| 긴 학습 | 저장본을 저장소에 주기적으로 쓰고, 같은 스크립트로 이어 받기 | Pod 가 죽어도 잃는 것이 한 주기 |
| 두 번째 지킴이 | 긴 학습 (1 시간 넘는 것) 은 로컬 감시 프로세스 말고 하나 더: 20 분마다 `jay-*` Pod 목록을 보고 상한을 넘긴 것이 있으면 알린다 (지우는 것은 lead) | 로컬 감시가 죽으면 Pod 가 25 시간 뒤에도 돈다 |

마지막 줄은 지금 없다. 본 학습 전에 만들어야 한다 (만들 사람은 lead 가 정한다).
