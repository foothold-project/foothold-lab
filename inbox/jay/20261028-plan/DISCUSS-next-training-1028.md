## 2. 기본 보행 1단계 명령 구성안

원칙
- **바꾸는 것은 명령 분포 하나.** 보상 · 신경망 · 지형 생성 · PPO 설정은 EX-35 와 같다. 결과를 읽기 쉽게.
- **옛 기술은 큰 몫으로 유지, 새 기술을 작은 몫으로 넣는다** (석헌 stones 5 % 방식, 공개 저장소 MoE-CTS 의 정지 10 %).
- 지형은 연속 지형 L0~2 만(D03 첫 묶음). 듬성 · 깃발 · DR 은 졸업 뒤(D23).

| 묶음 | 명령 | 몫 | 비고 |
|---|---|---|---|
| 전진 | vx U[0.3, 1.5] · vy 0 · wz 0 | 40 % | 기존 75 % → 40 % |
| 걸으며 돌기 | vx U[0.3, 0.8] · wz ±U[0.2, 0.5] | 5 % + 5 % | 기존 2.5 % + 2.5 % |
| 제자리 회전 | vx 0 · vy 0 · wz ±U[0.5, 1.2] | 10 % + 10 % | 좌우 같은 몫. 회전 중 몸 이동을 평가에서 같이 잰다 |
| 정지 | 0 · 0 · 0 | 10 % | 새 |
| 후진 | vx U[−0.8, −0.2] · vy 0 · wz 0 | 10 % | 새. 상한 0.8 은 가정 |
| 옆걸음 | vx 0 · vy ±U[0.2, 0.5] · wz 0 | 5 % + 5 % | 새 |

- 새 기술 몫 합 30 %. 대안은 정지 · 후진 · 옆 각 5 %(합 15 %). 출발선이 0 이라 5 % 로는 늦을 수 있어 30 % 를 권한다(가정, 첫 500 회 점수표로 확인).
- 재추출 4 s, 묶음 안 명령 도중 반전은 평가에서만(학습은 재추출로 자연히 섞임).
- 구현 전에 확인할 것: 추종 보상이 vy · 음의 vx 를 그대로 쓰는지, 관측 · 명령 경로 어딘가에서 vx ≥ 0 으로 자르거나 START 규칙(vx < 0.3 → 0)이 섞이지 않는지.

## 3. 부모 대 처음부터 대조

| | A 부모 | B 처음부터 |
|---|---|---|
| 출발 | S-B10 m1500 (sha 확인, W24) | 무작위 초기화 |
| GPU | cuda:0 | cuda:1 |

| 명령 · 지형 · 보상 | 2 절 구성 · L0~2 · START 그대로 | 같음 |

| 이어받기 | EX-35 와 같은 방식(가중치 · optimizer · lr 복원). 지형 레벨 · 명령 통계는 새로 | 해당 없음 |

부모 지형 상태(scripter 21:54 실측): S-B10 m1500 의 env 3,072 중 2,791 이 L3 이상(L0~9 분포). 두 판을 L0~2 로 하려면 A 는 재개 직후 지형 레벨을 L0~2 로 다시 배치하고 커리큘럼을 고정해야 한다. 그러면 A 에서는 명령 분포 말고 지형 상태도 바뀐다. 석헌 ST 판도 optimizer 는 잇고 지형 · 성공 이력은 새로 시작했다. 두 판 같은 L0~2 재배치 · 고정으로 준비하고, 이 차이는 영수증에 따로 적는다(팀장 확인 항목).

묻는 것
- A: 이미 걷는 정책에 새 기술을 얹을 수 있나, 옛 기술(전진 · 회전 생존)을 잃지 않나.
- B: 처음부터 전방향으로 배우면 같은 1,500 회에서 어디까지 가나. B1500(처음부터 1,500 회, 전진 위주)과 견주면 「전방향을 처음부터 넣은 값」 이 보인다.

판정(결과 전 등록)
- 같은 W15 확장 묶음 64 env 를 250 회마다 사슬로, 500 회 점수표(GATE-v3)로 본다.
- 축: 후진 0.5 생존 · 추종 / 옆걸음 이동 / 정지 멈춘 비율 / 회전 좌우 각각 생존 · 추종 · 몸 이동 / 반전 생존 / 전진 1.0 거리 · 생존.
- 안전 축: 전진 생존, 회전 생존. 출발선보다 떨어지면 GATE-v3 대로 HOLD → 영상 판독.
- 결론 규칙: 1,500 회에서 새 기술 축이 더 많이 오르고 안전 축 손실이 없는 쪽을 다음 단계 본선으로. 둘 다 안전 축을 잃으면 명령 몫을 15 % 안으로 다시.
- 새 숫자 문턱은 만들지 않는다(W25 전).

시간(추정): EX-35 는 1,000 회에 6 시간 47 분이었다. 1,500 회면 약 10 시간. 22:30 시작이면 내일 08:30 무렵 끝난다.
