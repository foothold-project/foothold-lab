# 실험 한 판의 흐름 (정본)

v1 에서 바뀐 것: EX-41(11/03 19:54 ~ 11/04 14:0x)에서 측정 실패가 DR 램프를 750 회 멈추고, 단계 끝 영상이 한 편도 나오지 않았다. 원인은 이 문서 v1 의 5 절(W50 실행기 P2 · P3)이 EX-41 에 구현되지 않았는데 출발 관문이 그것을 막지 않은 데 있다. v2 는 250 경계 · 단계 끝의 할 일과 GPU 순위를 모든 실험 공통으로 못 박고, 출발 관문을 「실제 예행 증거」 로 바꾼다.

## 1. 흐름 한눈에

1. **출발 관문**(4 절): 요구 등록부 열린 항목 0 · 한 HEAD · 실제 예행 한 바퀴 증거 · 팀장 출발 승인. 하나라도 없으면 띄우지 않는다.
2. **학습**: 시작 스크립트로만(D42 · D43). 돌기 시작한 사본은 아무도 고치지 않는다(쓰기 잠금). 마감은 회차가 주 조건, 시각은 상한(R21).
3. **250 경계마다**(2 절): P1 평가 → 숫자 판단 → 다음 경계 적용(유지 · 조정) 확인.
4. **단계 끝마다**(3 절): P2 평가 · P3 영상 · 정식 분석. 다음 단계 판단에 쓸 숫자는 P2 에서 먼저 낸다.
5. **실험 끝**: 졸업 판정 · 결과 문서 · 다음 실험은 자동으로 띄우지 않고 묻는다(D146).
6. **남는 GPU1 시간**: C층(P4)이 늘 깔려 있다가 위 순위가 들어오면 비켜 준다.

## 4. 출발 관문 (모든 실험 공통 · 증거 없는 행은 통과 아님)

1. **요구 등록부**: 그 실험의 요구 등록부 · 출발 점검표 · 최종 감사 결과 표의 열린 행 0. 남는 행은 팀장이 「받아들임」 으로 서명한 목록으로만.
2. **한 HEAD**: 학습 · 점수 감시기 · 단계 끝 평가 · 밀기 감시기 · 영상 촬영기 · 합성기 · 디스패처가 원격에 push 된 한 커밋. 프로세스마다 시작 때 HEAD 를 대조해 기록하고 다르면 거절. 저장소 밖 실행 파일 0.
3. **실제 예행 한 바퀴**: 운영 출력 자리 · 실제 승인 파일 · 실제 argparse 로 단계 길이만 줄인 실제 Kit 실행. 모든 단계 경계 · 250 평가 · 측정 실패 주입 → 자동 재측정 · 단계 끝 자동 등록 · 영상 넷 실제 촬영(lead 장면 확인) · C층 양보 · 학습 중 설정 바꾸기(W72) 되읽기 · 이어 가기(실제 저장본 · 감시기 재기동)까지 끝에서 끝으로. 가짜 자식 · 가짜 입력 시험은 통과로 치지 않는다.
4. **결정이 런타임에 닿는가**: 결정 D 마다 「실제 런타임이 이 함수를 부른다」 는 호출 증거. 같은 칸을 다룬 결정끼리의 충돌은 팀장이 정리.
5. **알려진 위험**: FAILURE-LOG 에서 「다음 실험에서 커진다」 고 적은 항목은 이 관문의 막음 행이다.
6. **부하 계산**: 단계 끝 묶음이 다음 250 경계 점수를 막지 않는지 실측 시간으로.
7. **평가 잡음**: 같은 저장본 · 시드 셋으로 잰 반복 폭을 기준선으로 둔다.
8. **팀장 출발 승인**: 출발 조건 표 + 증거 경로를 보이고 승인받은 뒤 「지금 띄웁니다」 한 줄.

## 5. GPU 배정

- 학습 GPU0 · 평가 · 촬영 GPU1(D149 · D62). 학습이 running 이 아니면 GPU1 에 Isaac 을 띄우지 않는다(재기동 막음).
- GPU1 순위: **P1 250 경계 평가 > P2 단계 끝 평가 > P3 단계 끝 영상 > P4 C층**. 낮은 일은 위 일이 들어오면 다음 단위부터 비켜 준다. P4 는 늘 깔려 있어 대기열이 비지 않는다.
- 디스패처: 띄우기 전 출력 폴더 · EULA · 대상 사본 도구 확인 · 인자 검사(dry-parse). 같은 종류 기술 실패 3 회 연속이면 그 종류를 막고 경보.
- 점검 문구에는 사용률만이 아니라 「지난 1 시간 산출 수 · 실패 수」 를 넣는다.

## 7. 평가 사다리와 기준 축

- **사다리**(단계마다 넓어진다): 기본 보행 L0~2 → L3 → L6 → L9 → 지형 추가 → 깃발 · 임무. 단계마다 A층 목록과 졸업 기준을 카드에 둔다.
- **기준 축**(단계와 상관없이 고정): 모든 정본을 같은 잣대로 잰다. 판 번호를 올리면 옛 판 결과와 섞지 않는다.
- 판정은 등록 기준 파일 하나만 읽고, 보고표에는 조건 열(보행 속도 · 레벨 · 지도)을 반드시 둔다(같은 이름의 다른 표본틀 금지).
