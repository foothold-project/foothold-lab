# 실험 한 판의 흐름 (정본)

## 1. 흐름

1. **시작 전**: 실행 카드 + 결과 시나리오표(S1~S4 · 밖) 등록. 가능성 높은 1~2 개 다음 실험은 시작 스크립트까지 만들어 실제 저장본으로 DRY.
2. **학습**: 시작 스크립트로만(D42 · D43). 마감은 회차가 주 조건, 시각은 상한(R21).
3. **평가**: 시작 전 점검(코드 판 · 명령 수 · 첫 건 칸 수). 실패 한 건은 기록하고 다음으로.
4. **한 표 → 1 차 숫자**: 성분(기준선 도달 · 생존 · 둘 다) · 명령 추종 오차 · 반복 폭 대비 차이 · 「숫자를 믿으면 안 되는 칸」 목록.
5. **A · B 층 영상 → 2 차**: 1 차 주장마다 맞음 · 틀림 · 영상으로도 모름.
6. **3 차 결정**: 시나리오표와 대조. 낮은 팀장, 밤은 등록 규칙대로 lead. 표 밖이면 해석부터 다시.
7. **다음 실험 시작**: 미리 만든 것을 바로. 남는 GPU 는 C 층.

GPU 우선순위: 학습 > 평가 > A · B 층 영상 > C 층 영상. 낮은 일은 다음 편부터 양보.

## 3. 평가 사다리와 기준 축

- **사다리**(단계마다 넓어진다): 기본 보행 L0~2 → L3 → L6 → L9 (D03 레벨 묶음) → 지형 추가(AME-2 12 종 · JEPLO 지형 · D44 계단참 회전 · 계단 위 정지 재출발) → 깃발 · 임무. 단계마다 그 단계의 A 층 목록과 졸업 기준을 카드에 둔다.
- **기준 축**(단계와 상관없이 고정): 모든 정본을 같은 잣대로 잰다. 지금은 W15 13 명령(L0~2, 64 env, 잡음 켬) + 레벨 묶음마다 대표 칸. 기준 축의 묶음 판(코드 커밋 · 명령 수 · 칸 목록)은 바꿀 때 판 번호를 올리고, 옛 판 결과와 섞지 않는다.
- 기준 정책: 단계마다 하나(지금은 S-B10 m1500 부모). 새 정본은 기준 정책 대비 반복 폭으로 읽는다.
