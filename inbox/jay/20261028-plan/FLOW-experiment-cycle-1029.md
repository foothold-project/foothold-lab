# 실험 한 판의 흐름 (정본)

## 1. 흐름

1. **시작 전**: 실행 카드 + 결과 시나리오표(S1~S4 · 밖) 등록. 가능성 높은 1~2 개 다음 실험은 시작 스크립트까지 만들어 실제 저장본으로 DRY.
2. **학습**: 시작 스크립트로만(D42 · D43). 마감은 회차가 주 조건, 시각은 상한(R21).
3. **평가**: 시작 전 점검(코드 판 · 명령 수 · 첫 건 칸 수). 실패 한 건은 기록하고 다음으로.
4. **한 표 + 학습 곡선 → 1 차 숫자** (곡선 산출 · 원자료 모드 수 = 표 모드 수 대조가 없으면 1 차 판단을 내지 않는다, 10/29 20:2x): 성분(기준선 도달 · 생존 · 둘 다) · 명령 추종 오차 · 반복 폭 대비 차이 · 「숫자를 믿으면 안 되는 칸」 목록.
5. **A · B 층 영상 → 2 차**: 1 차 주장마다 맞음 · 틀림 · 영상으로도 모름.
6. **3 차 결정**: 시나리오표와 대조(시나리오표에는 처치가 보일 칸 · 안 보일 칸 · 다음 단계에서 터질 것을 적는다, D56). 낮은 팀장, 밤은 등록 규칙대로 lead. 표 밖이면 해석부터 다시.
7. **다음 실험 시작**: 미리 만든 것을 바로. 남는 GPU 는 C 층.
8. **명령 비율을 바꾸는 단계(B3 · F1 · F2 · F3 등)는 시작 전과 끝난 뒤 둘 다** 그 시점 유지 축 점수표(줄어드는 몫의 명령 칸 생존 · 오차)를 다시 재고 카드에 붙인다. 줄인 몫의 칸이 반복 폭 넘게 떨어지면 다음 단계로 가지 않는다(D66, 10/30). 다음 단계에 같은 차감을 그대로 반복하지 않는다.

GPU 우선순위: 학습 > 평가 > A · B 층 영상 > C 층 영상. 낮은 일은 다음 편부터 양보.

## 1a. EX-40에 한정한 회차 전환 예외 (D72~D77)

[EX-40 실행카드](../20261030-plan/CARD-EX40-1030.md)와 [CURRICULUM v0.7](../20261026-experiments/CURRICULUM-GATES.md)의 현재 절을 함께 소비한다. EX-40은 처음부터8001갱신, B0→B1→B2→B3a→B3b→B3c→D→T0를 사전 고정 회차에 전환한다. 성과 판정은 그림자 기록이며 일반 흐름1절6~8의 성과로 다음 단계를 보류·승급·되돌리는 동작을 EX-40 안에서 자동 실행하지 않는다. 이 예외는 다른 실험이나 EX-40 종료 뒤 새 실험을 허용하지 않는다.

- 비율 변경 전·후의 유지 축 점수표·학습 곡선·영상은 계속 남긴다. 기준선 대비 하락·누락은 PASS로 바꾸지 않고 경고·판독·후속 설계 근거로 보존한다.
- 점수기가 실패하면 실패 이유와 저장본 SHA를 기록하고 다음 평가를 계속한다. 최종 학습 종료와 최종 T0 평가·그림·RESULT 발행 완료는 별개 상태다. 남은 평가를 끝까지 처리한다.
- NaN·기술 오류·STOP·마감 등의 운영 보호는 없애지 않는다. STOP은 저장 경계에서 정상 종료하고, END_BY는 예상 끝+24시간 이상이며 첫50회 속도로 여유를 다시 보고한다(M77).
- 기본 보행 안에서 다섯 DR을0→0.5로 넓히고 D에서1, T0에서도1 유지. 관측 잡음은 처음부터 끝까지1배 고정이다. D76 밀기값은 근거 재검토 가능 준비값으로 표시한다.
- D77의 본 기동은 B11 막음0·B12 학습 Kit·B13 전체 점수기 Kit PASS 뒤 **lead가 시작 스크립트로** 한다. analyst는 준비·보고와 이미 위임받은 B12/B13만. planner의 v0.7 검토는 사후 가능하다는 lead00:1x 판단을 기록하되 실제 실행카드·코드·설정 불일치를 면제하지 않는다.
- B11 통합 후속은 CPU 알려진 입력 시험과 verifier 재검토가 남아 있다. 18 update smoke의 여덟 단계 진입과 생산 DR 경계 매핑은 준비 계약이며 실제 Kit 실행·실현 readback은 미확인이다. model_17은 T0 진입 설정 확인용이지 T0 학습 증거가 아니다.

이 예외는 WORKLIST D72(10/30 20:3x)·D74·D75·D76·D77을 원자료로 삼는다. 지형 단계 이후의 성과 승급 요구는 계속 남는다. EX-40 완주만으로 기본 보행 졸업이나 지형 단계 진입을 선언하지 않는다.

## 3. 평가 사다리와 기준 축

- **사다리**(단계마다 넓어진다): 기본 보행 L0~2 → L3 → L6 → L9 (D03 레벨 묶음) → 지형 추가(AME-2 12 종 · JEPLO 지형 · D44 계단참 회전 · 계단 위 정지 재출발) → 깃발 · 임무. 단계마다 그 단계의 A 층 목록과 졸업 기준을 카드에 둔다.
- **기준 축**(단계와 상관없이 고정): 모든 정본을 같은 잣대로 잰다. 지금은 W15 13 명령(L0~2, 64 env, 잡음 켬) + 레벨 묶음마다 대표 칸. 기준 축의 묶음 판(코드 커밋 · 명령 수 · 칸 목록)은 바꿀 때 판 번호를 올리고, 옛 판 결과와 섞지 않는다.
- 기준 정책: 단계마다 하나(지금은 S-B10 m1500 부모). 새 정본은 기준 정책 대비 반복 폭으로 읽는다.
