# FOOTHOLD 앱 디자인 기준 (초안)

브랜드 정책의 부제는 `Terrain-Adaptive Locomotion Policy` 다. 팀장이 11/21 확정한 프로젝트 이름은 `Terrain-Adaptive Mission Platform for Legged Robots` 다. 둘이 다르다. 정책상 부제는 바꿔 그리지 않고 「Figma 제안 → 사람 승인」 경로로만 바뀐다. **팀장 결정 (11/21 22:59): 부제를 새 이름에 맞춰 바꾼다.** 11/22 11:33 PR #895 를 보고 「Terrain-Adaptive Mission Platform for Legged Robots · 이게 맞지 이제는」 이라고 다시 확인 (app-lx 전달). 부제 교체 요청서는 app-gen-lx 경로로.

## 2. 앱에 새로 필요한 의미 (제안 · 새 색을 만들지 않고 기존 토큰 조합으로)

| 의미 | 제안 표현 | 까닭 |
|---|---|---|
| **실기** (실제 로봇이 붙음) | 채운 테두리 `--brand` + 「실기」 글자 표 + 살아 있는 점 (깜빡임 1 Hz) | 팀장 요구: 관제탑과 시뮬 공간 둘 다에서 반드시 구분 |
| **시뮬** (가상만 돎) | 점선 테두리 `--ink-3` + 「시뮬」 글자 표 + 빗금 바탕 | 색만으로 구분하지 않음 (색맹 · 흑백 인쇄에도 보이게 모양으로) |
| 모드 START · AME-2 · 순정 | 글자 표 세 가지 (색은 `--ink-2` 하나, 글자로 구분) | 모드는 상태가 아니라 선택. 색을 쓰면 경고와 섞임 |
| 경고 단계 | 정상 `--brand` · 주의 `--note` · 위험 / STOP `--stop` 세 단계만 | 토큰에 이미 있는 세 뜻. 순정 앱 코드 무리 (100 · 300 · 400 · 600) 는 글자로 |
| 걸은 길 · 계획 길 | 걸은 길 실선 · 계획 길 점선 · 다른 로봇 길은 흐린 선 | 순정 앱 빨간 길 (M3) 은 우리 `--stop` 과 겹쳐 위험으로 읽힘 → 빨강 대신 `--brand` 실선 제안 |
| 점군 높이 색 | 브랜드 색과 따로인 색표 + 범례 | 브랜드 색을 데이터 색으로 쓰면 의미가 흐려짐 |

## 3. 화면 폭과 공용 조각

| 폭 | 대상 | 원칙 |
|---|---|---|
| 폰 가로 (기본 · 팀장 11/22 12:52) | 모든 화면 (관제탑 · 조종 · 기록 보기) | 순정 배치 (조이스틱 둘 · STOP 오른쪽 위) · 큰 터치 (44 px 이상) · 세로는 이번 범위 밖 |
| 태블릿 · 웹 (≥ 1024 px) | 관제탑 격자 · 지도 편집 · 시뮬 · 여러 대 동선 | 왼쪽 탐색 `--nav` 268 px · 큰 3D 화면 |

같은 조각을 쓰는 단위 (제안): 로봇 카드 · 상태 줄 (배터리 · 온도 · 망) · STOP 버튼 · 모드 표 · 실기 / 시뮬 표 · 지도 카드 · 경고 줄. 폰에서 못 하는 것 (지도 편집 · 여러 대 동선 맞추기) 은 웹 전용으로 표시한다.

## 4. 글 · 낱말

- 화면 낱말은 한국어 우선. 「실측 현장」 (팀장 18:4x 답에서 제안 · 확정 전) · 「실기」 · 「시뮬」 · 「관제탑」 (이름 미정).
- 우리 정책은 실기 미측정 (lead-lx 18:38). 화면 문구에 「검증됨 · 안전 보장」 을 쓰지 않는다.
- 브랜드 정책: 로고를 다시 그리거나 늘리지 않는다 · 성능 · 안전 주장을 브랜드에서 끌어내지 않는다.

## 4-1. 「너무 flat · 3D 고급스러움」 (팀장 11/22 11:33 · app-lx 전달 요지 · 의견 공유 단계 · 주제 8 에서 정함)

제안 방향 (팀장 확인 전):
- **깊이는 3D 화면에서 낸다.** 실측 지도 · 점군 · 로봇 모형에 빛 · 그림자 · 바닥 반사 · 안개 같은 깊이를 준다. 화면의 주인공이 3D 이니 고급스러움도 거기서 나와야 한다.
- **판 위에 층을 둔다.** 칸 (`--card`) 에 높이 단계 2~3 개 (그림자 · 가장자리 빛) 를 새 토큰으로 제안한다. 지금 토큰에는 높이 개념이 없어서 모두 같은 평면으로 보인다.
- **재질감은 절제한다.** 브랜드 청록을 금속 · 유리 느낌의 얇은 가장자리 빛으로만 쓴다. 넓은 면을 그라데이션으로 칠하지 않는다.
- 반대 의견: 조종 버튼 · STOP · 경고까지 유리 · 입체로 만들면 점군 위에서 글이 안 읽힌다. 조작 조각은 단단하고 또렷하게 두고 입체감은 배경 · 3D 쪽에 몰아준다.
- 새 토큰 (높이 · 빛) 은 브랜드 정책상 제안 → 사람 승인 뒤에만 정본에 들어간다. app-lx 는 그 전까지 토큰을 건드리지 않는다.
