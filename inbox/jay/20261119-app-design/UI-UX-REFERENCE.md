# 순정 앱 UI · UX 참고 목록

이 문서는 순정 앱을 베끼려는 것이 아니다. 화면을 짤 때 「이미 사람들이 익숙한 방식」 과 「우리가 다르게 보여 줘야 할 곳」 을 가르는 참고다 (메모리 원칙: 순정 앱은 설계 뒤 빈칸 찾기에도 쓴다). Go2 X 에 없는 기능 (동반 모드 · UWB · 4G 요금 · 눈 표정) 은 넣지 않았다.

## 1. 화면 짜임

| # | 순정 앱이 하는 것 | 근거 | FOOTHOLD 에서는 |
|---|---|---|---|
| L1 | 첫 화면: 왼쪽 큰 로봇 그림 + 배터리, 오른쪽 메뉴 다섯 칸 (Course · Guide · Me · Function · Device), 아래 큰 「GO!」 | Perspective-Switching_01 첫 칸 | 우리 첫 화면은 로봇 한 대가 아니라 **관제탑 (여러 대)**. 「GO!」 처럼 가장 자주 하는 한 가지 (그 로봇 열기) 를 크게 두는 원칙만 가져온다 |
| L2 | 조종 화면은 가로 전체 화면. 양쪽 아래 조이스틱 둘, 가운데 아래 동작 줄, 오른쪽 위 빨간 STOP, 위 줄에 배터리 · 온도 · 망 속도 | Perspective-Switching_01 | 폰 가로 조종은 같은 배치가 손에 익다. **STOP 은 오른쪽 위 고정 · 빨강** 을 그대로 따른다. 우리는 웹에서도 같은 조각을 쓰므로 웹에서는 조이스틱 대신 키보드 · 게임패드 안내 |
| L3 | 카메라 ↔ 점군 작은 창 눌러 바꾸기 · 두 손가락 쓸기 · 나란히 보기 | Perspective-Switching_01 | 우리는 **실기 카메라 ↔ 시뮬 화면** 을 같은 방식으로 바꾼다. 「같은 입력 · 두 화면」 을 보여 주는 가장 쉬운 방법 |
| L4 | 점군 색은 높이에 따라 무지개 (분홍 · 노랑 · 초록) · 로봇 3D 모형이 가운데 | Perspective-Switching_01 | 높이 색은 읽기 쉽다. 다만 우리 브랜드 색과 섞이지 않게 **점군 색표는 따로 정하고 범례를 붙인다** |
| L5 | 「…」 더보기에 속도 · 조명 · 볼륨 같은 덜 쓰는 것 | APK 3.4 | 화면을 비우는 원칙만. 우리 「…」 에는 모드 (START · AME-2 · 순정) 가 아니라 부가 설정만. 모드는 늘 보이게 |

## 2. 지도 · 순찰 흐름

| # | 순정 앱이 하는 것 | 근거 | FOOTHOLD 에서는 |
|---|---|---|---|
| M1 | 지도 목록: 카드 (미리보기 · 이름 · 날짜) + 오른쪽 아래 「+」 로 새 스캔 | 3D-LiDAR-Mapping_01 둘째 칸 | 지도 탭 자산 목록과 같다. 카드에 **실측 / 학습 지형 / 커스텀** 표시를 더한다 |
| M2 | 스캔 전 TIPS 상자: 천천히 · 평평한 곳 · 출발점에서 30 m 안 · 5 분 안 | 3D-LiDAR-Mapping_01 셋째 칸 · APK 3.11 | 시작 전에 조건을 한 번 보여 주는 방식은 좋다. 우리 값은 Point-LIO · L2 로 **우리가 재서** 정한다 (순정 숫자를 옮기지 않음) |
| M3 | 스캔 중 로봇이 걸은 길이 **빨간 선** 으로 지도 위에 그려짐 · 오른쪽 위 Save | 3D-LiDAR-Mapping_01 넷째 칸 | 팀장이 숙소 방 시험에서 본 빨간 동선과 같은 표현. 실시간 지도에 **걸은 길 + 지금 위치** 를 늘 그린다 |
| M4 | 저장 때 이름 입력 창 하나 (Cancel · Confirm) | 3D-LiDAR-Mapping_01 다섯째 칸 | 같게. 저장 뒤 GLIM 후처리를 이어 거는 선택을 붙인다 |
| M5 | 「Enter Navigation Mode」 → 「길게 눌러 끌어 지금 위치 · 방향 정하기」 → 「Initialization successful」 | 3D-LiDAR-Mapping_01 여섯~아홉째 칸 | 실기를 지도 위에 올리는 초기 위치 맞추기. 우리 시뮬 공간에 실기를 **같은 자리에** 놓는 데 꼭 필요한 단계 |
| M6 | 지도 아래 세 버튼: Go (누른 곳으로) · Charge (충전대로) · Patrol (순찰) | 3D-LiDAR-Mapping_01 아래 줄 | Go2 X 충전 단자 없음 (현장 기록 v0.16) → Charge 는 빼거나 「복귀」 로. Go · 순찰은 우리 임무의 가장 작은 단위 |
| M7 | 순찰 경로: Mark Point · Delete Point · Clear All · Save and Exit · 빨간 곡선 + 노란 화살표 방향 | 3D-LiDAR-Mapping_02 | 점 찍어 길 만들기는 우리 시나리오 편집의 출발점. 우리는 점마다 **할 일 (멈춤 · 촬영 · 측정)** 과 **시뮬 먼저 돌려 보기** 를 붙인다 |
| M8 | 순찰 설정 창: 전체 시간 (무제한 · 직접) · 한 바퀴 시간 · 충전 시간 | 3D-LiDAR-Mapping_02 | 시간 설정 칸 짜임은 참고. 여러 대일 때는 **다른 로봇 동선과 겹치는 시각** 을 같은 창에서 보여 준다 (팀장 공장 A 구역 예) |

## 3. 시뮬과 실기

| # | 순정 앱이 하는 것 | 근거 | FOOTHOLD 에서는 |
|---|---|---|---|
| S1 | 블록 코딩: 왼쪽 블록 종류 (Motion · Action · Mode · Multimedia · Light), 가운데 Start 상자에 끌어 넣기, 오른쪽 작은 3D 창에서 「Simulation」 → 문제없으면 창 닫고 실기 실행 | Programming_01 | **순정 앱도 「시뮬로 먼저 보고 실기로」 흐름을 이미 갖고 있다.** 다만 빈 바닥 위 동작 미리보기다. 우리 차이는 **실측 현장 위에서 · 물리 시뮬로 · 우리 험지 정책으로** 임무 전체를 먼저 걷는 것. 차별점 문장에 이 사실을 넣어야 정직하다 |
| S2 | 재생 · 한 단계 · 멈춤 세 버튼 | Programming_01 | 시뮬 재생 막대에 같은 세 버튼 + 「실기로 보내기」 |

## 5. 우리가 다르게 보여 줘야 할 곳 (순정 앱에 없음)

1. 여러 대를 한 화면에 (관제탑) · 실기 / 시뮬 구분 표시.
2. 실측 지도 위 물리 시뮬과 같은 입력으로 실기 투입.
3. 새 로봇 동선을 기존 동선 시간표와 겹쳐 먼저 맞춰 보기.
4. 모드 START · AME-2 (우리 학습 정책) · 순정. 단, 우리 정책은 실기 미측정 (lead-lx 보고 11/21 18:38) 이라 화면 문구에 「검증됨」 을 쓰지 않는다.
5. 웹 · 모바일 같은 조각 (순정 앱은 폰 가로 전용).
