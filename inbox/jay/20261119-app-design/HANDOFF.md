- 경고 타일: 칸 옅게 물듦 + 1 px 테두리 + 칸 위에 붙은 표지 (「과열」 등). 어두운 모드는 이름 · 숫자도 경고색.

- 동작 단추: 순정은 모두 켬 (인사만 회색 · SDK 번호 없음). 저수준은 동작 8 + 조회 2 만 켬, 나머지 회색 · 터치하면 까닭 한 줄 (PR #501, dev 대상, 안 합침).

- 키보드 · 앱 · 모바일 · 음성 명령은 순정이든 저수준이든 같은 길로 로봇에 간다: 서버 → foothold-robot → 순정 SDK 또는 START 실행기 (팀장 10:49 · app-lx 전달).
- 음성 호출어는 「Hey, Foothold」 (순정은 Hey, BenBen). 한국어 · 영어 둘 다 (팀장 10:49 · app-lx 전달). 순정 호출어는 바꿀 수 없다고 본다: SDK 음성 창구 (VuiClient) 에는 켜기/끄기 · 소리 · 밝기만 있고 호출어 설정이 없음 (app-lx 가 잼). 호출어 인식이 본체 펌웨어 안에 있다는 것은 짐작. 그래서 「Hey, Foothold」 는 우리 인식기로 따로 간다. 저수준 중 순정 음성을 VuiClient 스위치로 끌지는 실기로 재야 함 (app-lx 11:33).
- 음성 방향 (팀장 11:30 · app-lx 전달 · 원문 아님): SLAM 과 음성은 팀장이 직접 맡음. 민우 #950 · #953 은 기능 시험일 뿐. 시뮬 공간: Ctrl+E 누르고 말하면 PC 마이크 → 시뮬 로봇 동작. 모바일: 폰 마이크 또는 Go2 에게 직접 말하기 → 실기 동작 (Jetson 이 본체 마이크 소리를 받을 수 있는지 미확인 · 안 되면 마이크를 따로 붙임). 우리가 넣은 순정 동작 전부가 음성으로 움직임 (저수준 회색 규칙은 그대로). 화면: 시뮬은 로봇 옆 팝업, 로봇 탭은 왼쪽 큰 로봇이 말하는 듯한 팝업, 모바일도 같게.
- 음성 대답 (팀장 12:10 · 원장 답 17): 「앉아」 하면 로봇이 대답하고 앉는다. 대답은 화면 (말주머니) 과 소리 (Go2 스피커) 둘 다. 시뮬 · 실기를 붙인 앱 · Go2 에게 직접 말하기 모두 똑같다. ## 하지 말 것
- DESIGN.md 에 없는 색 · 글꼴 값을 새로 넣지 않는다. 필요하면 app-design-lx 에 묻는다.
