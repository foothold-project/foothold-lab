## 정해진 것 (요약 · 자세한 값은 정본)
- 밝은 모드 = 현장 폰 가로 기본. 어두운 모드 = 관제 FHD 기본. 강조색은 한 화면 한두 곳.
- 경고 타일: 칸 옅게 물듦 + 1 px 테두리 + 칸 위에 붙은 표지 (「과열」 등). 어두운 모드는 이름 · 숫자도 경고색.
- 예행 (시뮬): 파란 점선 + 「예행」 글자. 숫자 · 단위 자리는 실기 칸과 같다.
- 숫자: Inter Tight 400 · tabular-nums. 한글 Noto Sans KR.
- 동작 단추: 순정은 모두 켬 (인사만 회색 · SDK 번호 없음). 저수준은 동작 8 + 조회 2 만 켬, 나머지 회색 · 터치하면 까닭 한 줄 (PR #501, dev 대상, 안 합침).
- 저수준에서 켜진 동작은 실행기 받는 쪽이 아직 없어서 지금은 RUNNER_NOT_CONNECTED 로 거절됨. 통로는 app-lx 가 만드는 중.
- 키보드 · 앱 · 모바일 · 음성 명령은 순정이든 저수준이든 같은 길로 로봇에 간다: 서버 → foothold-robot → 순정 SDK 또는 START 실행기 (팀장 10:49 · app-lx 전달).
- 음성 호출어는 「Hey, Foothold」 (순정은 Hey, BenBen). 한국어 · 영어 둘 다 (팀장 10:49 · app-lx 전달). 순정 호출어는 바꿀 수 없다고 본다: SDK 음성 창구 (VuiClient) 에는 켜기/끄기 · 소리 · 밝기만 있고 호출어 설정이 없음 (app-lx 가 잼). 호출어 인식이 본체 펌웨어 안에 있다는 것은 짐작. 그래서 「Hey, Foothold」 는 우리 인식기로 따로 간다. 저수준 중 순정 음성을 VuiClient 스위치로 끌지는 실기로 재야 함 (app-lx 11:33).
- 음성 방향 (팀장 11:30 · app-lx 전달 · 원문 아님): SLAM 과 음성은 팀장이 직접 맡음. 민우 #950 · #953 은 기능 시험일 뿐. 시뮬 공간: Ctrl+E 누르고 말하면 PC 마이크 → 시뮬 로봇 동작. 모바일: 폰 마이크 또는 Go2 에게 직접 말하기 → 실기 동작 (Jetson 이 본체 마이크 소리를 받을 수 있는지 미확인 · 안 되면 마이크를 따로 붙임). 우리가 넣은 순정 동작 전부가 음성으로 움직임 (저수준 회색 규칙은 그대로). 화면: 시뮬은 로봇 옆 팝업, 로봇 탭은 왼쪽 큰 로봇이 말하는 듯한 팝업, 모바일도 같게.
- 음성 대답 (팀장 12:10 · 원장 답 17): 「앉아」 하면 로봇이 대답하고 앉는다. 대답은 화면 (말주머니) 과 소리 (Go2 스피커) 둘 다. 시뮬 · 실기를 붙인 앱 · Go2 에게 직접 말하기 모두 똑같다. Go2 에게 직접 말할 때도 로봇이 소리로 대답하고 움직인다 (원문 「대답을 하고 앉아야지」). 대답하는 동안 「멈춰」 로 그 명령을 안 하게 할지는 팀장 질문. Go2 스피커로 우리 대답 소리를 내는 것은 미확인 (Go2 메시지에 AudioData_ 가 있으나 재생용인지 · 토픽 이름 미확인 · app-lx 12:16).
- 움직이는 명령은 위에서 내려오는 알림창으로 한 번 보여 주고 실행 (팀장 12:10).
- 시뮬 음성 키: 누르는 동안 듣기 (팀장 12:10). 듣는 동안 화면에 듣고 있다는 움직임 표시. Ctrl+E 가 브라우저 단축키와 겹치는지는 app-lx 확인.
- 이 방향은 아래 「안전」 의 음성 규칙을 덮지 않는다.
- 웹 모드 키: Shift + 1 Classic · 2 Sport · 3 START · 4 AME-2 (원장 601 행 · 11/26 답 5). 입력 칸 선택 중이면 무시 · 전환 전 확인 한 번. 저수준에서 Classic 으로 갈 때는 멈춰 서 있을 때만 (앉기가 끼므로). 원장 216 행 Shift + 1 START 는 옛 값.
- 서버가 끊기면 기본 길의 앱 조종은 끊긴다. 0.3 초 뒤 로봇 멈춤 · 화면은 「리모컨만」. 서버 없는 폰 → Jetson 길은 코드가 있으나 (dev PR #41) 실기 미검증이라 화면에서 기대지 않는다 (app-lx 11:16). 끊긴 동안 기록: 일정 보고만 디스크에 쌓았다 다시 보냄 · 나머지는 빠짐 (실기 미검증).
- 저수준 → Classic 전환 조건 「멈춰 서 있을 때만」 은 실행기가 막는다 (app-lx 만드는 중). 화면은 IGNORED 까닭을 그대로 한 줄로 보인다.
- 관절 온도 단계 이름: 주의 50 · 경고 60 · 위험 70 °C (원장 A9). 막지 않음 = 글 + 「멈춤」 제안 단추만. 색만으로 가르지 않고 숫자 · 단계 글을 함께.
- 리모컨과 앱 명령이 동시에 들어오면 리모컨 먼저 (팀장 11:27 · 원장 답 16). 범위: 저수준 실행기 쪽 코드 (remote_active) 는 dev 에 있음. 순정 Classic · Sport 에서는 미측정 · 실기 시험 안 올림 (순정이 리모컨을 먼저 따른다는 근거 없음. app-lx 안: foothold-robot 이 리모컨 막대 · 키 상태를 보고 순정에서도 앱 명령을 막음 · app-lx 11:33).
- 악수 (SDK Hello) 는 팀장 실기 시험 통과 → 단추 옆 「시험 중」 표시 없음 (팀장 11:27).
- 현장 승인 (팀장 12:39 · 권고대로): 지금은 자동 통과 (dev 8f08d0d0) 그대로. 고객 현장에 넣을 때 설정에서 「현장 확인」 을 켜는 선택지로 다시 다룸.
- 가스 · 게이지 · Ex 구역 데모는 「가정」 표지로 우선 (팀장 12:39). assumed_hardware 칸 넣기 진행 (app-lx).
- 음성 대답 중 「멈춰」 가 들어오면 멈춰가 이긴다. 대답하던 명령 (예: 앉기) 은 하지 않는다 (팀장 12:39).
- 정지 단추 (팀장 12:39 물음 「~하지 않나? 안그래?」 에 대한 안 · 팀장 확인 전): 한 번 누름 = 그 자리 멈춤 → 단추가 「엎드려 힘 빼기」 로 바뀜 → 한 번 더 = 엎드린 자세로 2 초 보간한 뒤 감쇠 (sit_down 과 같은 길). 서 있는 채로 바로 감쇠하면 다리가 이상하게 접힘 (11/22 실기 · policy/lowlevel.py:594) 이라 날 Damping 은 넘어짐 · 끊김 비상에만. 단추가 바뀐 뒤 1 초는 눌러도 안 먹거나 길게 누르기로 (빨리 두 번 닿아 멈춤을 건너뛰지 않게). 계단 · 경사 위에서는 「엎드려 힘 빼기」 회색. 멈춘 뒤 「다시 시작」 단추. 순정 모드의 Damp 동작은 app-lx 확인 (app-reviewer-lx H13). 모든 로봇을 한 번에 멈추는 단추는 이름을 「모두 정지」 로 따로 두고 웹 머리 띠 (모든 탭) 에 둔다 (app-design-lx 안 · 팀장 확인 전 · 원문은 「모든 로봇이 다 멈추라는 건가?」 물음) (비상 정지는 어느 화면에서도 보인다는 앞 규칙). 로봇 하나의 정지 · 힘 빼기 · 다시 시작은 로봇 탭 · 조종 화면 · 폰. 임무 탭 시안의 「전체 비상 정지」 는 고침.
- 로봇 탭에 순서 점검 (팀장 12:39): Wi-Fi (Jetson) → 서버 → foothold-robot → 실행기 → Go2 몸통 → 센서 → 배터리 · 관절 순으로 돌고, 막힌 곳과 고칠 곳을 바로 보여 줌 (자동차 앱처럼).
- 데모 표시: 켬 = 타일에 작은 「데모」 표지, 끔 = 표지 없음 (발표 때 · 총괄만 끔) (팀장 12:10 확인).
- 시뮬 엔진은 MuJoCo (Gazebo 아님).
- 데모 로봇은 실기와 같은 길 (AgentState · robot_info · CameraFrame). 로봇에 demo=true 칸 하나만 다르고, STOP · 해제 · 일정 (run) · 기록 · 이력은 실기와 같은 서버 길로 DB 에 쌓인다 (팀장 10:49 · app-lx 전달). 뼈대 PR #500, 실기와 똑같이 만드는 일은 app-lx 진행 중.
- Go2 X 는 켠 채 충전 안 됨 → 데모 「충전기」 는 배터리 교체 칸.
- 가스 감지 · 게이지 읽기 · Ex (방폭) 구역은 상위 기체 가정이다 (Go2 X 에 없음). 화면 · 데모 설명에 「가정」 표지를 붙인다 (MAP-SITES 기체 가정).
- 경기장 「학습함 / 처음」 표지는 정책 판에 묶고, 색은 DESIGN.md 안에서만 (강조색 점 · 흐린 점선).
- 폰 직결 코드는 Jetson 에 깔린다 (설치판이 apps/agent 를 통째로 복사). 다만 켜는 길은 서버 에이전트와 갈리는 별도 모드다 (go2_direct · 「no server command authority」). 코드 읽기로는 자동 시작은 폰 길을 켜지 않는다: 설치판 launch.py 는 foothold_agent.setup --headless --onboard (install_jetson_bundle.py:39 · :210) 이고, setup 은 phone 의 tickets · observer 도우미만 가져온다. 폰 서버를 띄우는 곳은 go2_direct runtime · config · ros_bridge 뿐 (app-reviewer-lx 11:19 · app-design-lx 가 dev 에서 git grep 으로 다시 봄). Jetson 실제 상태: app-lx 가 11/26 11:21 Jetson 프로세스를 읽기 전용으로 봄 · foothold-robot.service 의 setup --headless --onboard · policy.factory_record · policy.depth_health 셋만 떠 있고 go2_direct.runtime (폰 서버) 없음 (app-lx 보고). 폰 직결로 조종하는 것은 실기 미검증.
- 「가정」 표지 자료: 계약 안 assumed_hardware: [gas_sensor, ex_rated, gauge_reader] 를 구역 · 임무 단계에 두고 사건은 물려받음. 로더는 상태 보고에 실어 보내기만 함. 팀장 결정 (비방폭 현장으로 바꿀지) 뒤 넣음 (app-lx 답 · 메시지 표기 11:24, 받은 시각 11:18).

## 안전 (먼저 읽기)
- foothold-robot 은 Jetson 부팅 때 자동 시작이 켜져 있다 (11/25 20:50 · app-lx 전달 · 원장 「자동 시작」 줄. 원장 A12 「자동 시작 금지」 는 뒤집힘). dev 에 사람 없는 현장 승인 (8f08d0d0) 이 들어 있어, 서버 경유 조종 스위치가 켜져 있으면 Jetson 이 켜지기만 해도 현장 승인까지 간다. 남은 관문은 STOP · 조종권 · 잠금 해제. 현장 승인을 사람이 누르게 되돌릴지는 팀장 질문 (아래 표).
- 음성: 「멈춰 / 정지」 는 늘 바로 실행 (팀장 11:30 음성 방향 뒤에도 그대로). 움직임을 일으키는 명령은 화면에 한 번 보여 주고 실행 (또는 2 초 안 취소). 누가 말했는지 기록 (원장 음성 줄). 저수준에서 회색인 동작은 음성으로도 안 됨 (팀장 08:01). 위험 동작 (뒤집기 · 두 발 · 물구나무) 은 음성 금지. 단, 비상 정지 수단은 말이 아니라 화면 · 리모컨 단추다 (말은 보조).

## 하지 말 것
- DESIGN.md 에 없는 색 · 글꼴 값을 새로 넣지 않는다. 필요하면 app-design-lx 에 묻는다.
- 시안 견본 (고르기 페이지 그림) 을 타일 배치로 그대로 옮기지 않는다. 견본은 색 · 상태 규칙만 보인다. 타일 배치는 WORK-PROCESS 5 단계에서 따로 나온다.
- 아직 안 정한 것 (둥글기 · 간격 · 움직임 · 타일 배치 · 임무 탭 화면) 을 짐작으로 만들지 않는다.
- 실기 로봇에 명령을 보내는 시험을 직접 하지 않는다. 실기는 app-lx 를 거친다.
- 공개 저장소에 내부 주소 · 계정 · 키 · 남의 시안 그림을 넣지 않는다.
