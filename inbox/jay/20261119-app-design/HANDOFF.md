## 정해진 것 (요약 · 자세한 값은 정본)
- 밝은 모드 = 현장 폰 가로 기본. 어두운 모드 = 관제 FHD 기본. 강조색은 한 화면 한두 곳.
- 경고 타일: 칸 옅게 물듦 + 1 px 테두리 + 칸 위에 붙은 표지 (「과열」 등). 어두운 모드는 이름 · 숫자도 경고색.
- 예행 (시뮬): 파란 점선 + 「예행」 글자. 숫자 · 단위 자리는 실기 칸과 같다.
- 숫자: Inter Tight 400 · tabular-nums. 한글 Noto Sans KR.
- 동작 단추: 순정은 모두 켬 (인사만 회색 · SDK 번호 없음). 저수준은 동작 8 + 조회 2 만 켬, 나머지 회색 · 터치하면 까닭 한 줄 (PR #501, dev 대상, 안 합침).
- 저수준에서 켜진 동작은 실행기 받는 쪽이 아직 없어서 지금은 RUNNER_NOT_CONNECTED 로 거절됨. 통로는 app-lx 가 만드는 중.
- 키보드 · 앱 · 모바일 · 음성 명령은 순정이든 저수준이든 같은 길로 로봇에 간다: 서버 → foothold-robot → 순정 SDK 또는 START 실행기 (팀장 10:49 · app-lx 전달).
- 음성 호출어는 「Hey, Foothold」 (순정은 Hey, BenBen). 한국어 · 영어 둘 다 (팀장 10:49 · app-lx 전달).
- 웹 모드 키: Shift + 1 Classic · 2 Sport · 3 START · 4 AME-2 (원장 601 행 · 11/26 답 5). 입력 칸 선택 중이면 무시 · 전환 전 확인 한 번. 저수준에서 Classic 으로 갈 때는 멈춰 서 있을 때만 (앉기가 끼므로). 원장 216 행 Shift + 1 START 는 옛 값.
- 서버가 끊기면 기본 길의 앱 조종은 끊긴다. 0.3 초 뒤 로봇 멈춤 · 화면은 「리모컨만」. 서버 없는 폰 → Jetson 길은 코드가 있으나 (dev PR #41) 실기 미검증이라 화면에서 기대지 않는다 (app-lx 11:16). 끊긴 동안 기록: 일정 보고만 디스크에 쌓았다 다시 보냄 · 나머지는 빠짐 (실기 미검증).
- 저수준 → Classic 전환 조건 「멈춰 서 있을 때만」 은 실행기가 막는다 (app-lx 만드는 중). 화면은 IGNORED 까닭을 그대로 한 줄로 보인다.
- 관절 온도 단계 이름: 주의 50 · 경고 60 · 위험 70 °C (원장 A9). 막지 않음 = 글 + 「멈춤」 제안 단추만. 색만으로 가르지 않고 숫자 · 단계 글을 함께.
- 시뮬 엔진은 MuJoCo (Gazebo 아님).
- 데모 로봇은 실기와 같은 길 (AgentState · robot_info · CameraFrame). 로봇에 demo=true 칸 하나만 다르고, STOP · 해제 · 일정 (run) · 기록 · 이력은 실기와 같은 서버 길로 DB 에 쌓인다 (팀장 10:49 · app-lx 전달). 뼈대 PR #500, 실기와 똑같이 만드는 일은 app-lx 진행 중.
- Go2 X 는 켠 채 충전 안 됨 → 데모 「충전기」 는 배터리 교체 칸.
- 가스 감지 · 게이지 읽기 · Ex (방폭) 구역은 상위 기체 가정이다 (Go2 X 에 없음). 화면 · 데모 설명에 「가정」 표지를 붙인다 (MAP-SITES 기체 가정).
- 경기장 「학습함 / 처음」 표지는 정책 판에 묶고, 색은 DESIGN.md 안에서만 (강조색 점 · 흐린 점선).
- 폰 직결 코드는 Jetson 에 깔린다 (설치판이 apps/agent 를 통째로 복사). 다만 켜는 길은 서버 에이전트와 갈리는 별도 모드다 (go2_direct · 「no server command authority」). 자동 시작이 이 모드를 켜는지는 미확인 · 실기 미검증 (app-lx 11:24).
- 「가정」 표지 자료: 계약 안 assumed_hardware: [gas_sensor, ex_rated, gauge_reader] 를 구역 · 임무 단계에 두고 사건은 물려받음. 로더는 상태 보고에 실어 보내기만 함. 팀장 결정 (비방폭 현장으로 바꿀지) 뒤 넣음 (app-lx 11:24).

## 안전 (먼저 읽기)
- foothold-robot 은 Jetson 부팅 때 자동 시작이 켜져 있다 (11/25 20:50 · app-lx 전달 · 원장 「자동 시작」 줄. 원장 A12 「자동 시작 금지」 는 뒤집힘). dev 에 사람 없는 현장 승인 (8f08d0d0) 이 들어 있어, 서버 경유 조종 스위치가 켜져 있으면 Jetson 이 켜지기만 해도 현장 승인까지 간다. 남은 관문은 STOP · 조종권 · 잠금 해제. 현장 승인을 사람이 누르게 되돌릴지는 팀장 질문 (아래 표).
- 음성: 「멈춰 / 정지」 는 늘 바로 실행. 움직임을 일으키는 명령은 화면에 한 번 보여 주고 실행 (또는 2 초 안 취소). 누가 말했는지 기록 (원장 음성 줄). 저수준에서 회색인 동작은 음성으로도 안 됨 (팀장 08:01). 위험 동작 (뒤집기 · 두 발 · 물구나무) 은 음성 금지. 단, 비상 정지 수단은 말이 아니라 화면 · 리모컨 단추다 (말은 보조).

## 하지 말 것
- DESIGN.md 에 없는 색 · 글꼴 값을 새로 넣지 않는다. 필요하면 app-design-lx 에 묻는다.
- 시안 견본 (고르기 페이지 그림) 을 타일 배치로 그대로 옮기지 않는다. 견본은 색 · 상태 규칙만 보인다. 타일 배치는 WORK-PROCESS 5 단계에서 따로 나온다.
- 아직 안 정한 것 (둥글기 · 간격 · 움직임 · 타일 배치 · 임무 탭 화면) 을 짐작으로 만들지 않는다.
- 실기 로봇에 명령을 보내는 시험을 직접 하지 않는다. 실기는 app-lx 를 거친다.
- 공개 저장소에 내부 주소 · 계정 · 키 · 남의 시안 그림을 넣지 않는다.
