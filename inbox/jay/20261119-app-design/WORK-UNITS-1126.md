# 앱 마감 작업 단위

## 1. 판넬 앱 화면이 왜 좋아 보였나 (사실)

판넬 「앱화면_오늘임무」 · 「앱화면_조종」 · 「앱화면_웹관제」 의 **화면 자체는 생성 AI 그림이 아니다.** 생성 AI 가 그린 화면은 글자가 깨져서 버렸고, 우리가 HTML · CSS 로 짠 화면을 그 기기 사진 안에 붙였다. 생성 AI 가 한 일은 기기 사진 (폰 · 노트북) 과 지도 그림 (3D 공장) 이다.

좋아 보인 까닭은 셋이다.

1. **요소가 적고 자리가 정해져 있다.** 오른쪽 기둥 폭 92 px 하나에 위에서부터 상태 아이콘 셋 → 모드 (START) → 조종 → 임무 멈춤 → (떨어져서) 말하기 → 맨 아래 정지. 모두 같은 폭 · 같은 둥글기 (14 px) · 같은 틈 (8 px). 왼쪽 위 로봇 칩 하나, 왼쪽 아래 임무 카드 하나. 나머지는 지도.
2. **유리 단추 값** (판넬 `ui.css` 의 `.g`):
   - 면: 위 → 아래 흰색 72 % → 48 % 그라데이션 (평평한 한 색이 아님)
   - 테: 1 px 흰색 85 %
   - 안쪽 빛: 위 가장자리 1 px 흰색 95 % · 아래 가장자리 1 px 검정 4 %
   - 그림자: 0 8 px 24 px, 남색 14 %
   - 뒤 흐림: blur 22 px · 채도 1.8 배
   - 어두운 유리: 면 검정 52 % → 38 % · 테 흰색 22 % · 위 빛 흰색 28 %
   - 정지: 빨강 그라데이션 (#f2575a → #d62f33) · 위 빛 흰색 35 % · 빨간 그림자 42 %
3. **뒤에 사진 같은 지도가 깔려 있다.** 유리는 뒤가 복잡해야 유리로 보인다. 흰 바탕 위에서는 같은 값도 평평해 보인다.

그래서 길은 「기능 · 흐름 → 우리가 화면을 실제 크기 HTML 로 마감 → 값은 코드에 그대로」 이다. 생성 AI 는 지도 · 배경 · 로봇 3D · 빈 화면 그림처럼 그림이 필요한 곳에만 쓴다. 생성 AI 에게 화면 전체를 맡기면 배치는 좋아도 글자 · 기능이 틀려서 다시 짜야 한다 (판넬에서 겪음).

## 2. 길 (한 화면마다)

1. 기능 카드: 그 화면에 남는 기능 · 상태 · 단추 (KEEP-CUT 3 절 · FLOWS) 를 한 표로.
2. 마감 HTML: 실제 크기 (폰 가로 844 × 390 · PC 1920 × 1080) 로 판넬 화면과 같은 유리 값 · 같은 기둥 규칙으로 짠다. 상태가 여럿이면 상태마다 한 장 (예: 정지 세 단계).
3. 그림 자산: 필요한 것만 생성 (지도 · 배경). 화면 안 글자는 생성하지 않는다.
4. 팀장 확인 (한 화면씩이 아니라 묶음으로).
5. app-lx: HTML 의 값 · 배치를 앱 코드로 옮김. 유리 값은 foothold-brand DESIGN.md 토큰으로 먼저 올린 뒤 쓴다.

## 4. 단위마다 「끝났다」 판정

- 실제 크기 PNG 와 HTML 이 같은 이름으로 있음. 넘침 0 (글자가 칸 밖으로 안 나감).
- 화면 안 단추가 모두 KEEP-CUT 「남김」 에 있음. 「뺀다」 에 있는 것이 하나도 없음.
- 유리 · 색 값이 1 절 값 (뒤에 DESIGN.md 토큰) 밖에서 새로 생기지 않음.
- 숫자는 예시 값이라고 화면 밖 설명에 적음.
