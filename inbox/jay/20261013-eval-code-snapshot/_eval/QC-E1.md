## 5. 해석

**확인됨:**
- **이동과 회전:** 5000 에 이미 대부분 통과한다. 계단 위 전진 · 후진 (stairs_down fwd03, stairs_up back03) 은 5000 → 10000 에 유의하게 좋아진다.
- **계단 후진 · 계단 횡이동:** 10000~20000 동안 96~100 % 를 유지하다 20499 에 무너진다 (noise 켬 Holm 2 cell, 끔 3 cell).
- **정지:**
  - noise 켬에서는 학습 내내 바닥에 가깝다 (최고 19500 평지 17 %).
  - 오르는 기울기는 15000 → 19500 에서 가장 컸지만 Holm 뒤 유의하지 않다.
  - noise 끔 정지는 19500 · 20000 이 같고 20499 에서 떨어진다.
- **0.1 m/s 로 실제로 움직이기 (a):**
  - 10000 에 가장 높다.
  - 15000 → 19500 (4 지형), 19500 → 20000 (7 지형), 20000 → 20499 (5 지형) 로 단계마다 유의하게 줄었다.
  - 하락은 명령 확대 (20k) 전부터 이미 시작됐다.
  - 현행 Q1 은 이 변화를 전혀 보지 못한다 (모두 100 %).
- **19500 대 20000:** 현행 판정 116 cell 로는 거의 같다 (noise 켬 1 cell, 끔 0 cell). 저속 이동 (a) 은 다르다.

**추정:**
- **19500 대 20000 의 차이 원인:** 20000 은 확대 범위 rollout 을 1~2 번만 거쳤다. 그 rollout 에서도 새 명령을 받은 env 는 일부뿐이다. 명령은 5.02 s 마다 resample 되고, 한 iteration 은 24 step 이다. 그래서 두 체크포인트의 차이는 대부분 같은 (확대 전) 분포로 500 iter 더 학습한 결과로 보인다.
  - 15000 → 19500 에서 이미 같은 방향 (fwd01 (a) 하락) 이 있었다는 점과도 맞는다.
  - 확대의 효과를 따로 보려면 「19500 + 확대 없이 500 iter」 대조가 필요하다.
- **저속 · 정지가 늘 약한 이유:** CMD-RESUME.md A 절의 명령 분포와 맞는 방향이다. 학습 중 정지 (0, 0, 0) 명령은 0 % 이고, 0.1 m/s 근처의 순수 전진은 0.01 % 다. 학습이 진행될수록 0.1 m/s 에서 실제로 움직이지 않고 서 있는 쪽으로 간다 (현행 Q1 은 통과로 셈).

**미확인:**
- 같은 경향이 E2 (시드 43) 에서도 나오는지.
- 5000 이전 체크포인트.
- 20499 하락이 확대 뒤 적응 중인 과도기인지 (20499 뒤 checkpoint 가 없다).
