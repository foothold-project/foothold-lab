# 14 · 명령 생성기와 지형 승급

## 0. 쉬운 요약

정책(로봇의 두뇌)은 「앞으로 얼마, 옆으로 얼마, 얼마나 돌아라」 세 숫자만 받는다. 학습 때 이 세 숫자를 누가 주느냐가 문제다. v2 는 옆 숫자를 늘 0 으로 주어서 로봇이 옆걸음을 평생 못 배웠고, 느린 속도(0.4 m/s 아래)도 안 가르쳐서 천천히 가라면 틀렸다. 이번에는 땅의 종류에 따라 다르게 준다. 평평하거나 울퉁불퉁해도 어디든 디딜 수 있는 **이어진 지형**에서는 세 숫자를 0 부터 무작위로 뽑아 준다(**자유 속도**). 징검다리처럼 **듬성한 지형**에서는 건너편에 **깃발**(목표점)을 꽂고 「깃발 쪽으로 가라」 는 숫자를 만들어 주는데, 속도를 뽑는 법은 START 논문 그대로다(아주 느리면 멈춰서 제자리에서 돌기). 그러면 로봇은 카메라로 앞을 보며 건너는 법과 발판 위에서 도는 법을 배운다. 이어진 지형 일부에도 깃발을 섞어, 나중에 길 찾기가 주는 「깃발 쪽으로」 명령이 낯설지 않게 한다. 이 생성기가 START · JEPLO 두 논문의 어디를 바꿨는지는 3.1 절 표에 「우리 변경」 으로 적었다. 이어진 지형에서 자유 속도로 걷는 로봇 가운데 일부(30 %)에게는 「저 방향을 바라보며 가라」 는 목표 방향을 주고 회전 명령을 자동으로 만들어 준다(**heading 모드**). 지난 판(v2)에서 이것을 아예 껐더니 성적이 가장 낮았기 때문인데, 그때 다른 것도 같이 바뀌어 원인이 그것 하나라고는 못 한다. 그래서 30 % 는 가정이고, 결과가 「방향을 못 지킨다」 로 나오면 v2 가 쓰던 75 % 로 올린 새 판을 돌린다. 난이도를 올리는 **승급** 규칙도 방식마다 다르다. 깃발 방식은 「깃발을 다 지나면 승급」, 자유 속도는 「시킨 만큼 움직였으면 승급」 이다.

- 1 차 듬성한 지형군의 명령 노출(**팀장 결정 D39 + J-B**): 앞 = 깃발 방향 U[0.3, 1.0](0.3 미만은 제자리 회전으로 접힘), 옆 = 깃발이 축과 어긋날 때 자연히 생기는 옆 성분(`wz` 가 몸을 돌리기 전까지, 분포를 6 절 로그로 기록해 95 분위 vy_obs 를 정함), 뒤 = 물러나기 모드의 −0.3 m/s 까지, 제자리 회전 = ±1.2(START), 이동 중 회전 = clip ±1.0. 배포 때 명령 정리기(31 §5)는 이 범위로 자른다. 옆으로 멀리 걷기 · −0.3 보다 빠른 후진은 1 차 범위 밖(S4). 좁은 평균대 위에서 몸 폭 때문에 못 도는 것은 결과로 드러나게 둔다(J-B · H14-6).

### 3.2 heading 모드와 이어진 지형 env 비율 (APPROVED K-G · 우리 변경 · 팀장 승인 10/20 00:1x)

**heading 모드**(자유 속도 env 의 일부): 재추출(4 s) 때 목표 방향 ψ* ~ U[−π, π] 를 뽑고, 매 제어 스텝 `wz` = clip(0.5 × wrap_to_pi(ψ* − yaw), −2, 2). vx · vy 는 자유 속도 표집 그대로. 강성 0.5 와 식은 Isaac Lab 2.3.2 기본값 그대로다(**코드** `velocity_env_cfg.py` 98~100 행 `rel_heading_envs=1.0 · heading_command=True · heading_control_stiffness=0.5` · 식은 `velocity_command.py` 150~158 행). 0.5 × π ≈ 1.57 < 2 라 자름은 실제로 걸리지 않는다(계산). 정지 플래그가 heading 보다 우선한다(**코드** `velocity_command.py` 160~162 행: standing 이 마지막에 세 칸을 0 으로 덮음). 정책 관측 · 배포 인터페이스(vx, vy, wz)는 그대로이고 학습 명령 분포만 바뀐다. **배포에는 heading 모드가 없다**(조이스틱 · 주행층이 wz 를 직접 준다).

**뽑는 순서**(자유 속도 env · 재추출마다 · 세 플래그는 독립으로 뽑고 우선순위는 정지 > 제자리 회전 > heading > 자유 wz):
1. 정지: 확률 0.1 → 세 칸 0 (**실측** v2b `rel_standing_envs` 0.1, 자유 속도 env 에 대한 확률).
2. 제자리 회전: 1,000 회 이후 확률 0.2 → v = 0 · `wz` ~ U[−2, 2] (**코드** JEPLO 1066~1083).
3. heading 모드: 확률 0.3 → 위 식 (**가정** K-G).
4. 나머지: 자유 `wz` ~ U[−2, 2] · 유지 확률 0.5 (**코드** JEPLO 154~156).

**env 비율 한 표**(이어진 지형 env = 100 %. fable 계산 10/20. 1,000 회 이후 = 제자리 회전이 켜진 뒤):

| 방식 | 자유 속도 env 안 비율 | 이어진 지형 env 전체 (1,000 회 이후) | 이어진 지형 env 전체 (1,000 회 전) | 출처 |
|---|---|---|---|---|
| 깃발 (이어진 지형) | 해당 없음(별도 env) | 20.0 % | 20.0 % | **가정** (VERIFY-lead-final 11) |
| 자유 속도 env 합 | 100 % | 80.0 % | 80.0 % | **가정** |
| 그중 정지 | 0.1 = 10.0 % | 8.0 % | 8.0 % | **실측** v2b 0.1 |
| 그중 제자리 회전 | 0.9 × 0.2 = 18.0 % | 14.4 % | 0 % | **코드** JEPLO (1,000 회 이후) |
| 그중 heading 모드 | 0.9 × 0.8 × 0.3 = 21.6 % (1,000 회 전 0.9 × 0.3 = 27.0 %) | 17.28 % | 21.6 % | **가정** K-G |
| 그중 자유 wz | 0.9 × 0.8 × 0.7 = 50.4 % (1,000 회 전 63.0 %) | 40.32 % | 50.4 % | **코드** JEPLO |
| **합** | 10 + 18 + 21.6 + 50.4 = **100.0 %** | 20 + 8 + 14.4 + 17.28 + 40.32 = **100.0 %** | 20 + 8 + 21.6 + 50.4 = **100.0 %** | 계산 |

- 「30 %」 의 뜻: 정지 · 제자리 회전을 뺀 「속도를 받고 움직이는」 자유 속도 env 가운데 30 % 가 heading, 70 % 가 자유 wz. 세 플래그가 독립이라 「움직이는 env 중 30 %」 와 「전체 env 에 플래그 0.3」 은 같은 기대 비율(21.6 %)이다. 자유 wz 70 % 를 남기는 이유는 조이스틱 요축 명령 노출을 지키기 위해서다(K-G).
- 정지 10 % 는 v2b 와 같은 뜻(자유 속도 env 에 대한 확률)이고 이어진 지형 env 전체로는 8 % 다. 3 절 초안의 「정지 env 10 % 포함」 은 이 뜻으로 읽는다(명확화, 값 변경 아님).
- 깃발 env(이어진 20 % · 듬성한 지형 전부)에는 heading 모드를 두지 않는다. 깃발 식의 `wz` = clip(깃발 방향 각, ±1) 이 이미 heading 제어(강성 1 · 자름 ±1)다.
- 자유 속도 방식을 쓰는 모든 판(S1-a 부터 S2-G0 · G1 · G3 · S4 의 이어진 지형 env)에 같이 적용된다. S1-a 가 첫 확인 자리다.
- **근거가 말하는 것은 「heading 0 은 위험」 까지이고 비율 값이 아니다**(K-G). E1(눈 없음 · 자유 wz)의 0.5 m/s 실패는 넘어짐이 아니라 방향 이탈이 묶는다: evidence/E1-vs-v2-axis1.csv 0.5 m/s 16 칸 중 15 칸에서 성분 넷(생존 · 전진 · 추종 · 방향) 가운데 방향이 최저(나머지 1 칸 stepping_stones 는 전진), 평균 생존 0.906 · 방향 0.679(**실측** · fable 재계산 10/20). E1 의 명령 cfg 가 heading 을 썼는지는 S0 에서 E1 cfg 로 확인한다(**미확인**).
- **판정(K-G)**: S1 관문 축 3 이어진 지형 · 계단 「방향 이탈 ≤ 0.1」(41 §9)과 축 1 실패 성분(방향 이탈 대 넘어짐)으로 본다. 이탈이 관문을 넘으면 60 C 처방 하나로 heading 비율 0.30 → **0.75**(v2 E 판 값, **실측** v2 보고 556 행) 새 판 **S1a-v1.1**. 대조 판(heading 0 %)은 돌리지 않는다(예산). 그래서 **「heading 효과」 단독 결론은 내지 않는다**(결합 효과로만 적는다).
