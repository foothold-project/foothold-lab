읽는 법:
- **v2 의 옆 · 뒤 잠김이 숫자로 확인됐다**(좌 0.01 · 뒤 0.00). NVIDIA 는 옆을 따라간다(0.98) → v2 가 험지를 얻으면서 이 능력을 잃었다. 이것이 S1 이 풀 문제.
- **E1 은 옆 · 뒤는 되지만 방향이 흐른다**(이탈 0.27~0.37).
- **방향 이탈 ≤ 0.1 은 달성 가능한 기준**: NVIDIA 가 0.09. 그래서 S1 관문 값은 그대로 둘 것을 권고.
- **듬성한 지형 뒤 0.3 · 옆 0.2 칸은 세 판 모두 0~0.29**: 기준 거리 3 m 가 듬성한 지형에 너무 길 수 있다 → 결정 2 의 「0.6 m」 와 같이 칸을 줄이는 것을 권고.
- v2 · NVIDIA 축 1 의 0.5 m/s 몇 칸이 옛 값과 최대 0.06 다르다. 새 도구는 두 번 돌려 비트 단위로 같아 결정적이고, 원인은 옛 평가의 실행 조건 쪽(기록 없음 · 미확인).
- 평가 도구 결함 셋을 밤에 잡아 고쳤다: 연쇄가 WSL bash 를 부름 · 음수 명령 인자 · v2 · NVIDIA 연결부가 리셋 직후 0 명령을 보게 함(축 2 만 영향 · 고친 뒤 옛 값과 비트 일치).
- 아직 없는 것: START 시험지 Kit 실행(생성기 · 치수 시험만 있음).
