# 53 · S2 START 지각 (G1 · G3)

## 0. 쉬운 요약

S1 의 로봇에 눈을 단다. 머리 카메라 깊이 영상을 START 의 TR-Net 이 발밑 높이 지도로 바꾸고(12), 그 지도로 징검돌 · 평균대 · 디딤 빔 · 틈을 건너게 배운다. 두 번에 나눠 한다. **G1** 은 지도만 더하고, **G3** 는 거기에 「돌 가장자리에 디디면 벌점」(16) 을 더한다. 그래야 「눈이 도움이 됐나」 와 「벌점이 도움이 됐나」 를 따로 말할 수 있다. 로봇 3,072 대로 10,000 번 반복(논문과 같음), 한 판에 18~30 시간, GPU 1 한 장에서 돈다. 다 되면 S3 의 길 찾기 밑에 깔 수 있는지 관문(F26)을 본다.

## 4. 학습 틀 (fable 20e R1 · F15)

- START 방식 단일 단계 비대칭 PPO + TR-Net 손실(거친 지도 MSE · 정제 지도 L1, 169 행) + AdaSmpl. DAgger 없음(13 §3).
