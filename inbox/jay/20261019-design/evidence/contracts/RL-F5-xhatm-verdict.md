[결정 값 · 가정]
1. 높이 정의: h = −(접지한 발들의 평균 높이, 중력 정렬 틀, 몸 원점 기준). 시뮬 정답은 발 위치 · 자세 · 접촉(순힘 ≥ 1 N, critic 접촉 플래그 문턱과 같음), 배포는 관절 FK + IMU 로 같은 식. 계단에서 단이 다르면 모호(단 0.05~0.23 m) · 정답도 같은 식이라 오차에는 안 잡힘 · 참고 표기.
2. invalid_output_rule: 접지 발 0 개 = 무효. 마지막 유효 높이를 최대 10 스텝(0.2 s) 유지 뒤 공칭 서 있기 높이로 고정(공칭 값은 Go2 기본 자세에서 계산 · 미확인). 정답에도 같은 규칙. 감독 손실은 무효 스텝 마스크. 무효 비율 · 연속 길이를 칸 종류별 보고.
3. error_threshold: (가) 판정 = HL teacher 를 정답 x_m 과 x̂_m 으로 같은 장면 · 시드에서 평가해 성공률 하락 ≤ 2 %p. (나) 참고(원인 분해) = 속도 축별 MAE ≤ 0.10 m/s · p95 ≤ 0.25, 높이 MAE ≤ 0.03 m · p95 ≤ 0.06, roll MAE ≤ 0.02 rad · p95 ≤ 0.05, 평지 · 계단 · 틈 따로. 키를 (가) · (나) 로 나눔. 결과 전 gates 에 고정.
4. age: 읽는 시점 age ≤ 1 하위 스텝(20 ms) 정상, 초과 = stale → 무효와 같은 hold. 100 ms 넘으면 상위 안전 규칙(23 · 42, rl 미확인 → sol 이 대조).
