# 실험 흐름 한 장 (10/21~23)

## 정정 먼저

- **실패 이야기는 「일찍 멈춰서」 가 아니다.** EX-17~22 는 처음부터 **301 회짜리 짧은 선별 실험**으로 설계됐다(run 스크립트 `--max_iterations 301`, 팀장 10/22 「작게 테스트 · 약 300 회면 확인 가능」). 1500 회 판(EX-11 · 14 · 15)은 끝까지 돌았고 그래도 기거나 뛰었다. 중간에 멈춘 판은 EX-16(501 회 설계, 330 회 중단) 하나다.
- lead 가 HANDOFF-LEADTMP 4 · 5 절에 「근거 없는 규칙으로 멈춤」 을 크게 써서 흐름을 흐렸다. 실제 교훈은 아래 줄기다.
- 「지도 유무는 1500 회에 차이 없다」 도 틀렸다(전진 숫자만 봄). 평지 회전은 EX-23(지도)이 낫다(아래 4 단계).

## 줄기: 무엇을 묻고 무엇을 알았나

**0. 출발점.** v2 는 NVIDIA 배포판에서 이어 학습해 잘 걷지만 좌우 명령이 잠겨 있다. 목표는 START 구조(지각 모듈 · 추정기 · 지도)로 열린 명령 · 험지 일반화. 그래서 START 구조를 처음부터 학습했다.

**1. START 구조 첫 학습이 걷지 못했다.**
EX-09 · 10(S2 G0, START 설정 그대로 · 센 DR): 1500 회 서 있기만. EX-11 · 12(추정기 0 · learned): 전진은 하지만 **몸을 낮춘 기는 자세** · 회전 없음 → 추정기는 원인 아님.

**2. 보상이 원인인가 (팀장: 보상 근본은 같다 · 기저 계보를 보라).**
EX-14 발 공중 시간 → 뒷발 끌기. EX-15 legged_gym A1 묶음 → 몸은 조금 섰지만(0.26~0.29) 네 발 동시 도약. EX-16 NVIDIA 보상 통째 → 초반 넘어짐 94~99 %. **보상만으로는 안 고쳐진다 = 보상 밖(환경)이 의심**.

**3. 환경을 v2 쪽으로 하나씩 (팀장: 환경적으로 접근, 작게 300 회).**
EX-17~22(각 301 회 선별): 몸통 접촉 종료 · 선속도 오라클 · **DR 약하게(EX-19)** · 행동 · 종료 · v2 묶음 · v2 명령. 알게 된 것: **DR 을 약하게 하자 초반 뒤집힘 붕괴가 사라졌다**(EX-19 넘어짐 94 % → 10~18 %). 300 회 자세는 811 300 회(낮게 서서 제자리)와 같아 이 회차로는 성패를 가를 수 없었다 → 811 처음부터 학습 기준선을 다시 재서 판단 시점을 500 · 1000 회로 정함(BASELINE-0811).
팀장 인사이트(10/22): NVIDIA 는 시뮬 보행용, START 는 실기 이전용이라 DR 이 필수지만 **처음부터 최대로 넣지 않았을 것 → 쉬운 것부터 커리큘럼**.

**4. 본류로 돌아와 검증 (Top-Down: START 구조 그대로, 환경만).**
EX-23(G1 정답 지도) · EX-25(G0 지도 없음): START 구조 · START 보상 · START 명령 그대로, **DR 약하게 고정 + 행동 지연 끔**, 1501 회.
결과: 둘 다 1000 회에 몸을 세운 대각 걸음(몸 0.30~0.35 m · 대각 0.89~0.97 · vx 약 1.0, 811 1000 회 0.40 · 0.97). 팀장 판독 「정상 보행처럼 보인다」. 811 보다 늦게 선다(500 → 1000).
지도 효과(1500 회, 팀장 판독과 숫자): 평지 회전 EX-23 wz +0.85 / -0.59 · EX-25 +0.01 / -0.46, 평지 전진 vx 1.02 대 0.91 → **지도 있는 판이 더 잘 걷고 더 잘 돈다**. rough 회전은 엇갈림(EX-23 +0.01 / -1.10 · EX-25 +0.75 / -0.84).

**5. 지금 결론(확인 수준).**
- 기는 자세의 가장 유력한 원인 = **처음부터 센 DR 과 행동 지연**(EX-11 과 EX-25 의 차이가 이것, astra 가 다른 교란 변수 확인 중).
- EX-23 · 25 는 **DR 을 약하게 고정하고 일부(무게중심 · 게인 · 세기 · 지연)를 끈 판**이다. START 기조(실기 이전)를 버린 게 아니라, 아직 커리큘럼으로 올리지 않은 상태다.
- 깊이 카메라 · TR-Net 복원 지도(G3)는 아직 한 번도 안 돌렸다.
