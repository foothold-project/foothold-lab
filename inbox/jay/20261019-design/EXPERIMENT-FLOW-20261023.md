## 10/24 원자료 대조 갱신

줄기는 유지하되 원인을 확정했던 표현을 아래처럼 좁힌다. 전체 조건표와 프레임·학습 곡선·반례는 [과거 실험 종합 분석](../20261023-experiments/ANALYSIS-experiment-failures-1024.md), 최신 실행 결정은 [실험 지도](../20261021-experiments/EXP-MAP.md)에 있다. 현재 B(EX-28)는 마찰 분포만 복원한 비교이며 model_1000에서 EX-23과 대조하고, 팀장 최신 직접 답에 따라 기존 model_1500까지 학습 후 자연 종료한다. EX-29는 복원 지도를 섞는 공동학습을 실제 실행했으나 200회 정책이 반복적으로 옆으로 넘어졌고, 완료229갱신을 보존한 채 재개 보류다. 다음 설계는 이 분석 뒤 정한다.

- lead 가 HANDOFF-LEADTMP 4 · 5 절에 「근거 없는 규칙으로 멈춤」 을 크게 써서 흐름을 흐렸다. 실제 교훈은 아래 줄기다.
- 「지도 유무는 1500 회에 차이 없다」 도 틀렸다(전진 숫자만 봄). 평지 회전은 EX-23(지도)이 낫다(아래 4 단계).

## 줄기: 무엇을 묻고 무엇을 알았나

**0. 출발점.** v2 는 NVIDIA 배포판에서 이어 학습해 잘 걷지만 좌우 명령이 잠겨 있다. 목표는 START 구조(지각 모듈 · 추정기 · 지도)로 열린 명령 · 험지 일반화. 그래서 START 구조를 처음부터 학습했다.

**1. START 구조 첫 학습이 걷지 못했다.**
EX-09(open) · 10(start)는 지도 없는 S2 진단이었다. EX-10의 1500회 재생에서 평균/표집 네 조합 모두 전진이 거의 없었다. EX-11 · 12(추정기 0 · learned)는 전진하지만 **몸을 낮춘 기는 자세**와 회전 미달이 남았다. zero에서도 포복이 남으므로 학습된 추정 출력은 포복의 필요조건이 아니다. 이를 추정기가 어떤 영향도 없다는 뜻으로 넓히지 않는다. EX-10에서 EX-11·12로 갈 때 지형도 혼합13항목에서 연속7종으로 바뀌었다.

**2. 보상이 원인인가 (팀장: 보상 근본은 같다 · 기저 계보를 보라).**
EX-14 발 공중 시간 → 뒷발 끌기. EX-15 legged_gym A1 묶음 → 몸은 조금 섰지만(기존 집계 0.26~0.29 m) **앞발 쌍과 뒷발 쌍의 동조 도약**. 네 발의 정확한 동시 이륙으로 부르지 않는다. EX-16 NVIDIA 보상 교체 → 초반 넘어짐이 많았고 약330회에 중단. 시험한 보상 변경만으로 원하는 trot이 완성되지 않아 환경을 조사한 흐름이다. 보상 전체가 원인에서 제외됐다는 증거는 아니다.

**3. 환경을 v2 쪽으로 하나씩 (팀장: 환경적으로 접근, 작게 300 회).**
EX-17~22(각 301 회 선별): 몸통 접촉 종료 · 선속도 오라클 · **DR 약하게(EX-19)** · 행동 · 종료 · v2 묶음 · v2 명령. 알게 된 것: **DR 을 약하게 하자 초반 뒤집힘 붕괴가 사라졌다**(EX-19 넘어짐 94 % → 10~18 %). 300 회 자세는 811 300 회(낮게 서서 제자리)와 같아 이 회차로는 성패를 가를 수 없었다 → 811 처음부터 학습 기준선을 다시 재서 판단 시점을 500 · 1000 회로 정함(BASELINE-0811).
팀장 인사이트(10/22): NVIDIA 는 시뮬 보행용, START 는 실기 이전용이라 DR 이 필수지만 **처음부터 최대로 넣지 않았을 것 → 쉬운 것부터 커리큘럼**.

**4. 본류로 돌아와 검증 (Top-Down: START 구조 그대로, 환경만).**
EX-23(G1 정답 지도) · EX-25(G0 지도 없음): START 구조 · START 보상 · START 명령 그대로, **DR 약하게 고정 + 행동 지연 끔**, 1501 회.
결과: 둘 다 1000 회에 몸을 세운 대각 걸음(몸 0.30~0.35 m · 대각 0.89~0.97 · vx 약 1.0, 811 1000 회 0.40 · 0.97). 팀장 판독 「정상 보행처럼 보인다」. 811 보다 늦게 선다(500 → 1000).
지도 효과(1500 회, 팀장 판독과 숫자): 평지 회전 EX-23 wz +0.85 / -0.59 · EX-25 +0.01 / -0.46, 평지 전진 vx 1.02 대 0.91 → **지도 있는 판이 더 잘 걷고 더 잘 돈다**. rough 회전은 엇갈림(EX-23 +0.01 / -1.10 · EX-25 +0.75 / -0.84).

**5. 지금 결론(확인 수준).**
- 포복의 조사 범위는 **물리·제어 조건의 변경 묶음**으로 좁혀졌다. EX-12와 EX-25는 learned·지도 없음·14항·START 명령·연속7종을 공유하지만 마찰·COM·gain·motor·지연·질량 범위와 지각 microbatch가 함께 바뀌었다. 어느 한 항을 원인으로 확정하지 않는다.
- EX-23 · 25 는 **DR 을 약하게 고정하고 일부(무게중심 · 게인 · 세기 · 지연)를 끈 판**이다. START 기조(실기 이전)를 버린 게 아니라, 아직 커리큘럼으로 올리지 않은 상태다.
- 10/23 당시 복원 지도 정책의 본류 실행은 없었다. **10/24 EX-29에서 GT/PRED AdaSmpl 공동학습을 실행했다.** 모듈 실행과 정상 보행·우리 요구 전체의 구현은 별개다. [요구 소비 감사](../20261023-experiments/VERIFY-astra-24f-requirements.md).

## 다음 (팀장과 lead_tmp 가 정할 것)

아래는 10/23의 제안 순서이며 최신 실행 승인이 아니다. 10/24에는 과거 조건·실패 분석과 B1000 비교를 먼저 하고, 열린 명령·연속 지형·성과 기반 진행을 빠뜨리지 않은 다음 설계를 다시 정한다. 이어받기도 비용 때문에 자동 선택하지 않는다.

1. **EX-23 · 25 면밀 분석 마무리**: 위상 · 프레임 · 관절각(v2 와 대조) · 회전 · rough · 명령 반응 평가. astra 검증과 맞춘다.
2. **DR · 지연 커리큘럼 판(본선 G1)**: 걸음이 선 뒤 마찰 · 무게중심 · 게인 · 세기 · 지연을 단계적으로 EX-11(START) 수준까지 올린다. 기준(언제 올리나 · 무엇을 보면 실패인가)은 학습 전에 고정. EX-23 1500 에서 이어 학습으로 시작하면 빠르다.
3. **열린 명령**: 회전 · 좌우 반응을 끝난 판에서 평가하고 약하면 코칭.
4. **G3**: 깊이 + TR-Net 복원 지도로 같은 걸음이 나오는지.
5. 보류: EX-26 · 27(토크 · NVIDIA 보상) 은 근거가 무너져 띄우지 않는다.
