# SOL-20y · S1a-v1.1 처방 기록

lead가 52 §3 처방 갈래로 scan·blind 본 학습 착수를 지시했다고 보고했다. 팀장께 이대로 진행할지 확인 질문을 올렸으며 아직 직접 답을 받지 않았다. 이 문서는 lead 결정의 기록·정합성 반영 의뢰이지 팀장 승인이나 실행 지시가 아니다. GPU·학습·평가·사슬·실행 코드·남의 프로세스는 건드리지 않는다.

최신 본인 작업 위에서 `16-REWARDS.md`, `52-S1-OPEN-COMMAND.md`, `17-GO2-MODEL.md`의 직접 연결 문구를 수정한다. 다른 단계·논문 원문 값을 일괄 덮어쓰지 않는다. 코드와 진단 원자료를 읽어 실제 설정 경로와 단위를 달고, 없는 근거는 미확인으로 남긴다.

## lead가 선택한 처방

- S1-a 정본 + lin·ang 추종 커널 `std=0.25`, `foot_below_ground=0.25`, `clip_actions=17`. 그 밖의 설정은 유지한다는 lead 선택.
- scan(GPU 0)·blind(GPU 1) 각 6000회, seed 42, 약 8 h 예상. 실제 기동 시각·완료·속도는 별도 실행 기록으로 확인하며 계획을 실적으로 쓰지 않는다.
- 1500회: random_rough 멈춤 비율 ≤0.383 AND 6초 전진 중앙값 ≥0.69 m.
- 3000회: 회전 추종 ≥0.264인지 확인. 미달이면 별도 D4 진단을 준비하되 본 학습은 계속한다는 lead 계획. 이것은 최종 S1-a 회전 관문 ≥0.80을 대체하지 않는다.
- 종료 뒤 gates v1.1·200판 평가 → lead 판정 → 통과 시 S1-b를 v1.1-blind에서 잇는 계획. bf16은 처방 뒤로 두며 독자적으로 새 순서를 정하지 않는다.

## 혼동 방지와 근거 대조

1. **std와 분모 구분**: 기존 std 0.5의 제곱은 0.25, 새 std 0.25의 제곱은 0.0625다. 설치 코드가 실제로 std²를 쓰는지 확인하고 식·예시·요지까지 맞춘다. START 논문의 분모 0.25와 우리 처방을 같은 값이라고 쓰지 않는다. 가중치와 std도 구분한다.
2. **종료 문턱**: foot_below_ground 0.2→0.25의 코드 경로·단위·레벨9 오판 근거를 대조한다. 16의 발 가장자리 낙하 마스크 0.2 m는 다른 설정이므로 바꾸지 않는다. 물리 지면·보상·종료를 혼동하지 않는다.
3. **action clip**: 17의 적용 위치, 학습·평가 동일성, action 되먹임과 action_rate에 실제 어떤 값이 들어가는지를 코드로 확인한다. 보상 clip이나 관절 각도·토크 17로 쓰지 않는다. clip값 산정에 사용한 정상 분포 p99.9와 단기 발산 재검사 경로를 출처로 남기며 원자료 없으면 미확인.
4. **판 이름 충돌**: 기존 52는 heading 30→50% 처방도 S1a-v1.1이라고 부른다. 이번 세 변경만의 판과 섞지 말고 과거 조건부 처방 이력과 실제 lead 선택을 구분한다. heading을 몰래 바꾸거나 새 판 이름을 독자 확정하지 않는다.
5. **숫자 분리**: seed42·1500회의 정지 0.766→0.078, 전진 0.19→1.94 m, 회전 0.264→0.039와, 등록 1500을 채우지 못한 seed43 발산 뒤 **1100회 비교**의 정지 기준0.921→seed42·43 각0.203, 전진0.11→2.22·1.42 m를 분리한다. 0.078이 두 시드에서 재현됐다고 쓰지 않는다. 커널 개선 근거는 지지되지만 모든 원인이 확정됐다고 확대하지 않는다.
6. **37% 문구**: 전체 보상인지 특정 항인지 분모·명령·정규화·비교 구간을 확인하기 전 확정 수치로 옮기지 않는다. 세 변경을 한 번에 넣은 본 학습은 각 변경의 단독 효과 실험이 아니다.
