## 4. 멈추는 방법 (제안 · 용어 바꿈)

| 이름 | 하는 일 | 언제 |

## 5. 조이스틱으로 우리 모드 다루기 (제안 · 팀장 01:27 · 02:54 「좋은 내용 기록」)

- 된다: Go2 의 조이스틱 막대 · 버튼 값은 로봇 상태 신호 (LowState) 의 `wireless_remote` 칸으로 Jetson 에 들어온다. 저수준 실행기가 이 칸을 직접 읽으면 Sport 서비스를 해제한 저수준 모드에서도 조이스틱을 쓸 수 있다.
- 순정 핫키 (예: `←` + `start` · `→` + `start` 로 Free Walk · Classic 같은 순정 모드 전환) 는 Sport 서비스가 처리한다. 우리 모드 핫키는 순정 조합과 겹치지 않는 조합으로 고른다 (예: `L1` + 방향키 · 아직 정하지 않음 · 겹침 검사가 먼저).
- 모드마다 막대의 뜻:

| 모드 | 왼쪽 막대 | 오른쪽 막대 | 버튼 |
|---|---|---|---|
| START (기본 명령) | 앞뒤 · 옆 속도 명령 (vx · vy) | 회전 (wz) | 우리 핫키로 모드 들어가기 · 나오기 |
| AME-2 (지형 극복) | 몸 기준 「앞 1 m 목표」 (앱의 `ame2Joystick` 과 같은 해석) | 목표 방향 (±60° 안) | 같음 |
| 어느 모드든 | | | `L2` + `B` = 안전 정지 (Damp) · 실행기가 직접 처리 |

- 같은 입력 해석 (앱 키보드 · 앱 시뮬 · 실기 조이스틱) 을 쓰면 「같은 입력에 시뮬과 실기가 같은 행동」 인지 바로 견줄 수 있다: sim to real 확인 도구이자 발표 시연 장면.
- 모드를 바꿀 때는 3 절 순서 (멈춤 → 정지 측정 → Sport 해제 / 다시 켜기) 를 따른다.
- 정할 것: 핫키 조합 표 · 모드 바뀜을 사람에게 알리는 방법 (앱 화면 · 로봇 LED · 소리).
