## 배운 것

1. 정체를 감추는 컷(다리만)을 텍스트 생성으로 만들면 모델은 사람 다리로 간다. 구도 정밀도도 문장으로 안 잡힌다. 카메라는 Isaac에서 먼저 잡고 편집으로 실사화한다.
2. Seedream 편집은 구도·형태(엣지·접점 돌)는 따르지만 톤(그림자 대비·안개)은 잘 안 따른다. 톤은 후반 DI로.
3. 줌을 당기면 같은 동작도 빨라 보인다. 첫발의 무게는 렌더가 아니라 시간 설계(슬로모 2.5~3배 + 접지 홀드)로 만든다.
