# 엔딩 피치 · 세 판 (그리고 진짜 주인)

> 분류: 조사
> 근거: 실측
> 요지: 지시대로 엔딩 타격음 세 판을 만들었다. 그런데 「피치가 높다」의 주인은 타격음이 아니라 무언 보컬 패드다. 층을 하나씩 꺼서 확인했다. 그래서 보컬을 가르는 세 판을 따로 만들어 같이 낸다.
> 상태: 판단 대기

들을 파일은 `sound/pitch-test/` 에 있다. 엔딩만 잘랐다 (13.0초부터 10.06초).
전체 wav 는 `python scripts/build-sound2.py pitch` 와 `voice` 로 다시 만들어진다.

## 먼저 문제 대역을 확인했다

리드 관측을 내 손으로 다시 냈다. 맞는다.

| 구간 | 500-3000 Hz | 스펙트럼 무게중심 |
|---|---|---|
| 걷기 2.5-13.3초 | 0.1에서 1.8 % | 80 Hz 근처 |
| 엔딩 14.4-23.1초 | 평균 8.24 % | 116.6 Hz |
| 17.2-17.6초 (최대) | **20.4 %** | 281 Hz |

## 그런데 그 대역의 주인은 타격음이 아니다

층 이득을 하나씩 0 으로 두고 다시 만들어 쟀다.

| 끈 층 | 엔딩 500-3k | 17.2-17.6초 |
|---|---|---|
| 없음 (기준) | 8.24 % | 20.38 % |
| 드론 | 13.71 % | 66.25 % |
| 발자국 | 8.45 % | 20.16 % |
| **무언 보컬** | **0.93 %** | **0.06 %** |
| 우쉬 | 8.18 % | 20.42 % |
| 상승 음형 | 8.24 % | 20.38 % |
| **엔딩 타격음** | 13.67 % | **20.39 %** |
| 오프닝 | 8.23 % | 20.38 % |

**보컬을 끄면 20.38 이 0.06 으로 사라진다. 타격음을 꺼도 20.39 로 그대로다.**

드론과 타격음을 껐을 때 값이 **올라가는** 것은 그 층이 저역을 담당하기 때문이다.
분모에서 저역이 빠지니 비중이 오른다. 비중이지 절대량이 아니다.

보컬 패드는 포먼트가 700 / 1200 / 2600 Hz 다. 걷는 동안은 발자국에 덮여 안 들린다.
엔딩에서 발자국이 멎어서 그대로 드러난다. 팀장이 듣는 것이 이것이다.

## 그래도 지시대로 만들었다. 그리고 안 움직인다

| 판 | 무엇 | 엔딩 500-3k | 17.2-17.6초 | 무게중심 |
|---|---|---|---|---|
| `p1` | 타격 기음 45 Hz 계열. 발자국과 같은 몸 | 7.64 % | 20.47 % | 107.8 Hz |
| `p2` | 타격 한 옥타브 위 | 7.81 % | 20.41 % | 110.9 Hz |
| `p3` | 지금 판 | 8.24 % | 20.38 % | 116.6 Hz |

최대 순간이 20.47 · 20.41 · 20.38 이다. **셋이 안 갈린다.**
타격음을 아무리 내려도 문제 대역이 안 움직인다. 위 표가 그 이유다.

`p1` 은 발자국 파형(`K_STRONG`)을 타격 자리에 그대로 얹는다. 새로 만들지 않았다.
「발자국과 같은 몸」이라는 말이 그대로 사실이 되게 하려는 것이다.

## 실제로 움직이는 판

엔딩 구간에서만 보컬 포먼트를 내린다. **걷는 구간은 안 건드린다.**
같은 배음 더미에 색만 두 번 입혀 formation 끝에서 0.5초로 건너간다.

| 판 | 무엇 | 엔딩 500-3k | 17.2-17.6초 | 무게중심 |
|---|---|---|---|---|
| `v1` | 포먼트 0.55배 · 저역통과 2100 Hz | **2.83 %** | **4.39 %** | 100.6 Hz |
| `v2` | 포먼트 0.75배 · 저역통과 2900 Hz | 3.62 % | 5.52 % | 97.2 Hz |
| `v3` | 지금 판 | 8.24 % | 20.38 % | 116.6 Hz |

17.4초 최대가 20.38 에서 4.39 로 내려간다. 이쪽이 팀장이 말한 것을 움직인다.

## 여섯 판이 나머지는 같다는 증거

| 판 | 라우드니스 | 트루피크 | 걷는 구간이 지금 A 판과 |
|---|---|---|---|
| p1 | -16.0 LUFS | -2.5 dBTP | 최대 2.44e-03 차 |
| p2 | -16.0 | -2.5 | **0. 완전히 같다** |
| p3 | -16.0 | -2.5 | **0. 완전히 같다** |
| v1 | -16.0 | -2.5 | 최대 2.44e-03 차 |
| v2 | -16.0 | -2.5 | **0. 완전히 같다** |
| v3 | -16.0 | -2.5 | **0. 완전히 같다** |

`p1` 과 `v1` 의 2.44e-03 은 내용 차이가 아니라 **마스터 게인** 차이다.
엔딩 에너지가 바뀌면 -16 LUFS 로 맞추는 게인이 바뀌고 그것이 전 구간에 실린다.
걷는 구간 비율의 중앙값이 0.992583 (-0.065 dB) 이고 표준편차가 6.24e-03 이다.

`p3` 와 `v3` 는 지금 A 판과 **비트 단위로 같다.** 「지금 판」이 진짜 무변경이라는 증거다.

## 고친 것 하나. 시드가 한 프로세스에서 이어지고 있었다

`rng` 를 모듈 수준에서 한 번만 잡고 있었다. 그래서 한 프로세스에서 `main` 을
두 번 부르면 두 번째가 첫 번째가 쓰고 남긴 자리에서 이어 갔다.

- `build-sound2.py both` 로 낸 A 와 `build-sound2.py a` 로 낸 A 가 **달랐다**
- 음정 세 판도 잡음까지 달라져서 「높이만 다르다」가 성립하지 않았다

`main` 첫머리에서 시드를 다시 잡게 고쳤다. 고치고 나서 `p3` 가 지금 A 판과
비트 단위로 같아졌다. 그것이 고쳐졌다는 증거다.
`a` 를 단독으로 낼 때의 결과는 안 바뀐다. 원래 0번 자리에서 시작했기 때문이다.
