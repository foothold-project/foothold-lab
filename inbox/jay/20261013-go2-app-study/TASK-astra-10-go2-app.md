# ASTRA 의뢰 10 · Unitree Go2 앱 리버스 엔지니어링

**답하는 자세 (팀장 10/13 00:30 지시):** 이 분야를 평생 탐구한 최고 수준의 전문가로서 비판적이고 냉정하며 현실적으로 조사 · 판단한다. 무난한 결론으로 닫지 말고, 모르면 모른다고, 못 찾았으면 무엇을 해 봤는지 적는다. 「이 정도면 됐다」 로 멈추지 말고 끝까지 판다.

## 할 일

1. **앱 확보.** Unitree Go2 용 공식 앱 (Google Play 의 「Unitree Go」 등, 또는 Unitree 공식 사이트 배포본) 을 내려받는다. 받은 곳 · 판 번호 · 파일 sha256 을 보고서 맨 앞에 적는다. Play 스토어에서 PC 로 바로 받기 어려우면 같은 판을 얻는 방법을 찾아 쓰고, 어디서 받았는지 적는다. 여러 판이 있으면 최신판 하나를 주로 보고 필요하면 이전 판과 견준다.
2. **rea 설치와 분석.** `github.com/morluto/rea` 를 README 대로 설치해 (`npx rea-agents setup` 등) 앱을 분석한다. 앱이 무엇으로 만들어졌는지 (Flutter · React Native · Unity · 네이티브 · WebView · WASM) 부터 확인하고, 그에 맞는 rea 경로와 디컴파일 도구 (Ghidra 등) 를 쓴다. 무료로 안 되는 도구가 꼭 필요하면 그때 lead 에게 알린다 (구매는 팀장 몫).
3. **파악할 기술 (끝까지).**
   - 로봇에서 앱으로 오는 지도 자료: 형식 · 압축 · 디코더 · 좌표계 · 갱신 주기 · 누적 방식.
   - 정제: 잡음 제거 · voxel 화 · 다운샘플 · 평활 · 높이 색 · 바닥 / 장애물 구분 · 지도 누적과 갱신 · 오래된 점 지우기 · 보간. 어느 단계가 로봇에서 오고 어느 단계가 앱에서 일어나는지.
   - 그리기: 3D 엔진 · 셰이더 · mesh 생성 · LOD · 카메라 조작 · 로봇 모델과 자세 표시 · 경로 · 목표점 · 카메라 영상 겹치기.
   - 임무 · 조작 UI 가 로봇 명령으로 바뀌는 길 (우리 app 이 나중에 SDK 로 실기를 조작할 때 참고).
   - 이미 공개된 분석 (예: `legion1581/unitree_webrtc_connect` · `abizovnuralem/go2_ros2_sdk` · `VectorRobotics/unitree_webrtc_connect` · `phospho-app/go2_webrtc_connect`) 과 대조해 같은 것 · 새로 찾은 것을 나눈다. 이 저장소들이 참조한 다른 저장소 · 글도 따라가 본다.
4. **우리 app 에 옮기기.** 찾은 기법마다 「무엇을 · 왜 깔끔해 보이나 · 우리 dashboard · app (웹) 에서 어떻게 구현하나 (라이브러리 후보 · 의사 코드)」 를 적는다. foothold-app 기획 (오현민 「FOOTHOLD 관제 UI」 · https://claude.ai/artifact/9q2JtTgeitsnhFTGHTVPgw) 의 지도 · 관제 화면과 연결한다.
