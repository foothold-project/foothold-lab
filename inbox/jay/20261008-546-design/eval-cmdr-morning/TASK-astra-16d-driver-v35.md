## 바꾼 것 (`code/cmdr_eval_driver_v35.py` 머리 (h)~(m))

### (h) 읽기 실패와 마감

반복마다 마감을 먼저 본다. base 기록을 못 읽으면 실패 이유와 마지막 정상 스냅숏 (시각 · 해시) 을 남기고 다시 시도한다. 마감이 오면 `stopped=deadline` · `complete=False` 로 끝 기록을 남긴다.

### (i) 작성자 식별

- 다른 프로세스의 argv 를 argparse 처럼 읽는다 (`--log X`, `--log=X`, 접두어). 로그 경로는 정규화한 절대 경로로 비교한다 (대소문자 · `./`).
- 읽지 못하는 argv 는 작성자로 친다.
- v3.5 자기 인스턴스는 `out/<log>.lock` OS 잠금을 일생 동안 잡는다. remeasure 는 base 잠금이 잡혀 있으면 작성자가 있다고 본다.
- 이 스크립트는 약어 옵션을 받지 않는다.

### (j) 선별 상태

- 선별 상태는 반복마다 현재 스냅숏으로 다시 만든다.
- 전에 있다가 사라진 칸은 `withdrawn` (시각 · base attempt · 스냅숏 해시) 에 남기고 미측정으로 센다.
- 더는 걸리지 않는 칸의 대기 작업은 큐에서 빼고 `dequeued` 에 남긴다 (이미 돈 실행은 그대로 둔다).
- **끝내는 조건:** 같은 바이트의 스냅숏을 두 번 연속 읽고, base 작성자 (프로세스 · 잠금) 가 없고, 그 스냅숏을 선별 · 큐 처리한 뒤일 때만 끝난다.

### (k) 공통 종료 기록

모든 출구 (마감 · pins · checkpoint · 시험 실패 · 거부 · 예외) 가 끝 기록 하나를 지난다. 기록 항목은 stopped · exit_code · not_run · not_valid 다. base 재검사 중이면 옛 표를 지키려고 `out/<log>.stopped.json` 에 따로 쓴다.

### (l) stamp 와 guard 재시도

- stamp 교체가 Windows 공유 위반이면 다시 시도한다.
- guard 재시도마다 앞 시도의 로그 · 요약을 `out/attempts/` 로 옮긴다. 실행 기록에 시도마다 k · rc · 초 · 옮긴 파일을 남긴다.

### (m) GPU 0 인계

다음을 모두 본다.
- `result.json` 내용: tag · cmdr on · `final_state.where=end` · `label_next=24000`
- night 로그에서 on 갈래 `EXIT 0` **뒤에** `NIGHT DONE`
- checkpoint 크기
- 메모리 < 3000 MiB (3000 은 거부)
