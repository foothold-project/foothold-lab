## 바꾼 것

### 집계 `code/cmdr_post_v6.py`

**2.1 MAE 결측.** 축마다 양 갈래 · 시드마다 유한 값이 100 개여야 판정한다. 하나라도 모자라면 「결측」 으로 두고 (군 · 시드 · 유한 n 목록을 남김) 전체는 「미확인」 이다. 남은 판으로 판정하지 않는다.

**2.2 인증.**
- **로그:** 다섯 pin 파일이 다 있어야 한다. v3.3+ 이거나 experiment 가 있으면 `cmdr_s1042_pair_eval` 이어야 한다.
- **실행마다:** stamp 를 읽을 수 있어야 하고, pins 가 자기 로그와 같아야 하며, ckpt_sha256 이 자기 로그의 그 모델 checkpoint 와 같아야 한다.
- **stamp_version 이 있으면:** 네 출력 해시가 다 있고 맞아야 한다. 없으면 v3.2 구형으로 세어 `legacy_stamps` 에 남긴다.
- **그 밖은:** `auth_fail` (이유와 함께) 로 빼고 쓰지 않는다. 실데이터 316 실행은 모두 구형 stamp 로 통과했고 탈락은 0 이다.

**2.5 MAE 경계.** 정확히 10 % 는 허용한다. `y − 1.1x > 1e-9·x` 일 때만 초과다. 0.30 → 0.33 은 허용이고 0.3301 은 초과다. 대조가 0 일 때의 절대 한도도 같은 방식이다.

**4.3 목표 표시.** 세 목표를 비교가 없어도 항상 0 쌍으로 남긴다.

**이름.** 「퇴행 방지 조건 충족 (통과율 · MAE)」 · 「퇴행 방지 조건 미충족」 · 「미확인」. `schema = "cmdr_post v6"`.

**Markdown.** 다시 잰 열에 n · 시드를 붙이고, 기본 계약은 잰 칸 전부를 k/n · Wilson 으로 적는다.
