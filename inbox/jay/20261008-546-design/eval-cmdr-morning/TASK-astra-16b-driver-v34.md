## 바꾼 것 (`code/cmdr_eval_driver_v34.py` 머리 (a)~(g))

1. **remeasure 의 선별과 끝을 한 스냅숏에서 정한다.** base 기록을 한 번 읽고, 그 스냅숏으로 선별과 「최종인가」 를 함께 정한다. 「최종」 은 다음을 모두 만족할 때다.
   - version 3.4 · 같은 experiment
   - ended 또는 stopped
   - base 작성자 프로세스가 없음

   마지막 스냅숏에서 새로 걸린 칸은 줄에 들어가고, 그 줄이 빌 때까지 끝나지 않는다.
2. **기록 경로와 작성자 관문.**
   - `--plan remeasure` 에서 `--log` 와 `--base_log` 의 정규화 경로가 같으면 종료 6.
   - 같은 기록을 쓰는 다른 `cmdr_eval_driver*.py` 가 살아 있으면 종료 6. v3.2 는 `--log` 가 없어 `cmdr_eval_driver` 로 친다.
3. **남은 실행 대기.** 시작할 때, 이 계획의 태그를 가진 `q_eval_cmdr.py` (또는 그 guard) 가 살아 있으면 기다린다.
4. **GPU 0 인계.** 아래가 모두 참인 것을 60 초 간격 두 번 연속으로 본 뒤에만 쓴다. 한 번이라도 거짓이면 처음부터 다시 센다.
   - on 갈래 `result.json`
   - `model_24000.pt`
   - night 로그의 `NIGHT DONE`
   - `branch_run.py` 없음
   - GPU 0 사용 메모리 < 3000 MiB
5. **기록 · stamp.**
   - base 는 재검사 한 바퀴가 끝날 때까지 기존 기록을 디스크에 그대로 둔다. 끝나면 전체 표를 한 번에 쓴다.
   - stamp 는 tmp + replace 로 쓴다. 끊기거나 깨진 stamp 는 「재사용 불가」 로 보고 다시 돈다.
   - stamp_version 이 있는 stamp 는 해시가 있어야 한다.
6. **시도 ID · 시험 폴더.** 실행마다 시도 ID (`드라이버시도-j번호`) 를 붙인다. 시험 폴더 이름은 초 + pid 까지 쓴다.
7. **끝 기록.**
   - `complete` 는 모든 계획 실행이 valid (base) 일 때만 참이다. remeasure 는 96 선별 칸이 모두 재지고, 걸린 칸의 1001~1004 양 갈래가 모두 valid 일 때만 참이다.
   - 아니면 `not_run` · `not_valid` · `screen_unmeasured` · `remeasure_missing` 에 이유를 남긴다.
   - 시작 시험 실패는 stopped 로 남긴다.
   - 드라이버 자기 sha256 도 기록한다.
8. **시험 가능 구조.** 주 반복문을 함수 (`start` · `main_base` · `main_remeasure`) 로 뺐다. 시험은 이 실제 함수들을 부작용만 대체해 돈다.
