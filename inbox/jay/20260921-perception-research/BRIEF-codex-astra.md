## 0. 왜 이 조사를 하나

FOOTHOLD 는 Unitree Go2 사족보행 RL 정책이다. 지금까지 **명령(command) 과
학습 지형 배치**만 바꿔 왔고 **신경망과 관측 구조는 한 글자도 안 건드렸다.**
그 결과 두 축을 동시에 넘는 정책이 아직 없다.

우리 신경망 실측(2026-09-21 · `nvidia_pretrained.pt` 텐서와 `params/*.yaml` 원문):

```
ActorCritic (rsl_rl)
  actor   235 -> 512 -> 256 -> 128 -> 12   ELU   286,604 파라미터
  critic  235 -> 512 -> 256 -> 128 ->  1   ELU   285,185
  std     12 (상태를 안 봄)
  합계 571,801

관측 235 = base_lin_vel 3 + base_ang_vel 3 + projected_gravity 3
         + velocity_commands 3 + joint_pos 12 + joint_vel 12 + actions 12
         + height_scan 187                        <- 79.6 %

height_scan  격자 17 x 11 · resolution 0.1 m
             몸통기준 x [-0.8,+0.8] · y [-0.5,+0.5] · ray_alignment "yaw"
             값 = 몸통높이 - 광선높이 - 0.5, clip [-1,1] (미터)
             균일 노이즈 +-0.1 m · 50 Hz · 빗나간 광선은 +1.0

없는 것   history_length = None (기억 없음) · RNN/CNN/어텐션 없음
          관측 그룹이 policy 하나뿐 (critic 특권관측 없음 · 교사-학생 없음)
          187 을 일렬로 펴서 MLP 에 붓는다 (격자 구조를 안 씀)
```

우리가 **못 넘는 지형의 특징 크기**가 격자 간격 0.1 m 와 노이즈 +-0.1 m 에
걸쳐 있다.

| 지형 | 특징 크기 | 광선 몇 개 | 우리 성적 |
|---|---|---|---|
| `rails` 두께 0.08~0.18 m · 높이 0.05~0.18 m | 0.08 m | **0~2** | 정책별 1~100 (요동) |
| `stepping_stones` 돌간격 0.08~0.20 m | 0.08 m | **0~2** | **일곱 정책 전부 0 %** |
| `gap` 폭 0.15~0.40 m | 0.15 m | 1~4 | 21~98 (요동) |
| `pyramid_stairs` | 넓음 | 여럿 | 전 정책 양호 |

## 2. 각 논문마다 반드시 채울 칸

표로 답하라. **추측 칸은 비우고 「논문에 없음」이라고 쓴다.**

| 칸 | 무엇을 적나 |
|---|---|
| 정식 제목 · 저자 · 소속 · 연도 · arXiv 번호 | |
| 한 문장 요지 | |
| **관측 구조** | 입력 차원 · 지각 입력이 무엇인가(height map / depth / lidar / 촉각) · 해상도와 물리 크기 · 갱신률 |
| **신경망 구조** | 인코더 종류(CNN/트랜스포머/MLP) · 은닉 크기 · 파라미터 수 · 순환/기억 유무와 길이 |
| **학습 방식** | 단일 PPO 인가 · 교사-학생(privileged distillation) 인가 · 몇 단계인가 · 특권 관측이 무엇인가 |
| **잠재 표현** | 지형을 압축한 잠재 벡터가 있나 · 차원 · 어떻게 학습되나 |
| **기억** | 히스토리 스택 길이 · RNN/GRU/LSTM · 상태 추정기 유무 |

| **보고된 정량 이득** | 무엇 대비 몇 %p 인가. 기준선이 무엇인지 반드시 명시 |
| **코드 공개 여부** | 저장소 URL · 라이선스 · IsaacLab/legged_gym 기반인가 |
| **계산 비용** | 학습 GPU 수 · 시간 · env 수 · iter 수 |

## 3. 그다음 · 우리에게 붙일 수 있는가

각 논문의 기법마다 아래 넷을 판정한다.

```
(가) 우리 235 / 571,801 / rsl_rl ActorCritic 구조에 얹을 때
     «관측만» 바꾸면 되나, «망 구조»를 바꿔야 하나, «학습 절차»까지 바꿔야 하나
(나) NVIDIA-Go2 rough 사전학습 가중치를 이어받을 수 있나, 처음부터 다시인가
     (235 입력 차원이 바뀌면 첫 층을 못 이어받는다)
(다) 우리 GPU 둘 · 한 판 95~190 분 예산에 들어오나
(라) 우리가 못 넘는 8~20 cm 짜리 특징을 «실제로» 건드리는 기법인가,
     아니면 다른 문제를 푸는 기법인가
```

**(라) 에서 「관계없음」이 나오면 그렇게 쓴다.** 좋아 보인다고 끌어오지 말 것.

## 4. 주변 조사 (셋 말고)

우리 실패 양상에 직접 닿는 최신(2024~2026) 연구를 **추가로 5건 이내** 찾는다.

- 높이맵 해상도와 지형 특징 크기의 관계를 정량화한 것
- 관측 노이즈가 미세 지형 학습을 막는 것을 다룬 것
- 기억 없는 MLP 정책 대 히스토리/순환 정책의 사족보행 비교
- `stepping_stones` / 얇은 구조물(rails, 철망, 파이프)을 푼 것
- 사전학습 가중치를 유지하며 관측 차원을 늘리는 기법 (첫 층 확장 · 어댑터)
