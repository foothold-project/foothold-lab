# LUNA24e B1000 중간 영상 독립 판독

## 판독 범위와 프레임

- `comparison_1x.mp4`는 1280×720, 25 fps, 300프레임이며 표시 구간은 0.00~11.96초다. 영상의 2×2 배열은 위가 flat, 아래가 rough이며 각 행에서 왼쪽 EX23, 오른쪽 B다.
- `comparison_05x.mp4`는 1280×720, 25 fps, 600프레임, 24초다. manifest의 설명대로 각 원본 프레임을 반복해 재생한 영상이며 마지막 프레임이 끝에 유지된다. 새 동작을 보간한 영상은 아니다.
- 두 영상의 전체 내용은 1배에서 0.5초 간격으로 0.00~11.50초까지 비교했다. 회전 구간은 1배 영상을 6.00초부터 11.50초까지 0.50초 간격으로 다시 확인했다. 같은 원본 6.00~11.50초 구간은 0.5배 영상의 12.00~23.00초를 1초 간격으로 확인했다. 표본만으로 전체 프레임의 모든 순간을 확인했다고 보지는 않는다.
- 네 `review.json`의 `step_contract`는 각 원 run에서 제어 샘플 600개와 영상 프레임 300개를 기록한다. NPZ의 `dt=0.02초`는 제어 tick 간격이다. 적용 설정은 physics `sim.dt=0.005초`, `decimation=4`이므로 물리 한 스텝은 0.005초이고 한 제어 tick은 물리 네 스텝, 0.02초다. 영상 샘플 step은 제어 tick 기준 0, 2, …, 298 다음 301, 303, …, 599다. 대부분 2 제어 tick 간격인 0.04초이며 5.96초에서 6.02초 사이에는 3 tick, 0.06초 간격이다.
- `ex-23_flat_overview.jpg`, `b_flat_overview.jpg`, `ex-23_rough_overview.jpg`, `b_rough_overview.jpg`는 각각 0, 1, 3, 4, 6, 7, 9, 11초 프레임을 보여 준다. 네 `*_stride.jpg`는 전진 1.0 구간의 4.00~4.88초를 0.08초 간격으로 보여 준다. `gait_height_commands.png`는 발 접촉, 명령과 실제 속도, 접촉 발 중심 기준 높이를 나란히 나타낸다.

## 영상에서 보이는 동작

- **EX23 flat 마지막 프레임:** 1배 MP4의 마지막 frame 299에서 로봇이 옆으로 누운 상태가 보인다. NPZ `roll`의 11.00~11.98초 구간 최대 절댓값은 76.596°이며 마지막 샘플 `t=11.98초`, index 599에서 기록됐다. `review.json`은 reset 0회, NPZ `done`은 0이다. 따라서 이전 판독의 끝부분 요약을 정정한다. 이 flat 에피소드는 기록상 중단이나 reset 없이 끝까지 갔지만 마지막 프레임에서 옆으로 무너진 자세를 보인다.
- **B rough 접촉 집계 정정:** `t >= 10.00초` 및 `t < 12.00초`인 NPZ 100개 샘플의 접촉 수 분포는 0, 0, 0, 0, 100이다. 네 발 모두 접촉한 샘플은 100/100이다. `matched_metrics.json`의 같은 run 마지막 구간 `four_contact_fraction=1.0`도 일치한다. 기존 표의 98은 분모나 구간 차이가 아니라 제 접촉 집계 오기이며 100으로 고쳤다.
- **rough 타일 경계:** 적용 설정의 지형 생성 크기는 단일 타일 8×8m, 월드 기준 x 범위는 -4~+4m다. NPZ `root_pos_w.x`는 x=+4m를 EX23 flat 5.64초, B flat 5.54초, EX23 rough 5.68초, B rough 5.68초에 처음 넘는다. 모든 run에서 6~12초 x는 +4m보다 크다. 마지막 EX23 flat 프레임에도 코드 유래 HUD가 발이 타일 XY 경계 밖이라고 표시한다. 따라서 6초 이후 rough 회전 구간은 해당 단일 rough 타일 안의 동작으로 일반화할 수 없다.

- **몸 높이:** 전진 명령이 0.5에서 1.0 m/s로 바뀐 뒤 네 경우 모두 높이 중앙값이 0.006~0.016 m 증가했다. 이 수치는 접촉 발 중심 기준이다. 회전 중 지속적으로 더 높아지지는 않았고, 10~12초 창의 중앙값은 0.291~0.312 m로 7~9초보다 낮았다. 회전 때 자세를 낮추거나 접는 모습은 영상에서도 보이지만, 단일 에피소드의 접촉 지형과 동작을 분리하지 않은 수치이므로 원인 설명으로 확장하지 않는다.
- **전진 위상:** 4.00~4.88초의 0.08초 간격 표본에서 네 경우 모두 대각선 발 조합이 번갈아 지지하는 움직임이 보인다. NPZ에서도 4~6초 두 발만 접촉한 샘플 중 대각선 조합은 62~75개였고, 앞발 두 개 또는 뒷발 두 개가 함께 접촉한 샘플은 0~3개였다. 앞뒤 쌍 도약의 반복 증거는 확인되지 않았다.
- **회전 위상:** 6초 이후 왼쪽 회전과 9초 이후 오른쪽 회전 때 몸 방향이 변하는 것은 영상에서 확인된다. 다만 각 구간의 실제 평균 yaw 속도는 목표 ±1.2 rad/s보다 작다. 화면 시각도 6~8초 사이에서 처음에는 목표 방향으로 빠르게 움직인 뒤 속도가 줄거나 흔들리고, 9~10초 무렵 오른쪽 회전에서도 초반 반응 뒤 속도가 낮아진다. 회전 중에는 7~9초 표본 100개 중 98~100개에서 3개 또는 4개 발 접촉이 있었고, 앞뒤 두 발만 함께 접촉하는 규칙적인 패턴은 보이지 않았다.
- **도약 여부:** 20ms NPZ 샘플에서 발 접촉 0개 상태는 1~3초와 4~6초의 각 100개 샘플에서 네 사례 모두 0개였다. 시각 표본과 접촉 위상에서 주기적인 앞뒤 쌍 도약이나 반복적인 전발 공중기를 확인하지 못했다. 짧은 사건이 샘플 사이에 있었는지는 이 표본만으로 판단하지 않는다.

## 범위와 한계

이 자료는 flat/rough 각각 정책당 한 번 수행한 순차 명령 에피소드다. 독립 반복이나 성공률 자료가 아니며, 평균 동작의 시각 판독과 네 NPZ의 기록값 대조다. 영상과 NPZ는 정해진 시각 간격으로 샘플링해 확인했다. 재료 마찰이 원인이라는 결론, EX29를 재개할지에 대한 판단은 하지 않는다. root가 진행 중인 추가 학습과 별개인 기록이다.
