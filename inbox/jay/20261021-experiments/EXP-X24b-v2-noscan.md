# EX-24b · v2 actor 높이 스캔 제거

## 가설과 결과 전 등록

> [선행] “EX-24 = v2 작업에서 actor 높이 스캔만 뺀 대조.” [LEAD-HANDOFF-20261022.md §21](../20261019-design/LEAD-HANDOFF-20261022.md#21-지금-단계-2137-ex-2122-결과와-ex-2324)

EX-24a와 같은 v2 scratch에서 actor 높이 스캔 입력만 제거하면 초기 걸음 형성이 달라지는지 비교한다. START 정책으로 바꾸는 실험은 아니다.

## 설정

| 항목 | 기록 |
|---|---|
| 부모 설정 | `[lead 기록]` EX-24a v2 scratch 설정. 이는 설정 파생이며 checkpoint 계승을 뜻하지 않는다. resume 상태 미확인이다. |
| 변경 | `[선행·handoff §21]` actor 높이 스캔 입력 제거. 예상 입력 차원은 스캔 칸 수만큼 감소하고 `env.yaml` 차이는 한 군데인지 확인하도록 등록됐다. 실제 차원 대조 미확인이다. |
| 평가 | `[선행·handoff §21]` v2 전용 `record_seq --policy v2 --checkpoint <model_N.pt>`. |
| 실행 | `[lead 기록·handoff §22]` EX-24a 뒤 GPU 1에서 301 update 계획·종료. 완료 시각과 소비 cfg를 직접 재확인하지 않았다. |

## 판정 · 결과 전 등록

EX-24a와 같은 update·시드·명령·촬영 도구를 비교하고 실제 입력 차원 및 `env.yaml` 차이가 의도한 한 묶음인지 확인한다. 낮은 자세만으로 100~300회 실패 판정을 내리지 않는다. v2 scratch는 START 본류가 아니다.

## 결과

`[lead 기록·handoff §22]` 301 update 종료로 적혀 있다. 비교 영상·위상·숫자 판독은 제공된 기록에서 확인되지 않아 미측정이다. 영상 없음 · 미확인.

## 다음

실제 설정 diff와 입력 차원, 같은 회차 결과를 EX-24a와 연결한다. 이 짧은 대조를 START 구조의 성능 또는 지도 필요성의 최종 결론으로 확대하지 않는다.
