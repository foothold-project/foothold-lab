# EX-16 · NVIDIA Go2 rough 보상 교체

## 가설과 결과 전 등록

> [선행] “NVIDIA Go2 보상 세트를 통째로 교체해.” 보상 교체 뒤 trot이 나타나도 NVIDIA Go2 기저 전체를 따랐다는 뜻으로 확대하지 않는다. [lead 채팅 기록 · 2026-10-22]

EX-11의 환경을 고정하고 보상 항만 NVIDIA Go2 rough 구성으로 바꾸면 걸음 위상이 달라지는지 판별한다. 이는 보상 원인 확인용이며 로봇 모델·관측·명령·PD·지형·커리큘럼·정책 기저를 NVIDIA Go2로 바꾸는 실험이 아니다.

## 설정

| 항목 | 기록 |
|---|---|
| 설정 계보 | `[코드] 13d77863`의 `FootholdS2X16nEnvCfg`는 EX-11 환경 설정을 상속하고 `self.rewards`만 교체한다. 이는 설정 계보이며 체크포인트 계승 근거가 아니다. 체크포인트 사용 여부는 미확인이다. |
| 추종 보상 | `[코드] track_lin_vel 1.5, std 0.5`; `[코드] track_ang_vel 0.75, std 0.5`. |
| 벌점 | `[코드] lin_vel_z -2.0`; `[코드] ang_vel_xy -0.05`; `[코드] joint_torques -2e-4`; `[코드] joint_acc -2.5e-7`; `[코드] action_rate -0.01`. |
| 발 공중 시간 | `[코드] feet_air_time +0.01`, threshold `[코드] 0.5`, `.*_foot` contact sensor. |
| 0 가중치·비활성 항 | `[코드] flat_orientation 0.0`, `[코드] dof_pos_limits 0.0`; `undesired_contacts`는 설치 Go2 rough 설정에서 꺼짐. START 고유 보상 항과 `only_positive_rewards`는 포함되지 않는다. |
| 학습 설정 | `[코드] 3072 env`, seed `[코드] 42`, `max_iterations=501`, 저장 주기 `[코드] 100`, 실험 폴더 `foothold_s2_x16n`, run 이름 `ex16-nvgo2`. 코드에는 `[선행] 300회`와 `[선행] 500회` 위상 점검 지점이 적혀 있다. |
| 실행 상태 | 코드 준비 커밋은 `[코드] 13d77863`. 이 카드 작성 중 GPU·Kit을 실행하지 않았다. 실제 EX-16 학습 시작 기록은 미확인이다. |

## 판정 · 결과 전 등록

`[선행] 300회`와 `[선행] 500회`에서 다리가 몸 아래로 펴지는지, 네 발이 번갈아 움직이는지 보행 영상을 통해 판정한다. 명령 조건은 EX-11과 같은 표로 기록하고, 회전은 자세와 분리한다. 새 숫자 합격선을 만들지 않는다. 짧은 판정은 1500회 본 학습 결과나 NVIDIA 기저 전체의 우위를 뜻하지 않는다.

## 결과

최종 수치, 영상, 보행 판정은 `[미측정]`이다. 이 문서 작업은 실행이 아니며 EX-16 GPU·Kit 예행도 하지 않았다. 영상 없음 · 미확인.

lead의 실행 재개 지시와 결과 문서가 생기면 300·500 위상 판독과 사용한 환경·보상 설정을 연결한다. 결과를 EX-11 환경 위의 보상 교체 효과로만 해석하고 NVIDIA Go2 기저 정책으로의 전환이라고 부르지 않는다.
