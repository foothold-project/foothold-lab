# EX-10 diag-G0-start · START 명령 진단

## 가설과 결과 전 등록

같은 지도 없는 START 구조를 START 원문 명령으로 학습하면 정상 보행 자세를 얻는가. [diag-G0-open](EXP-G0-open.md)과 비교해 다음 명령 코칭 방향을 고른다. START 전체 재현이나 모든 명령에 대한 일반화 검증으로 부르지 않는다.

결정 댓글은 2026-10-21 16:11:07 KST에 게시됐다(본문은 「15시대 결정」). 결정 내용은 `확인됨`이며 실제 실행은 미확인이다. S1-a 실패에서 본류 S2-G0로 연결하는 진단 지류다.

## 다음 · 판정과 코칭

lead가 2행2열 영상을 보고 위 세 질문을 기록한다. 몸 높이·발 높이·요·멈춤·전진은 기록용이다. 몸 크기 비율·3 cm·10° 합격선은 폐기하고 기존 41·52·gates v1.1 관문은 유지한다. 영상 장면·길이는 결정 원문에 미기재이므로 촬영 조건을 실행 기록에 남긴다.

- 둘 다 정상 보행: S2-G0 본선, S1 단계를 S2로 합치는 설계 수정.
- START 명령 판만 정상: 결정 원문의 해석은 「열린 명령이 자세를 망침」. START 명령부터 범위를 넓히는 커리큘럼으로 설계 14 수정. 한 시드의 짧은 결과를 일반적인 인과 결론으로 확대하지 않음.
- 둘 다 기어감: Go2 이식의 보상 크기·PD 점검 후 다음 판을 기록.
- 열린 명령 판만 정상·미완료·영상 판단 불명확: 다음 처방 미등록. 결과를 보존하고 lead에게 보고, 위 세 갈래로 자동 분류하지 않음.

다른 시드 검증은 전체 과정 뒤 같은 과정으로 한 번에 한다. 이번 seed42 결과를 여러 시드 재현으로 쓰지 않는다. 본류 복귀와 문서 연결은 [실험 지도](EXP-MAP.md) · [결정 반영표](../20261019-design/DECISION-SYNC.md) · [일정](../20261019-design/SCHEDULE-NOW.md)에 기록한다.
