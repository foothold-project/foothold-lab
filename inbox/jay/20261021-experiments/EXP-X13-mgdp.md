# EX-13 · MGDP 보상 묶음

## 가설과 결과 전 등록

> [선행] “발 공중 시간 +1.0, 토크 벌점은 그대로, 걸음 모양·정지 벌점은 MGDP를 따르고, 음수 보상 0 자르기도 MGDP를 따른다.” [#555 사전 등록](https://github.com/foothold-project/foothold-lab/issues/555#issuecomment-6332758762)

EX-11의 S2-G0 구성에서 위 보상 묶음이 자세와 걸음 모양을 바꾸는지 보려는 판이다. 단일 항의 효과를 분리하는 설계는 아니다.

## 설정

| 항목 | 기록 |
|---|---|
| 환경 설정 계보 | `[코드] cce2de44`에서 EX-13 설정은 EX-14를, EX-14는 EX-11 설정을 상속한다. 이는 설정 계보이며 체크포인트에서 이어 학습했다는 근거가 아니다. 체크포인트 계승은 미확인이다. |
| MGDP 보상 네 항 | `[코드] feet_air_time +1.0`, `motion_trot -0.1`, `stand_still -0.1`, `only_positive_rewards` 합산 보상 하한 0. |
| 항 정의 | `motion_trot`은 기본 관절각을 뺀 대각 관절 차이며 지형 단계가 `[코드] 3`을 넘거나 전체 step이 `[코드] 20,000`을 넘으면 꺼진다. `stand_still`은 수평 명령 크기 `[코드] 0.1` 미만과 회전 명령 절댓값 `[코드] 0.1` 미만을 함께 요구한다. 발 공중 시간은 수평 명령 크기가 `[코드] 0.1`을 넘을 때만 적용한다. |
| 기준 항 | 토크 벌점은 START 설정 `[코드] -1e-5`를 유지한다. lead 대조에 따르면 이 묶음은 legged_gym의 Unitree 기저 항을 완성해서 옮긴 것이 아니다. |
| 실행 상태 | `[실측·lead 기록]` 팀장 결정으로 `[실측·lead 기록] 14:19`에 약 `[실측·lead 기록] 230 update`에서 중단. PID·실행 폴더·소비 설정 전체는 이 카드에서 미확인이다. |

## 판정 · 결과 전 등록

새 숫자 합격선을 두지 않는다. 자세는 발 기준 몸 높이와 발 들림을 같은 도구로 기록하고 영상과 나란히 본다. 걸음은 다리가 몸 아래로 펴지는지, 네 발이 번갈아 움직이는지 영상으로 본다. 명령 표는 EX-11과 같은 조건으로 두며 회전은 자세와 따로 적는다. 등록 근거는 [#555 6332758762](https://github.com/foothold-project/foothold-lab/issues/555#issuecomment-6332758762)다.

## 결과

최종 수치와 판정은 `미측정`으로 둔다. lead의 종합 결과 문서를 기다린다. 중단된 묶음은 원인 결론에 쓰지 않는다. 영상 없음 · 미확인.

## 다음

EX-13은 판정에서 제외된 중단 기록으로 보존한다. EX-14의 단일 항, EX-15의 A1 보상 묶음, EX-16의 NVIDIA Go2 보상 교체와 결과를 섞지 않는다. 새 GPU 실행은 하지 않는다.
