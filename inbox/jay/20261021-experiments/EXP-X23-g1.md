# EX-23 · START G1 정답 지도

## 가설과 결과 전 등록

> [선행] “EX-23: START 구조 G1(정답 지도) · DR 약하게 · 지연 없음.” [#555 6342453922](https://github.com/foothold-project/foothold-lab/issues/555#issuecomment-6342453922)

START의 지각·순환 정책 구조를 먼저 세운 G1 본류에서 정답 높이 지도를 actor에 넣으면 처음부터 학습할 때 보행이 어떻게 형성되는지 본다. NVIDIA v2의 학습 checkpoint에서 이어가는 판이 아니다.

## 설정

| 항목 | 기록 |
|---|---|
| 흐름 | `[lead 결정·handoff §21·25]` EX-23은 EX-25와 함께 START 구조 본류다. |
| 구조 | `[lead 기록]` 지각 모듈 · GRU · 추정기 · AdaSmpl 및 정답 높이 지도 입력, `force_gt` 사용. actor 지도 칸에 실제 지형값이 들어가는지 확인 항목이다. |
| 보상·환경 | `[lead 기록]` START 보상, S1 지형, START 명령. 관절 한계 벌점 미사용. |
| DR·지연 | `[lead 기록]` 약한 DR은 EX-19의 다섯 설정, 행동 지연 끔. 소비 cfg 일치는 미확인이다. |
| 학습 | `[코드·lead 기록]` microbatch 64, 목표 1501 update, GPU 0 배정. handoff에는 22:35 시점 107/1501 진행 보고가 있다. 23시 현재 update는 미확인이다. |
| 시작점 | `[lead 기록]` 처음부터 학습 계획. 설정 계보와 checkpoint 계승은 구분한다. 학습 checkpoint를 이어받은 근거는 없다. |

## 판정 · 결과 전 등록

`[선행·handoff §21·23·25]` 100회는 종료·episode 길이·처음 자세 신호, 300회는 위상·자세를 확인한다. `[가설]` 300회 경고는 낮은 자세 단독 중단선이 아니다. 811은 `[실측·BASELINE-0811]` 100·300회 몸 높이 0.19 m, 거의 제자리, 500회 0.32 m로 상승·전진, 1000회 0.40 m와 대각 비율 0.97 trot였다. START G1이 더 천천히 배울 가능성도 미리 기록한다.

## 결과

`[lead 기록·handoff §27]` GPU 0에서 1501 목표로 진행 중이며 23:09에 194/1501이라고 보고됐다. 직접 로그 검증과 같은 회차 영상·위상 판독은 미확인이다. 최종 결과 미측정. 영상 없음 · 미확인.
