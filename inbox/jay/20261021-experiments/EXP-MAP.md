GT와 복원 지도의 오차는 force_gt=True에서도 측정할 수 있다. 그 조건만으로 복원 지도를 실제 써서 걷는 내성은 확인할 수 없다. 설명 정정은 [학습 개념 기록](../20261023-experiments/NOTE-start-learning-gt-1023.md)에 남겼다. 기존 완료 기록과 봉인 gates는 바꾸지 않는다. 아래 A/B 동시 재학습·순차 두 판 ETA·DR 일부 복원 우선안은 **이전 논의 이력이며 현재 실행 지시가 아니다.**

고정 코드·독립 검토·직접 CPU 결과와 남은 실제 확인은 [실행 준비 기록](../20261023-experiments/READINESS-B-START-1023.md)에 모았다. 원격 코드 `ea664f1e`는 확인됐고 새 GPU 실행은 없다.

## 이전 결정 이력 · B 단독 비교로 좁힌 단계

**이 단계에서 정했던 방향은 B만 새로 학습하고 기존 EX-23을 대조군으로 사용하는 것이었다. 새 A 학습은 제외하며 learned를 유지한다.** 아래에 남은 새 A/B 두 판 우선 권고·순차 두 판 ETA는 이전 제안 이력으로 대체됐다. 설정·코드·초기화의 동등성을 먼저 대조하고, 기존 판도 동일 평가 조건으로 비교한다. 원인 규명이 START 본류의 성능 개선을 막는 필수 선행 단계는 아니다.

당시에는 GPU 0 B·GPU 1 성능 개선까지만 제안됐고 GPU 1 세부 처치는 미정이었다. 현재안은 위 EX-29 START-TD로 구체화됐다. 이번 기록은 새 기동 지시가 아니다. [START 학습 설명·결정 원문·force_gt 정정](../20261023-experiments/NOTE-start-learning-gt-1023.md).


번호 정본은 이 문서의 「관계」 표다. EX-01~25와 보류된EX-26·27을 보존한다. EX-28은B, EX-29는START-TD 준비안으로2026-10-23 lead_tmp가 배정했다. 번호는 기동·승인·성공 표시가 아니다. [EXPERIMENT-FLOW-20261023](../20261019-design/EXPERIMENT-FLOW-20261023.md)이 옛 HANDOFF보다 우선한다. EX-11·14·15는 1500회까지 돌고도 기거나 뛰었고, EX-17~22는 처음부터 301회 선별 실험이었다. 보상 변경으로 해결되지 않아 환경을 조사했고, 약한 DR·지연 제거 상태의 EX-23·25에서 보행이 형성됐다. 811 같은 회차는 비교 자료이며 보편적 중단선이 아니다.

**10/23 분석과 이후 결정:** EX-23·25는 전진에서 몸 상승·대각 교대를 확인했다. G1-GT는 평지 회전 유지가 낫지만 rough 양의 회전에서는 정체한다. [RESULT](RESULT-EX23-25.md)에 표·영상·위상·관절·학습 곡선과 결측을 묶었다. 두 판의 DR은 약한 고정 설정이며 커리큘럼 미실행이다. 처음 선택한 다음 목표는 DR·지연 일부 복원이었고, 이후 팀장은 B 원인 비교와 START 전체 구성의 TopDown 본류를 병행 준비하라고 구체화했다. 위 EX-28·29가 현재안이고 이전 목표·검토는 이력으로 남긴다.

**옛 후속 설계 이력:** [마찰 원인 비교 계획](../20261023-experiments/PLAN-friction-curriculum-1023.md)은 같은 초기화의 G1-GT scratch A/B를 우선 권고했으나 현재 두 판의 실행 지시가 아니다. 현재안에서는 A 재학습 없이 EX-28 B와 EX-29 START-TD를 병행 준비한다.

## 본류와 진단 지류 · 10/23 결과 자료 반영

[10/23 이어 학습 논의](../20261023-experiments/DISCUSSION-curriculum-linux-1023.md)의 이름 대응은 유지한다. EX-23은 G1-GT, 설계53의 복원 지도·AdaSmpl 본선은 DG1(옛 G1), 발 가장자리 보상 추가 본선은 DG3(옛 G3)다. EX-23을 이어받는 안은 과거 권고이며 현재 EX-29는 scratch다. G1-GT의 G0 대비 전반 우월을 입증한 것으로 쓰지 않는다. 당시 배정 제안은 EX-28 GPU0·EX-29 GPU1이었다. 실제 기동과 EX-29 저장 종료는 위 최신 원장을 따른다.

현재 본류 연결: EX-23/25 분석 → EX-29 START-TD의 원문 기반 깊이·보행 동시 학습 → 복원전용 보행·필요한 DR/지연·열린 명령·지형 확장 검증 → HiPAN 하위 정책 연결. EX-28 B는 옆의 마찰 원인 지류이며 본류 착수의 선행 조건이 아니다. 화살표는 계획이며 완료 표시가 아니다. 모든 새 카드는 본류 단계·부모·이번 질문·변경 묶음·대조·복귀 조건을 명시한다. 단기 GT 진단을 START 전체 공동 학습 또는20,000회 본선 완료로 바꾸지 않는다.

기준은 verify-v2 `99dbf578`와 [결정 #555 6310259601](https://github.com/foothold-project/foothold-lab/issues/555#issuecomment-6310259601)이다. **S1-a 실패 → START 구조·지도 없는 S2-G0의 두 명령 판 → 영상 판정 → 결과별 코칭 → S2 본류**로 연결한다. S1-a를 합격으로 바꾸거나 S1-b를 자동 시작하는 뜻은 아니다.

### 판정과 반복의 범위

lead가 2행2열 영상에서 다리를 몸 아래로 펴는가·네 발이 번갈아 걷는가·직진 명령에 곧게 가는가를 기록한다. 몸 높이·발 높이·요·멈춤·전진 수치는 기록용이다. **몸 크기 비율·3 cm·10° 합격선은 폐기**, 41·52·gates v1.1의 등록 관문은 유지한다. 다른 시드 검증은 전체 과정 뒤 같은 과정으로 한 번에 한다. 이번 두 판을 여러 시드 재현이나 전체 구조×명령 2×2 완료라고 부르지 않는다.

두 판 약2h는 일정 가정이다. 구체 cfg·코드·폴더·영상 조건·완료·판독 시각은 각 카드에 남긴다. S0-L 등 기존 본선 전제와 진단의 관계는 [결정 반영표](../20261019-design/DECISION-SYNC.md)에서 별도로 추적한다. 이 문서 작업이 실행 재개 승인은 아니다.

## 밤 기록을 읽는 범위

아래 「영상 없음」은 밤 촬영·판독 부재를 뜻한다. 오후 [Rx1 중단 보고](https://github.com/foothold-project/foothold-lab/issues/555#issuecomment-6309063175)는 이후 영상 관찰을 언급하지만 lead_tmp의 직접 판독은 아니다. 검사 계약 `exp-sync-v1`: 아래 「관계」 표의 첫 칸은 카드 파일 `EXP-<식별자>.md`로 연결한다. 각 카드에는 내용이 있는 `## 가설`, `## 설정`, `## 결과`, `## 다음` 절이 필요하다. `## 결과` 절에는 `영상 없음 · 미확인` 또는 `.mp4`·`.mov`·`.mkv`·`.webm` 영상 경로를 적는다. 「사슬 작업 이름」 표는 `chain_state.json`의 `running`·`done` 이름을 기록한다. 실험 작업은 카드 식별자에, 실험이 아닌 보조 작업은 `운영`에 연결한다. 이름 없는 실행은 검사 실패로 남기고 임의로 실험에 귀속하지 않는다.

> 원자료 재집계: `미측정`. 수치 표는 원보고와 실행 기록을 출처로 하며 이 초안에서 다시 계산하지 않았다.
실험 식별자와 경로의 숫자는 이름이다. 결과 수치에는 등급을 붙였다. `[실측]`은 지정 보고서·로그에 기록된 측정값이며, 이 초안 작성 중 원자료를 다시 집계하지 않았다. `[코드]`는 설정 또는 커밋에서 읽은 값이다. `[가정]`은 계획·해석이다. 영상은 lead 확인상 밤 보행 영상이 없다.
