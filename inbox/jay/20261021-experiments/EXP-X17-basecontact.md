# EX-17 · 몸통 접촉 종료

## 가설과 결과 전 등록

> [선행] “EX-17 = EX-16 + 몸통 접촉 종료(v2 env.yaml 과 같게).” [#555 6336845347](https://github.com/foothold-project/foothold-lab/issues/555#issuecomment-6336845347)

EX-16 환경에서 몸통 접촉 종료를 v2 설정에 맞추면 초반 뒤집힘 종료가 줄어드는지 살핀다. 이 변경 하나의 비교이며 v2 환경 전체를 복원하는 실험은 아니다.

## 설정

| 항목 | 기록 |
|---|---|
| 설정 계보 | `[코드·lead 기록]` EX-16 설정에서 파생. 이는 환경 설정 계보이며 체크포인트 계승을 뜻하지 않는다. 체크포인트 사용 여부는 미확인이다. |
| 변경 | `[선행]` 몸통 접촉 종료 조건을 v2 `env.yaml`에 맞춘다. 나머지 EX-16 설정은 유지한다. |
| 학습 한도 | `[선행·#555]` 최대 301 update. `[실측·#555]` 206 update에서 중단 보고가 있다. 정확한 소비 설정·실행 폴더는 이 카드에서 재확인하지 않았다. |
| 코드 근거 | `[코드·lead 기록]` 관련 코드 묶음은 `aec7f4ae` · `f3897551`. 개별 변경과 커밋의 대응은 미확인이다. |
| 체크포인트 | 이어 학습인지 처음부터인지 미확인. 설정 상속에서 추정하지 않는다. |

## 판정 · 결과 전 등록

자세·위상은 `[선행]` 100회와 300회 자료를 811 기준선의 같은 update와 비교한다. 811은 `[실측·BASELINE-0811]` 100회와 300회 모두 몸 높이 0.19 m로 낮고 거의 움직이지 않았다. 따라서 낮은 자세만으로 조기 실패 판정을 내리지 않는다. `[가설]` 300회는 낮은 자세에서 이동을 먼저 배우는지 살피는 경고 시점이지 합격·중단선이 아니다.

## 결과

`[실측·#555 6338232352]` 50회 에피소드 길이 207, 몸통 접촉 종료 81%. 100회 영상은 몸 높이 0.24 m의 웅크린 서기였고 206 update에서 멈췄다고 기록됐다. 이 조기 중단 판정은 811의 같은 회차 기준으로 뒷받침되지 않는다. 300회 비교 미측정. 영상 없음 · 미확인.

## 다음

기존 측정은 그대로 보존하고 낮은 자세만으로 붙인 실패 해석은 사용하지 않는다. 재실행·재평가는 별도 lead 지시와 811 동회차 자료가 있을 때 기록한다. 원영상 파일 상태는 이 작업에서 확인하지 않았다.
