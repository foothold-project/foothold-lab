제안 배경
및 필요성
산업시설, 지하시설, 터널, 재난 현장 등에는 사람이 직접 접근하기 어렵거나 위험한 공간을 지속적으로 이동·순찰·점검해야 하는 업무가 존재합니다. 사족보행 로봇은 작업 자체를 모두 대체하지는 못하지만 작업자보다 먼저 현장에 진입해 영상·온도·가스·설비 상태 등을 확인하고 반복 점검을 수행함으로써 사람의 위험 노출을 줄이고 점검 빈도와 데이터 축적 수준을 높일 수 있습니다. 실제 National Grid는 로봇 도입 후 고위험 설비의 점검 주기를 연 1회에서 2주 단위로 단축하였고, AB InBeV는 매주 약 1,800건의 점검을 수행하며 초기 6개월 동안 약 150건의 이상 상태를 발견하였습니다.
이러한 현장은 계단, 경사, 협소 통로, 불규칙 지면 등이 혼재하기 때문에 이동성과 지형 적응성이 중요합니다. 최근 휴머노이드 로봇이 주목받고 있지만 본 프로젝트와 같이 이동·순찰·점검이 중심인 임무에서는 네 개의 다리를 활용해 다양한 지형에 대응할 수 있는 사족보행 구조가 적합합니다.
이러한 활용 가능성은 국내에서도 실제 도입으로 이어지고 있습니다. 2026년 KCC건설은 공사현장에 Unitree Go2 Air를 도입해 고위험 작업환경의 안전관리에 활용하고 있으며[1], 한국수자원공사 역시 고위험·반복 점검 업무에 로봇을 시범 도입하고 있습니다[2]. 또한 과학기술정보통신부의 하이퍼-AI 네트워크 실증사업에서는 공장 내 위험지역을 순찰하고 촬영 영상을 실시간으로 분석하는 사족보행 로봇이 주요 실증 대상으로 포함되었습니다[3].
이미 고성능 사족보행 로봇이 상용화되었지만, 모든 비정형 지형에 안정적으로 대응하는 Locomotion 일반화 문제는 아직 완전히 해결되지 않았습니다. 실제 환경에서는 서로 다른 지형들이 연속적으로 등장하며, 특정 조건에서 높은 성능을 보인 정책이 처음 접한 지형에서도 동일한 성능을 유지한다는 보장이 없습니다.
이러한 Locomotion의 적응성과 일반화는 현재도 중요한 연구 과제입니다. KAIST는 2026년 HOUND 기반 APT-RL 연구를 발표하여 하나의 정책이 다양한 실제 지형을 통과하면서 상황에 맞는 보행 기술로 전환하도록 학습하였습니다[4]. 특히 새로운 환경의 지형 특성에 맞게 행동을 전환할 수 있도록 정책 자체의 적응 능력을 개선했다는 점에서 고성능 사족보행 로봇이 이미 존재하더라도 새로운 지형에 대한 적응성과 일반화 성능을 높이기 위한 학습·제어 연구가 여전히 필요함을 보여줍니다.

본 시스템은 실제 대상 환경을 기준으로 시뮬레이션 기반 RL Locomotion과 실제 Unitree Go2 기반 자율주행·환경 인지를 병렬적으로 구성합니다.

개발 내용
▪ 따라서 본 프로젝트 역시 상용 사족보행 로봇보다 높은 절대 성능을 달성하는 것을 목표로 하지 않습니다. 본 프로젝트의 핵심은 기존 보행 정책이 미경험 지형에서 보이는 성능 한계를 확인하고, 학습 지형과 물리 조건의 변화가 일반화 성능에 어떠한 영향을 미치는지 분석하는 것입니다. 이를 위해 Unitree Go2와 Isaac Lab을 활용하여 Baseline 평가 → 실패 지형 분석 → 학습환경 개선 → 재학습 → 미경험 지형 재평가를 반복하고 Locomotion 일반화에 효과적인 학습 조건을 탐색합니다.
한편, 안정적인 보행 능력만으로 실제 자율주행 로봇의 임무 수행이 완료되는 것은 아닙니다. 로봇은 자신의 위치와 주변 환경을 파악하고 목표 지점까지 스스로 이동할 수 있어야 합니다. 이에 별도의 실제 로봇 트랙에서는 Unitree Go2에 SLAM·Nav2 기반 자율주행과 Computer Vision 기반 환경 인지 기능을 구현합니다.
두 기술 트랙은 하나의 제어 시스템으로 직접 연결하지 않습니다. 대신 실제 주행 대상 공간을 Digital Twin으로 재구성하여 동일한 실제 공간을 공통 기준 환경으로 사용하도록 구성합니다. 이를 통해 시뮬레이션에서는 Locomotion의 일반화 성능을 연구하고 실제 공간에서는 자율주행과 환경 인지 기능을 검증함으로써 두 연구를 하나의 프로젝트 흐름으로 연결합니다.
국내시장 규모 및 현황
▪ 본 프로젝트는 두 개의 독립적인 기술 트랙과 이를 연결하는 Digital Twin 환경으로 구성됩니다. 강화학습 기반 험지 Locomotion 연구와 실제 자율주행을 하나의 직렬 파이프라인으로 묶지 않고 동일한 실제 대상 공간을 기준 환경으로 공유하는 병렬 구조로 설계합니다.
Track A. 강화학습 기반 험지 Locomotion
Isaac Sim·Isaac Lab 환경에서 Unitree Go2 보행 정책을 학습하고 다양한 험지 조건에 대한 적응성과 미경험 지형에서의 일반화 성능 평가
Terrain 구성 → PPO 기반 Policy 학습 → 미경험 지형 평가
→ 실패 원인 분석 → 학습 조건 개선 → 재학습 → Generalization 비교
단순히 높은 Reward를 얻는 것이 아니라 어떤 학습 지형과 보상 함수가 새로운 지형에서 보행 성능에 영향을 주는지 분석하는 것이 목적
Track B. 실제 Unitree Go2 자율주행 및 환경 인지
SLAM을 통해 주변 환경 지도를 생성하고 로봇의 위치를 추정하며, Nav2를 이용해 지정된 목표 지점까지 경로를 계획하고 자율주행을 수행하며, 카메라 기반 Computer Vision을 적용하여 주행 중 장애물이나 지정된 환경 요소를 인지하도록 구성
LiDAR·Camera·Robot State → ROS2 → SLAM/CV → Nav2 → 자율주행
CV는 Nav2의 제어 입력으로 사용되는 구조로 한정하지 않고 주변 환경의 의미적 정보를 추가적으로 인지하는 모듈로 구성
Track C. Digital Twin
Digital Twin의 역할은 Sim-to-Real이 아니라 시뮬레이션과 로봇이 동일한 실제 공간을 기준으로 연구·검증될 수 있도록 공통 환경을 제공하는 Real-to-Sim
