# 20260904_NVIDIA공식체크포인트_학습지형결과분석

## 1. 분석 목적

NVIDIA에서 제공하는 Unitree Go2 사전학습 체크포인트를 동일한 평가 조건에서 6개 지형에 적용하고, 현재 정책의 강점과 실패 원인을 episode 단위 지표로 진단한다.

본 분석은 기존 E0~E4 실험 결과를 사용하지 않고 다음 두 CSV만 독립적으로 분석한다.

- `에피소드별_평가지표(2).csv`
- `지형별_통계요약(2).csv`

분석의 핵심 질문은 다음과 같다.

- 계단 상승 실패가 낙상인지 장기 정체인지 구분
- 계단 턱 충돌과 foot clearance가 실패에 연결되는지 확인
- 같은 높이의 계단 상승과 하강 결과가 다른 이유 분석
- 성공률이 높은 지형에서도 보행 품질 문제가 존재하는지 확인
- Go2 공식 최대 단차 16cm를 고려한 Sim-to-Real 유효성 판단

## 2. 평가 대상 및 조건

### 2.1 체크포인트

```text

evaluation seed: 42
terrain difficulty: 0.65
episodes per terrain: 100
```

CSV의 `평균전진속도 + 속도추종평균오차 ≈ 1.0m/s` 관계를 고려하면 전진 명령속도는 약 1.0m/s로 추정된다. 실제 실행 인자가 다르다면 평가 코드의 오차 정의를 확인해야 한다.

Isaac Lab의 difficulty는 로봇 능력의 백분율이 아니라 설정된 최소·최대 terrain parameter 사이의 보간값이다. 계단 높이 범위가 5~23cm이면 difficulty 0.65에서 단차는 다음과 같다.

```text
0.05 + (0.23 - 0.05) × 0.65 = 0.167 m
```

### 4.3 정체와 시간초과

시간초과 episode의 95.4%에서 정체가 발생했고, 평가시간의 평균 67.2%를 정체 상태로 보냈다. 최대 정체 지속시간은 평균 6.77초였다.

|---|---:|

일부 episode는 거의 모든 계단을 오른 후 마지막 단차에서 멈췄고, 상당수는 전체 구간 중간에서 멈췄다. 특정 단차 접근 상태에서 반복적으로 local optimum에 빠지는 것으로 판단한다.

### 4.4 Foot clearance

계단 상승의 평균 foot clearance는 다음과 같다.

```text
성공:     11.56cm
시간초과:  7.41cm
낙상:      6.78cm
```

Foot clearance와 실패 여부의 상관계수는 약 `r=-0.700`으로, 낮은 clearance와 실패가 강하게 연결됐다.

다만 평균 clearance를 단차 높이 16.7cm와 직접 비교해 절대적인 신체 한계로 판단하면 안 된다.

- Swing 전체 구간의 평균일 가능성
- Local terrain 기준과 world-frame 기준 확인 필요
- 최대 clearance 35~43cm로 측정되어 지표 정의 점검 필요

절대 높이 해석에는 제한이 있지만 동일 지형에서 성공과 실패를 구분하는 상대 지표로는 유효하다.

### 4.5 충돌

발 측면 충돌은 성공 18.96회, 시간초과 19.14회로 거의 같아 실패를 구분하지 못했다. 현재 발 측면 충돌 지표는 정상적인 수평 지면 반력도 포함할 가능성이 있다.

반면 몸체 충돌은 성공 6.38회, 시간초과 17.65회였고 이동거리 기준으로는 1.93회/m와 7.15회/m로 약 3.7배 차이를 보였다.

따라서 현재 데이터에서는 발 충돌 횟수 자체보다 다음 조합이 더 중요하다.

```text
Thigh·calf·base 계열 충돌
+
전진속도 감소
+
장기 정체
```

### 4.6 탈출 행동 부족

성공 episode는 시간초과보다 torque와 action 변화량이 높았다.

```text
성공
Torque RMS 8.50N·m
Action 변화량 0.572

시간초과
Torque RMS 6.49N·m
Action 변화량 0.304
```

시간초과에서 낮은 torque와 action 변화량은 효율적인 보행을 의미하지 않는다. 턱에 걸린 뒤 다리를 다시 들어 올리거나 후퇴 후 재진입하지 않고, 작은 동작만 반복하며 멈춰 있는 정책으로 해석된다.

### 4.7 낙상 11회

낙상 episode의 81.8%에서도 정체가 발생했다. 일부 낙상은 즉각적인 자세 붕괴가 아니라 다음 과정일 가능성이 있다.

```text
단차에 걸림
→ 정체
→ 뒤늦은 자세 복구
→ 낙상
```

성공 episode의 pitch RMS와 pitch-rate가 실패 episode보다 높으므로 전역 pitch penalty를 강화하는 것은 적절하지 않다. 계단 상승에는 일정 수준의 적극적인 pitch 변화와 체중 이동이 필요하다.

### 5.2 랜덤 박스

랜덤 박스는 98% 성공했다. 실패 2회는 낙상 1회와 시간초과 1회였다.

### 5.3 랜덤 요철

통과율은 100%이나 Roll RMS 8.25°, 발 미끄러짐 28.29%가 측정됐다. 성공률에는 영향을 주지 않았지만 실제 적용 전 횡방향 흔들림과 접지 품질을 영상으로 확인해야 한다.

발 측면 충돌 38.79회는 정상적인 수평 접촉력을 포함할 가능성이 높아 단독 문제 판정에는 사용하지 않는다.

14.6° 경사 상승과 하강 모두 성공률 100%로 추진력과 기본 제동 능력에는 문제가 없다.

## 7. Go2 공식 사양과 Sim-to-Real 해석

### 7.1 공식 성능과 평가 조건

Unitree 공식 페이지는 Go2 Pro/X/EDU의 `Max Climb Drop Height`를 약 16cm로 제시한다. 동시에 실제 성능은 상황과 구성에 따라 달라질 수 있다고 명시한다.

현재 평가 단차 16.7cm는 공식 수치보다 0.7cm, 약 4.4% 높다. 완전히 불가능한 기구학 영역이라고 단정할 수는 없지만 반복 운용 목표로 삼기에는 여유가 없다.

계단 높이 범위 5~23cm에서 공식 16cm에 해당하는 difficulty는 다음과 같다.

```text
(0.16 - 0.05) / (0.23 - 0.05) ≈ 0.611
```

| 계단 높이 | 대응 difficulty | 권장 역할 |
|---:|---:|---|
| 10cm | 약 0.28 | 기본 실제 검증 |
| 12cm | 약 0.39 | Sim-to-Real 주 목표 |
| 14cm | 0.50 | 도전 목표 |
| 15cm | 약 0.56 | 경계 접근 |
| 16cm | 약 0.61 | 공식 한계 시험 |
| 16.7cm | **0.65** | Out-of-spec stress test |

### 7.2 단일 단차와 연속 계단의 차이

공식 수치의 시험 프로토콜은 공개된 사양표만으로 확인할 수 없다. 단일 16cm 장애물을 넘는 것과 16.7cm 계단을 연속으로 오르는 것은 난이도가 다르다.

- 단차 통과 직후 다음 단차 진입
- 앞발과 뒷발의 지속적인 높이 차이
- 몸체 pitch 누적
- 뒷다리 추진력과 반복 clearance 필요
- 재접근 공간 부족

따라서 16.7cm 연속 계단과 약 1.0m/s 명령의 조합은 공식 운용 경계를 넘어선 매우 공격적인 평가로 분류한다.

### 7.3 시뮬레이션 성공의 의미

16.7cm 성공은 스트레스 테스트와 정책 한계 비교에는 의미가 있지만, 그 결과만으로 실제 Go2의 통과 능력을 주장할 수 없다.

다음 요소가 시뮬레이션과 실제 로봇 사이에서 결과를 바꿀 수 있다.

- Motor torque-speed envelope
- 순간 토크·속도 제한
- 배터리 전압 강하와 관절 열 제한
- Actuator·communication delay
- Foot 재질과 계단 모서리 접촉
- 마찰계수와 접촉 restitution
- 관절 백래시와 state-estimation noise
- USD collision geometry 오차

정책이 링크 충돌, 과도한 순간 토크 또는 collision mesh 관통을 이용해 16.7cm를 넘는다면 시뮬레이션 exploit일 가능성이 있다.

### 7.4 권장 목표 구간

| 구분 | 계단 높이 | Difficulty | 목적 |
|---|---:|---:|---|
| 기본 운용 | 8~10cm | 약 0.17~0.28 | 초기 실제 적용 |
| Sim-to-Real 주 목표 | **10~12cm** | **약 0.28~0.39** | 반복 성공률 KPI |
| 도전 목표 | **12~14cm** | **약 0.39~0.50** | 고난도 실제 검증 |
| 경계 시험 | 14~16cm | 약 0.50~0.61 | 통제된 실험실 검증 |
| 스트레스 시험 | **16~16.7cm** | **약 0.61~0.65** | 시뮬레이션 한계 분석 |

16.7cm는 학습 curriculum의 상한이나 정책 비교용으로 유지할 수 있지만 실제 시연의 주 성공 기준으로 사용하지 않는다.

## 8. 후속 평가 및 개선 방향

### 8.1 높이·속도 sweep

Reward 변경 전에 계단 높이와 전진속도를 분리해 평가한다.

| 변수 | 평가값 |
|---|---|
| 계단 높이 | 10cm · 12cm · 14cm · 16cm · 16.7cm |
| 명령속도 | 0.2m/s · 0.5m/s · 0.8m/s · 1.0m/s |

| 관찰 결과 | 진단 |
|---|---|
| 낮은 속도에서 성공 회복 | 접근 속도·timing 문제 |
| 낮은 계단에서만 성공 | Clearance·기구학 한계 문제 |
| 낮은 속도·낮은 계단에서도 정체 | Recovery·reward local optimum 문제 |
| 첫 단차 성공 후 중간 정체 | 반복 단차 coordination 문제 |

### 8.2 Reward 수정 우선순위

1. 양의 높이 변화가 있는 상향 단차에서만 swing-foot clearance 활성화
2. 충돌 후 전진속도와 진행률을 다시 회복했을 때 recovery 보상
3. Foot contact와 thigh·calf·base collision 분리
4. 10cm에서 시작해 12cm·14cm·16cm로 증가하는 curriculum

전역 pitch·roll·torque penalty 강화는 우선하지 않는다. 계단 상승 성공 episode가 실패 episode보다 큰 pitch 움직임, torque 및 action 변화를 사용하기 때문이다.

### 8.3 Sim-to-Real 검증 KPI

| 항목 | 목적 |
|---|---|
| Joint torque peak | 실제 모터 한계 초과 확인 |
| Joint velocity peak | 관절 응답 가능성 확인 |
| Torque-speed envelope violation | 비현실적인 동시 토크·속도 확인 |
| Joint limit 접근률 | 극단 관절 자세 확인 |
| Link별 collision | 몸체·다리 지렛대 exploit 확인 |
| Foot penetration | Collision mesh 관통 확인 |
| Action-rate | 실제 제어기 추종 가능성 확인 |
| Contact impulse | 비현실적인 충격 확인 |
| Friction·delay randomization | 특정 시뮬레이션 조건 의존성 확인 |

## 9. 분석 한계

1. 평가 seed가 42 하나이므로 seed 간 분산을 확인할 수 없다.
2. Difficulty 0.65 한 지점만 평가해 계단 성능 임계점을 확인할 수 없다.
3. 평균 foot clearance가 local terrain 기준인지 world-frame 기준인지 CSV만으로 확정할 수 없다.
4. 몸체 충돌이 thigh·calf·base 중 어떤 링크인지 구분되지 않는다.
5. 발 측면 충돌은 정상적인 수평 접촉력을 포함할 가능성이 있다.
6. 공식 16cm 수치의 세부 시험속도·마찰·단일 또는 연속 단차 조건은 공개 사양표만으로 확인할 수 없다.
7. 실제 actuator와 저수준 제어기의 제한이 현재 시뮬레이션에 얼마나 반영됐는지 추가 확인이 필요하다.

## 10. 최종 결론

이 체크포인트는 경사 상승·하강, 랜덤 요철, 계단 하강에서 100%, 랜덤 박스에서 98%를 기록해 기본 험지 적응과 속도 유지 능력은 우수하다. 그러나 16.7cm 계단 상승에서는 성공률 24%, 시간초과율 65%, 정체율 72%로 성능이 급격히 무너진다.

실패의 핵심은 낙상보다 다음 연쇄이다.

```text
상향 단차 발 궤적·착지 위치 부족
→ 다리 또는 몸체 링크 충돌
→ 전진속도 감소
→ 탈출 행동 감소
→ 장기 정체와 시간초과
```

16.7cm는 Go2 공식 최대 단차 약 16cm를 넘어선 경계 밖 조건이다. 따라서 이 조건은 정책 스트레스 테스트로는 유효하지만 Sim-to-Real의 주 성공 KPI로 사용하지 않는다. 실제 시연 목표는 10~12cm, 도전 목표는 12~14cm로 설정하고, 16~16.7cm는 별도의 한계 시험으로 분리하는 것이 적절하다.
