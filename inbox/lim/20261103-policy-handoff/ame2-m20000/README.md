## 확인 (`실측`)

- 3단계 필수 시험(학습 env 기록 평지 · 계단 각 정책 200 스텝 · 매퍼 40 장), 저장된 판정: 정책 action 최대 차이 평지 1.907e-06 · 계단 2.146e-06(기준 1e-4, 통과). 매퍼 높이 최대 차이 평지 0.009477 mm · 계단 **0.179768 mm**(기준 0.1 mm, **실패**).
- 저장된 판정을 낸 판정기에는 NaN 을 건너뛰는 틈이 있었다(검토 430_55). 파일 지문(기준 정책 코드 포함) · 기록 완전성 · 유한성 검사를 더한 판정기로 같은 기록을 배포판과 같은 onnxruntime 1.18.1 에서 다시 판정해도 결론이 같다: 계단 매퍼 **0.166893 mm** 로 실패(세 장이 기준 초과), 기록 검사 49 항 통과, 비교한 배열 모두 유한. 판정기 시험 18 건 모두 기대대로.
- 두 ONNX 의 sha256 은 석헌 PC `bundle/` 의 ACTIVE 기록 · versions 기록 · `parity.json` 과 같다.
