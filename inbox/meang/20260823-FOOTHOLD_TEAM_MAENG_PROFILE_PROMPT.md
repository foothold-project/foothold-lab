# FOOTHOLD 사이트 · 맹라현 팀 카드 클릭 프로필

나중에 **팀 사이트 Git 저장소**에서 작업할 때 쓴다.  
이 OneDrive `Foothold` 문서 폴더가 사이트 레포가 아니다.

- 라이브: https://foothold-project.vercel.app/
- 팀 사이트 갱신 담당(팀 문서 기준): 이민우 MAIN, 오흥재 SUB
- 사이트 상단 표기: `인공지능사관학교 7기 · AI 도약과정 · 실증 프로젝트`

---

## 작업 순서 (사람용)

1. 팀 사이트 Git 저장소를 연다. (Vercel에 물려 있는 그 레포)
2. `main`/`master` 최신으로 맞춘 뒤 브랜치를 딴다. 예: `feat/team-maeng-profile`
3. 아래 **원샷 프롬프트**를 그 레포 Cursor 채팅에 그대로 붙인다.
4. 로컬에서 홈 `/` 팀 섹션 → 맹라현 카드 클릭 → 패널이 뜨는지 확인한다.
5. 다른 멤버 카드·모바일·다크모드가 깨지지 않는지 본다.
6. 커밋 후 PR. 머지되면 Vercel이 [foothold-project.vercel.app](https://foothold-project.vercel.app/)에 올린다.

레포 경로를 이 문서에 적지 않은 이유: 이 폴더에는 사이트 소스가 없고, 원격 URL을 추측해서 넣지 않는다. Vercel 대시보드나 팀 GitHub에서 확인한다.

## 원샷 프롬프트 (여기부터 복사)

```
목표
https://foothold-project.vercel.app/ 홈페이지 「팀 Team」 섹션에서 맹라현 카드를 누르면, Scene·Viz 담당 내용과 시뮬 파이프라인(Blender / USD / MuJoCo)이 뜨게 한다. 새 페이지로 튕기지 말고, 같은 페이지에서 오버레이·드로어·모달 중 기존 UI와 가장 잘 맞는 방식으로 구현한다.

현재 라이브 카드 (그대로 유지, 문구를 바꾸지 말 것)
- PM · TWIN / 오흥재 / 영상·VFX 12년 / 공간 재구성 · 기획
- POLICY / 임석헌 / 모델 학습·데이터 구축 / 파인튜닝 R&D
- SCENE · VIZ / 맹라현 / Blender·3ds Max·Unity / 시각화·디자인
- ENV · INFRA / 이민우 / 웹 풀스택·서버 구성 / 환경 구축
- PERCEPTION / 오현민 / 컴퓨터비전 · 프론트엔드 / 데이터 검증

카드 겉면 두 줄은 바꾸지 않는다. 클릭 시에만 상세가 열린다.
다른 멤버 카드는 이번 작업에서 상세를 만들지 않는다. 클릭해도 열리지 않거나, 커서가 맹라현만 pointer로 보이게 한다. 다섯 장을 전부 눌러지게 만들면서 빈 모달을 넣지 말 것.

먼저 할 일
1. 홈의 Team 섹션 컴포넌트/HTML을 찾는다. (정적 html이면 index, 프레임워크면 Team 관련 파일)
2. 기존 카드 레이아웃·폰트·색·간격·다크모드 토큰을 그대로 쓴다. 새 디자인 시스템을 만들지 말 것.
3. 접근성: 카드는 button이거나 role=button + keyboard(Enter/Space). Esc와 바깥 클릭으로 닫기. 포커스 트랩 또는 닫기 후 카드로 포커스 복귀.
4. 모바일에서도 카드 그리드가 깨지지 않게, 패널은 화면 안에서 스크롤 가능하게.

패널에 넣을 내용 (이 문구를 사실로 쓰고, 부처명·회사명·취업 멘토링 내용은 넣지 말 것)

제목: 맹라현
역할: Scene · Viz

담당
사족보행 로봇이 시험받을 가상 지형과 씬을 설계·제작한다.
Isaac Lab에서 학습용 지형과 평가용 지형을 분리하고, 계단·경사·요철을 난이도별로 구성한다.
마찰·질량 조건을 바꿔 시험 시나리오를 만든다.
실측은 3D Gaussian Splatting으로 받아 평가 씬에 연결한다.
발표용 시각화는 학습 씬과 나눠 Path Tracing으로 제작한다.

도구
Blender · 3ds Max · Unity
NVIDIA Isaac Lab (Isaac Sim)
MuJoCo

시뮬레이터와 포맷 (이 설명이 이번 작업의 핵심)
- Isaac Sim이 씬·로봇·지형을 다루는 형식은 USD(Universal Scene Description, 3D 씬 포맷)다. 파일을 손으로 안 만들어도 시뮬레이터 안에는 USD로 들어간다.
- Isaac Lab이 코드로 뽑는 학습용 험지(계단·경사 등)는 Blender가 없어도 된다.
- Blender(또는 3ds Max)가 필요한 지점은 커스텀 지형·스캔·렌더 씬이다. 3DGS 메시를 다듬거나 USD로 내보낼 때 쓴다.
- MuJoCo는 USD가 아니라 MJCF(XML)다. Isaac에서 학습한 뒤 엔진이 다른 환경에서도 보행이 유지되는지 볼 때 쓴다. 같은 지형을 쓰려면 변환이 한 번 더 필요하다.

확인하지 못한 것은 쓰지 말 것
- 과학기술정보통신부 등 주관 부처를 FOOTHOLD 앞에 붙이지 말 것. 사이트 표기는 「인공지능사관학교 7기 · AI 도약과정 · 실증 프로젝트」다.
- 취업용 회사 목록, 자격증 목록, 개인 연락처를 이 패널에 넣지 말 것.

디자인
라이브 팀 카드와 같은 계열: 오프화이트 그리드 배경, 흰 카드, 역할명 컬러, 이름 큰 볼드, 본문은 작은 회색 톤.
패널 안에서도 제목 / 역할 / 본문 위계를 카드와 같게 맞춘다.
그라디언트, 이모지, 그림자 과다, 무지개 포인트 색 금지.

검증
- / 에서 맹라현 클릭 → 패널 내용이 위에 적은 핵심을 포함하는지
- Esc·바깥 클릭·닫기 버튼으로 닫히는지
- 다른 멤버 카드 겉 문구가 그대로인지
- 다크 모드가 있으면 그 모드에서도 읽히는지
- 기존 팀 섹션 레이아웃이 밀리지 않는지

커밋
팀 컨벤션을 따른다. 없으면 예:
feat(team): 맹라현 카드에서 Scene·Viz 시뮬 파이프라인 상세 표시

구현만 하고 배포 설정·Vercel 프로젝트 생성은 하지 말 것.
```

## 패널에 넣을 내용 요약 (프롬프트와 동일, 로컬 참고)

Isaac Sim → **USD**가 씬 형식이다.  
학습용 절차 지형 → Blender 없이 Isaac Lab만으로 된다.  
스캔·커스텀·렌더 → Blender/3ds Max로 다듬고 USD로 넣는다.  
MuJoCo → USD가 아니라 XML. 엔진이 달라도 걷는지 볼 때 쓴다.
