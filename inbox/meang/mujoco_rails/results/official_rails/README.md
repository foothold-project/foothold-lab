# 공식 mjlab Go2 정책 · 레일즈 50회

사이트 일반화 벤치와 **같은 판정 축**으로 레일즈만 50회 돌린 기록이다.

참조: [일반화 벤치마크 10종](https://foothold-project.vercel.app/research-generalization-benchmark-10-terrains)

이 숫자는 Isaac 기준선 1,500 iter가 **아니다**. 엔진·정책·관측·시간이 다르다. 같은 표에 섞어 읽지 않는다.

## 1. 구성

| 항목 | 이 실험 `확인됨` | 사이트 v2 (Isaac, 임석헌) |
|---|---|---|
| 엔진 | MuJoCo 3.12 | Isaac Lab |
| 정책 | unitree_rl_mjlab `Unitree-Go2-Flat` ONNX (Hugging Face `diasAiMaster/unitree-go2-velocity-flat`) | 기준선 rough 1,500 iter |
| 관측 | 45차원 (각속도·중력·명령·관절·직전 행동). height_scan **없음** | 235차원 (height_scan 187점 포함) |
| 지형 | 팀 v2 레일즈 기하: 높이 11.5 cm, 안쪽 8 cm, 바깥 18 cm, platform 1.5 m, tile 8 m | 같은 cfg (`docs/research/benchmark-setup-lim.md`) |
| 횟수 | 50 | 50 |
| 시간 | **10초** (영상 길이에 맞춤) | **6초** |
| 명령 | vx 0.5 m/s | vx 0.5 m/s |
| 이상 거리 | 5.0 m | 3.0 m |
| 전진 성공 | 3.5 m (70%) | 2.1 m (70%) |
| 변동 | 시드 `1000+ep`, yaw ±0.15 rad, xy ±0.08 m | 변동 주입 (스크립트 항목은 사이트 기준 `미확인`) |

판정 4축 동시 (사이트와 같음):

- 종합 = 생존 AND 전진 AND 추종 AND 방향
- 생존 = 10초까지 낙상 없음 (몸통 높이 0.12 m 미만, 또는 pitch/roll 1.0 rad 초과)
- 전진 = 이상 거리의 70%
- 추종 = planar velocity MAE 0.25 m/s 이하
- 방향 = 측면 0.75 m 이하

원자료: `raw.csv` · 요약: `summary.csv`

정책 파일: `vendor/unitree_go2_policy/`. Unitree 깃허브에 들어 있는 Go2 가중치가 아니다. mjlab 스택으로 학습된 공개 체크포인트다.

## 2. 결과 `확인됨`

n = 50, 2026-08-27, 이 환경 헤드리스.

| 지형 | 종합 성공률 | 생존 | 전진 성공 | 추종 | 방향 | 전진 평균±표준편차 | 판정 |
|---|---|---|---|---|---|---|---|
| rails (이 실험, 10초) | **0%** (0/50) | **2%** (1/50) | 0% (0/50) | 96% (48/50) | 98% (49/50) | **0.63 ± 0.25 m** | 실패 · 낙상형 |
| rails (사이트 v2, 6초) | 2% (1/50) | 36% | (사이트 표에 없음) | (사이트 표에 없음) | (사이트 표에 없음) | 0.93 ± 0.32 m | 실패 · 낙상형 |

이 실험 부가치:

- 낙상 49/50. 평균 낙상 시각 2.72초 (가장 빠른 1.68초, 가장 늦은 7.40초)
- 평균 에피소드 길이 2.86초
- 전진 1 m 이상 3회 (ep12 1.02 m, ep29 1.22 m, ep34 1.26 m). 그래도 턱에서 넘어진다
- 유일한 생존 ep14: 10초를 버텼으나 전진 0.84 m, 속도 MAE 0.39 m/s → 전진·추종 실패, 종합 실패
- 방향 실패는 ep35 한 번 (측면 0.78 m)
- 추종 실패는 오래 버틴 ep14·ep15뿐. 일찍 넘어지면 MAE가 작게 남는다

사이트 v2와 방향은 같다: 레일즈는 낙상형이다. 생존율 2% vs 36%를 같은 정책의 차로 읽으면 안 된다. 이쪽 정책은 평지용이고 height_scan이 없다.

## 3. 영상 (각 10초)

낙아도 녹화는 10초까지 간다. 판정용 전진·측면은 **첫 낙상 시점**에서 멈춘다.

카메라는 `base` 추적 (azimuth 145, elevation -22, distance 2.2 m). 640×352, 30 fps. 충돌 메시(group 3)를 켠다.

| 파일 | 고른 이유 | 50회에서의 역할 |
|---|---|---|
| [rails_v2-ep00.mp4](videos/rails_v2-ep00.mp4) | 대표 낙상 | 전진 0.42 m, 3.84초에 낙상 |
| [rails_v2-ep14.mp4](videos/rails_v2-ep14.mp4) | 유일한 10초 생존 | 전진 0.84 m, 턱 앞에서 멈칫 |
| [rails_v2-ep34.mp4](videos/rails_v2-ep34.mp4) | 최대 전진 | 1.26 m 뒤 2.72초에 낙상 |

같은 시드로 더 뽑은 영상 (용량 때문에 깃에는 안 넣음, 로컬에서 재생성):

```bash
cd inbox/meang/mujoco_rails
xvfb-run -a env MUJOCO_GL=glfw python3 run_official_rails.py \
  --only-episodes 0,1,2,14,15,26,29,34,35,42 --duration 10 --keep-csv
```

ep01·02 전형 낙상, ep15·42 늦은 낙상, ep26 후진, ep29 전진 1.22 m, ep35 방향 실패.

## 5. 재실행

50회 (영상 없음, CSV 갱신):

```bash
cd inbox/meang/mujoco_rails
MUJOCO_GL=disable python3 run_official_rails.py --episodes 50 --videos 0 --duration 10
```

평지 스모크 (정책이 앞으로 걷는지):

```bash
MUJOCO_GL=disable python3 run_official_rails.py --flat --episodes 1 --videos 0 --duration 4
```

헤드리스 영상은 EGL/OSMesa가 이 환경에서 실패해서 `xvfb-run` + `MUJOCO_GL=glfw` 를 쓴다.
