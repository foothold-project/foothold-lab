## 노트

1. Unitree·NVIDIA 공개 보행 정책을 AI-WS01(Windows · Python 3.11 · Isaac Sim 5.1 · Isaac Lab v2.3.2)에서 실행한다. 산출물은 재현 영상과 수행계획서다. 우리는 보행을 0부터 학습하지 않는다.
2. 우리는 학습 지형과 평가 지형을 분리한다. 미경험 지형에서 성공·낙상을 통과율로 보고한다. 오픈소스 그대로와 미세조정 결과를 같은 시험·같은 시행 수로 비교한다.
3. 시뮬은 학습장, 실기는 시험장이다. 우리는 Go2에서는 학습하지 않는다. 8/18 원문은 평지부터 이전, 데모 6컷, 시뮬-실기 차이 리포트를 적었다. 이 저수준 이전 줄은 8/19에 폐기됐다 `확인됨`.
4. 우리는 성공 여부를 기능 개수가 아니라 아래 기준으로 판단한다. Nav2가 늦어도 보행 검증은 유지한다.

## 평가 · 산출물

성공 = 지정 거리 도달 · 낙상 없음. 통과율 = 성공 / 시행. 우리는 지형명·시드·시행 수를 표에 고정한다.

KPI 는 오현민이 맡고, 지형은 맹라현이, 정책은 임석헌이 맡는다.

| 9/21 ~ 10/25 | train/test 통과율 표 |

## 스택 (8/18 원문)

학습: Windows WS. Isaac은 공유 워크스테이션만. 우리는 노트북에 Isaac을 설치하지 않는다.

실기: Ubuntu 22.04 · ROS 2 Humble · unitree_ros2 · ONNX 50Hz 관절.

SLAM/Nav: slam_toolbox · Nav2.

8/18 원문: 저수준 관절 정책이 주 경로이고, cmd_vel은 항법 연동용이다. 오리엔테이션의 high-level only는 팀 사실이 아니다. **저수준 주 경로 문장은 8/19 이후 정본이 아니다** `확인됨`.

제어 사슬 (8/18): 목적지 → Nav2 → cmd_vel → 보행 정책 → 관절 → Go2
