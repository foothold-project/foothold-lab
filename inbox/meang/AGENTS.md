## 메인 최신화

아침과 커밋 전:

```bash
git fetch origin main
git merge origin/main
```

메인을 내 브랜치로 가져온다. 메인을 덮지 않는다.

아침이면 사용자에게 짧게: main에 새로 들어온 커밋·파일, 이슈(목록을 열 수 있을 때만), 규칙 변경. 이슈 API가 막히면 막혔다고만 한다. 없는 이슈를 만들지 않는다.

## 충돌

혼자 고르지 않는다. 설명하고 멈춘다.

같은 줄을 두 사람이 다르게 적으면, 한쪽을 지우면 그 글이 사라진다. 그래서 합치기를 멈춘다.

사용자가 고른다.

1. 메인 쪽 (내 줄 버림)
2. 내 브랜치 쪽 (메인 줄 버림)
3. 둘 다 (사용자가 한 줄로 섞는 법)
4. 취소 (합치기 전으로)

1·2·3·4가 이번 메시지에 없으면 `git add`하지 않는다. 커밋하지 않는다.
