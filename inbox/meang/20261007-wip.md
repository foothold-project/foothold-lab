# 20261007 진행 상황 · 맹라현

> 분류: 운영  
> 작성: 맹라현 · 2026-10-08 15:29

> 요지: 기존 촬영 자료로 복원한 ACC 공간이 실제 장소처럼 보이도록 개선하고 있습니다.  
> 상태: 진행중

## 1. 무엇을 하고 있나

기존 촬영 자료로 복원한 **국립아시아문화전당(ACC) 공간의 현실감을 높이고 있습니다.** 현재는 하늘에 남는 번짐, 보는 방향에 따른 색 표현, 벽·바닥의 사진 질감이 앞쪽 구조물을 덮는 문제를 다루고 있습니다.

## 2. 기술적으로 어떻게 접근하나

**하늘:** 원본 사진과 거리 정보를 대조해, 번짐이 남는 이유가 하늘 표시 누락인지, 구조물 보호 범위가 너무 넓어서인지, 큰 3D 조각이 경계를 넘어 번져서인지 나눠 확인합니다. 현재 후보는 하늘로 판단한 화면 영역의 색과 불투명도를 함께 제외하며, 조각별로 구분하는 방법도 검토합니다. 건물·나무·전봇대·중앙광장의 흰색 조형물 모양을 유지하고, 정리된 부분은 단색 배경으로 표시합니다.

**색·화면 비율:** 원래 학습 모델의 시점별 색 정보(SH)를 이용해 보는 방향에 맞는 색을 계산하는 수정본을 최신 하늘 제거 화면에 연결하고 있습니다. 화면 크기를 바꿔도 물체 비율과 표시 위치가 같은 기준을 따르도록 함께 확인합니다.

**벽·바닥:** 사진과 거리 정보로 만든 작은 3D 표면에 줄눈과 돌 질감을 입히고 있습니다. 실제 사진 질감을 켠 상태에서 앞쪽 기둥과 뒤쪽 벽의 거리를 구분해, 벽 무늬가 기둥을 덮지 않는지 비교하고 있습니다.

## 3. 구성

| 용도 | 사용 자료·도구 |
|---|---|
| 입력 자료 | 기존 ACC 사진·영상, 등록된 원본 사진 12장과 거리 정보 5장 |
| 촬영 위치 계산 | COLMAP으로 계산한 카메라 위치·방향 |
| 공간 표현 | 사진으로 공간을 표현하는 3DGS, 원본 모델의 시점별 색 정보, 벽·바닥의 작은 3D 표면 |
| 화면 수정·비교 | Python 처리 코드와 웹 3D 화면 |
| 실행 환경 | V100 32GB GPU 서버와 로컬 웹 브라우저 |
| 결과 공유 | Vercel 공개 웹페이지 |

## 4. 지금까지 한 것

- **진행중 · 하늘:** 구조물 경계의 번짐을 원본 사진·거리 정보와 대조해 남는 이유를 구분하고 있습니다.
- **진행중 · 색 표현:** 최신 하늘 제거 후보에 시점별 색·화면 비율 수정본을 연결해 비교하고 있습니다.
- **진행중 · 사진 질감:** 기둥 뒤쪽 벽의 사진 무늬가 앞쪽 기둥을 덮는지 비교하고 있습니다.

## 6. 다른 사람과 주고받는 것

**진행중:** 색·화면 비율 수정과 하늘 제거 작업이 같은 원본 사진·카메라·모델을 쓰도록 자료와 수정 파일을 연결하고 있습니다.

**계획:** 팀장과 팀원이 직접 확인할 수 있도록 최신 후보의 비교 화면·영상을 [공개 웹페이지](https://acc-real2sim.vercel.app)에 연결하고, 남는 문제와 적용 범위를 함께 표시합니다.

## 7. 막힌 것 · 판단이 필요한 것

화면 해상도와 색 표현을 개선해도 벽 위의 번짐, 기둥 윤곽의 흐림, 각진 하늘 공백이 남는 문제를 다루고 있습니다. 기둥 주변은 보존 범위가 넓어 하늘 정리 효과를 아직 확인해야 합니다.

기둥의 거리 정보에는 빈 곳과 크게 튀는 값이 있어, 거리 값이 있다는 이유만으로 기둥 표면이라고 판단하기 어렵습니다. 사진 질감이 벽에 보이면서도 앞쪽 구조물을 덮지 않는 조건을 확인하고 있습니다.

## 8. 다음에 할 것

1. 남는 하늘과 보호하는 구조물의 범위를 색으로 표시해, 원인별로 정리 조건을 비교합니다.
2. 원본 사진의 구조물 윤곽과 대조해 기둥·나뭇가지·벽 상단이 잘리거나 새 얼룩이 생기는지 확인합니다.
3. 사진 질감을 켠 후보에서 기둥과 흰색 조형물의 가림, 벽·바닥 무늬의 고정 상태를 확인합니다. 거리 정보가 부족한 구역은 필요한 자료를 구체적으로 정리합니다.
4. 최신 색 표현을 적용한 같은 화면에서 하늘 정리 전후를 10초 동안 비교하고, 웹 3D 화면에서도 보는 위치와 방향을 바꿔 확인합니다.
