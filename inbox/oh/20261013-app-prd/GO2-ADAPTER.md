## 어댑터 계약 - `ros/go2_adapter.py` 에 구현(오프라인)

| 순서 | 구간 |
|---|---|
| 1 | gateway → `/cmd_vel_mux` → collision_monitor |
| 2 | collision_monitor → `/cmd_vel`(최종) → go2_adapter |
| 3 | go2_adapter → Move·StopMove → SDK(비활성. 지금은 가짜 기록기) |

1. **입력은 collision_monitor 뒤의 최종 `/cmd_vel` 하나.** `/cmd_vel_mux` 를 직접 받으면 충돌 감시를 건너뛴다. 화면·임무 서버에서도 직접 받지 않는다
2. **켜질 때 래치**: 첫 tick 에 `Move(0,0,0)` + `StopMove()` 를 한 번 시도하고, 그 뒤 0 아닌 입력은 무시한다
3. **입력 검증**: 유한한 숫자만(NaN·inf·문자는 버리고 상류 신호로도 치지 않음). `max_vx`·`max_wz` 로 다시 자르고 후진은 기본 금지, 옆걸음 `vy` 는 항상 0
4. **상류 끊김 감시**(steady 시계 20 Hz): 마지막 입력이 `timeout`(0.3 s) 넘게 없으면 `Move(0,0,0)` + `StopMove()` 를 **한 번** 부르고 정지 래치
5. **재연결 자동 재개 없음**: 래치는 «**원입력**(자르기 전) vx·wz 가 둘 다 0 인 명령을 `hold_s`(1 s) 동안 **끊김 없이**(입력 간격 ≤ timeout) 받을 때»만 풀린다. 후진 금지로 잘려 0 이 된 값은 0 으로 치지 않는다. 간격이 timeout 을 넘거나 0 아닌 값이 끼면 처음부터 다시 센다
6. **호출 실패 기록**: 예외·0 아닌 코드를 모두 기록하고, `Move` 가 실패하면 정지 시도 + 래치. 감시 루프는 예외로 죽지 않는다
7. **정지 결과는 «정지했다»가 아니다**: `stop_result` 는 `StopMove 응답 0 - 몸 정지는 odom·영상으로 따로 확인` 또는 `StopMove 실패(코드) - 정지 미확인`. 정지 완료는 odom 속도 0 이 이어진 것으로만 판정한다(실기)
8. `StandUp`·`Damp`·sport 모드 전환 등 **자세·모드 바꾸기는 부르지 않는다.** 사람이 리모컨·앱에서 직접 한다
9. **설정 fail-closed**: `max_vx`·`max_wz`·`timeout`·`hold_s` 가 유한한 양수가 아니면 시작을 거절한다
10. `transport` 는 `mock` 만. 다른 값이면 노드가 시작을 거절한다 - 실제 SDK backend 는 실기 검수 뒤 이 자리에 넣는다

| A. 위쪽 끊김 | 어댑터 살아 있음, gateway·collision_monitor·네트워크 죽음 | 어댑터가 0.3 s 뒤 0 + StopMove 한 번, 래치 | **오프라인 통과**(아래) - 가짜 기록기의 호출 기록까지. 몸이 서는지는 실기 |
