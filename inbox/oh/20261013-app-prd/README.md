## 사본에서 바꾼 것 (원본은 그대로)

내용·수치·확정/제안/미정 구분·«현재» 칸은 원본 그대로다. 아래 형식만 바꿨기 때문에 파일 해시는 원본과 다르다.

- 문서마다 제목 아래에 팀 저장소 메타 5줄, 사본 안내 한 줄, 원 출처 한 줄을 넣었다.
- 문자 도식(선·화살표 그림)은 같은 내용의 표·목록으로 바꿨다. 예: PRD 2장 시스템 연결 개요.
- 긴 대시 문자를 `-` 로 바꿨다(팀 저장소 표기 규칙).
- 작성자 로컬의 절대경로·해시·계정·내부 주소는 지우거나 «작성자 로컬 기록»으로 바꿨다. 근거 기록 자체는 팀 열람 링크가 없다.
- 문서끼리의 상대 링크는 같은 폴더 안이라 그대로 열린다. 원래 문서팩 안내(README)로 가던 링크는 `0-docpack-guide.md` 로 바꿨다.
