## 1. 이것이 왜 산출물인가

숫자만으로는 「걷는다」가 전달되지 않는다. 통과율 표 옆에 **같은 정책이 실제로 걷는 장면**이
있어야 심사위원이 판단할 수 있다.

그리고 이미 실증된 것이 하나 있다. **학습 씬과 렌더 씬은 완전히 분리된다.**
회색 험지에서 학습한 정책을 **정책 파일 하나만 들고** 창고 씬에서 걷게 하는 데 성공했다.
근거: `docs/research/visual-evidence.md` §03

### 1-1. MVP 까지 실제로 한 것

| 단계 | 상태 | 근거 |
|---|---|---|
| 폰 영상 -> SfM (COLMAP) | **됐다** | `RESULTS-3dgs-terrain.md` · 35.9 초 영상 한 편 |
| SfM -> 3DGS 스플랫 (Brush) | **됐다** | 같은 문서 · 워커 보고서 `REPORT-03` |
| 스플랫 -> 지면 2.5D 메시 | **됐다** | `REPORT-04` · `REPORT-05` |
| 메시 -> Isaac Lab 충돌체 USD | **됐다** | `REPORT-05` · Go2 두 판이 로드·추론·이동 |
| 스플랫 -> NuRec USDZ -> Windows Isaac Sim 5.1 배경 렌더 | **됐다** | `REPORT-07` · 시스템 설치 없이 |
| 실제 축척 확정 | **안 됐다** | 노면 도색·연석을 법정 규격과 대조해 가설별 구간까지 (k 0.986~1.134 / 1.184~1.512). **단일 값 미확정** |
| 상영용 컷 렌더 | **안 됐다** | 마스터 14 컷이 전멸했다 (#438) |

> **「됐다」가 「보여줄 수 있다」는 아니다.** 위 여섯 줄은 파이프라인이 통했다는
> 기록이고, 품질 판정이 아니다. 각 12 초 실행에는 낙상과 재시작이 섞여 있다.
> 원문이 그렇게 적고 있고 여기서도 그대로 옮긴다.

## 3. 렌더 조건

| 항목 | 값 | 실측 기준 |
|---|---|---|
| 해상도 | `미정` | 1080p |
| 샘플 수 (spp) | `미정` | 128spp |
| 프레임당 시간 | `미정` | **1.75초** (1080p · 128spp Path Tracing) |
| 총 렌더 시간 | `미정` | 30초 영상 = 약 44분 |
| 장비 | RTX 5080 | RTX 5080 |

> **렌더 시간은 병목이 아니다.** 30초 영상이 44분이면 하루에 여러 번 다시 뽑을 수 있다.
> 병목은 **씬을 만드는 시간**이다.
> 근거: `docs/research/render-benchmarks.md`

> **렌더에서 걸린 것 하나를 적어 둔다.** Isaac 렌더는 **화면용 GPU** 를 쓴다.
> `CUDA_VISIBLE_DEVICES` 로 가리면 창 생성에서 조용히 멈춘다. 마스터 14 컷이
> 전멸한 원인이 여기였다 (#438). 최종 렌더를 걸 때 같은 자리에서 또 멈추지
> 않도록 이 줄을 남긴다.

## 4. 트윈 구성

| 항목 | 값 |
|---|---|
| 재구성 대상 공간 | 스마트폰으로 찍은 실외 노면 (35.9 초 영상 한 편) |
| 방식 | **3DGS.** COLMAP 으로 SfM · Brush 로 스플랫 · 지면만 2.5D 메시로 |
| 물리 표현 | **렌더용 스플랫과 물리용 메시를 나눴다.** 스플랫은 충돌체가 아니라서 지면 메시를 따로 복원한다 |
| Isaac Sim 임포트 절차 | 충돌체는 USD · 배경은 NuRec USDZ. Windows Isaac Sim 5.1 에서 시스템 설치 없이 열린다 |
| 축척 | **미확정.** 노면 도색·연석을 법정 규격과 대조해 가설별 구간까지 냈다 (H1 k 0.986~1.134 · H3 1.184~1.512). 규격이 범위라 단일 k 가 안 나온다 |

## 5. 하지 않을 것

| 무엇 | 왜 |
|---|---|
| 학습에 기여하지 않는 렌더를 「성과」로 제시 | 렌더는 보여주기다. 학습 기여도는 0이다 |
| 로봇 렌더를 설명 없이 화면 채우기용으로 | 브랜드 규범: 로봇 렌더는 증거나 설명 요소로만 쓴다 |
| 축척 미확정인 복원물의 치수를 숫자로 인용 | k 가 가설별 «구간» 이다. 단일 값이 아니다 |
