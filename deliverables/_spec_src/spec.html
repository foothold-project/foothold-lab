2.산출물 개요

본 프로젝트는 정적 (Static) 데이터셋을 쓰는 지도학습과 달리, 물리 시뮬레이터 (Isaac Sim / Isaac Lab) 안에서 에이전트가 실시간으로 상호작용하며 데이터를 만드는 심층 강화학습 (Deep Reinforcement Learning) 연구입니다. 그래서 학습 과정에서 쌓인 정책 신경망 가중치 (.pt) 와 환경 설정 데이터 (.yaml) 를 최종 데이터 산출물로 제출합니다. 같은 파일이 프로젝트 저장소 에도 있습니다.

6.파일 검증 및 활용 방법

  1. 받기 · ZIP 안의 .pt 는 실제 가중치 파일이다. 프로젝트 저장소 에서 받을 때는 git LFS 로 저장돼 있어 아래 명령이 필요하다. git-lfs 없이 받으면 130 바이트 남짓한 포인터 파일만 생긴다. 
    git lfs pull --include "deliverables/FOOTHOLD_UnitreeGo2_RL_Data_Deliverable/**/*.pt"
  2. 무결성 · 각 .pt 의 sha256sum 값이 3 · 4 절 표와 model_manifest.json 의 sha256 과 같아야 한다 (예: sha256sum */model_*.pt).
  3. 로드 · PyTorch 로 읽는다. 저장본에 학습 재개용 상태 (최적화기 · 난수 · 커리큘럼) 도 들어 있어 weights_only=False 로 읽는다. 
    import torch
ckpt = torch.load("01_START_Baseline/model_15500.pt", map_location="cpu", weights_only=False)
policy = ckpt["model_state_dict"]          # actor · critic (actor 입력 98 · 출력 12)
perception = ckpt["perception_state_dict"] # 깊이 영상 → 높이 지도 복원 모듈

ame2 = torch.load("02_AME2_Reproduction/model_27000.pt", map_location="cpu", weights_only=False)
actor = ame2["actor_state_dict"]           # AME2GazeModel teacher (prop 49 · mapping 29x13x3 → 12)
critic = ame2["critic_state_dict"]         # MoE 16 전문가 가치 함수
state = ame2["go2_env_state"]              # 완료 회차 · 출발 저장본 · 커리큘럼 기록 (optimizer_state_dict 도 있음)
  4. 설정 읽기 · 두 config_*.yaml 은 YAML 문서 두 개다 (문서 1 = 학습기 · PPO · 망, 문서 2 = 환경 · 관측 · 행동 · 보상 · 종료 · 커리큘럼). Isaac Lab 이 남긴 !!python 태그가 있어 yaml.unsafe_load_all 로 읽는다. 파일 안의 경로는 학습 기계의 로컬 경로 기록이라 재현할 때 자기 경로로 바꾼다.
  5. 재현 (Play / Eval) · 같은 Isaac Lab 버전과 학습 코드 위에서 이 설정과 저장본으로 추론 모드를 돌리면 같은 보행을 재현한다. 산출물 1 은 FOOTHOLD 학습 코드 (과제 FootholdS2-Go2-S2-SB-v0) 위에서, 산출물 2 는 AME-2 공개 코드 와 FOOTHOLD Go2 코드 (과제 Ame2-Go2-Gaze-N9P12) 위에서 돌린다. 실기 Go2 (산출물 1) 와 앱 시뮬 (산출물 1 · 2) 에서는 같은 정책의 ONNX 를 쓴다.

이 문서의 원본은 ZIP 안의 README.md 이고, 프로젝트 저장소의 같은 폴더 에 같은 내용이 있다.
