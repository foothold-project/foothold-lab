## 제출 방법

운영진 안내 원문: *"아래와 같이 폴더를 구성하여 모든 폴더를 1개 파일로 압축하여 제출하며,
파일명은 「(트랙명_팀명)팀장이름」으로 변경하여 업로드"*

공식 폴더 이름은 한글이고 공백·마침표가 들어간다. 그대로 저장소에 두면 경로가 다루기
번거로워서, **저장소에는 영문 폴더로 두고 제출할 때 `make_zip.py` 가 공식 이름으로
바꿔 압축한다.** 사람이 이름을 고치면 잊지만 스크립트는 잊지 않는다.

| 저장소 | 제출 zip 안 |
|---|---|
| `01-plan/` | `1. 기획 및 분석/` |
| `03-build/` | `3. 구현/` |
| `04-done/` | `4. 완료/` |

`2. 설계` 는 빈 폴더로 넣지 않는다. 빈 폴더는 「안 했다」로 읽힌다.

## 상태를 어떻게 판정하나

각 파일 머리의 `> 상태:` 한 줄이 진실이다. 홈페이지 표지가 이 줄을 읽어 그린다.

| 표지 | 파일 상태 |
|---|---|
| 대기 | 아직 초안조차 없다 (DoD 만 적혀 있다) |
| 진행중 | `> 상태: 초안` 또는 `검토중` |
| 완료 | `> 상태: 확정` |

**무엇이 완료인지는 각 파일 안의 「완료 기준」이 정한다.** 그 기준을 보고 사람이
`확정` 으로 바꾼다. 기준이 파일 안에 있으므로 나중에 「이거 다 된 건가」를 물을 일이 없다.
