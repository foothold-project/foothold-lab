# docs/: 문서 작성 규칙

## 폴더

| 폴더 | 무엇 |
|---|---|
| `research/` | 자료조사 정제본 (원 출처 링크 필수) |
| `meetings/` | 회의록 (타임코드 인용) |
| 루트 | 기획·계획 문서 |

## 형식

- **Markdown.** 이미지·PDF 는 문서 옆에 같이 커밋한다 (100MB 미만이면 git 에 그냥 올려도 된다).
- 제목(h1) 은 파일당 하나. 날짜와 작성자를 머리에.
- 표를 아끼지 않는다. 목록보다 표가 빨리 읽힌다.

## 웹 자동 반영 (구축 중)

여기 올린 md 는 검증 게이트(민감정보 검사)를 거쳐 공개 사이트로 나가는
파이프라인이 붙을 예정이다. **공개되면 안 되는 문서는 `meetings/` 에 두거나
머리에 `<!-- private -->` 를 적는다.**
