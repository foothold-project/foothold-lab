**[Go2 X 실기] Jetson 실행기 설정 갈아 끼우기 · 리모컨 조작 정리 (11/25)**

1. runner.env 갈아 끼우기
- 아래 파일 내용을 그대로 Jetson `~/foothold-policy-1122/runner.env` 에 넣고 `chmod 600` 하세요. 비밀값은 없습니다.
- 그 뒤 Go2 를 껐다 켜면 자동으로 적용됩니다.
```
FH_GO2_DIRECT_ENABLED=1
FH_GO2_DIRECT_NIC=enP8p1s0
RUNNER_ARGS=--folder ../policy/start-m15500-app --mode off --nic enP8p1s0 --live --armed-by-remote --trace-dir ../trace --stop-mode sit --fwd-max 1.2 --status 5 --debug-est ../policy/start-m15500-debug-est
```
- 예시 원본: foothold-app `apps/agent/installer/policy-runner/runner.env.example`

2. 리모컨 (START C++ 실행기)

| 조합 | 하는 일 |
|---|---|
| 위 + start | 순정 → START 모드로 서기 |
| L2 + A | START 중 앉기 |
| L2 + A (앉은 상태) | 바로 서서 START 정책 (약 4 초) |
| L2 + B | 비상: 즉시 힘 빼기 |
| start + 왼쪽 / 오른쪽 | 앉은 뒤 순정 free walk / Classic 으로 넘김 |
| 아래 + start | AME-2 자리 (지금은 알림만) |

- 속도: 전진은 끝까지 밀면 1.2 m/s 이고 제곱 곡선이라 반만 밀면 0.3 입니다. 후진 1.3 · 옆 0.8 · 회전 1.5 rad/s.
- 자세한 값 (섞인 명령의 상한, 가감속): `apps/agent/runner_cpp/REMOTE.md`

3. 오늘 바뀐 것
- 앉은 상태에서 L2+A 를 누르면 접기 없이 바로 섭니다. 일어서는 중에 다시 눌러도 앉지 않습니다.
- Go2 를 켜면 C++ 실행기가 본체 선이 붙기를 기다렸다가 저절로 켜집니다 (약 19 초).
- 기록 상한이 4 GB 로 늘었습니다. 2 GB 가 넘으면 ai-lx01 이 자동으로 백업합니다.

5. Jetson 저수준 제어 공유 사항

**실행기**
- Go2 를 켜면 Jetson 의 C++ 실행기가 저절로 켜집니다. 본체 선 (enP8p1s0) 에 IP 가 잡힐 때까지 기다렸다가 약 19 초 뒤 준비됩니다. 실패하면 3 초 뒤 다시 시작합니다.
- 정책은 START m15500 (지도 끔) 입니다. 주기는 50 Hz, 제어는 200 Hz 입니다.
- 코어 나눔: 제어는 코어 4 (FIFO 40), 감각은 코어 5~7 (FIFO 30), 기록은 코어 0~3 입니다.

**환경 파일 runner.env**
- foothold-app `apps/agent/installer/policy-runner/runner.env.example` 을 Jetson `~/foothold-policy-1122/runner.env` 로 복사하고 chmod 600 합니다. 비밀값은 없습니다.

**리모컨 (정본 `apps/agent/runner_cpp/REMOTE.md`)**
- 위 + start: START 로 서기
- L2 + A: 앉기. 앉은 상태에서 다시 누르면 바로 섬 (약 4 초)
- L2 + B: 비상 힘 빼기
- start + 왼쪽 / 오른쪽: 순정 free walk / Classic 으로 넘김
- 속도: 전진 1.2 (제곱 곡선) · 후진 1.3 · 옆 0.8 · 회전 1.5

**앉기 · 서기**
- Classic 의 관절 궤적을 그대로 씁니다.
- 전환 게인은 Kp 60 · Kd 5 입니다. Kp 25 · Kd 0.5 에서는 앉다가 넘어졌습니다.
- 정책 게인은 Kp 25 · Kd 0.5 입니다.

**기록**
- 실행기는 50 Hz 로 관절 · 토크 · 온도 · 배터리 · 몸 높이 (h_kin) · 정책 속도 추정 (est_v) 을 남깁니다. 순정 모드 기록, 깊이, 유선 상태도 따로 남습니다.
- 기록 폴더 상한은 4 GB 입니다. 2 GB 가 넘으면 ai-lx01 이 10 분마다 자동으로 백업하고, 확인된 파일만 Jetson 의 보관 폴더로 옮깁니다. 지우지 않습니다.

**안전**
- 로봇이 켜진 동안 Jetson 에서 새 DDS 프로그램을 띄우지 않습니다. 11/24 에 이 때문에 본체 통신이 멈췄습니다.
- 실기 중에는 Jetson 파일을 읽기만 합니다.
- Go2 X 는 켠 채 충전할 수 없습니다. 배터리를 빼서 충전합니다.
- 넘어지면 실행기가 힘을 빼고 순정 RecoveryStand 로 넘깁니다.
