
📢 **자료 제출함(inbox)이 열렸습니다** (2026-08-12)

**한 줄: 이제 다듬지 말고 그냥 올리세요.**

`foothold-lab` 저장소에 **`inbox/`** 가 생겼습니다. 자기 이름 폴더에 올리면 됩니다.

```
inbox/
  meang/  맹라현
  oh/     오현민
  lim/    임석헌
  lee/    이민우
```

**규칙**
1. **자기 폴더에만** 씁니다. 남의 폴더를 안 건드리면 git 충돌이 아예 안 납니다.
2. 파일 맨 위에 **두 줄**을 답니다. 이 두 줄이 있어야 주간 다이제스트 자동 초안에 물립니다.
```
작성 2026-08-13
요지: 한 문장으로, 이 문서가 말하는 것
```
3. 파일 이름은 `YYYYMMDD-주제.md` 권장. **10MB 넘는 파일은 넣지 마세요**(알려주시면 처리합니다).
4. **여기 올린 것은 웹에 나가지 않습니다.** 공개 사이트로 가는 것은 `docs/` 뿐입니다.

**무엇을 올리나**
측정 로그, 실패 기록, 캡처, 참고 링크, 설치하다 막힌 지점, 회의 중 메모.
**정리 안 된 것일수록 여기가 맞습니다.** 정리해서 올리려다 안 올리는 게 제일 나쁩니다.

**그 다음**
팀장이 읽고 쓸 만한 것을 `docs/research/` 로 옮깁니다. 옮겨지면 **자동으로 공개 사이트에 실립니다.**
지금 8편이 그렇게 올라가 있습니다: <https://foothold-project.vercel.app/research.html>

**클론 안 받으신 분**
```
git clone https://github.com/foothold-project/foothold-lab.git
```
받기 어려우면 #foothold-general 에 파일을 올려주셔도 됩니다.

**주의**: 비밀번호·토큰·개인 연락처는 저장소에 적지 않습니다. 그건 #foothold-resource 로 갑니다.
