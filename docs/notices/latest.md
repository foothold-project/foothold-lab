
📢 **그동안 바뀐 것 모아서 한 번에** (2026-08-14)

며칠 사이 바뀐 것 중 **여러분이 직접 쓰게 되는 것들**만 정리했습니다.

**1. 이슈 템플릿이 훨씬 짧아졌습니다**
필수는 **큰 칸 하나 + 갈래 하나 클릭**뿐입니다. 나머지는 전부 선택이고 비워도 제출됩니다.
- lab: 작업 · 리서치 · 막힘/오류
- rl: 작업 · 실험 · 막힘/오류
막힘/오류는 **에러 메시지를 통째로 붙여넣기만** 하면 됩니다. 정리 안 해도 됩니다.

**2. 이슈를 만들 때 고르는 «갈래»가 5개로 바뀌었습니다**
```
평가 체계   통과율·자동 평가·기준선
험지 환경   지형 제작·3DGS
정책 학습   학습·보상·실험
실기 전이   sim2sim·ROS2·실기
운영        문서·회의·인프라·발표
```
고르면 해당 갈래의 부모 이슈에 **자동으로 매달립니다.** 애매하면 운영을 고르세요.
전에 있던 퀘스트 13개 목록은 없앴습니다. 너무 잘게 나뉘어 있었습니다.

**3. 마일스톤이 생겼습니다**
PoC(9/30) · MVP(10/31) · 중간보고(11/30) · 최종(12/11).
이슈 만들 때 해당하는 게 있으면 골라 주세요. 없으면 비워도 됩니다.

**4. 회의록 폴더가 생겼습니다** (`docs/meetings/`)
회의록은 **웹에 게시되지 않습니다.** 인용은 타임코드를 달아 주세요.

**5. 임석헌 님 문서가 웹에 실렸습니다** 🎉
inbox 에 올려주신 «Isaac Lab v2.3.2 지형 가이드»를 정본으로 승격해 게시했습니다.
<https://foothold-project.vercel.app/research-terrain-guide-isaaclab.html>

디스코드 알림과 검토 큐가 자동으로 만들어집니다. **묻히지 않습니다.**
