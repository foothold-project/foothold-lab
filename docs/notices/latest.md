
📢 **외부 GPU 샌드박스 사용 신청 완료** (2026-08-13)

학원 GPU 자원(V100)을 프로젝트용으로 신청했습니다. 배정되면 팀원 전원이 씁니다.

**신청 규모**
- GPU: 상시 8장, 실험 집중 기간 최대 16장
- Storage: 2Ti (팀 공유 볼륨 + 개인 작업 볼륨)
- 기간: 8월 중순 ~ 12월 최종 발표까지

**무엇에 쓰나**
1. 평가 대량 롤아웃: 난이도 10단계 × 지형 6종 × 100회 = 6,000회 이상을 병렬로
2. 정책 증류: Teacher(특권 정보 봄) → Student(실물 센서만 봄)
3. sim-to-sim 교차 검증: 다른 물리엔진에서도 걷는지
4. 3DGS 지형 재구성: 실제 험지를 스캔해 시뮬 지형으로

**알아두실 것 세 가지**
- 접속은 **교육장 네트워크에서만** 됩니다. 공인 IP 를 등록하는 방식이라 자택·테더링은 막힙니다.
- **데이터는 반드시 마운트한 볼륨에 저장하세요.** 컨테이너가 재시작되면 볼륨 밖 데이터는 복구가 안 됩니다.
- 계정과 접속 포트는 배정 후 **#foothold-resource** 에 올립니다. 저장소에는 적지 않습니다.
