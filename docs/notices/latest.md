**2) 금주 목표를 정합니다**

**3) 이슈 쓰는 법 · 자동화 지도**

**우리 자동화가 어떻게 도는지 한 장으로 정리했습니다.**
<https://claude.ai/code/artifact/c1cd2bdf-11c7-4d5d-940f-7c29d2df3096>

여러분이 올린 것이 어디로 가고, 무엇이 저절로 일어나고, 어디서 사람이 필요한지 색으로 구분해 두었습니다.

**기억하실 것은 이것뿐입니다.**

| 하고 싶은 것 | 하면 되는 것 |
| --- | --- |
| 무엇을 할지 알리고 싶다 | 이슈 → **작업** |
| 모르는 것이 있다 | 이슈 → **리서치** |
| 막혔다 | 이슈 → **막힘·오류** (에러 그대로 붙여넣기) |
| 결과물을 냈다 | `inbox/본인폴더/` 에 넣고 commit → PR |

**«리서치» 템플릿이 그동안 고장나 있었습니다.** 템플릿이 지정한 라벨이 저장소에 없어서 이슈 생성이 실패하고 있었습니다. 시도했다가 안 되셨던 분이 있다면 그 때문입니다. **오늘 고쳤습니다.**

**PR 템플릿도 새로 만들었습니다.** 무엇을 했나 · 왜 · 확인한 것 · 남은 것 네 칸입니다. 길게 안 쓰셔도 됩니다.
