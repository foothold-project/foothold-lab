
📢 **자료 제출함(inbox)이 열렸습니다** (2026-08-12)

**한 줄: 이제 다듬지 말고 그냥 올리세요.**

`foothold-lab` 저장소에 **`inbox/`** 가 생겼습니다. 자기 이름 폴더에 올리면 됩니다.

```
inbox/
  lim/    임석헌
  lee/    이민우
  meang/  맹라현
  oh/     오현민
```

**규칙은 세 줄입니다**
1. 자기 폴더에만 올립니다. 남의 폴더는 건드리지 않습니다. 그래야 충돌이 안 납니다.
2. 파일 이름은 `YYYYMMDD-주제.md` (예: `20260813-지형타일-측정메모.md`)
3. **여기 올린 것은 웹에 나가지 않습니다.** 공개 사이트로 가는 것은 `docs/` 뿐입니다.

**무엇을 올리나**
측정 로그, 실패 기록, 캡처, 참고 링크, 설치하다 막힌 지점, 회의 중 메모.
**정리 안 된 것일수록 여기가 맞습니다.** 정리해서 올리려다 안 올리는 게 제일 나쁩니다.

**그 다음**
팀장이 읽고 쓸 만한 것을 `docs/research/` 로 옮깁니다. 옮겨진 문서는 **자동으로 공개 사이트에 실립니다.**
지금 8편이 그렇게 올라가 있습니다: <https://foothold-project.vercel.app/research.html>

**클론 안 받으신 분**
```
git clone https://github.com/foothold-project/foothold-lab.git
```
받기 어려우면 파일을 #foothold-general 에 올려주셔도 됩니다. 제가 넣겠습니다.

**주의**
100MB 넘는 파일은 올리지 마세요(영상은 알려주시면 처리합니다).
비밀번호·토큰·개인 연락처는 저장소에 적지 않습니다. 그건 #foothold-resource 로 갑니다.

질문은 #foothold-general 로.
