📢 **자기소개, 각자 원하는 방식으로** (오늘 오후 3시 박철제 멘토님 미팅 전)

오늘 3시 멘토링에서 각자 본인 소개를 하기로 했습니다. **이건 팀 과제라기보다 각자가 자기를 어떻게 표현하고 싶은지의 문제입니다.** 형식도 분량도 정해두지 않았습니다. 본인이 담고 싶은 정보와 형태로 자유롭게 쓰세요.

**팀 페이지에 넣고 싶은 분만** 아래를 보시면 됩니다. 안 올려도 됩니다.

---

**1) 마크다운으로 쓰는 경우**

본인 inbox 폴더에 올려주세요. 파일 이름은 폴더 이름과 같게 합니다.

| 이름 | 올릴 곳 |
| --- | --- |
| 임석헌 | `inbox/lim/lim.md` |
| 맹라현 | `inbox/meang/meang.md` |
| 이민우 | `inbox/lee/lee.md` |
| 오현민 | `inbox/oh/oh.md` |

**2) 직접 사이트로 만든 경우**

HTML·CSS로 본인 페이지를 만들었다면 **그 파일들을 그대로** 본인 inbox 폴더에 넣어주세요. `index.html` 을 포함해 css·이미지까지 폴더 통째로 올리면 됩니다. **본인이 만든 모양 그대로 게시됩니다.** 저희 틀에 맞추려고 고치지 않아도 됩니다.

```
inbox/meang/
  index.html
  style.css
  images/...
```

**3) 반영되는 절차 (중요)**

파일을 올린 것만으로는 웹에 안 올라갑니다. **commit 후 PR을 올려주셔야 반영됩니다.**

```
git checkout -b intro/본인이름
git add inbox/본인폴더
git commit -m "intro: 자기소개 추가"
git push -u origin intro/본인이름
```

그리고 GitHub에서 **Pull Request 생성**. `main` 에 직접 push는 막혀 있습니다.

PR을 올리면 **자동으로** 이런 일이 일어납니다.

- 디스코드에 «새 제출» 알림이 뜨고, 팀장에게 텔레그램으로 바로 보고됩니다
- 기계가 파일을 먼저 읽어 **공개해도 되는지 검사**합니다
- 팀장이 확인 후 머지하면 웹에 반영됩니다

**4) 이것만 지켜주세요**

팀 페이지는 **공개 사이트**입니다. **전화번호·주소·주민번호 같은 개인정보는 넣지 마세요.** 자동 검사가 걸러내지만, 애초에 안 쓰는 게 맞습니다. GitHub 아이디, 블로그, 포트폴리오 링크는 괜찮습니다.
