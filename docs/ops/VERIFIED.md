## 발견한 결함 2건 — 그리고 교훈

### ① rl 워크플로가 등록만 되고 0회 실행 (08-07)
- Public 레포에서 Actions 첫 사용 시 **UI 의 Enable 버튼을 눌러야** 실제로 돈다.
- API 는 누르기 전에도 `enabled: true` 를 돌려줬다 — **API 상태와 실제 동작이 어긋날 수 있다.**
- 해소: 팀장이 Enable 클릭 → 즉시 정상.

### ② docs push 알림이 조용히 skip (08-08) — 세 번 만에 잡음
- 1차 원인: `git diff` — 러너에 저장소가 없어(checkout 안 함) 항상 빈 결과.
- 2차 수정(payload jq 파싱)도 실패 — 그런데 **건너뛰는 분기에 로그가 없어 이유를 볼 수 없었다.**
- 3차: GitHub API 로 커밋 파일 목록을 직접 조회 + **생략 사유를 항상 출력**하게 변경 → 통과.
- ★ 교훈: **조용히 건너뛰는 분기에는 반드시 이유를 출력한다. 침묵은 성공과 구별되지 않는다.**
