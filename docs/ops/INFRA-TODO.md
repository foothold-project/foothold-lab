## 1. NAS 회의 오디오 폴더

- [ ] UGREEN 공유폴더 `foothold/meetings/` 생성, 팀 계정 읽기/쓰기 권한
- [ ] 규칙: 파일명 `YYMMDD_제목.m4a` · 회의 직후 업로드
- [ ] (Phase 2) 워크스테이션이 이 폴더를 감시 → MOSS 전사 → lab `docs/meetings/` 보고서 자동 커밋

### 제안 폴더 구조

```
foothold/
├─ meetings/                 회의 원본 오디오
│   ├─ 2026-08/
│   │   ├─ 260806_멘토미팅.m4a
│   │   └─ 260813_조선대방문.m4a
│   └─ _transcripts/         전사 결과(txt·json) · 원본과 분리
├─ datasets/                 학습·평가 산출물 중 git 에 넣기엔 큰 것
│   ├─ checkpoints/          .pt (git LFS 한도를 넘는 것)
│   ├─ eval/                 평가 CSV·영상
│   └─ scans/                3DGS 스캔 원본
└─ media/                    렌더 결과·발표 소재
    ├─ renders/
    └─ reference/            타사 레퍼런스 영상 (저작권 주의, 배포 금지)
```

**왜 이렇게 나누나**
- `meetings/` 는 **원본 보존**이 목적이다. 전사본과 섞이면 원본을 덮어쓸 위험이 있다
- `datasets/` 는 git 에 넣으면 안 되는 크기다. lab 저장소는 **문서와 코드만** 둔다
- `media/reference/` 는 **타사 저작물**이라 공개 저장소·웹에 절대 올리지 않는다

### #foothold-resource 에 올릴 안내 문안 (초안)

> **📁 NAS 공유 폴더 열렸습니다**
>
> **접속**: Tailscale 로 NAS 에 붙은 뒤 SMB 로 `foothold` 공유폴더를 마운트합니다.
> (Tailscale 이 안 깔린 분은 이 채널에 알려주세요 · 초대 보내드립니다)
>
> **무엇을 어디에 두나**
> ```
> meetings/YYYY-MM/  회의 녹음 · 파일명 YYMMDD_제목.m4a, 회의 직후 업로드
> datasets/          체크포인트·평가 CSV·3DGS 스캔 (git 에 넣지 않는 큰 것)
> media/             렌더 결과·발표 소재
> ```
>
> **규칙 3개**
> 1. **문서와 코드는 NAS 가 아니라 GitHub 에.** NAS 는 «큰 것»과 «원본» 전용입니다
> 2. `media/reference/` 의 타사 영상은 **팀 내부 참고용**입니다. 공개 저장소·웹·발표자료에 그대로 넣지 마세요
> 3. **비밀번호·토큰은 이 채널에 올리지 않습니다.** Vaultwarden 개통 후 거기서 공유합니다
>
> ⚠️ NAS 는 백업이 아닙니다. 지우면 사라집니다. 중요한 산출물은 GitHub 에도 남기세요.

## 2. NAS Vaultwarden (팀 비밀 금고)

**무엇인가**: Bitwarden 서버의 가벼운 재구현. **우리 NAS 안에서 도는 팀 비밀번호 금고**다.
브라우저 확장·모바일 앱이 그대로 붙는다. 외부 서비스에 비밀을 맡기지 않아도 된다.

**왜 필요한가**: 지금 RunPod 계정·PAT·웹후크가 **디스코드 대화에 흩어져 있다.**
채팅은 검색되고, 나가는 사람이 생기면 회수가 안 되고, 화면 공유 중에 노출된다.

### 사전 확인 (여기서 막히면 계획을 바꿔야 한다)

- [ ] **UGREEN 모델이 Docker 를 지원하는가**: UGOS Pro 필요. 모델명으로 확인
- [ ] NAS 에 Tailscale 이 올라가 있는가 (`tailscale cert` 를 쓰려면 필요)
- [ ] NAS 의 Tailscale 도메인 이름 확인 (`<머신명>.<tailnet>.ts.net`)

### 개통 절차

**① 폴더와 컨테이너**
- [ ] NAS 에 데이터 폴더 생성 (예: `docker/vaultwarden/data`)
- [ ] Docker 앱 → 이미지 `vaultwarden/server:latest`
- [ ] 볼륨 매핑: 위 폴더 → 컨테이너 `/data`
- [ ] 포트: 컨테이너 `80` → 호스트 임의 포트 (예: `8100`)
- [ ] 재시작 정책: `unless-stopped`

**② HTTPS · 건너뛸 수 없다**
브라우저의 암호화 API(Web Crypto)는 **보안 컨텍스트에서만 동작한다.**
HTTP 로 열면 **로그인 자체가 안 된다.** 이건 설정 문제가 아니라 브라우저 규격이다.

- [ ] `tailscale cert <머신명>.<tailnet>.ts.net` 으로 인증서 발급
- [ ] 발급된 `.crt` / `.key` 를 컨테이너가 읽을 수 있는 위치에 두고 환경변수로 지정
      (`ROCKET_TLS={certs="...",key="..."}`) · 또는 NAS 의 리버스 프록시에 붙인다
- [ ] ⚠️ **인증서 갱신 주기 확인.** 만료되면 어느 날 갑자기 전원이 못 들어간다

**③ 계정과 잠금**
- [ ] 관리자 계정 생성 → **즉시** `SIGNUPS_ALLOWED=false` 로 잠근다
      (열어두면 tailnet 안 누구나 계정을 만든다)
- [ ] `ADMIN_TOKEN` 설정 · **이 값은 문서에 적지 않는다.** 발급 후 본인 금고에 먼저 저장
- [ ] 팀원 5명 초대 → 조직 생성 → 공유 컬렉션 `FOOTHOLD`

**④ 이관과 정리**
- [ ] RunPod 계정 · GitHub PAT · 디스코드 웹후크 URL · NAS 계정 → 등록
- [ ] **등록 확인 후 디스코드의 임시 공유분 삭제**
- [ ] **삭제만으로는 부족하다 · 노출됐던 토큰은 회전(재발급)한다.** 채팅 기록은 복구될 수 있다

### 검증 (개통했다고 끝이 아니다)

> 도구가 «성공»을 보고해도 결과가 아니다. **사용자 층위에서 확인한다.**

- [ ] 다른 기기(휴대폰)에서 **실제로 로그인**된다
- [ ] 브라우저 확장에서 항목이 **보이고 자동채움이 된다**
- [ ] 팀원 1명이 **초대를 받아 들어와 컬렉션을 읽는다**
- [ ] NAS 를 재부팅해도 컨테이너가 **자동으로 다시 뜬다**
- [ ] `/data` 폴더가 **NAS 백업 대상에 포함**돼 있다 · 여기가 날아가면 전부 잃는다
