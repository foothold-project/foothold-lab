## 세션 운영 규칙 (어느 세션이든 동일 적용)

1. **답변마다 어떤 전문가 관점인지 표기**한다.
2. **웹에 올리는 구조도는 ASCII 금지** — SVG·이미지·표로. (채팅·md 원문은 무방)
3. 방대한 요청은 **우선순위로 분류해 단계 진행**, 병렬 가능한 것은 병렬로.
4. 정보가 부족하면 **grilling(되묻기)** 한다. 추측으로 메우지 않는다.
5. **결정·발견은 즉시 이 문서에** 적는다. 채팅은 휘발이다.
6. 기술 답변은 **"7단계 지도의 어디인가"를 먼저 찍고** 시작한다 — 질문의 근원이 대부분 "전체 흐름을 모름"이기 때문 (팀장 자가진단 08-08).
