## 1. 목적과 합격 기준 (재확인)

- 문서가 늘어날수록 더 잘 찾아지게. 설계자 외의 사람도 쉽게.
- 화면의 주어는 문서가 아니라 상태다. **팀장에게 묻지 않고 다음 행동을 할 수 있는가.**
- 새 문서는 머리말만 갖추면 저절로 제자리에 선다.

## 2. 정보 구조 (확정 재확인)
