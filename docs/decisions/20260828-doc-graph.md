## 1. 왜 이 표를 만드나

지금 사이트에는 **묶음(허브)만 있고 관계가 없다.** 그래서 표지에 7개 절이 평평하게 놓이고,
그중 「길잡이」·「찾아보려면」은 **다른 절의 문서를 다시 가리키는 절**이라 같은 문서가 두 번 나온다.

층위가 서면 노출 기준이 저절로 나온다. **뿌리는 표지에, 하위는 상위 안에서.**

위 표에서 자동으로 나오는 규칙이다. 사람이 매번 고르지 않는다.

| 3 | 이번 주 새로 올라온 것 | 가변 |

특히 `QUESTIONS.md` 는 구판 `FLOW.md` 를 **7곳**에서 정답으로 가리킨다 `실측`.
