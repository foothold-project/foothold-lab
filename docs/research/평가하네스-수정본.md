## 결함 4건 - 왜 이것들이 위험한가

**넷 다 에러를 내지 않습니다.** 예외가 나거나 종료 코드가 0 이 아니면 다음 사람이
바로 알아챕니다. 이것들은 반대로 **스크립트가 끝까지 돌고, 종료 코드가 0 이고,
CSV 도 정상적으로 나오고, 숫자만 조용히 틀립니다.**

틀렸다는 것을 알아낼 계기가 스스로는 생기지 않습니다. 그래서 기록이 유일한
방어선입니다.

| 이슈 | 무엇이 틀렸나 | 왜 조용한가 | 고친 자리 |
|---|---|---|---|
| **#297** | `terrain_audit.py` 안에서 `AssertionError` 가 났는데 러너가 `exit=0` 을 반환했다. **검사에 실패한 지형으로 평가가 그대로 진행된다** | 게다가 `_app.close()` 가 stdout 버퍼를 버려서 **로그에 실패 흔적조차 안 남는다.** 사람이 로그를 열어 봐도 아무 일 없이 끝난 것으로 보인다 | `terrain_audit.py:293-305` flush 를 `close()` 앞으로 옮기고 `os._exit(2)`. `run_audits.sh:5` 는 종료코드에 더해 로그의 `[AUDIT] OK` 를 같이 본다 |
| **#298** | 픽셀 수를 `int()` 로 구했다. `int(0.075 / 0.025)` 는 3 이 아니라 `int(2.9999999999999996)` = **2** 다. 요청한 틈 7.5 cm 가 **5 cm 로 만들어져** 다른 조건과 같은 지형이 된다 | 스윕 표의 한 행이 조용히 사라지고 그 자리에 앞 행의 복제본이 앉는다. 높이 축도 같다 (`0.03 / 0.005 = 5.999…` 가 5 로 절단) | `terrain_cfg.py:417-419` · `:596`. `round` 로 픽셀 수를 먼저 정하고 `eps = hs * 1e-6` 을 더해 스냅. 수평 · 수직 양쪽 |
| **#299** | ① `horizontal_scale` 을 하위 cfg 에 전파하지 않아 hs = 0.025 로 **만든** 지형을 전부 hs = 0.1 로 **검사**했다. ② 검사기가 생성기 함수를 하드코딩해 커스텀 생성기를 원본으로 착각해 검사했다 | 검사기는 끝까지 돌고 「이상 없음」을 보고한다. 그 보고가 검사 대상이 아닌 것에 대한 보고다. **만든 지형과 검사한 지형이 달랐다** | `terrain_audit.py:80` 전파, `:114` `cfg.function` 을 따라감 |
| **#300** | `play_eval.py` 가 `--flat` `--mixed` `--mixed8` 셋만 받았다. 지형 cfg 이름이 코드에 박혀 있어 **새로 정의한 cfg 를 부를 방법이 없었다** | 틀린 숫자가 나오는 게 아니라 인계 문서에 적힌 명령이 애초에 실행 불가였다. 따라 한 사람은 지형이 안 바뀐 채 평가가 도는 것을 눈치채기 어렵다 | `play_eval.py:140-147` `--terrain_cfg NAME` · `DICT:key` 문법. 선택된 cfg 를 manifest 에 기록 |

## 무엇을 확인했나

**#298** `확인됨` 지형 감사 23조건 전부에서 요청 틈 = 실현 틈. 7.5 cm 가 격자 **3칸**으로
나옵니다. 수정 전에는 2칸(= 5 cm)이었습니다.

**#299** `확인됨` hs = 0.025 지형에서 틈 2.5 / 5 / 7.5 cm 가 검사 보고에 **그 값으로**
나옵니다. 수정 전에는 전부 「틈 0」으로 나왔습니다.

**#300** `확인됨` `--terrain_cfg FLAT_GAP_SWEEP:flat025` 형태로 23런을 실제로 돌렸고
`manifest.json` 에 `terrain_cfg` 가 남는 것을 확인했습니다.

**#297** `미측정` 러너가 검사 실패에서 실제로 멈추는지는 아직 안 재봤습니다. 아래 참조.

## 경로를 어떻게 가렸나

Pod 볼륨 절대경로와 계정명이 코드에 박혀 있어서 환경변수로 뺐습니다.

| 무엇 | 어떻게 |
|---|---|
| 셸 러너 4개 | `VOL="${VOL:-/data/$USER}"`. 기본값이 계정명을 안 박습니다 |
| `analysis/` 표 생성기 3개 | `GAP_OUT` 환경변수. 미지정이면 무엇을 지정해야 하는지 한 줄로 알리고 멈춥니다 |
| `analysis/stride.py` | `STRIDE_OUT` |
| `terrain_audit.py` · `analysis/verify_alt.py` 의 `sys.path.insert` | 러너가 항상 `cd <볼륨>/isaaclab` 후 실행하므로 상대경로로. **동작 동일** |
| `play_eval.py` 의 주석 · 도움말 | `<볼륨>` · `<사용자ID>` placeholder |
| `run_pipeline.sh` 가 형제 러너를 부르는 자리 | `$(dirname "$0")` 기준 |

`chain.sh` 는 `run_pipeline.sh` 로 이름을 바꿨습니다. 나머지 러너 셋이 전부 `run_*`
이고 "chain" 이 무엇을 잇는지 이름만으로 알 수 없어서입니다. 부르는 곳은 없었습니다.
옛 이름은 `HARNESS.md` 에 병기했습니다.
