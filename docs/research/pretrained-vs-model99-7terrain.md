# NVIDIA Pretrained vs Model99: 난이도 0.50~0.70 7종 지형 성능 비교 보고서

> Baseline: `nvidia_pretrained.pt`  
> 비교 모델: `0905_nvidia_gap_v1_seed42_iter100/model_99.pt`

## 1. 결론

**Model99는 Gap을 유의미하게 학습했고, 기존 6종 지형의 평균 성공률도 하락하지 않았다.** 전체 Gap 성공률은 **37.33% → 88.17%(+50.83%p)**, 기존 6종 성공률은 **83.69% → 94.97%(+11.28%p)**였다. 두 개선 모두 Fisher의 정확검정에서 `p < 0.001`이다.

따라서 model99는 현재 최선 체크포인트로 채택할 수 있다. 다만 같은 설정으로 장기간 무제한 추가학습하는 판단은 보류한다. 계단 상승에서 충돌·수직 운동·행동 변화가 커졌고, 경사 하강의 착지 충격도 증가했기 때문이다. **동일 설정으로 50 iteration만 통제 연장하고 25 iteration마다 검증**하는 것이 적절하다.

## 2. Model99 추가학습 설정

Model99는 처음부터 새로 학습한 모델이 아니라 **NVIDIA pretrained checkpoint를 시작 정책으로 불러와 100 iterations 추가학습한 체크포인트**다. 본 보고서의 비교는 따라서 `NVIDIA pretrained 원본` 대 `Gap 지형을 포함해 100 iterations fine-tuning한 model99`의 비교다.

### 2.1 변경한 항목

| 항목 | Model99 추가학습 설정 |
|---|---|
| 시작 정책 | NVIDIA pretrained checkpoint |
| 학습 반복 | `100 iterations` |
| 저장 간격 | `25 iterations` |
| 학습률 | `1.0e-4` |
| 환경 수 / seed | `4096` / `42` |
| 전진 속도 명령 | `0.5~1.5 m/s` |
| 횟방향 / 회전 명령 | `0` / `0` |
| 지형 비율 | 기존 6종 `90%`, Gap `10%` |
| Gap 폭 | `0.05~0.20 m` |
| Gap 아래 바닥 | 없음 |
| 초기 최대 지형 레벨 | `2` |
| Height scan ray miss | `+1.0`으로 보정 |
| 추락 종료 | base가 타일 원점보다 `2 m` 아래로 내려갈 때 |
| 초기 위치 오차 | X `±0.10 m`, Y `±0.20 m` |
| 초기 방향 오차 | Yaw `±0.05 rad` |

### 2.2 그대로 유지한 항목

| 유지 항목 | 설정 |
|---|---|
| 관측·행동 | 차원과 순서 유지 |
| 신경망 | `[512, 256, 128]` 유지 |
| 보상 | 기존 NVIDIA 보상 함수와 가중치 유지 |
| 관절·action | 관절 순서와 action scale 유지 |

즉, 성능 변화를 신경망 확장이나 보상 함수 교체의 결과로 보기 어렵다. 주요 차이는 **Gap 10%를 포함한 지형 노출, 0.5~1.5 m/s 전진 명령, 낮은 학습률 1.0e-4의 짧은 fine-tuning**이다. 기존 6종을 90% 유지한 구성은 Gap을 학습하면서 원래 보행 능력을 보존하는 rehearsal 역할을 한 것으로 해석할 수 있다.

## 3. 평가 설계와 비교 가능성

| 항목 | Short | Corridor |
|---|---:|---:|
| 지형 크기 | 8×8 m | 24×8 m |
| 목표 거리 | 3 m | 15 m |
| 명령 속도 | 1.0 m/s | 1.0 m/s |
| 제한 시간 | 20 s | 20 s |
| Gap 개수 | 1 | 5 (2, 5, 8, 11, 14 m) |
| 반복 | 모델·지형·난이도별 100회 | 모델·지형·난이도별 100회 |

총 표본은 모델당 4,200회, 합계 8,400회다. 난이도는 0.50/0.60/0.70이고 Gap 폭은 각각 12.5/14.0/15.5 cm, 계단 단차는 14.0/15.8/17.6 cm다. 시작 상태 분포는 모든 프로토콜·난이도에서 KS 검정 `p ≥ 0.70`으로 확인되어 두 모델 간 조건 불균형의 증거가 없다.

> 통계 방법: 성공·낙상·시간초과·정체는 독립표본 양측 Fisher 정확검정, 연속형 지표는 양측 Mann–Whitney U 검정. 동일 난수 조건이더라도 에피소드별 완전한 쌍 대응 키가 없어 보수적으로 독립표본 검정을 사용했다.

## 4. 핵심 성능

| 평가 묶음 | Baseline | Model99 | 변화 | p-value |
|---|---:|---:|---:|---:|
| Short Gap | 66.00% | 99.33% | +33.33%p | <0.001 |
| Corridor Gap | 8.67% | 77.00% | +68.33%p | <0.001 |
| 전체 Gap | 37.33% | 88.17% | +50.83%p | <0.001 |
| Short 기존 6종 | 92.28% | 99.67% | +7.39%p | <0.001 |
| Corridor 기존 6종 | 75.11% | 90.28% | +15.17%p | <0.001 |
| 전체 기존 6종 | 83.69% | 94.97% | +11.28%p | <0.001 |

채택 기준인 “기존 6종 평균 성공률 하락 5%p 이내 + 학습 범위 Gap 성공률 상승”을 넉넉히 충족한다. 기존 6종은 하락하지 않고 오히려 11.28%p 상승했으며, Gap은 50.83%p 상승했다.

## 5. Gap 학습 분석

| 프로토콜 | 난이도 | Gap 폭 | Baseline | Model99 | 변화 |
|---|---:|---:|---:|---:|---:|
| Short | 0.50 | 12.5 cm | 65% | 98% | +33%p |
| Short | 0.60 | 14.0 cm | 73% | 100% | +27%p |
| Short | 0.70 | 15.5 cm | 60% | 100% | +40%p |
| Corridor | 0.50 | 12.5 cm | 14% | 73% | +59%p |
| Corridor | 0.60 | 14.0 cm | 8% | 77% | +69%p |
| Corridor | 0.70 | 15.5 cm | 4% | 81% | +77%p |

Model99의 Corridor Gap 성공률 73/77/81% 사이에는 유의한 난이도 차이가 검출되지 않았다(`p=0.62/0.24/0.60`). 즉 15.5 cm에서 붕괴하지 않았고, 5개 Gap을 반복 통과하는 능력까지 학습했다.

전체 Gap에서 낙상은 22.67%→4.00%, 시간초과는 40.00%→7.83%, 정체는 45.33%→9.33%로 감소했다. 속도추종 RMSE는 0.594→0.291 m/s, 최대 정체시간은 5.45→1.13 s, 몸체충돌률은 2.082→0.625회/s로 개선됐다. 평균 발 클리어런스는 4.86→6.42 cm로 증가했다.

평균 착지 충격은 51.91→55.80 N(+7.5%)로 소폭 증가했으나 최대 충격은 184.15→156.13 N(-15.2%)로 감소했다. 따라서 Gap에서는 점프가 전반적으로 더 성공적이고 극단적 충격도 줄었지만, 평균 충격의 상승은 계속 감시할 필요가 있다.

## 6. 기존 6종 보존 여부

| 프로토콜·지형 | Baseline | Model99 | 해석 |
|---|---:|---:|---|
| Short 계단 상승 | 55.67% | 99.00% | 정체 48.67%→1.67%, 가장 큰 개선 |
| Short 계단 하강 | 100.00% | 99.33% | -0.67%p, 통계적으로 유의하지 않음 |
| Corridor 계단 상승 | 0.00% | 44.33% | 큰 개선이나 절대 성능은 아직 부족 |
| Corridor 계단 하강 | 62.33% | 98.00% | +35.67%p, 시간초과 제거 |
| Corridor Boxes | 88.33% | 99.33% | +11.00%p |
| 경사 상승·하강, Rough | 100% | 100% | 성공률 유지 |

기존 6종 전체에서 낙상 4.22%→1.42%, 시간초과 12.08%→3.61%, 정체 7.72%→2.42%로 모두 개선됐다. 속도추종 RMSE도 0.265→0.188 m/s로 낮아졌다. **과제 성공률 관점의 catastrophic forgetting은 없다.**

다만 Corridor 계단 상승은 난이도 0.50/0.60/0.70에서 Model99 성공률이 81/36/16%다. 30개 안팎의 긴 계단과 17.6 cm 단차 조합에서는 여전히 실패가 집중되므로, “계단 상승 문제 해결 완료”로 해석하면 안 된다.

## 7. 성능 향상의 비용과 위험

- 계단 상승에서 더 공격적인 동작이 나타났다. Short의 수직속도 RMS +55.9%, 미끄러짐 +47.6%, 발 충돌률 +21.6%, 행동 변화량 +50.1%; Corridor의 발 충돌률 +84.8%, 몸체 충돌률 +56.1%, 행동 변화량 +30.9%다.
- 경사 하강의 충격이 증가했다. Short 평균/최대 착지 충격은 +10.5%/+23.2%, Corridor는 +33.3%/+46.0%다. 성공률과 자세 RMS는 좋아졌지만 sim-to-real 안전성에는 불리할 수 있다.
- 기존 6종 전체 몸체충돌률은 0.802→0.932회/s(+16.3%)였으나 Mann–Whitney 검정 `p=0.078`로 5% 수준에서 유의하지 않았다. 다만 지형별 악화와 함께 보수적으로 감시해야 한다.

## 8. 종합 판정 및 다음 학습

**판정: 조건부 계속(Go), model99 채택.** Gap 학습은 명백히 유의미하며 기존 6종 성능도 보존됐다. 그러나 동일 정책을 그대로 장기간 진행하면 계단 상승의 충돌성 gait와 경사 하강 충격이 더 커질 가능성이 있다.

권장 실행안:

1. Model99에서 동일 설정으로 **50 iteration만** 추가학습한다.
2. `iter 125`, `iter 150`을 저장해 매번 동일 평가를 수행한다.
3. 현재 seed 42에서 학습·평가가 모두 이루어졌으므로 최종 채택 전 seed 43/44/45로 재평가한다.
4. 아래 기준을 처음 위반하면 추가학습을 중단하고 직전 체크포인트를 채택한다.

| 지표 | 계속/채택 기준 |
|---|---:|
| Short Gap 성공률 | ≥ 98% |
| Corridor Gap 성공률 | ≥ 80% |
| Short 기존 6종 성공률 | ≥ 98% |
| Corridor 기존 6종 성공률 | ≥ 88% |
| Corridor 계단 상승 성공률 | ≥ 50% |
| 계단 하강 성공률 | ≥ 95% |
| Corridor Gap 낙상률 | ≤ 8% |
| Corridor 경사 하강 최대 착지 충격 | ≤ 275 N |
| 계단 상승 발·몸체 충돌률 | model99 대비 10% 초과 악화 금지 |

50 iteration 후 Gap이 정체되고 충격·충돌만 증가한다면, 추가 iteration이 아니라 별도 ablation으로 전환해야 한다. 우선순위는 ① 경사 하강 착지 충격 완화, ② 계단 상승 발/몸체 충돌 억제, ③ Corridor 계단 상승 난이도 커리큘럼이다.

## 9. 해석 한계

- 모든 결과는 seed 42 한 개에서 측정됐다. 에피소드 수가 많아 에피소드 수준 차이는 잘 검출되지만, 학습 seed 간 변동성은 아직 검증되지 않았다.
- 동일한 100개 초기조건을 사용했더라도 현재 CSV에 완전한 pair ID가 없어 독립표본 검정을 적용했다.
- 성공률은 시뮬레이션 내 과제 달성을 의미한다. 특히 17.6 cm 계단과 증가한 착지 충격은 실제 Go2의 물리 한계·충격 내구성·접촉 모델 오차를 별도로 검증해야 한다.

## 10. 최종 요약

Model99는 **Gap 성공 +50.83%p**, **기존 6종 성공 +11.28%p**로 목표를 달성했다. 따라서 현재 모델을 폐기하거나 원본 체크포인트로 돌아갈 이유는 없다. 다만 개선 방식이 일부 지형에서 더 공격적인 gait를 동반했으므로, 다음 단계는 “더 오래 학습”이 아니라 **짧은 통제 연장 + 체크포인트별 안전 지표 검증**이어야 한다.
