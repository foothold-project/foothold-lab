# 8/13 운영 미팅: 기획과 제시안이 갈라진 날

> 2026-08-13 · 조선대 멘토 · 운영진 조율. 팀 브리프.
> 원본: `조선대멘토_운영진조율_회의록_260813`. 같은 날 현장 확인 목록은 [8/13 조선대 방문](../FIELD-CHECK-0813.md)이다. 이 페이지는 조율에서 확정한 것만 담는다.

당일 팀 기획(미경험 험지 · Isaac/체크포인트 · 시뮬 MVP · SLAM 비메인)과 제시안(ROS → 매핑 → Nav2 · 험지 보행 배제 · 내장 보행 + 자율주행)이 갈렸다. 주제는 팀이 정하고, 험지·시뮬 역제안이 가능하다는 전제에서 아래를 고정했다.

| 항목 | 내용 | 지위 |

| 멘토링 | 주 2~3시간. 제공 경로는 ROS·SLAM 정석 | 확인됨 |
| 권한 | 주제는 팀 결정. 험지·시뮬 역제안 가능 | 확인됨 |

## 하지 말 것 (당일)

- Edu에 커스텀 RL 정책을 이식하지 않는다
- SLAM·Nav2를 12월 메인 산출물로 두지 않는다 (8/19 이후 트랙 B로 재배치)
- 실기 주 2~3시간을 개발 시간으로 쓰지 않는다
- B안을 사양 확인 전에 확정하지 않는다
