## 중요하고 급함

- Unitree·NVIDIA 사전학습 checkpoint 재현
- 커스텀 험지에서 오픈소스 대비 미세조정 성능 비교
- 학습 지형과 평가 지형 분리, 미경험 지형 정량 평가
- Go2 정책 배포 경로 확인 (API·제어 모드)

보행을 0부터 학습하지 않는다. 산출물은 재현 영상과 수행계획서다.

## 중요하지만 급하지 않음

- 마찰·질량은 한 변수씩 변경
- 시뮬에서 실기로 이전 (평지부터). **8/19 이후 저수준 실기 이전은 폐기** `확인됨`
- LiDAR · SLAM 오픈소스 스택
- Nav2 cmd_vel과 보행 정책 연동
- 성공 기준 사전 정의

## 하지 않음

- Nav2 이론 학습에 기간을 과도하게 배정
- 멘토 커리큘럼을 그대로 따라 과제 중심을 변경
- 기능 수로 완성도를 판단
- 초기부터 험지 시연을 목표로 설정
- 보행 정책을 처음부터 신규 학습
- 공개 예제 실행만으로 종료
- 보행·실기·항법을 동일 비중으로 완성
- 종료 직전 신규 기능 추가
- 디지털 트윈·카메라 기능 확장. **8/19 이후 트랙 A에 디지털 트윈 시각화가 들어갔다** `확인됨`

## 성공 등급 (8/18 원문)

| 등급 | 뜻 |
|---|---|
| C · 과제 성립 | 커스텀 험지 + 오픈소스(필요 시 fine-tune) + 미경험 지형 성공률·낙상률 |
| B · 이전 | C + 조건 변화 + 실기 Go2 배포(평지부터). 저수준 배포는 이후 폐기 |
| A · 목적지 | B + SLAM/Nav2로 미경험 험지에서 목적지까지 이동 |

성공 = 지정 거리 도달 · 낙상 없음. 통과율 = 성공 / 시행. 지형명·시드·시행 수를 표에 고정한다.
