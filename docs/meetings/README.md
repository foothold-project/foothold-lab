# meetings: 회의록

웹 길잡이(Meeting · 회의)에 실리는 원본은 이 폴더의 `YYYYMMDD-영문slug.md`다.
제목은 `# M/D 종류: 한 줄 요약`이고, 머리 인용에 날짜·참석·원본을 적는다.
같은 날짜의 같은 회의는 파일을 늘리지 않고, 없는 내용만 그 파일에 보탠다.

## 이 폴더는 기본적으로 비공개다

회의록에는 아직 정리되지 않은 판단, 사람 이야기, 외부 관계자 언급이 섞인다.
공개할 회차는 **이미 올라간 8/20·8/21처럼** `YYYYMMDD-slug.md` 한 페이지로 정리한다.
금액·개인 식별이 남는 줄은 넣지 않는다.

## 파일명 · 제목

| 종류 | 파일 | 제목 예 |
|---|---|---|
| 운영·협력 | `YYYYMMDD-짧은영문.md` | `# 8/20 운영 미팅: 전담 현직자 멘토 투입 확정` |
| 팀 미팅 | 같음 | `# 8/21 팀 미팅: 역할 그룹핑 확정, 클라우드 운용 개시` |
| 멘토링 | 같음 | `# 8/24 멘토링: 본 과제와 CAD 학습은 분리한다` |

HTML·PDF 인쇄본은 새로 만들지 않는다. 정본은 md다.

## 형식

- 머리에 **날짜 · 참석자 · 원본·녹음 여부**를 적는다.
- 확정은 표로. 직접 확인한 줄에는 `확인됨`, 아직이면 `미확인`.
- 인용은 **타임코드**를 단다. 예: `(12:34) "선 긋지 말고"`
- 결정이 나오면 그 자리에서 `docs/DECISIONS.md` 에 한 줄 옮긴다.

## 원본 음성·전사

원본은 저장소에 넣지 않는다. NAS 회의 폴더에 둔다(경로는 #foothold-resource).
