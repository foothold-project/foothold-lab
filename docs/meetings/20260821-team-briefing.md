# 8/21 팀 미팅 브리핑: 오늘 정할 것 다섯 가지

> 2026-08-21 오전 팀 미팅 안건 정리 (WS 사전 브리핑). 근거는 8/20 두 회의 전사와 실측 기록.

## 1. 멘토 세션 시간대: 오후안으로 확정 제안

멘토 본인이 오후안을 제시했다: 오전~15시는 팀 작업, **15~18시 멘토 세션**. 오전 코어타임(집중 작업)을 지키는 구조라 팀에도 유리하다. 오늘 확정해 멘토·PM에 회신한다.

## 2. 로보틱스 강의: 희망자 구조(opt-in) 제안

멘토도 강제를 전제하지 않았다. 제안 구조:

- **15~16시: 이론 강의 (희망자)** : 안 듣는 사람은 그 시간 프로젝트 계속
- **16~18시: 프로젝트 점검·개별 멘토링 (전원)**
- 중간발표 2주 전부터 강의 축소(라이트 모드) 옵션을 미리 합의
- 멘토께 요청: 강의 예시를 우리 프로젝트 소재로 (Go2 관절 기구학, 관측 벡터의 물리적 의미)

## 3. 컴퓨팅: Runpod 파일럿 충전

- 배경: 팀원 개인 장비로는 Isaac Sim 구동 불가. GIST 샌드박스는 V100이라 Isaac Sim 계열이 돌지 않는다.
- **임석헌이 이미 Runpod 헤드리스로 일반화 벤치마크를 완주** : 파이프라인이 클라우드에서 도는 것은 실증됨. → [일반화 벤치마크 보고서](../research/generalization-benchmark-10-terrains.md)
- 현황: **Runpod 팀 계정 가동 실적 있음** (팀장 소유). 첫 실측 단가: IsaacLab 템플릿 $0.74/hr, 벤치마크 작업일 하루 청구 약 $5. 유휴 팟은 Terminate로 정리(정지 상태도 디스크 과금).
- 제안: 사용량 확인 → 소액 파일럿 추가 충전 → 1주 실측 → 본충전 규모 결정. 수요자 중심(지형·씬 작업 우선).
