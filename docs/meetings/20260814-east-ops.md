# 8/14 운영 미팅: 이스트는 ROS2·인프라, 멘토는 인사이트

> 2026-08-14 · 이스트 / 운영 미팅. 장소 이스트. 어제 조선대 OT·조율 후속.
> **확정값은 운영 재확인**이 남아 있다. 연계: [8/13 운영 미팅](20260813-ops-alignment.md).

## 그날 무슨 일이었나

어제 조선대에서 기획과 제시안이 갈린 다음 날, 이스트 창구와 멘토 라인을 한 테이블에 올려 역할을 나눴다. 질문은 「지원을 어디서 받고, 멘토는 누구 라인인가」였다.

이스트가 맡는 축은 **ROS2 교육과 인프라**로 고정했다. Win 물리서버, GPU 두 장(RTX 2000), 컨테이너 GPU 사용 가능 여부는 아직 확인 전이다. 자율주행·SLAM을 이스트 교육 트랙에 넣지 않는다. 그건 별도 인력 트랙이다.

멘토 전담은 이스트 인프라 라인에만 기대지 않는다. **인사이트(김유진) 계열**로 보강하고, 구이사 가이드를 체크한 뒤 담당 강사 배치를 요청한다. 교육은 팀이 진행하되 난이도를 조율하고, 전담강사 코드 리뷰를 넣는다. 전담강사 없이 팀만으로 코드 리뷰를 닫지 않는다.

범위 조정안은 유지한다. 일정을 맞추려고 범위를 줄이지 않는다. 일정만 늘리고 목표를 방치하지도 않는다. 프로세스는 **목표 설정(제안서·범위 유지) → 스케줄링(ROS2 1~2개월 → 실기 3~4개월, 시뮬 포함) → 구체 로드맵(10~12월 테스트 · 영상 시연)**이다.

10월 축은 ROS2 학습 다음에 로봇 구현과 영상 시연이다. 산출물도 그 영상 시연으로 잡았다.

## 하드웨어·SDK : 아직 물어봐야 하는 것

교육용 SDK가 하드웨어에 붙어 있는지, 발표 때 로봇을 반출할 수 있는지는 유진님께 다시 묻는다. SDK를 확인하기 전에 발표 반출을 가정하지 않는다. Cmd 코드 스위치 on/off도 같이 본다.

GPU를 확인하기 전에 시뮬 일정을 확정하지 않는다. 이스트 컨테이너 GPU와 Win 물리서버 RTX 2000×2를 금주에 확인한다.

조선대 트랙과 역할은 어제 OT 후속으로 다시 정렬한다.

## 그날 고정한 것

| # | 내용 |
|---|---|
| 1 | 이스트 지원 축 = ROS2 교육 · 인프라 (Win 물리서버) |
| 2 | 멘토 전담 = 인사이트(김유진) 계열. 구이사 가이드 체크 후 강사 배정 |
| 3 | 범위 조정안 유지. 일정만 목표 → 스케줄 → 로드맵으로 푼다 |
| 4 | 10월 축: ROS2 학습 → 로봇 구현 · 영상 시연 |
| 5 | 자율주행·SLAM은 별도 인력 트랙. 이스트 교육에 넣지 않는다 |
| 6 | 교육 = 팀 진행 + 난이도 조율 + 전담강사 코드 리뷰 |

## 지키면 되는 것 · 늦으면

범위는 유지한다. 이스트는 ROS2와 인프라, 멘토는 인사이트, 10월은 영상 시연이다.

늦어도 SLAM을 이스트에 넣지 않는다. GPU·SDK가 늦어도 제안서 방향은 유지한다. 교육 난이도를 확인 없이 고정하지 않는다.

사슬: 제안서 확인 → 내부 정렬 → 목표 · 스케줄 · 로드맵 → 강사 · GPU · SDK.

## 바로 할 일

당일: 제안서 방향·범위를 확인한 뒤 이어서 논의한다.

금주: 내부 정렬이 필요한 항목을 재논의하고, 인사이트 담당 강사 배치를 요청하고, 컨테이너 GPU와 Win/RTX 2000×2를 확인한다.

차주: 목표 → 스케줄 → 로드맵 초안. SDK 하드웨어 부착 여부와 발표 반출을 유진님께 재확인한다.

8/20에 전담 현직자 멘토가 확정되면서 멘토 축은 다시 갱신된다. 이 날의 「인사이트 계열 보강」은 그 전 단계의 운영 합의로 읽으면 된다.
