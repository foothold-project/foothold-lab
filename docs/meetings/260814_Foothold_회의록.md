# 8/14 Foothold 회의록: 이스트 운영 조율

> 2026-08-14 · 이스트 / 운영 미팅 · 어제(조선대 OT) 후속.
> 인쇄본: [Foothold 회의록_260814.pdf](./Foothold_회의록_260814.pdf) (`docs/meetings/print/` 한 페이지 디자인)

오늘 초점: **이스트 지원 = ROS2·인프라. 멘토는 인사이트 계열.**

## 프로세스

목표 설정 (제안서 · 범위 유지) → 스케줄링 (ROS2 1~2개월 → 실기 3~4개월) → 구체 로드맵 (10~12월 테스트 · 영상 시연)

## 확정

- 이스트 지원 축은 ROS2 교육과 인프라다.
- 멘토 전담은 인사이트(김유진) 계열로 보강한다. 구이사 가이드를 체크한다.
- 범위 조정안은 유지한다. 일정만 목표 → 스케줄 → 로드맵으로 푼다.
- 10월 축: ROS2 학습 → 로봇 구현 · 영상 시연.

## 인프라 · 교육

- Win 물리서버 · GPU×2(RTX 2000) · 이스트 활용. 컨테이너 GPU 확인.
- 교육용 SDK 하드웨어 부착 여부 · 발표 반출 가능 여부를 유진님께 재확인.
- Cmd 코드 스위치 on/off 확인.
- 교육은 팀 진행 + 난이도 조율. 전담강사 코드 리뷰.
- 자율주행·SLAM은 별도 인력 트랙이다. 이스트 교육 트랙에 넣지 않는다.

## 하지 않음

- 범위를 줄여 일정을 맞추기
- 멘토를 이스트 인프라 라인에만 의존
- SDK 확인 없이 발표 반출 가정
- GPU 미확인 상태로 시뮬 일정 확정
