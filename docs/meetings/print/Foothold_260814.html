NOTES

1 이스트 지원 축은 ROS2 교육과 인프라다. 멘토 전담은 인사이트(김유진) 계열로 보강한다. 구이사 가이드를 체크한다.

2 일정: ROS2 1~2개월 → 실기 3~4개월(+시뮬) → 10~12월 테스트. 10월 축은 ROS2 학습 후 로봇 구현·영상 시연.

3 교육용 SDK 하드웨어 부착 여부와 발표 반출 가능 여부를 유진님께 재확인한다. Cmd 스위치 on/off도 같이 본다.

4 교육은 팀 진행 + 난이도 조율. 전담강사 코드 리뷰. 자율주행·SLAM은 별도 인력 트랙이다.
