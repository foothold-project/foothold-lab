## 실행 절차 (윈도우 기준)

```
export KMP_DUPLICATE_LIB_OK=TRUE
export OMNI_KIT_ACCEPT_EULA=YES
C:/Users/AI-WS01/anaconda3/envs/isaac311/python.exe <스크립트>
```

`conda activate isaac311` 만으로는 안 된다. `isaaclab.bat` 은 base 파이썬을 써서
`tensordict` 가 없다고 죽는다. KMP 를 빼면 `libiomp5md.dll` 중복 초기화로 죽고,
EULA 를 빼면 동의 프롬프트에서 멈춘다. 임석헌이 확인해 알려 준 절차다.
