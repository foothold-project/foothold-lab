# 조사 의뢰 · 에이전트 코딩에서 「컨텍스트 관리」를 지금 사람들이 어떻게 하는가

산출: inbox/jay/20260923-lineage/RESEARCH-context-codex.md 한 파일

## 배경 (우리 상황)

- Claude Code / Codex CLI 같은 에이전트로 며칠짜리 연구 작업을 돌린다
- 문제: 대화가 길어지면 자동 compact 가 일어나 세부가 사라진다
- 팀장 요구: 자동 compact 말고 «작업 단위로 수동 관리» 하고 싶다
- 이미 한 대응: 상태를 저장소 파일로 빼서 세션 의존을 줄였다
- 그래도 남는 본질 문제: 한 세션 «안에서» 컨텍스트를 어떻게 관리하나

## 조사할 것

1. 2026 년 기준으로 실제 쓰이는 컨텍스트 관리 기법은 무엇인가
   - 이름이 붙은 기법 (예: context engineering, memory compaction,
     sub-agent offloading, scratchpad, RAG-over-transcript 등)
   - 각각 «무엇을 해결하고 무엇을 못 하는지»
2. Anthropic / OpenAI 공식 문서나 엔지니어링 블로그가 권하는 방법
3. 실제 개발자들이 쓰는 구체적 습관
   (CLAUDE.md / AGENTS.md 운용, /compact 수동 호출 시점,
    세션 쪼개기 기준, 서브에이전트로 읽기 오프로딩 등)
4. 도구 (오픈소스 포함) · 컨텍스트를 재우거나 요약하거나 외부화하는 것
5. «하면 안 되는 것» · 자주 나오는 실패담
