# EX-40 B14 준비와 남은 조건

## 현재 본기동은 준비 완료가 아니다

`foothold_s2/curriculum/ex40.yaml:14`는 `runtime_adapter_status: implementation_in_progress`다. `ex40_dr.py:192~201`의 실제 `require_launchable()`를 CPU에서 호출하면 `EX-40 DR runtime adapter is not verified; refusing launch`로 거절한다. 원출력은 `B14-CPU-READINESS.json`이다. 이는 이번 DR 물리시험 실패가 아니라, 본기동을 여는 검증 상태 표식이 아직 바뀌지 않았다는 뜻이다.

현재 B12/B13은 승인된 `f1fff17f` 그대로다. 실행 중인 사본이나 표식을 수정하지 않았다. B13 결과까지 받은 뒤 lead가 최종 표식 반영·고정 HEAD와 본기동을 판단해야 한다. 바뀌는 표식·설정 해시와 기존 Kit 증거의 대응도 남겨야 하며, 지금 파일이 본기동 승인을 대신하지 않는다.

## 시간은 짧은 시험에서 외삽한 추정

실측 B12 18갱신은 평균27.374444초, 중앙27.375초, 최소25.69초, 최대29.46초다. 학습 순환 합492.74초이며 Kit 기동과 마지막 저장·종료를 포함한 총시간과 다르다. 18갱신은 긴 학습의 처리량 확정값이 아니다. GPU1 평가와 병행할 때의 속도, 단계가 오래 유지될 때의 속도, 장기 메모리 변화는 미측정이다.

## 승인 뒤 사용할 명령 형태

`run_ex40_b11.sh`는 arm B, cuda:0, 새 로그 폴더, scratch,3072env,seed42,8001갱신,50회 저장,31개 그림자 평가를 소비한다. 점수기는 cuda:1이다. B12의 m17에서 이어받는 명령이 아니다. 본기동 고정본과 표식 문제를 먼저 해결한 뒤 아래 형태를 사용한다.

```powershell
# 준비 예시이며 이 문서 작성 중 실행하지 않았다.
# cwd는 lead가 확정한 최종 고정본. source HEAD·clean·설정 SHA 먼저 대조.
$ex40Start = Get-Date
$ex40Expected = $ex40Start.AddHours(67) # 짧은 실측 최대속도 외삽에 기동 여유를 더한 잠정값
$ex40EndBy = $ex40Expected.AddHours(24)
$env:EX40_EXPECTED_FINISH = $ex40Expected.ToString('o')
$env:LIVE = '0'
$ex40Root = 'C:/Users/AI-WS01/s2_lab/ex40_main_' + $ex40Start.ToString('yyyyMMdd_HHmmss')
& 'C:/Program Files/Git/bin/bash.exe' foothold_s2/run_ex40_b11.sh B cuda:0 $ex40EndBy.ToString('o') $ex40Root ($ex40Root + '/scores') main
# DRY PASS와 실제 기동 승인을 받은 뒤만 LIVE=1. 이 파일은 기동하지 않는다.
```

예시 마감은 시작 뒤91시간이다. 코드의 `max-wall-s=345600`은96시간이므로 이 예시의 예상 완료+24시간보다 길다. 예상 시간이 달라지면 절대마감과 max-wall-s 두 상한을 함께 대조한다. 현재의 B13 1회는 평가 전체 경로의 기능·시간 측정이며, 본학습 성능 또는 장기 재개·외부 보고의 성공을 보장하지 않는다.
