| 대비 | 무엇이 다른가 | 하락 | 상승 |

| `v1` -> `rails30` | 학습량 + 지형 | 0 | 4 |

**학습량만 늘렸을 때** (`v1` -> `control`)

```

하락  floating_ring 0.5   95 ->  70      [60.4, 78.1]
상승  gap 1.5             70 -> 100      [96.3, 100.0]
```

**같은 자리에 지형만 더했을 때** (`control` -> `rails30` · **깨끗한 단일 변수**)

```
상승  rails 0.5           73 -> 100      여유 +15.6 %p
상승  rails 1.0           55 -> 100      여유 +31.9 %p
상승  rails 1.5            1 -> 100      여유 +90.9 %p
상승  floating_ring 0.5   70 ->  97      여유 +13.4 %p
하락  gap 0.5             99 ->  90      여유  +0.07 %p   <- 아래 참조
```

> **`rails` 1.5 가 학습량만으로는 24 -> 1 로 무너지고, 지형을 넣으면
> 1 -> 100 이다.** 같은 표 · 같은 iter · 지형만 다르다. **판정 자 문제와
> 표 사이 실행 차이는 안 걸린다** · 한 표 안이기 때문이다.
>
> **다만 «실행 분산» 을 배제한 것은 아니다** `미확인`. 두 열 다 **한 번씩
> 돌린 것**이고, 같은 설정을 두 번 돌리면 얼마나 흔들리는지는 **아무도 안
> 쟀다.** 1 -> 100 처럼 큰 칸이 분산으로 뒤집힐 것 같지는 않지만 **그것도
> 내 짐작이다.**

**단 하나의 「대가」는 한 판 차이로 뒤집힌다** `확인됨`. `gap` 0.5 의
99 -> 90 은 구간이 **0.07 %p** 로 갈린다. `rails30` 이 90 이 아니라 **91
이었으면 겹친다.** 상승 네 칸이 13 ~ 91 %p 여유인 것과 **자릿수가 다르다.**
**「지형을 넣은 대가로 `gap` 0.5 를 잃는다」를 이 한 칸으로 말하지 않는다.**

|---|---|---|
| `rails10_3000` | **우리** | 100 / 100 / 100 |
| `rails30_3000` | 석헌 | 100 / 100 / 100 |

**이것을 재현성의 근거로 쓰지 않는다** `미확인`. **둘은 서로 «다른 모델»
이다** (`rails` 비율 0.10 대 0.30). 다른 모델 둘이 같은 값을 냈다는 것으로
실행 분산을 말할 수 없고, **100 / 100 이라고 다음 실행이 안 흔들린다는
뜻도 아니다.**

적어 두는 까닭은 **반대쪽 유혹을 막으려는 것**이다 · 「여기서는 두 쪽이
맞더라」를 보고 **재현성이 괜찮다고 읽으면 안 된다.** 같은 v1 이 두 실행에서
`rails` 70 / 48 / 21 대 55 / 57 / 24 로 갈렸다는 사실은 **그대로 남아
있다.**

### 덧 · 방향 판정이 숫자를 크게 움직인다 `확인됨`

위 차이를 설명해 보려고 v1 의 **같은 에피소드**를 복원본 규칙으로 다시
채점해 봤다 (새로 돌린 것 아니다).

```
우리 자로 성공인데 복원본 자로 실패한 판   199
  끝점 이탈«만» 어긴 판                    198
  전진 문턱(4.2 m)«만» 어긴 판               0
  둘 다 어긴 판                              1
```

**전진 문턱을 «단독으로» 어긴 판은 0 이다** (둘 다 어긴 한 판은 전진
4.1955 m · 끝점 이탈 1.796 m 다). 사실상 전부 **방향 판정**이다 · 통과선에서
재느냐 끝점에서 재느냐만으로 `rails` 가 70 / 48 / 21 에서 33 / 14 / 5 가
된다. (엄격함의 일방 관계는 아니다 · 통과선에서 벌어졌다가 끝점에서
돌아오면 반대로 뒤집힌다.)

**다만 이것으로 석헌 재평가도 설명되지 않는다** · 55 / 57 / 24 는 두 채점
어느 쪽과도 안 맞는다. **원인은 여전히 미상이다.**
