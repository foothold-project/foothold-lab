## 2. **안 배운 것을 한다** · 이 판의 놀라운 점 `확인됨`

**「배운 적 없다」와 「못 한다」가 다르다는 것을 이 판이 보여 준다.**
명령을 준 적이 없는데도 **명령이 0 이면 가만히 서 있고, 왼쪽으로 크게 돌라고

**단, 회전은 한쪽뿐이다.** `-1.00` 은 0.508 인데 `+0.50` 은 0.052 ·
`+1.00` 은 0.000 이다. **오른쪽으로는 거의 안 돈다.** 왜 한쪽만인지는
`미확인`.

## 3. v1 과 견주기 · **갈리는 것은 `turn` 하나다** `확인됨`

명령 여섯 칸이 v1 과 같으므로 v1 이 가장 가까운 비교 대상이다. **낙상은
비율이므로 Wilson 으로 견준다.**

| | v1 | 석헌 | 판정 |
|---|---|---|---|
| `stop` 낙상 | 13 / 64 [12.3, 31.7] | 26 / 64 [29.5, 52.9] | **겹침** |
| `hold` 낙상 | 5 / 64 [3.4, 17.0] | 0 / 64 [0.0, 5.7] | **겹침** |
| `turn` 낙상 | 64 / 64 [94.3, 100] | 21 / 64 [22.6, 45.0] | **안 겹침** |

> **「석헌 모델이 `stop` 에서 더 나쁘다」고 말하지 않는다.** 0.203 대 0.406
> 이지만 **구간이 겹친다.** 겹침은 판단 보류다.
>
> **「`hold` 낙상이 좋아졌다」도 낙상만으로는 못 말한다.** 5 / 64 와 0 / 64 는
> 겹친다.
>
> **갈리는 것은 `turn` 뿐이다** · v1 은 64 판 전부 넘어지는데 석헌 모델은
> 21 판이다.

**`hold` 의 «연속» 지표는 다르다.** 잔류속도 0.0240 -> 0.0011 (21 배) ·
목표각 변화 0.1258 -> 0.0017 (74 배) 다. **이것은 비율이 아니라 Wilson 을
안 쓰지만 차이가 크다.** 두 지표 모두 문턱을 넘느냐 못 넘느냐가 갈린다
(v1 미달 · 석헌 통과).

## 5. 왜 v1 과 갈렸나 · **못 가른다** `미확인`

석헌 모델은 v1 과 **두 가지**가 다르다.

| | v1 | 석헌 |
|---|---|---|
| 학습 지형 | rough6 + `forward_gap` (7 종) | **+ `rails` 0.10** · 나머지 비율 재분배 (8 종) |
| iter | 1500 | **2950** (1450 더) |

**명령 여섯 칸은 같다.** 그러므로 축 2 의 차이는 **지형이거나 학습량이거나
둘의 조합**인데 **이 자료로는 못 가른다.**

가르려면 판이 하나 더 필요하다 · **v1 설정 그대로 2950 iter** 이거나
**석헌 지형에 1500 iter** 다. **지금 돌릴 것을 권하지 않는다** · 우리
후보 계보(`I` · `I'`)가 먼저다.

## 6. 반드시 같이 읽을 것 · **「못 한다」가 아니다**

> **이 모델은 `stop` · `hold` · `turn` 을 학습에서 한 번도 안 받았다.**
> `rel_standing_envs` 0.0 · `ang_vel_z` (0, 0) 이다.
>
> **낮은 숫자는 모델의 결함이 아니라 학습 설정의 결과다.** v1 도 같은
> 자리에 있었고, D 이후 우리 판들이 `rel_standing_envs` 를 0.02 로 열고
> `ang_vel_z` 를 (-1, 1) 로 연 것이 정확히 그 이유다.
>
> **거꾸로 통과한 네 칸은 「안 가르쳤는데 된다」는 뜻이라 더 눈여겨볼
> 자리다.**
