## 1. 이 판이 무엇이었나 · **어느 쪽에서 봐도 단일 변수** `확인됨`

H 는 **F 에서 `lin_vel_x` 하한 하나만** (0.4, 1.5) -> (0.0, 1.5) 로 되돌린
판이다. 지형 설정은 글자 하나도 안 바꿨다.

**주장이 아니라 쟀다.** 각 판이 **실제로 저장한** `params/env.yaml` 세 개를
통째로 평탄화해 견줬다. 「지어 보니 이렇더라」가 아니라 **그때 그 학습이 쓴
값**이다.

```
H 대 F   env.yaml 전체에서 다른 칸 2 개
           commands.base_velocity.ranges.lin_vel_x   H [0.0,1.5]  F [0.4,1.5]
           log_dir                                    (출력 경로 · 손잡이 아님)

H 대 D   다른 칸 22 개 · 전부 지형 교체 하나
           forward_gap.* 열 칸이 H 에 없고 omni_gap.* 열한 칸이 D 에 없음
           그리고 log_dir

관측     92 칸 중 다른 것 0 개  (H 대 F · H 대 D 둘 다)
```

보상 · 이벤트 · 커리큘럼 · 종료 · 관측까지 포함해 **`log_dir` 말고는 설계가
말한 그 한 칸뿐**이다. 결과는 `h_cfg_diff.json` 에 있다.

> **이 방법을 다음 판에도 쓴다.** 설정을 다시 지어 견주는 것보다 낫다.
> 지어 견주면 「지금 지으면 이렇게 된다」를 보고, 저장된 것을 견주면
> **「그 학습이 실제로 쓴 값」**을 본다.

### 2 x 2 의 어느 칸인가

| | +x 띠 (`forward_gap`) | 고리 (`omni_gap` ring) |
|---|---|---|
| **하한 0.0** | **D** | **H** |
| **하한 0.4** | G · E | **F** |

**왼쪽 아래에 F 의 명령을 그대로 쓴 판이 없다** `미확인`. G 는
`heading_command=False` 이고 E 는 `heading` 범위가 (-0.5, 0.5) ·
`rel_heading_envs` 0.75 다. **둘 다 heading 블록이 F 와 다르다.**

> **그래서 깨끗한 단일 변수 대비는 둘뿐이다** · **H 대 F**(하한만) 와
> **D 대 H**(지형만). G 나 E 가 들어가는 대비는 heading 블록이 섞인다.

## 4. **2 x 2 가 채워졌다** · 이 판의 값 `확인됨`

낙상 판 수 / env 64. 축 1 은 진짜 하락 칸 수.

| | +x 띠 | 고리 | | +x 띠 | 고리 |
|---|---|---|---|---|---|
| | **하한 0.0** | **하한 0.0** | | **하한 0.4** | **하한 0.4** |
| `stop` | D 0 | H 0 | | G 7 | **F 10** |
| `hold` | D 0 | H 0 | | G 0 | **F 24** |
| `turn` | D 2 | **H 22** | | G 8 | **F 26** |
| 축 1 하락 | D 4 | H 5 | | G 7 | **F 1** |

네 대비를 전부 Wilson 으로 돌린 것.

| 항목 | H 대 F (고리에서 하한) | D 대 G (띠에서 하한) | D 대 H (하한 0 에서 지형) | G 대 F (하한 .4 에서 지형) | 읽는 법 |
|---|---|---|---|---|---|
| `hold` | **안 겹침** 0 대 24 | 겹침 0 대 0 | 겹침 0 대 0 | **안 겹침** 0 대 24 | **둘 다 있어야 무너진다** |
| `stop` | **안 겹침** 0 대 10 | 겹침 0 대 7 | 겹침 0 대 0 | 겹침 7 대 10 | 하한 방향 · **고리에서만** 갈린다 |
| `turn` | 겹침 22 대 26 | 겹침 2 대 8 | **안 겹침** 2 대 22 | **안 겹침** 8 대 26 | **지형 단독** |
| 저속 0.10 낙상 | **안 겹침** 1 대 14 | 겹침 0 대 4 | 겹침 0 대 1 | 겹침 4 대 14 | 하한 방향 · **고리에서만** |

> **셋이 서로 다른 이야기를 한다.**
>
> - **`hold`** · **순수 상호작용.** 고리 지형과 하한 0.4 가 **같이** 있을
>   때만 무너진다. 어느 하나만으로는 0 / 64 다
> - **`stop` 과 저속 0.10** · 하한 방향이지만 **고리 위에서만** 갈린다.
>   띠에서는 이 표본으로 못 가른다
> - **`turn`** · **지형 단독.** 하한을 내려도 안 돌아온다 (H 22 / 64)

**축 1 도 상호작용이다.** 고리의 축 1 이득은 **하한 0.4 가 있어야** 나온다.
F 1 칸이 H 에서 5 칸이 됐고, 하한 0.0 에서는 지형이 거의 무의미하다
(D 4 · H 5).

### 칸 수준으로 본 두 깨끗한 대비

| | H 대 F (하한만 · 둘 다 고리) | | D 대 H (지형만 · 둘 다 하한 0.0) |
|---|---|---|---|
| `gap` 0.5 | 98 -> 35 **낮음** | `gap` 0.5 | 9 -> 35 **높음** |
| `gap` 1.5 | 99 -> 87 **낮음** | `gap` 1.5 | 19 -> 87 **높음** |
| `rails` 0.5 | 64 -> 38 **낮음** | `rails` 0.5 | 86 -> 38 **낮음** |
| `rails` 1.0 | 75 -> 54 **낮음** | `rails` 1.0 | 89 -> 54 **낮음** |
| `rails` 1.5 | 60 -> 6 **낮음** | `rails` 1.5 | 80 -> 6 **낮음** |
| `floating_ring` 1.0 | 54 -> 88 **높음** | `floating_ring` 1.0 | 96 -> 88 겹침 |

**`rails` 는 하한과 지형이 «서로 반대로» 얽힌다.** 하한 0.0 에서 고리는
rails 를 **깎고**(D 86 / 89 / 80 -> H 38 / 54 / 6), 하한 0.4 에서는
**올린다**(F 64 / 75 / 60). **지형 단독으로도 하한 단독으로도 설명이 안 된다.**

**H 가 F 의 «유일한» 축 1 하락을 고쳤다** (`floating_ring` 1.0 · 54 -> 88 ·
안 겹침). 고치면서 새로 다섯 개를 만들었다.

### 네 칸 어디에도 답이 없다

| | 축 1 진짜 하락 | 축 2 통과 / 9 |
|---|---:|---:|
| **D** (띠 · 0.0) | 4 | **8** |
| G (띠 · 0.4) | 7 | 5 |
| **H** (고리 · 0.0) | 5 | 6 |
| **F** (고리 · 0.4) | **1** | 3 |

> **대각선 교환이다.** 축 1 이 가장 좋은 칸(F)이 축 2 가 가장 나쁘고,
> 축 2 가 가장 좋은 칸(D)이 축 1 에서 두 번째로 나쁘다.
> **이 2 x 2 안에는 두 축을 같이 넘는 자리가 없다.**

## 6. 예측 대조 · **틀린 것을 그대로 남긴다**

설계 3 절이 돌리기 전에 적은 표다. **판정 전에 고치지 않았다.**

| 항목 | 예측 | 실제 | |
|---|---|---|---|
| **축 1 진짜 하락** | **1 칸** (F 수준) | **5 칸** | **틀림** |
| **축 2 통과** | **8 / 9** (D 수준) | **6 / 9** | **틀림** |
| `rails` | F 수준 (64 / 75 / 60) | **38 / 54 / 6** | **틀림** |
| `gap` | F 수준 (98 / 100 / 99) | **35 / 99 / 87** | **틀림** (0.5 가 무너짐) |
| `floating_ring` 1.0 | **미지** | 88 · 진짜 하락이나 **F 보다 높다** | 미지라 적은 것이 맞았다 |
| 저속 **추종** | D 수준으로 내려감 (0.40 에서 0.93 근방) | **1.022** · F · G 수준 | **틀림** |

설계 3-1 절의 네 갈래 중 **「둘 다 틀림」**이다. 그 칸은 「2 x 2 로 설명이
안 된다」고 적었는데 **절반만 맞다** · `hold` · `stop` · `turn` · 축 1 은
2 x 2 로 잘 설명된다. 설명이 안 되는 것은 **`wz -1.00` 하나**다.

**가장 크게 빗나간 것은 축 1 이다.** 「지형이 F 와 같으니 축 1 도 F 수준」
이라고 적었는데 **지형이 같아도 하한이 다르면 축 1 이 달라진다.** 예측이
지형과 하한을 **독립**으로 다뤘고 그것이 틀렸다.
